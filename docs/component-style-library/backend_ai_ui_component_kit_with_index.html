验收清单

用于判断 AI 生成结果是否符合组件样式库。

Checklist
  • 是否补齐完整组件目录索引。
  • 是否补齐 Token 分类索引。
  • 是否明确组件与 Ant Design 的映射关系。
  • 是否明确控件高度 24 / 32 / 40。
  • 是否明确表格密度 48 / 40。
  • 是否明确默认、悬浮、聚焦、激活、禁用、错误状态。
  • 是否统一 iconfont 图标库。
  • 是否避免 .ant-* 直接污染全局，必要时增加 .backend-kit 命名空间。
