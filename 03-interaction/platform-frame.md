# 平台固定底层框架规范
## Locked Platform Frame Rules

Keywords: platform frame, locked shell, top navigation, sidebar, cascade menu, return header, icon rules, html demo

本文定义所有后台页面必须使用的固定底层框架。AI 生成任何后台页面、HTML 可演示页面、Vue 页面代码、高保真原型或页面截图时，必须先使用本文框架，再把业务内容放入页面内容区。

> 这是硬约束，不是参考样式。

## 1. 固定原则

所有后台页面由以下固定结构组成：

```text
平台固定框架
├── 顶部通用导航 TopNavigation
├── 页面主体 PlatformBody
│   ├── 页面内左侧菜单 Sidebar
│   └── 页面右侧区域 MainPanel
│       ├── 可返回页头 ReturnHeader
│       └── 页面内容区 PageContent
```

### 1.1 不允许变化的区域

| 区域 | 是否允许变化 | 规则 |
|---|---|---|
| 顶部通用导航 | 不允许变化 | 结构、尺寸、颜色、交互、右侧状态区固定 |
| 页面内左侧菜单 | 不允许变化 | 展开 / 收起、级联浮层、菜单状态、底部按钮固定 |
| 可返回页头 | 不允许变化 | 只包含返回按钮和标题，不允许加面包屑或右侧操作 |
| 页面内容区 | 允许变化 | 仅这里允许替换业务页面内容 |
| Logo 占位 | 允许替换 | 后续项目接入时可替换为真实 Logo，尺寸和位置不变 |
| 业务文案 / 菜单数据 | 允许替换 | 只能替换文案、路由、业务字段，不改变结构样式 |

AI 生成页面时，业务内容只能放入 `.platform-page-content`，不得改动顶部导航、左侧菜单、页头的结构、尺寸和交互。

## 4. 固定 icon 规则

### 4.1 icon 来源

框架内 icon 必须优先使用仓库或页面包内 `asset/icons/` 目录下的 SVG，不允许临时用字符、emoji、CSS 自造图标替代。

| 场景 | 引用方式 | 说明 |
|---|---|---|
| Logo 占位 | `./asset/icons/svg_21e691e3.svg` | 可替换为真实 Logo，但尺寸和容器不变 |
| 左侧菜单业务 icon | `./asset/icons/svg_1f7be3ff.svg` | 示例业务 icon，可按业务替换为同规范 icon |
| 左侧底部整体展开 / 收起 | `./asset/icons/svg_c7bf2c0f.svg` | 必须使用源文件 icon，不允许 CSS 自造 |
| 可返回页头返回 icon | `./asset/icons/svg_9875e337.svg` | 只用于返回按钮 |
| 顶部右侧功能 icon | 使用顶部导航源文件 SVG | 不允许用字符替代 |
| 顶部用户下拉 icon | 使用顶部导航源文件 SVG | 不允许用字符替代 |
| 菜单标题展开 / 收起上下箭头 | 使用规范 SVG icon | 不允许 CSS 自造三角 |

### 4.2 icon 状态色

| 状态 | icon 色 | 规则 |
|---|---|---|
| 默认 | gray-7 #8A9099 | 左侧菜单 icon 默认灰色 |
| hover | p7 #039972 | icon 与文字同步变绿 |
| active | p7 #039972 | icon 与文字同步变绿 |
| disabled | gray-6 #AEB2B8 | 禁用 icon 与禁用文字同步 |

icon 和文字的状态必须同步，不允许 icon 一直绿色，也不允许选中时文字变色但 icon 不变。

## 5. 顶部通用导航 TopNavigation

### 5.1 固定结构

```text
顶部通用导航 56px
├── Logo 占位区
├── 一级导航区
└── 右侧状态与功能区
    ├── 系统状态文案
    ├── 运行天数
    ├── 功能 icon
    ├── 通知 icon
    └── 用户信息 / 下拉
```

### 5.2 固定样式

| 项目 | 固定值 |
|---|---|
| 高度 | 56px |
| 背景 | #242933 |
| Logo 区 padding | 14px 22.75px |
| Logo 占位尺寸 | 250.33 × 24px |
| 一级导航高度 | 56px |
| 一级导航左右 padding | 16px |
| 一级默认文字 | #D3D4D6 |
| 一级 hover 文字 | #FFFFFF |
| 一级选中文字 | #FFFFFF |
| 一级选中下划线 | 4px #00AB7A |
| 右侧功能 icon 热区 | 28 × 28px |
| 右侧功能 hover 背景 | rgba(255,255,255,.08) |

### 5.3 顶部导航交互

- 一级导航支持 default / hover / active。
- 有子级的一级导航点击后出现下拉菜单。
- 顶部下拉浮层使用 `position: fixed` 和 `z-index: 9999`，不得被页面内容遮挡。
- 顶部右侧功能 icon 支持点击浮层。
- 用户信息支持点击浮层。
- 顶部导航不得承载业务表单、搜索区、表格操作或页面级按钮。

## 6. 页面内左侧菜单 Sidebar

### 6.1 固定结构

```text
左侧菜单
├── 菜单滚动区
│   ├── 一级菜单
│   │   ├── 二级菜单
│   │   │   └── 三级菜单
│   └── ...
└── 底部展开 / 收起按钮 + 版本号
```

### 6.2 展开态样式

| 项目 | 固定值 |
|---|---|
| 宽度 | 216px |
| 背景 | #FFFFFF |
| 菜单项高度 | 40px |
| 菜单外层左右 padding | 8px |
| 菜单项宽度 | 200px |
| 菜单项圆角 | 4px |
| 一级 padding | 9px 12px |
| 二级 padding-left | 38px |
| 三级 padding-left | 56px |
| 默认文字 | #242933 |
| hover 文字 | #039972 |
| hover 背景 | 透明，或收起态 icon 热区使用 #F2F3F5 |
| active 背景 | #D9F4EE |
| active 文字 | #039972 |
| disabled 文字 | #AEB2B8 |
| 底部版本文字 | #8A9099 |

### 6.3 展开态交互

- 一级菜单有子级时，右侧显示上下箭头 icon。
- 二级菜单有三级时，右侧也必须显示上下箭头 icon。
- 展开 / 收起箭头必须使用 SVG icon，不允许 CSS 自造三角。
- 展开状态为向上，收起状态为向下。
- 点击带子级的菜单标题可展开 / 收起下级。
- 点击最终叶子菜单时切换选中态，并同步页面标题。
- 禁用菜单不可点击，不响应 hover 变绿。

## 7. 左侧菜单收起态

### 7.1 收起态样式

| 项目 | 固定值 |
|---|---|
| 收起宽度 | 56px |
| 菜单项热区 | 40 × 40px |
| 菜单外层左右 padding | 8px |
| 菜单文字 | 隐藏 |
| 二级 / 三级展开区 | 隐藏 |
| 展开 / 收起小箭头 | 隐藏 |
| 横向滚动条 | 禁止出现，`overflow-x: hidden` |
| 底部版本号 | 隐藏 |
| 底部收起按钮 | 保留 |

### 7.2 收起态 hover 规则

- 收起态 hover 一级 icon 时，icon 热区背景使用 #F2F3F5。
- hover 一级 icon 后，在右侧显示级联菜单浮层。
- 浮层必须使用 `position: fixed` 和 `z-index: 9999`，不得被内容区遮挡。
- 浮层默认背景为 #FFFFFF。
- 浮层项高度为 36px。
- 浮层项默认文字 #242933。
- 浮层项 hover：背景 #F2F3F5，文字 #039972。
- 浮层项 active：背景 #D9F4EE，文字 #039972。

### 7.3 收起态多级菜单级联规则

收起态多级菜单必须逐层展开：

```text
hover 一级 icon
→ 展示第一层浮层（二级菜单）
hover 有子级的二级菜单
→ 向右展示第二层浮层（三级菜单）
```

禁止把二级、三级一次性全部堆在同一个浮层里。

收起态级联浮层中：

- 有子级的菜单项不额外显示 icon。
- 菜单项是否有子级通过 hover 后展开下一层表达。
- 点击最终叶子菜单后，必须同步切换选中态和页面标题。
- 展开态菜单和收起态浮层必须来自同一份菜单数据，不允许内容不一致。

| 背景 | #FFFFFF |
| padding | 15px 24px |

## 10. 页面内容区 PageContent

页面内容区是唯一允许替换业务内容的区域。

| 项目 | 固定值 |
|---|---|
| 背景 | #F2F3F5 |
| padding | 16px |
| overflow | auto |

允许放入：

```text
列表页搜索区和表格
表单页字段和步骤
详情页信息分组
工作台指标卡片
配置页配置项
异常状态说明
```

禁止：

- 业务内容侵入顶部导航。
- 业务内容侵入左侧菜单。
- 业务内容改写可返回页头。
- 业务内容直接贴边，不经过内容区 padding。

## 11. 数据驱动要求

左侧菜单必须由同一份菜单数据驱动展开态和收起态浮层。

推荐数据结构：

```ts
interface MenuItem {
  id: string
  label: string
  icon?: string
  disabled?: boolean
  active?: boolean
  expanded?: boolean
  children?: MenuItem[]
}
```

要求：

- 展开态菜单来自 `MenuItem[]`。
- 收起态级联浮层也来自同一份 `MenuItem[]`。
- 顶部导航来自独立的 `TopNavItem[]`。
- 点击叶子菜单时更新 `activeMenu` 和页面标题。
- 有子级的菜单点击时展开 / 收起，不直接切换页面。

## 12. HTML 可演示页面生成要求

生成任何 HTML demo 时必须：

- 使用本文固定框架。
- 保留顶部通用导航。
- 保留左侧菜单展开 / 收起交互。
- 保留收起态级联浮层。
- 保留可返回页头。
- 业务内容只写入 `.platform-page-content`。
- 使用真实 `asset/icons/*.svg` 引用，不使用字符图标。
- 不新增游离色值。
- 不简化交互状态。

## 13. Vue / 工程代码生成要求

正式工程建议抽象为：

```text
PlatformLayout
├── TopNavigation
├── Sidebar
├── ReturnHeader
└── PageContent slot
```

业务页面只能通过 `PageContent slot` 注入内容。

组件职责：

| 组件 | 职责 |
|---|---|
| TopNavigation | 顶部导航、顶部下拉、右侧功能浮层 |
| Sidebar | 展开态菜单、收起态级联菜单、底部收起按钮 |
| ReturnHeader | 返回按钮和标题 |
| PageContent | 业务内容 |

## 14. AI 生成禁止项

- 禁止重新设计顶部导航。
- 禁止重新设计左侧菜单。
- 禁止省略左侧菜单收起态。
- 禁止省略收起态 hover 级联浮层。
- 禁止把多级菜单一次性堆到一个浮层。
- 禁止使用 CSS 自造菜单箭头。
- 禁止用 emoji、字符图标替代 SVG icon。
- 禁止新增不在规范内的颜色。
- 禁止业务内容改动固定框架。
- 禁止只生成业务表格 / 表单而缺少平台框架。

## 15. 可替换项清单

AI 后续生成页面时，仅允许替换：

```text
Logo 占位图片
顶部一级导航文案和路由
左侧菜单业务文案和路由
页面标题文案
页面内容区业务内容
mock 数据
```

不允许替换：

```text
顶部导航高度、颜色、布局
左侧菜单宽度、颜色、状态、收起交互
级联浮层交互
可返回页头结构
框架 icon 状态规则
页面内容区 padding 和背景
```
