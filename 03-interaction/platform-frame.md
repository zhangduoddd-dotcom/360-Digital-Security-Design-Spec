# 平台固定底层框架规范
## Locked Platform Frame Rules

Keywords: platform frame, locked shell, top navigation, sidebar, cascade menu, page header, icon rules, html demo, template first

本文用于解释后台平台固定框架的设计原则、布局意图和交互边界。

**重要：平台固定框架不是视觉参考稿，也不是重新实现框架的文字蓝图。生成 HTML Demo / Vue 页面时，必须继承 `06-vue-code/templates/` 下的对应 HTML 母版，不得根据本文描述重新实现同名框架结构。**

具体 DOM、CSS、JS、iconfont、hover、active、open、disabled、collapsed、响应式规则，以 HTML 母版为准。

默认母版：

```text
06-vue-code/templates/common-single-nav.html
```

明确双层导航时调用：

```text
06-vue-code/templates/double-nav-frame.html
```

模板选择、可变 / 不可变范围详见：

```text
06-vue-code/templates/README.md
```

> 本文件只负责说明框架原则和校验边界，不允许被用来手写替代平台框架。

## 1. 固定原则

所有后台页面必须先继承固定 HTML 母版，再替换业务内容。

```text
HTML 母版
├── 顶部导航 TopNavigation
├── 页面主体 Body
│   ├── 页面内左侧菜单 Sidebar
│   └── 页面右侧区域 MainPanel
│       ├── 页头 Header
│       └── 页面内容区 PageContent
```

### 1.1 不允许变化的区域

| 区域 | 是否允许变化 | 规则 |
|---|---|---|
| 顶部导航 | 不允许变化 | 结构、尺寸、颜色、交互、右侧状态区固定；以 HTML 母版为准 |
| 页面内左侧菜单 | 不允许变化 | 展开 / 收起、级联浮层、菜单状态、底部按钮固定；以 HTML 母版为准 |
| 页头区 | 不允许变化 | 高度、结构、层级和与内容区的上下关系固定；以 HTML 母版为准 |
| 页面内容区 | 允许变化 | 仅这里允许替换业务页面内容 |
| Logo 占位 | 允许替换 | 后续项目接入时可替换为真实 Logo，尺寸和位置不变 |
| 业务文案 / 菜单数据 | 允许替换 | 只能替换文案、路由、业务字段，不改变结构样式和交互逻辑 |

AI 生成页面时，业务内容只能放入母版指定的业务内容区，不得改动顶部导航、左侧菜单、页头的结构、尺寸和交互。

## 4. 固定 icon 规则

### 4.1 icon 来源

框架内 icon 必须优先使用 `02-components/icon.md` 中指定的 iconfont Font Class。

禁止：

```text
CSS 自绘 icon
emoji 替代 icon
字符替代 icon
临时拼接 icon
同一语义跨页面使用不同 icon
```

无明确语义或没有合适匹配图标时，统一使用规范占位 icon：

```text
icon-APTzuzhiguanli1
```

### 4.2 icon 状态色

| 状态 | icon 色 | 规则 |
|---|---|---|
| 默认 | gray-7 #8A9099 | 左侧菜单 icon 默认灰色 |
| hover | p7 #039972 | icon 与文字同步变绿 |
| active | p7 #039972 | icon 与文字同步变绿 |
| disabled | gray-6 #AEB2B8 | 禁用 icon 与禁用文字同步 |

icon 和文字的状态必须同步，不允许 icon 一直绿色，也不允许选中时文字变色但 icon 不变。

## 5. 顶部导航 TopNavigation

顶部导航结构、尺寸、颜色和交互以所调用 HTML 母版为准，不得根据本文重新实现。

### 5.1 固定结构

```text
顶部导航
├── Logo 区
├── 导航区
└── 右侧状态与功能区
```

### 5.2 顶部导航交互

- 顶部导航支持 default / hover / active / open 状态。
- 有子级的导航通过母版内置下拉逻辑展开。
- 顶部下拉浮层不得被页面内容遮挡。
- 顶部右侧功能支持母版内置浮层或下拉。
- 顶部导航不得承载业务表单、搜索区、表格操作或页面级按钮。

## 6. 页面内左侧菜单 Sidebar

左侧菜单结构、宽度、收起态、级联浮层和交互以所调用 HTML 母版为准，不得根据本文重新实现。

### 6.1 固定结构

```text
左侧菜单
├── 菜单滚动区
│   ├── 一级菜单
│   │   ├── 二级菜单
│   │   │   └── 三级菜单
│   └── ...
└── 底部展开 / 收起按钮 + 版本号
```

### 6.2 展开态交互

- 一级菜单有子级时，右侧显示上下箭头 icon。
- 二级菜单有三级时，右侧也必须显示上下箭头 icon。
- 展开 / 收起箭头必须使用 iconfont，不允许 CSS 自造三角。
- 展开状态为向上，收起状态为向下。
- 点击带子级的菜单标题可展开 / 收起下级。
- 点击最终叶子菜单时切换选中态，并同步页面标题。
- 禁用菜单不可点击，不响应 hover 变绿。

## 7. 左侧菜单收起态

### 7.1 收起态样式

| 项目 | 规则 |
|---|---|
| 收起宽度 | 以 HTML 母版为准 |
| 菜单项热区 | 以 HTML 母版为准 |
| 菜单文字 | 隐藏 |
| 二级 / 三级展开区 | 隐藏 |
| 展开 / 收起小箭头 | 隐藏 |
| 横向滚动条 | 禁止出现 |
| 底部版本号 | 隐藏 |
| 底部收起按钮 | 保留 |

### 7.2 收起态 hover 规则

- 收起态 hover 一级 icon 时，icon 热区显示中性 hover 背景。
- hover 一级 icon 后，在右侧显示级联菜单浮层。
- 浮层不得被内容区遮挡。
- 浮层项 hover：只显示中性背景，文字不变色。
- 浮层项 active：背景和文字使用品牌色规则。

### 7.3 收起态多级菜单级联规则

收起态多级菜单必须逐层展开：

```text
hover 一级 icon
→ 展示第一层浮层（二级菜单）
hover 有子级的二级菜单
→ 向右展示第二层浮层（三级菜单）
```

禁止把二级、三级一次性全部堆在同一个浮层里。

收起态级联浮层中：

- 有子级的菜单项不额外显示 icon。
- 菜单项是否有子级通过 hover 后展开下一层表达。
- 点击最终叶子菜单后，必须同步切换选中态和页面标题。
- 展开态菜单和收起态浮层必须来自同一份菜单数据，不允许内容不一致。

## 8. 页头 Header

页头结构以 HTML 母版为准。

要求：

```text
页头必须位于右侧内容区域顶部。
页头与页面内容区保持上下结构。
页头标题应与当前选中菜单或页面对象一致。
业务按钮是否出现，以母版和具体页面规范共同约束。
```

业务内容不得改写页头所在层级。

## 9. 页面内容区 PageContent

页面内容区是唯一允许替换业务内容的区域。

允许放入：

```text
列表页搜索区和表格
表单页字段和步骤
详情页信息分组
工作台指标卡片
配置页配置项
异常状态说明
```

禁止：

- 业务内容侵入顶部导航。
- 业务内容侵入左侧菜单。
- 业务内容改写页头层级。
- 业务内容直接贴边，不经过母版内容区 padding。

## 10. 数据驱动要求

左侧菜单必须由同一份菜单数据驱动展开态和收起态浮层。

推荐数据结构：

```ts
interface MenuItem {
  id: string
  label: string
  icon?: string
  disabled?: boolean
  active?: boolean
  expanded?: boolean
  children?: MenuItem[]
}
```

要求：

- 展开态菜单来自 `MenuItem[]`。
- 收起态级联浮层也来自同一份 `MenuItem[]`。
- 顶部导航来自独立的 `TopNavItem[]`。
- 点击叶子菜单时更新 `activeMenu` 和页面标题。
- 有子级的菜单点击时展开 / 收起，不直接切换页面。

## 11. HTML 可演示页面生成要求

生成任何 HTML demo 时必须：

- 先读取 `06-vue-code/templates/README.md`。
- 再读取并完整复制对应 HTML 母版。
- 默认使用 `06-vue-code/templates/common-single-nav.html`。
- 明确双层导航时使用 `06-vue-code/templates/double-nav-frame.html`。
- 保留母版顶部导航。
- 保留母版左侧菜单展开 / 收起交互。
- 保留母版收起态级联浮层。
- 保留母版页头。
- 业务内容只写入母版指定业务内容区。
- 使用规范 iconfont，不使用字符图标。
- 不新增游离色值。
- 不简化交互状态。

## 12. Vue / 工程代码生成要求

正式工程建议抽象为：

```text
PlatformLayout
├── TopNavigation
├── Sidebar
├── PageHeader
└── PageContent slot
```

业务页面只能通过 `PageContent slot` 注入内容。

组件职责：

| 组件 | 职责 |
|---|---|
| TopNavigation | 顶部导航、顶部下拉、右侧功能浮层 |
| Sidebar | 展开态菜单、收起态级联菜单、底部收起按钮 |
| PageHeader | 页面标题、返回或页签等母版内置页头结构 |
| PageContent | 业务内容 |

工程代码中的 layout / shell / navigation 组件必须与所调用 HTML 母版结构一致，不得重新设计。

## 13. AI 生成禁止项

- 禁止重新设计顶部导航。
- 禁止重新设计左侧菜单。
- 禁止省略左侧菜单收起态。
- 禁止省略收起态 hover 级联浮层。
- 禁止把多级菜单一次性堆到一个浮层。
- 禁止使用 CSS 自造菜单箭头。
- 禁止用 emoji、字符图标替代 iconfont。
- 禁止新增不在规范内的颜色。
- 禁止业务内容改动固定框架。
- 禁止只生成业务表格 / 表单而缺少平台框架。
- 禁止根据本文文字描述重新实现框架。

## 14. 可替换项清单

AI 后续生成页面时，仅允许替换：

```text
Logo 占位图片
顶部导航文案和路由
左侧菜单业务文案和路由
页面标题文案
页面内容区业务内容
mock 数据
业务字段
```

不允许替换：

```text
顶部导航高度、颜色、布局
左侧菜单宽度、颜色、状态、收起交互
级联浮层交互
页头结构和层级
框架 icon 状态规则
页面内容区 padding 和背景
母版 DOM / CSS / JS / 响应式规则
```
