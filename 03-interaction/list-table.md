# 列表表格区交互规范
## List Table Interaction Rules

Keywords: list table, toolbar, batch action, pagination, row action

本文定义列表页表格区，包括顶部操作栏、表头、数据行、状态标签、行操作、批量操作、排序筛选和分页。

## 1. 标准结构

```text
表格顶部操作栏
→ 表头
→ 数据行
→ 操作列
→ 分页区
```

## 2. 顶部操作栏

左侧放新建、导入等新增类操作；中间放批量删除、批量启用、批量导出等与勾选联动的操作；右侧放刷新、导出、字段配置、密度切换等工具操作。

新建按钮优先放在左侧并使用主按钮。批量操作默认禁用，勾选数据后启用。右侧工具类操作不使用主按钮。

## 3. 表格规则

- 表头文本不建议换行。
- 表头字段按业务重要程度从左到右排列。
- 主信息列通常放在第一列。
- 空值统一展示为 `-`。
- 长文本单行省略，hover 出现 Tooltip。
- 状态字段使用标签或状态点，不只用颜色。
- 行操作放在最右侧，常用操作直接展示 1 到 3 个，低频操作收进“更多”。

## 4. 分页规则

分页位于表格底部，应包含总数、每页条数、页码和跳页能力。表格数据为空时，展示空状态，通常不显示分页。

## 5. 代码生成要求

Vue 代码必须包含 `a-table`、columns、dataSource、rowKey、pagination、loading、empty、操作列和勾选逻辑。HTML 预览文件必须支持搜索结果刷新、分页切换、勾选、批量操作、行操作和删除确认。
