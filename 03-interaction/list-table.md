# 列表页表格区域交互规范
## List Page Table Interaction Rules

Keywords: list table, toolbar, batch action, pagination, row action, freeze, sorting, filtering, html demo

本文定义列表页表格区域的结构、操作栏、表头、内容区、操作列、分页、权限与反馈规则。AI 生成列表页 HTML Demo 或 HTML 预览文件时，必须遵循本文。

## 1. 整体原则

表格区是列表页的主工作区，应优先保证数据可扫读、操作可判断、状态可反馈。视觉上保持轻量、克制、规整，不做营销卡片式装饰。

表格区标准结构：

```text
工具栏 / 批量操作区
→ 表格主体
→ 分页区
→ loading / empty / error / toast / confirm 状态
```

## 2. 工具栏

工具栏位于表格上方，分为左侧主操作区和右侧辅助操作区。

| 区域 | 内容 | 规则 |
|---|---|---|
| 左侧 | 新建、导入、批量启用、批量停用、批量删除 | 与当前数据处理强相关 |
| 右侧 | 导出、字段配置、刷新、密度切换、规则配置 | 全局辅助能力 |

规则：

- 新建类按钮放在左侧最前，通常为主按钮。
- 导入按钮紧邻新建按钮右侧。
- 批量操作仅在有选择行为时具备强意义。
- 无勾选数据时，批量按钮为 disabled，并通过 Tooltip 说明原因。
- 已勾选后展示 `已选 N 项`，该文本不做成按钮或高强调标签。

## 3. 表格主体

| 项目 | 规则 |
|---|---|
| 表头 | 浅灰背景，字段名称清晰 |
| 行高 | 表头和普通行默认 40px |
| 单元格 | 高密度信息保持足够 padding，不拥挤 |
| 空值 | 统一显示 `-` |
| 时间 | 使用 `YYYY-MM-DD HH:MM:SS` |
| 超长文本 | 单行省略，hover 展示 Tooltip |
| 行 hover | 整行高亮 |
| 多列场景 | 支持横向滚动 |
| 首列 | 关键识别列可固定 |
| 操作列 | 固定在最右侧 |

## 4. 列类型

常见列类型必须按语义表达：

- 文本列：展示名称、编号、IP、账号等可识别信息。
- 状态列：使用状态标签或状态点，颜色和文字同时表达。
- 时间列：统一格式，不混用短日期与长日期。
- 数字列：右对齐或按业务统一对齐，单位明确。
- 风险列：使用标准风险等级文案和颜色。
- 操作列：只放与当前行直接相关的操作。

## 5. 排序与筛选

- 支持排序的列必须有明确排序图标。
- 排序状态包括升序、降序、取消排序。
- 当前排序方向需要高亮。
- 支持列筛选的列必须有筛选入口。
- 筛选弹层包含筛选项、确定、重置。
- 存在生效筛选条件时，筛选图标高亮。
- 排序和筛选触发后刷新表格数据，并展示 loading。

## 6. 行操作

| 场景 | 规则 |
|---|---|
| 操作数量 ≤ 3 | 直接展示 |
| 操作数量 > 3 | 前 2 个直接展示，其余折叠到 `更多` |
| 高风险操作 | 必须二次确认 |
| 操作不可用 | disabled + Tooltip 说明原因 |
| 操作完成 | Toast / Message 反馈成功或失败 |

行操作应固定在最右侧操作列，不要散落在其他列中。

## 7. 批量操作

- 勾选列位于表格最左侧。
- 支持全选、单选、跨页选择时需要说明范围。
- 已选数量实时更新。
- 未勾选时批量按钮禁用。
- 批量删除、停用、还原等高风险操作必须二次确认。
- 批量操作成功或失败后刷新表格并给出反馈。

## 8. 分页

| 项目 | 规则 |
|---|---|
| 默认每页 | 20 条 |
| 可选条数 | 10 / 20 / 50 / 100 |
| 位置 | 表格底部右侧 |
| 总数 | 必须展示 |
| 空数据 | 隐藏分页器或展示不可用分页状态，避免误导 |

分页必须支持页码切换和每页条数切换，并触发表格刷新。

## 9. 状态与反馈

表格区必须覆盖以下状态：

- loading：搜索、排序、筛选、分页、批量操作期间展示。
- empty：无数据时展示空状态和下一步建议。
- error：加载失败时展示错误原因和重试入口。
- disabled：无权限或条件不足时禁用并说明原因。
- success / failure：操作完成后给出 Toast / Message 反馈。
- confirm：删除、停用、覆盖、还原等高风险操作必须确认。

## 10. HTML Demo 要求

HTML Demo 必须支持点击验证：

- 搜索 / 清空刷新表格。
- 表头排序切换。
- 列筛选弹层打开、确定、重置。
- 行勾选与 `已选 N 项` 联动。
- 批量按钮禁用 Tooltip。
- 行 hover 高亮。
- `更多` 菜单展开。
- 分页切换和每页条数切换。
- 删除或停用二次确认。
- Toast 成功 / 失败反馈。
- loading、empty、error 状态切换。

## 11. AI 生成禁止项

- 禁止只生成静态表格截图式页面。
- 禁止只有“搜索 + 表格 + 分页”的粗结构，缺少排序、筛选、勾选、固定列和反馈。
- 禁止危险操作只有 Toast，没有二次确认。
- 禁止批量操作在未勾选时仍可点击。
- 禁止超长文本撑破列宽。
- 禁止操作列不固定，导致横向滚动后操作不可见。

## 12. 验收清单

- [ ] 工具栏左侧主操作、右侧辅助操作分区清晰。
- [ ] 表格包含表头、数据行、状态标签、操作列。
- [ ] 支持排序、列筛选、勾选、批量操作、分页。
- [ ] 首列或关键列、操作列在多列场景下保持可见。
- [ ] disabled 操作有 Tooltip 说明。
- [ ] 高风险操作有二次确认。
- [ ] loading、empty、error、success、failure 状态完整。
- [ ] HTML Demo 中主要交互均可点击验证。

缺少任一当前业务适用项，视为表格区生成失败。
