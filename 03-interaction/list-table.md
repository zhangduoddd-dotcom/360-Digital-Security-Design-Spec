# 列表页表格区域交互规范
## List Page Table Interaction Rules

Keywords: list table, toolbar, batch action, pagination, row action, freeze, sorting, filtering

本文定义列表页表格区域的结构、操作栏、表头、内容区、操作列、分页、权限与反馈规则。AI 生成列表页、Vue 代码或 HTML 预览文件时，必须遵循本文。

## 1. 整体设计原则

表格区域遵循：功能关联明确、操作优先级清晰、视觉层次统一、交互反馈精准。

表格视觉应轻量化，适合企业级 SaaS 后台：

- 表格无外边框、无圆角。
- 仅通过行底部分隔线区分数据层级。
- 分隔线颜色使用 `#E8EAED`。
- 表格背景为白色 `#FFFFFF`。
- 不使用冗余装饰，突出核心数据内容。

表格区域由五部分组成：

```text
表格顶部操作栏
→ 表头区域
→ 数据内容区域
→ 操作列区域
→ 分页区域
```

## 2. 外部容器规范

| 项目 | 规则 |
|---|---|
| 外部容器圆角 | 8px |
| 容器与表格区域间距 | 上下左右 24px |
| 表格背景 | #FFFFFF |
| 行分隔线 | #E8EAED |

表格区域应嵌入固定样式的外部容器内，保证与页面其他模块边界清晰、布局规整。

## 3. 冻结与滚动规则

| 区域 | 冻结规则 |
|---|---|
| 表格顶部操作栏 | 固定在表格内容区域顶部 |
| 表头 | 固定在内容区域顶部，随横向滚动保持列对齐 |
| 分页器 | 固定在表格内容区域底部 |
| 首列 | 多列场景下默认固定，作为数据标识列 |
| 尾列 | 默认固定，作为操作列 |
| 中间数据区 | 支持横向 / 纵向滚动 |

补充规则：

- 当表格内容较少、不足以充满内容区时，分页器紧贴最后一行表格内容排布，避免无效空白。
- 当列较多时，仅中间核心数据区域可横向滚动，首列和操作列保持可见。
- 用户滚动表格时，应始终能看到操作栏、表头、分页器、首列和操作列。

## 4. 表格顶部操作栏

### 4.1 布局原则

操作栏统一放在表格表头正上方，遵循四个原则：

1. 功能关联分区。
2. 操作优先级排序。
3. 高频操作显性化。
4. 全站一致性布局。

操作栏横向划分为三大区域：

| 区域 | 功能属性 | 对齐方式 |
|---|---|---|
| 左侧核心操作区 | 数据新增类操作，属于表格核心入口操作 | 左对齐 |
| 中间批量操作区 | 勾选数据后的批量处理操作 | 左对齐 |
| 右侧全局配置区 | 表格整体维度的配置与操作 | 右对齐 |

区域内所有按钮水平间距统一为 8px。

### 4.2 左侧核心操作区

仅承载与表格数据新增强关联的操作，优先级最高。

排序规则：

1. 新建：固定排布在区域最左侧，采用主按钮样式。
2. 导入：紧邻“新建”按钮右侧，采用辅助按钮样式。

特殊规则：

- 若页面不支持单条数据“新建”，仅开放批量导入能力时，“导入”按钮升级为主按钮。

### 4.3 中间批量操作区

仅承载勾选多条数据后的批量处理操作。

排序规则：

```text
导出 → 批量编辑 → 其他批量操作 → 删除
```

删除按钮固定在区域最右侧，降低误操作风险。

状态联动：

- 默认无数据勾选时，所有批量操作按钮禁用。
- 用户勾选任意一条或多条数据后，批量操作按钮解除禁用。
- 禁用状态不可点击。

折叠规则：

- 批量操作按钮数量超过 3 个时，保留导出、删除等高频核心操作直接展示。
- 其余低频操作折叠到“操作”下拉菜单。
- 按钮命名仅保留核心动词，如“删除”“导出”“编辑”，不额外增加“批量”前缀。

### 4.4 右侧全局配置区

承载整个表格维度的全局操作与配置，不针对单条或多条数据。

固定排序：

```text
刷新 → 打印 → 全屏 → 导出全部 → 配置表格字段
```

规则：

- “配置表格字段”固定在区域最后一位。
- 低频辅助操作可使用纯图标按钮。
- 高频操作保留文字 + 图标或纯文字，确保可识别。
- 页面宽度不足时，非核心按钮自动折叠至“更多”下拉菜单。
- 小屏下仅保留“导出全部”“配置表格字段”两个核心功能按钮可见。

## 5. 表格整体视觉规范

- 无外边框、无圆角。
- 背景色为 #FFFFFF。
- 仅通过行底部分隔线区分数据。
- 数据区域支持横向滚动。
- 横向滚动时，表头、首列、操作列固定。

## 6. 分页器规范

| 项目 | 规则 |
|---|---|
| 显示条件 | 仅在表格非空且存在数据时显示 |
| 无数据时 | 隐藏分页器 |
| 组件规格 | 使用大分页栏 |
| 默认每页数量 | 20 条 / 页 |
| 可选数量 | 10 / 20 / 50 / 100 |
| 位置 | 表格底部正下方 |
| 对齐 | 右对齐 |
| 与表格底部间距 | 8px |

## 7. 表头规范

### 7.1 基础样式

| 属性 | 规范 |
|---|---|
| 行高 | 40px |
| 内边距 | 上下 10px；左右 16px |
| 字号 | 12px |
| 字重 | Medium |
| 文本颜色 | #242933 |
| 背景色 | #F8F9FA |

表头文本强制单行显示，超出宽度时省略。鼠标 hover 表头时，通过 Tooltip 展示完整文本。

### 7.2 表头 Hover

| 表头类型 | Hover 规则 |
|---|---|
| 可操作表头 | 有排序或筛选功能，hover 背景变为 #F2F3F5 |
| 不可操作表头 | 仅做数据标识，hover 无样式变化 |

## 8. 排序图标规范

| 属性 | 规范 |
|---|---|
| 尺寸 | 14px × 14px |
| 与文字间距 | 4px |
| 默认颜色 | #8A9099 |
| hover 颜色 | #1DB887 |
| 激活颜色 | #00AB7A |

交互规则：

- 点击排序图标，循环切换：升序 → 降序 → 取消排序。
- 精准点击上箭头时，直接触发升序。
- 精准点击下箭头时，直接触发降序。
- 当前生效方向对应图标高亮。

## 9. 筛选图标规范

| 属性 | 规范 |
|---|---|
| 尺寸 | 14px × 14px |
| 与文字间距 | 4px |
| 默认颜色 | #8A9099 |
| hover 颜色 | #1DB887 |
| 激活颜色 | #00AB7A |

规则：

- 若表头同时存在排序与筛选，筛选图标固定在排序图标右侧。
- 两个图标间距为 4px。
- 点击筛选图标，弹出当前列筛选菜单。
- 菜单内包含可筛选项、确定按钮、重置按钮。
- 确定：应用筛选条件并刷新表格。
- 重置：清除当前列筛选条件并恢复默认数据。
- 存在生效筛选条件时，筛选图标高亮。

## 10. 内容单元格规范

### 10.1 基础样式

| 属性 | 规范 |
|---|---|
| 行高 | 40px |
| 内边距 | 上下 10px；左右 16px |
| 字号 | 12px |
| 字重 | Regular |
| 文本颜色 | #525966 |
| 对齐方式 | 默认左对齐 |

### 10.2 文本规则

- 普通文本强制单行显示。
- 超出单元格宽度时自动省略。
- hover 单元格时通过 Tooltip 展示完整内容。
- 禁止多行文本导致表格高度错乱。
- 时间字段格式统一为 `YYYY-MM-DD HH:MM:SS`，完整展示，不省略。

### 10.3 行背景与 Hover

| 状态 | 规则 |
|---|---|
| 默认 | 单元格背景 #FFFFFF，行底部分隔线 #E8EAED |
| 行 Hover | 整行背景切换为 #F2F3F5，包含内容列与操作列 |

## 11. 操作列规范

### 11.1 基础规则

- 操作列所有按钮使用文字按钮常规样式。
- 不随意更换为主按钮、面性按钮或图标堆叠样式。
- 操作列固定在最右侧。

### 11.2 展示规则

| 操作项数量 | 展示规则 |
|---|---|
| ≤ 3 | 所有操作项直接横向展示 |
| > 3 | 前 2 个高频核心操作直接展示，第 3 个及以后折叠为“更多” |

“更多”使用文字按钮 + 下箭头图标。鼠标 hover“更多”按钮时，展开下拉菜单，展示剩余操作项。

### 11.3 行联动

鼠标 hover 操作列任意位置时，对应数据整行同步高亮，背景为 #F2F3F5。

## 12. 权限与状态规范

### 12.1 权限控制

所有操作按钮根据用户角色权限动态处理：

| 权限结果 | 处理方式 |
|---|---|
| 有权限 | 正常显示 |
| 完全无权限且不应感知 | 隐藏 |
| 暂不可操作但应感知能力 | 禁用 |

示例：普通用户默认隐藏“删除”和“配置表格字段”；管理员开放高权限操作。

### 12.2 禁用状态

- 禁用按钮置灰，不可点击。
- hover 禁用按钮时，自动弹出 Tooltip 提示禁用原因。
- 禁用状态不能只依赖透明度，需要保持可读。

### 12.3 操作反馈

- 表格内所有操作必须有即时反馈。
- 核心操作触发 Toast 提示。
- 异步操作展示 Loading。
- 操作完成给出成功 / 失败反馈。
- 可点击按钮 hover 时应有明确高亮或变色反馈。
- 删除、停用 / 启用等关键操作必须二次确认。

删除确认文案模板：

```text
标题：确定删除所选内容吗？
内容：删除后将无法恢复，请谨慎操作。
```

## 13. Vue 代码生成要求

Vue 代码必须包含：

- `a-table`。
- columns 配置。
- dataSource / mock 数据。
- rowKey。
- pagination。
- loading。
- empty 状态。
- 横向滚动配置。
- 固定首列 / 操作列。
- 操作列 slot 或 customRender。
- rowSelection 勾选逻辑。
- 批量操作禁用 / 启用逻辑。
- 排序、筛选、分页事件。
- 删除 / 停用确认弹窗。
- Toast / message 反馈。

## 14. HTML 预览文件要求

HTML 预览文件必须支持：

- 表格数据展示。
- 搜索结果刷新。
- 表头 hover。
- 排序切换。
- 列筛选弹层。
- 行 hover 高亮。
- 勾选数据。
- 批量操作启用 / 禁用。
- 分页切换。
- 行操作与“更多”菜单。
- 删除确认与 Toast 反馈。
- 多列横向滚动时首列和操作列固定的视觉表达。

## 15. AI 生成禁止项

- 禁止给表格加外边框和圆角。
- 禁止缺少顶部操作栏、表头、操作列、分页区。
- 禁止批量操作不与勾选状态联动。
- 禁止行操作超过 3 个仍全部平铺。
- 禁止删除等风险操作无确认。
- 禁止无数据时仍显示分页器。
- 禁止表头排序 / 筛选图标无 hover 与激活状态。
- 禁止时间格式不统一。
- 禁止多行文本撑高表格行。
