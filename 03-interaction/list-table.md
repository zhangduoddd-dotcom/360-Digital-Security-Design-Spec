# 列表页表格区域交互规范
## List Page Table Interaction Rules

Keywords: list table, toolbar, batch action, pagination, row action, freeze, sorting, filtering

本文定义列表页表格区域的结构、操作栏、表头、内容区、操作列、分页、权限与反馈规则。AI 生成列表页、Vue 代码或 HTML 预览文件时，必须遵循本文。

## 1. 整体设计原则

表格区域遵循：功能关联明确、操作优先级清晰、视觉层次统一、交互反馈精准。

表格视觉应轻量化，适合企业级 SaaS 后台：

- 表格无外边框、无圆角。
- 仅通过行底部分隔线区分数据层级。
- 分隔线颜色使用 `#E8EAED`。
- 表格背景为白色 `#FFFFFF`。
- 不使用冗余装饰，突出核心数据内容。

表格区域由五部分组成：

```text
表格顶部操作栏
→ 表头区域
→ 数据内容区域
→ 操作列区域
→ 分页区域
```

## 2. 外部容器规范

| 项目 | 规则 |
|---|---|
| 外部容器圆角 | 8px |
| 容器与表格区域间距 | 上下左右 24px |
| 表格背景 | #FFFFFF |
| 行分隔线 | #E8EAED |

表格区域应嵌入固定样式的外部容器内，保证与页面其他模块边界清晰、布局规整。

## 3. 冻结与滚动规则

| 区域 | 冻结规则 |
|---|---|
| 表格顶部操作栏 | 固定在表格内容区域顶部 |
| 表头 | 固定在内容区域顶部，随横向滚动保持列对齐 |
| 分页器 | 固定在表格内容区域底部 |
| 首列 | 多列场景下默认固定，作为数据标识列 |
| 尾列 | 默认固定，作为操作列 |
| 中间数据区 | 支持横向 / 纵向滚动 |

补充规则：

- 当表格内容较少、不足以充满内容区时，分页器紧贴最后一行表格内容排布，避免无效空白。
- 当列较多时，仅中间核心数据区域可横向滚动，首列和操作列保持可见。
- 用户滚动表格时，应始终能看到操作栏、表头、分页器、首列和操作列。

## 4. 表格顶部操作栏

### 4.1 布局原则

操作栏统一放在表格表头正上方，遵循四个原则：

1. 功能关联分区。
2. 操作优先级排序。
3. 高频操作显性化。
4. 全站一致性布局。

操作栏横向划分为两大区域：

| 区域 | 功能属性 | 对齐方式 |
|---|---|---|
| 左侧表格操作区 | 与表格数据创建、勾选行处理相关的操作 | 左对齐 |
| 右侧全局配置区 | 与表格整体内容、展示、规则配置相关的操作 | 右对齐 |

区域内所有按钮水平间距统一为 8px。

### 4.2 左侧表格操作区

左侧表格操作区承载两类操作，它们在视觉上连续左对齐展示，但交互逻辑不同：

```text
新增类操作 → 勾选行相关操作
```

#### 4.2.1 新增类操作

新增类操作与表格数据创建强相关，优先级最高，排在左侧表格操作区最前面。

排序规则：

1. 新建：固定排布在最左侧，采用主按钮样式。
2. 导入：紧邻“新建”按钮右侧，通常采用辅助按钮样式。

特殊规则：

- 若页面不支持单条数据“新建”，仅开放批量导入能力时，“导入”按钮可升级为主按钮。
- 若页面既无新建也无导入能力，则不展示新增类操作，左侧直接展示勾选行相关操作。

#### 4.2.2 勾选行相关操作

勾选行相关操作紧跟新增类操作之后展示，用于处理用户已勾选的表格行。

典型操作包括：

```text
启用、停用、导出、删除
```

交互规则：

- 默认未勾选任何数据时，勾选行相关操作全部禁用。
- 用户勾选任意一条或多条数据后，相关操作启用。
- 禁用状态不可点击，hover 时可通过 Tooltip 说明“请选择数据后操作”。
- 删除、停用等风险操作必须二次确认。

命名规则：

- 按钮文案只保留核心动词，例如“启用”“停用”“导出”“删除”。
- 不在按钮文案前增加“批量”二字，避免与全局操作混淆，也避免操作栏视觉冗余。
- 若业务确实存在单条导出与勾选导出并存，应通过位置和禁用状态区分，不通过文案堆叠区分。

排序建议：

```text
启用 → 停用 → 导出 → 删除
```

风险操作建议靠后展示，删除放在该组最后。

选中数量注解规则：

- 当用户已勾选一条或多条数据时，在勾选行相关操作后方展示弱化注解文案。
- 注解文案格式固定为：`已选 N 项`。
- 示例：用户勾选 2 条数据时，展示为 `已选 2 项`。
- 注解放在“启用 → 停用 → 导出 → 删除”等操作按钮之后，和按钮组保持同一行。
- 注解使用辅助文字样式，不使用按钮、标签或高强调色。
- 未勾选数据时，不展示该注解。
- 注解仅用于提示当前操作影响范围，不作为可点击控件。

推荐展示结构：

```text
新建  导入  启用  停用  导出  删除  已选 2 项
```

折叠规则：

- 勾选行相关操作超过 4 个时，保留高频核心操作直接展示。
- 低频操作折叠进“更多”下拉菜单。
- “删除”等高风险操作即使折叠，也必须在触发时二次确认。
- 存在选中数据时，即使部分操作被折叠，`已选 N 项` 注解仍展示在可见操作组后方。

### 4.3 右侧全局配置区

右侧全局配置区承载与表格整体内容、展示、业务规则相关的操作，不针对单条或多条勾选数据。

典型操作包括：

```text
导出全部、配置业务相关规则、配置表格字段
```

规则：

- 右侧全局配置区不是高频操作区，不使用主按钮。
- 一般采用辅助按钮或纯图标按钮形式，减少对表格主要操作的干扰。
- 纯图标按钮 hover 时必须显示 Tooltip，说明具体操作名称。
- 图标语义不清时，不建议只显示图标，应使用图标 + 文案或文字按钮。
- “配置表格字段”通常固定在右侧配置区最后一位。
- “导出全部”属于全表范围导出，与左侧勾选后的“导出”不同，必须放在右侧全局配置区。

响应式规则：

- 页面宽度不足时，右侧非核心配置按钮优先折叠至“更多”菜单。
- 小屏下优先保留与业务最相关的配置入口和“配置表格字段”。
- 折叠后仍需通过 hover 或菜单文案明确操作名称。

### 4.4 操作区边界规则

- 左侧操作区关注“当前表格数据的创建和已选数据处理”。
- 右侧配置区关注“表格整体内容、展示方式和业务规则配置”。
- 左侧勾选行相关操作与右侧全局操作不能混放。
- “导出”如果依赖勾选行，放左侧；“导出全部”如果作用于全表，放右侧。
- “配置表格字段”“配置业务规则”属于右侧全局配置区，不放在左侧。
- 右侧配置区不使用高强调样式，避免和左侧主操作抢层级。

## 5. 表格整体视觉规范

- 无外边框、无圆角。
- 背景色为 #FFFFFF。
- 仅通过行底部分隔线区分数据。
- 数据区域支持横向滚动。
- 横向滚动时，表头、首列、操作列固定。

## 6. 分页器规范

| 项目 | 规则 |
|---|---|
| 显示条件 | 仅在表格非空且存在数据时显示 |
| 无数据时 | 隐藏分页器 |
| 组件规格 | 使用大分页栏 |
| 默认每页数量 | 20 条 / 页 |
| 可选数量 | 10 / 20 / 50 / 100 |
| 位置 | 表格底部正下方 |
| 对齐 | 右对齐 |
| 与表格底部间距 | 8px |

## 7. 表头规范

### 7.1 基础样式

| 属性 | 规范 |
|---|---|
| 行高 | 40px |
| 内边距 | 上下 10px；左右 16px |
| 字号 | 12px |
| 字重 | Medium |
| 文本颜色 | #242933 |
| 背景色 | #F8F9FA |

表头文本强制单行显示，超出宽度时省略。鼠标 hover 表头时，通过 Tooltip 展示完整文本。

### 7.2 表头 Hover

| 表头类型 | Hover 规则 |
|---|---|
| 可操作表头 | 有排序或筛选功能，hover 背景变为 #F2F3F5 |
| 不可操作表头 | 仅做数据标识，hover 无样式变化 |

## 8. 排序图标规范

| 属性 | 规范 |
|---|---|
| 尺寸 | 14px × 14px |
| 与文字间距 | 4px |
| 默认颜色 | #8A9099 |
| hover 颜色 | #1DB887 |
| 激活颜色 | #00AB7A |

交互规则：

- 点击排序图标，循环切换：升序 → 降序 → 取消排序。
- 精准点击上箭头时，直接触发升序。
- 精准点击下箭头时，直接触发降序。
- 当前生效方向对应图标高亮。

## 9. 筛选图标规范

| 属性 | 规范 |
|---|---|
| 尺寸 | 14px × 14px |
| 与文字间距 | 4px |
| 默认颜色 | #8A9099 |
| hover 颜色 | #1DB887 |
| 激活颜色 | #00AB7A |

规则：

- 若表头同时存在排序与筛选，筛选图标固定在排序图标右侧。
- 两个图标间距为 4px。
- 点击筛选图标，弹出当前列筛选菜单。
- 菜单内包含可筛选项、确定按钮、重置按钮。
- 确定：应用筛选条件并刷新表格。
- 重置：清除当前列筛选条件并恢复默认数据。
- 存在生效筛选条件时，筛选图标高亮。

## 10. 内容单元格规范

### 10.1 基础样式

| 属性 | 规范 |
|---|---|
| 行高 | 40px |
| 内边距 | 上下 10px；左右 16px |
| 字号 | 12px |
| 字重 | Regular |
| 文本颜色 | #525966 |
| 对齐方式 | 默认左对齐 |

### 10.2 文本规则

- 普通文本强制单行显示。
- 超出单元格宽度时自动省略。
- hover 单元格时通过 Tooltip 展示完整内容。
- 禁止多行文本导致表格高度错乱。
- 时间字段格式统一为 `YYYY-MM-DD HH:MM:SS`，完整展示，不省略。

### 10.3 行背景与 Hover

| 状态 | 规则 |
|---|---|
| 默认 | 单元格背景 #FFFFFF，行底部分隔线 #E8EAED |
| 行 Hover | 整行背景切换为 #F2F3F5，包含内容列与操作列 |

## 11. 操作列规范

### 11.1 基础规则

- 操作列所有按钮使用文字按钮常规样式。
- 不随意更换为主按钮、面性按钮或图标堆叠样式。
- 操作列固定在最右侧。

### 11.2 展示规则

| 操作项数量 | 展示规则 |
|---|---|
| ≤ 3 | 所有操作项直接横向展示 |
| > 3 | 前 2 个高频核心操作直接展示，第 3 个及以后折叠为“更多” |

“更多”使用文字按钮 + 下箭头图标。鼠标 hover“更多”按钮时，展开下拉菜单，展示剩余操作项。

### 11.3 行联动

鼠标 hover 操作列任意位置时，对应数据整行同步高亮，背景为 #F2F3F5。

## 12. 权限与状态规范

### 12.1 权限控制

所有操作按钮根据用户角色权限动态处理：

| 权限结果 | 处理方式 |
|---|---|
| 有权限 | 正常显示 |
| 完全无权限且不应感知 | 隐藏 |
| 暂不可操作但应感知能力 | 禁用 |

示例：普通用户默认隐藏“删除”和“配置表格字段”；管理员开放高权限操作。

### 12.2 禁用状态

- 禁用按钮置灰，不可点击。
- hover 禁用按钮时，自动弹出 Tooltip 提示禁用原因。
- 禁用状态不能只依赖透明度，需要保持可读。

### 12.3 操作反馈

- 表格内所有操作必须有即时反馈。
- 核心操作触发 Toast 提示。
- 异步操作展示 Loading。
- 操作完成给出成功 / 失败反馈。
- 可点击按钮 hover 时应有明确高亮或变色反馈。
- 删除、停用 / 启用等关键操作必须二次确认。

删除确认文案模板：

```text
标题：确定删除所选内容吗？
内容：删除后将无法恢复，请谨慎操作。
```

## 13. Vue 代码生成要求

Vue 代码必须包含：

- `a-table`。
- columns 配置。
- dataSource / mock 数据。
- rowKey。
- pagination。
- loading。
- empty 状态。
- 横向滚动配置。
- 固定首列 / 操作列。
- 操作列 slot 或 customRender。
- rowSelection 勾选逻辑。
- 左侧新增类操作与勾选行相关操作。
- 勾选行相关操作禁用 / 启用逻辑。
- 已选数量注解，格式为 `已选 N 项`。
- 右侧全局配置区图标按钮与 Tooltip。
- 排序、筛选、分页事件。
- 删除 / 停用确认弹窗。
- Toast / message 反馈。

## 14. HTML 预览文件要求

HTML 预览文件必须支持：

- 表格数据展示。
- 搜索结果刷新。
- 表头 hover。
- 排序切换。
- 列筛选弹层。
- 行 hover 高亮。
- 勾选数据。
- 勾选行相关操作启用 / 禁用。
- 勾选后在操作组后方显示 `已选 N 项`。
- 右侧配置区 icon hover 显示操作名称。
- 分页切换。
- 行操作与“更多”菜单。
- 删除确认与 Toast 反馈。
- 多列横向滚动时首列和操作列固定的视觉表达。

## 15. AI 生成禁止项

- 禁止给表格加外边框和圆角。
- 禁止缺少顶部操作栏、表头、操作列、分页区。
- 禁止把左侧新增类操作和勾选行相关操作拆成视觉割裂的两个区域。
- 禁止勾选行相关操作不与勾选状态联动。
- 禁止勾选行相关操作按钮文案加“批量”前缀。
- 禁止勾选后缺少 `已选 N 项` 注解。
- 禁止把 `已选 N 项` 做成按钮、标签或高强调状态。
- 禁止把“导出全部”“配置表格字段”“配置业务规则”放到左侧勾选行操作区。
- 禁止右侧全局配置区使用主按钮或强强调样式。
- 禁止右侧纯图标按钮没有 Tooltip。
- 禁止行操作超过 3 个仍全部平铺。
- 禁止删除等风险操作无确认。
- 禁止无数据时仍显示分页器。
- 禁止表头排序 / 筛选图标无 hover 与激活状态。
- 禁止时间格式不统一。
- 禁止多行文本撑高表格行。

## 16. AI 生成强制验收清单

AI 生成列表页、HTML Demo 或 Vue 页面代码时，表格区必须通过以下验收：

- [ ] 表格顶部操作栏存在。
- [ ] 左侧新增类操作与勾选行相关操作连续展示。
- [ ] 右侧全局配置区独立展示。
- [ ] 未勾选数据时，勾选行相关操作禁用。
- [ ] 禁用按钮 hover 展示 Tooltip。
- [ ] 勾选数据后展示 `已选 N 项`。
- [ ] `已选 N 项` 使用辅助文字样式。
- [ ] 表头支持排序切换。
- [ ] 表头支持列筛选弹层。
- [ ] 筛选弹层包含确定和重置。
- [ ] 表格文本单行省略。
- [ ] 超长文本 hover 展示 Tooltip。
- [ ] 首列固定。
- [ ] 操作列固定。
- [ ] 行 hover 高亮。
- [ ] 行操作超过 3 个时折叠为“更多”。
- [ ] 删除、停用等风险操作二次确认。
- [ ] 操作完成后展示 Toast / Message 反馈。
- [ ] loading 状态完整。
- [ ] empty 状态完整。
- [ ] 默认分页为 20 条 / 页。
- [ ] 分页支持 10 / 20 / 50 / 100。
- [ ] 无数据时隐藏分页器。
- [ ] HTML Demo 中以上行为可被点击验证。

缺少任一适用项，视为表格区生成失败。
