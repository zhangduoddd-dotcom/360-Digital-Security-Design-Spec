# 后台管理系统页面容器搭建规范
## Background Management System Page Container Rules

Keywords: background system, page construction, layout structure, top navigation, sidebar, content container

本文定义后台管理系统页面的基础容器结构。AI 生成页面、Vue 代码或 HTML 预览文件时，必须遵循「顶部导航栏 + 左侧边栏 + 主内容区」的三层嵌套结构。

## 1. 整体布局结构

系统页面采用典型企业级后台管理系统布局：

```text
全屏外层容器
→ 顶部单行导航栏
→ 下方主体区域
   → 左侧边栏
   → 主内容区
```

整体使用 Flex 水平 + 垂直嵌套布局。

## 2. 三大模块容器

| 模块 | 尺寸 / 定位 | 容器规则 |
|---|---|---|
| 顶部单行导航栏 | 高度固定 56px，宽度 100% | 深色背景，内部元素水平分布，左侧品牌区，右侧用户 / 功能区 |
| 左侧边栏 | 展开宽度 184px，收起宽度 56px，高度 100% | 白色背景，内部为垂直导航菜单，底部固定版本号，菜单支持二级选中态高亮 |
| 主内容区 | 剩余宽高自适应 | 白色背景，内部按功能模块分块，所有业务容器在此区域内排列 |

## 3. 顶部导航栏容器

### 3.1 基础规则

- 高度固定 56px。
- 背景使用深灰 / 黑色，与下方内容区形成明确分隔。
- 宽度 100%。
- 内部采用 flex 水平布局。
- 容器内元素垂直居中对齐。
- 间距固定，不随内容变化挤压变形。

### 3.2 内部结构

顶部导航栏分为左、中、右三部分：

| 区域 | 内容 |
|---|---|
| 左侧 | 品牌 Logo + 系统名称 + 本级中心下拉菜单 |
| 中间 | 安全状态提示文本 |
| 右侧 | 可视化下拉、功能图标、通知、设置、安全入口、用户头像 / 账号下拉 |

## 4. 左侧边栏容器

### 4.1 基础规则

- 展开宽度固定 184px。
- 收起宽度固定 56px。
- 高度 100%。
- 背景色使用 #FFFFFF。
- 内部为垂直导航菜单。
- 底部固定版本号或辅助信息。
- 支持二级菜单选中态高亮。

### 4.2 响应式规则

- 顶部导航栏和左侧边栏尺寸固定，不随窗口缩放改变自身规格。
- 主内容区自适应窗口宽度。
- 当主内容区内容超出可用宽度时，显示水平滚动条。
- 小屏或窄屏场景下，侧边栏可收起为 56px 图标态。

## 5. 主内容区容器

主内容区是所有业务模块的父容器，内部按以下结构垂直排列：

```text
页面标题区
→ 内容容器
```

### 5.1 页面标题区

| 项目 | 规则 |
|---|---|
| 高度 | 固定 48px |
| 宽度 | 100% |
| 内容 | 页面标题、面包屑、页面级操作等 |

页面标题应清晰表达当前对象和任务。页面级主操作可放在标题区右侧。

### 5.2 内容容器

内容容器用于承载具体业务区域。

| 项目 | 规则 |
|---|---|
| 内容容器背景 | #F2F3F5 |
| 内容容器内边距 | 上下左右 16px |
| 子容器背景 | #FFFFFF |
| 子容器圆角 | 8px |
| 子容器间距 | 水平 / 垂直均 16px |

不同页面中的常见组合：

| 页面类型 | 内容容器内子容器组合 |
|---|---|
| 列表页 | 搜索区域 + 表格及操作区域 |
| 详情页 | 摘要区 + 详情区域 + 关联列表 / 操作记录 |
| 表单页 | 表单区 + 操作区 |
| 工作台 | 指标区 + 待办 / 风险区 + 图表 / 快捷入口 |

## 6. 通用容器规则

- 页面整体必须包含顶部导航栏、左侧边栏和主内容区。
- 不要只生成业务卡片而缺少后台框架。
- 内容区内部至少有一个白色子容器。
- 子容器圆角统一 8px。
- 内容容器与子容器间距统一，不要随意变化。
- 页面内容过宽时，主内容区出现水平滚动，顶部和侧边容器不变形。

## 7. 弹窗与抽屉关系

弹窗、抽屉、浮层属于内容弹层，不替代主内容区。

规则：

- 高风险确认优先使用弹窗。
- 详情查看、轻量编辑、筛选配置可使用抽屉。
- 弹窗和抽屉必须有明确标题。
- 关闭前如有未保存内容，应提示用户确认。
- 弹层不应遮挡关键确认文案和主要操作按钮。

## 8. Vue 代码生成要求

生成 Vue 页面代码时，必须体现：

- 全屏外层容器。
- 顶部导航栏，高度 56px。
- 左侧边栏，展开 184px，收起 56px。
- 主内容区自适应。
- 页面标题区，高度 48px。
- 内容容器，背景 #F2F3F5，内边距 16px。
- 内容子容器，背景 #FFFFFF，圆角 8px。
- 页面内容过宽时支持横向滚动。

## 9. HTML 预览文件要求

HTML 预览文件必须能直接看出后台页面框架：

```text
顶部导航栏
+ 左侧边栏
+ 页面标题区
+ 内容容器
+ 子容器
```

预览文件中不要只展示一张孤立表格、孤立表单或孤立卡片。

## 10. AI 生成禁止项

- 禁止缺少顶部导航栏。
- 禁止缺少左侧边栏。
- 禁止把主内容区做成纯白无层级页面。
- 禁止内容容器没有灰色背景和白色子容器。
- 禁止侧边栏宽度随内容随机变化。
- 禁止页面标题区高度和层级不稳定。
- 禁止只生成组件，不生成完整页面框架。
