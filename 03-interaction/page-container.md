# 页面容器交互规范
## Page Container Interaction Rules

Keywords: page container, layout, navigation, breadcrumb, drawer, modal

本文定义后台页面的外层结构，包括顶部导航、侧边导航、页面标题、内容区、弹窗、抽屉和浮层关系。

## 1. 标准页面结构

```text
顶部导航
+ 侧边导航
+ 页面标题区
+ 主内容区
+ 弹窗 / 抽屉 / 浮层
```

## 2. 页面标题区

标题应简短明确，优先使用业务对象 + 页面任务。复杂层级页面可使用面包屑。页面级主操作可放在标题区右侧。

## 3. 主内容区

主内容区承载用户完成任务的核心模块。列表页优先保证表格可读性，表单页优先保证字段分组和提交路径清晰，工作台优先展示指标、待办、风险和快捷入口。

## 4. 弹窗与抽屉

高风险确认优先使用 Modal。行详情、轻量编辑、筛选配置可使用 Drawer。关闭前如有未保存内容，应提示用户确认。

## 5. 代码生成要求

生成 Vue 代码或 HTML 预览文件时，应保留完整页面容器、标题区、内容卡片、操作区、弹窗 / 抽屉结构。
