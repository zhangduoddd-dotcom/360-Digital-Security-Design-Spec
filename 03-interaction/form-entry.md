# 表单页信息录入交互规范
## Form Page Information Entry Interaction Rules

Keywords: form entry, validation, conditional visibility, step structure, form state, operation priority, backend

本文定义企业级 B 端系统表单信息录入的交互规则。AI 生成任何 B 端表单页面、Vue 代码或 HTML 预览文件时，必须遵循本文，不得自创页面结构、交互模板、校验规则或文案格式。

## 1. 适用场景

适用于信息上报、基础配置、分析规则、处置策略、系统对接、账号权限、安全设置、后台管理、参数配置、数据填报等所有 B 端表单类页面。

## 2. 核心设计原则

| 原则 | 要求 |
|---|---|
| 易理解 | 降低学习与操作门槛，字段、说明和错误提示直白易懂 |
| 准录入 | 必填完整、格式合规、避免无效非法数据 |
| 强引导 | 动态提示、分步流程、错误即时反馈、问题可追溯 |
| 统一化 | 组件样式、交互逻辑、提示文案、布局排版统一 |

## 3. AI 自动选择页面结构决策树

```text
if 无需按顺序填写：
   if 仅单一维度 → 线性结构-不分组
   if 多维度需分类 → 线性结构-分组

if 必须按顺序填写：
   if 存在动态显示 / 隐藏 / 切换 → 条件可见结构
   if 需前后对照查看 → 单页面步骤结构
   if 无需前后对照 → 多页面步骤结构
```

## 4. 五大表单结构模板

| 模板名称 | 启用条件 | 典型业务场景 |
|---|---|---|
| 线性结构-不分组 | 单一维度、无分组、可乱序填写 | 基础信息上报、简单表单 |
| 线性结构-分组 | 多维度、可分组、可乱序填写 | 服务器配置、系统基础设置 |
| 条件可见结构 | 开关 / 单选 / 复选控制内容显隐 / 切换 | 告警配置、通知方式、规则类型选择 |
| 单页面步骤结构 | 强顺序 + 需前后对照查看 | 分析规则、处置策略配置 |
| 多页面步骤结构 | 强顺序 + 无需前后对照 | 账号注册、服务开通、复杂流程 |

### 4.1 线性结构-不分组

- 所有录入项同级垂直排列。
- 无分组标题、无步骤导航、无动态显隐、无关联联动。
- 按业务常规逻辑和常用填写顺序依次展示。
- 必填项强制标注 `*`，星标紧跟字段标题后方。
- 支持用户任意顺序填写，提交时统一校验。

### 4.2 线性结构-分组

- 按业务维度、功能模块拆分分组。
- 层级最多 2 级，禁止超过 3 级。
- 组内可乱序填写，组与组之间无强制依赖。
- 分组标题加粗突出，组间间距统一。
- 不可跨组混搭排布字段。

### 4.3 条件可见结构

- 由开关、单选框、复选框作为触发控件。
- 未满足触发条件时，关联配置模块默认隐藏，不占用页面布局。
- 切换选项后，对应模块即时刷新，界面不得抖动或错乱。
- 隐藏模块不参与前端实时校验，激活显示后再开启校验规则。
- 禁用选项置灰，hover 必须提示禁用原因。

### 4.4 单页面步骤结构

- 固定步骤流程，禁止跳跃步骤。
- 全程单页面展示，上下滚动查看所有步骤。
- 顶部固定步骤导航，当前步骤高亮，未完成步骤置灰不可编辑。
- 支持前后配置内容对照查看。
- 修改前置步骤导致后续模块数据清空时，必须弹出二次确认。

### 4.5 多页面步骤结构

- 每一步为独立页面，每页只展示当前步骤内容。
- 底部固定「上一步 / 下一步」操作按钮。
- 步骤间无需对照查看，内容相互独立。
- 当前页所有校验通过后，下一步按钮才可点击，否则置灰禁用。
- 返回修改上一步内容且影响后续数据时，必须二次确认。

## 5. 录入组件与校验规则

### 5.1 通用全局规则

1. 必填项未填写，输入框失焦即时提示：`请输入{字段名称}`。
2. 输入格式不符合要求，失焦即时提示：`格式错误，请输入{格式要求}`。
3. 所有错误提示固定展示在输入框正下方，靠左对齐，红色标注。
4. 全局操作提示顶部居中展示，默认停留 3 秒，自动关闭，文案不超过 50 字。
5. 输入框禁止非法字符自动过滤，不符合规则的内容无法录入。

### 5.2 输入框类型标准

| 输入类型 | 规则 |
|---|---|
| 普通输入框 | 字符超限无法继续录入；文本域随内容自动增高，必要时带滚动条 |
| 数字输入框 | 仅允许录入数字，自带上下调节箭头，超出范围自动修正为边界值 |
| IP 输入框 | 4 段式拆分输入，单段输满 3 位自动跳转，粘贴完整 IP 自动填充，数值 0–255 |
| 手机号输入框 | 仅限 11 位数字，超出不录入，自动校验手机号号段格式 |
| MAC 地址 | 固定格式 `XX:XX:XX:XX:XX:XX`，非法字符直接拦截 |
| MD5 | 仅限 32 位英文 + 数字，禁止中文、特殊符号，超长拦截 |
| 身份证 | 15 / 18 位，支持末尾大写 X，自动校验地址、生日合规格式 |
| 密码 | 支持明文 / 密文切换；高密级场景不暴露密码规则 |

### 5.3 选择类组件标准

- 单选 / 复选框：不可用选项置灰禁用，hover 提示原因，选中状态高亮统一。
- 下拉选择器：单选选中后自动关闭弹窗。
- 多选下拉：选中项展示为标签，超出数量用数字角标展示，支持一键清除。
- 选择器默认无选中值，禁止默认选中非法选项。
- 默认占位文案遵循表单控件规范。

## 6. 信息密度规范

| 字段数量 | 处理规则 |
|---|---|
| 单屏可见字段数 ≤ 8 | 保持舒适录入密度 |
| 字段数 > 12 | 必须按业务维度分组 |
| 字段数 > 20 | 必须采用步骤化结构 |
| 高频字段 | 优先放在首屏 |
| 低频高级配置 | 默认折叠展示，用户主动展开 |

## 7. 布局栅格规范

- 标题与输入框优先采用同行组合，提升空间利用率。
- 内容较少时，标题与输入框可垂直排列，保持结构清晰。
- 内容较多时，短文本输入项可采用 2 到 3 列栅格排布。
- 长文本，如文本域、备注，必须独占一行。
- 所有输入框需左右垂直对齐。
- 标题统一右对齐。
- 标题占位宽度保持一致，避免布局抖动。
- 标题字数控制在 8 字以内。
- 复杂标题可增加注解 icon，点击 icon 展示详细解释，不占用标题空间。

## 8. 表单状态体系

### 8.1 草稿态

表单未完成填写，可自由编辑、修改，无锁定限制，未提交至审核或发布流程。

### 8.2 审核中

表单已提交，处于审核流程中。页面为只读状态，不可编辑、不可修改任何内容。

### 8.3 已发布

表单已审核通过并发布，页面部分锁定。如需编辑，需先判断修改影响范围；影响较大时，需要增加“取消发布”操作，取消发布后才可编辑。

### 8.4 脏状态

表单内容已变更但未保存，此时触发离开页面、跳转、关闭等操作时，必须弹出提示。

固定文案：

```text
标题：确定离开当前页面吗？
说明：离开后已配置内容将被清除请谨慎操作
```

### 8.5 自动保存中

自动保存可通过定时、输入框失焦、输入停顿三种方式触发。

优先采用异步自动保存：发送请求后即放行，页面可继续操作，不阻塞用户行为。若业务要求同步保存，则同步期间页面不可操作，并展示阻塞状态。

## 9. 操作优先级体系

| 操作类型 | 样式 | 规则 | 常见文案 |
|---|---|---|---|
| 主操作 | 品牌色实心按钮 | 页面内仅可存在 1 个 | 保存、发布、应用、保存并启用、提交、上报 |
| 次操作 | 品牌色描边按钮 | 可根据业务设置 1–2 个 | 仅保存 |
| 其他操作 | 无品牌色辅助按钮 | 用作主次操作补充 | 取消、保存草稿 |
| 低频操作 | 文字按钮或链接 | 跳转关联页面或辅助配置 | 查看配置、关联设置 |

规则：

- 当页面存在“保存并启用”主操作时，次操作固定显示为“仅保存”。
- 默认不显示清空、删除操作；如业务需要，需说明影响并增加确认。
- 禁止一个表单页面出现多个主操作。

## 10. 提示文案与符号规范

### 10.1 全局提示文案

| 场景 | 模板 |
|---|---|
| 操作成功，无后续 | `{操作}成功` |
| 操作成功，带跳转 | `{操作}成功，可前往【路径】查看` |
| 操作失败 | `{操作}失败，{原因}，{解决方案}` |
| 输入错误 | `{字段}{问题}，请重新输入` |

### 10.2 符号规范

| 用途 | 符号 |
|---|---|
| 目录层级分隔 | `>` |
| 页面 / 功能模块 | `【】` |
| 按钮 / 操作指令 | `「」` |
| 变量占位符 | `{}` |

全文符号必须统一，禁止混用或自创格式。

## 11. AI 生成页面强制输出标准

AI 生成任何 B 端表单页面，必须完整包含：

1. 页面结构类型，五大模板五选一，禁止自创。
2. 分组规划 / 步骤流程规划，层级清晰。
3. 完整录入项清单，包括字段名称、是否必填、对应组件类型。
4. 专项校验规则，包括为空校验、格式校验、数值范围校验。
5. 条件显隐触发逻辑和关联模块，有联动场景必填。
6. 步骤流转和前后关联逻辑，步骤类表单必填。
7. 底部操作按钮，包括确定、取消、上一步、下一步等。
8. 全套提示文案，包括默认占位、错误提示、操作成功提示。

## 12. 标准实践模板

### 12.1 线性结构-不分组实践

适用于日常基础信息上报、人员信息登记、简单数据填报、基础台账录入。页面全屏单列垂直排布，无分组、无模块拆分，字段依次排列，必填字段标 `*`，无联动、显隐、步骤逻辑。

### 12.2 线性结构-分组实践

适用于系统基础配置、服务器参数配置、设备信息配置、后台基础设置。按功能拆分为 2 级分组，每组独立区块，标题加粗区分，组内字段平铺排布，组间距统一。

### 12.3 条件可见结构实践

适用于告警策略配置、通知方式选择、规则类型切换、参数开关配置。顶部放置开关 / 单选 / 复选触发控件，下方默认隐藏对应配置模块，选中对应选项后展示专属配置项。

### 12.4 单页面步骤结构实践

适用于数据分析规则配置、风险处置策略配置、复杂流程参数配置。单页面顶部步骤导航，全程不跳转新页面，滚动展示所有步骤，前置步骤完成后解锁后续步骤。

### 12.5 多页面步骤结构实践

适用于企业账号注册、服务开通、资质认证、分步闭环复杂流程。每一步独立页面，只展示当前步骤内容，底部提供上一步、下一步按钮。

## 13. Vue 代码生成要求

Vue 代码必须包含：

- 页面结构类型声明。
- 表单模型类型定义。
- 字段配置清单。
- 必填项标识。
- 校验规则。
- 条件显隐逻辑。
- 步骤状态逻辑。
- 脏状态离开提示。
- 提交 loading。
- 成功 / 失败反馈。
- 禁用选项 hover 说明。
- 高风险配置二次确认。

## 14. HTML 预览文件要求

HTML 预览文件必须支持：

- 字段输入。
- 必填校验。
- 格式错误提示。
- 条件显隐切换。
- 步骤切换。
- 上一步 / 下一步。
- 提交 loading。
- 操作成功提示。
- 离开页面脏状态提示模拟。

## 15. AI 禁止行为

- 禁止自创页面结构、交互模板，只能使用五大标准模板。
- 禁止自创校验规则、输入限制规则。
- 禁止自创文案风格、语气、格式。
- 禁止随意跳跃步骤、无理由显隐模块、破坏流程逻辑。
- 禁止表单层级超过 3 级。
- 禁止错误提示模糊、缺失或无引导。
- 禁止更改组件样式、排布位置、提示展示位置。
- 禁止字段超过 12 个不分组。
- 禁止字段超过 20 个不步骤化。
- 禁止标题与输入框排布混乱或对齐不一致。
- 禁止审核中状态仍可编辑。
- 禁止脏状态离开无提示。
- 禁止一个页面出现多个主操作。
