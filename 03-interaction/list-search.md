# 列表搜索区交互规范
## List Search Interaction Rules

Keywords: list search, filter, query, search bar, backend

本文定义列表页搜索区和筛选区的布局、控件、按钮、展开收起和查询反馈规则。

## 1. 搜索区定位

搜索区用于缩小数据范围，不应比表格更抢眼，也不应占据过高首屏空间。

## 2. 基础结构

```text
关键词输入框 + 高频筛选项 + 时间范围 + 查询按钮 + 重置按钮 + 展开 / 收起
```

## 3. 布局规则

- 简单查询建议一行展示 3 到 5 个字段。
- 高频筛选项默认展示，低频筛选项放入展开区域。
- 字段过多时应支持展开 / 收起。
- 查询按钮和重置按钮应放在搜索项末尾。

## 4. 交互规则

点击查询后刷新表格数据。点击重置后清空所有查询条件，并刷新表格。搜索中应展示 loading。搜索无结果时展示空状态，并提示调整筛选条件。
