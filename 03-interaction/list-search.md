# 列表页搜索栏区域交互规范
## List Page Search Bar Interaction Rules

Keywords: list search, filter, query, search bar, layout, responsive, backend

本文定义列表页搜索栏区域的容器、搜索项、占位文案、操作按钮、换行和响应式规则。AI 生成列表页、Vue 代码或 HTML 预览文件时，必须遵循本文。

## 1. 搜索区定位

搜索区用于帮助用户缩小数据范围，提高查找效率。搜索区不应比表格更抢眼，也不应占据过高首屏空间。

搜索区通常位于页面标题区下方、表格区域上方。

## 2. 整体容器规范

| 项目 | 规则 |
|---|---|
| 默认背景 | 纯白色 |
| 容器宽度 | 铺满外部内容容器 |
| 圆角 | 8px |
| 内边距 | 上下左右 24px |
| 内部垂直间距 | 20px |
| 内部水平间距 | 32px |
| 响应式 | 横向拉伸时元素间距相对固定；横向收缩空间不足时搜索项自动换行 |

## 3. 搜索项通用布局

所有搜索项均采用：

```text
标题 + 输入控件
```

标题与输入控件横向组合，并垂直居中对齐。

### 3.1 单个搜索项尺寸

| 项目 | 规则 |
|---|---|
| 标题与输入控件间距 | 8px |
| 输入控件最小宽度 | 200px |
| 输入控件最大宽度 | 260px |
| 输入控件宽度 | 同一页面内保持一致 |
| 标题最大字数 | 8 个汉字 |
| 标题最大宽度 | 112px，基于 14px 字号 |
| 标题对齐 | 右对齐 |
| 搜索项垂直对齐 | 标题与输入控件垂直居中 |

### 3.2 多行搜索项对齐规则

- 多行搜索项布局时，所有标题宽度统一以字数最多的标题宽度为标准宽度进行约束。
- 单行搜索项布局时，标题宽度可自适应，无需额外对齐约束。
- 纵向单列布局时，标题与输入控件宽度整体对齐。
- 标题过长时，应优先优化字段命名，不建议强行展示长标题。

## 4. 占位文案规范

| 控件类型 | 默认占位文案 | 补充说明 |
|---|---|---|
| 输入类控件 | 请输入 | 如需补充说明，在逗号后追加，例如“请输入，支持模糊搜索” |
| 下拉选择类控件 | 请选择 | 如需补充说明，在逗号后追加，例如“请选择，支持多选” |
| 日期 / 时间范围 | 请选择 | 可根据业务改为“开始时间 / 结束时间” |

占位文案过长时，单行省略展示，鼠标悬停通过 Tooltip 展示完整内容。

## 5. 操作按钮规范

| 按钮 | 样式 | 固定文案 | 说明 |
|---|---|---|---|
| 搜索按钮 | 主按钮 | 搜索 | 触发查询并刷新列表 |
| 清空按钮 | 辅助按钮 | 清空 | 清空所有搜索条件并刷新列表 |

按钮组规则：

- 按钮组整体右对齐。
- 按钮组跟随最后一行搜索项布局。
- 按钮之间间距统一 8px。
- 搜索区内不要出现多个主按钮。
- 不建议将“重置”“查询”等近义文案混用，默认使用“搜索”“清空”。

## 6. 换行规则

- 所有搜索项从左至右依次排列。
- 单行空间无法容纳完整一组“标题 + 输入控件”时，整组自动换行。
- 操作按钮默认跟随最后一行搜索项。
- 若最后一行剩余空间不足，按钮可单独换行，但整体仍保持右对齐。
- 搜索项数量较少时，整体跟随容器宽度自适应排布。
- 禁止只让标题或输入控件单独换行，必须整组换行。

## 7. 查询交互规则

- 点击“搜索”后，刷新表格数据。
- 点击“清空”后，清空所有查询条件，并刷新表格数据。
- 搜索中应展示 loading。
- 搜索无结果时展示空状态，并提示用户调整筛选条件。
- 高级筛选展开 / 收起时，应保留用户已输入的查询条件。
- 默认不建议筛选项变化后立即查询，除非业务明确要求实时刷新。

## 8. Vue 代码生成要求

生成 Vue 代码时，必须包含：

- 搜索表单状态。
- 搜索方法。
- 清空方法。
- 表格数据刷新逻辑。
- loading 状态。
- 空结果状态。
- 输入控件宽度约束。
- 自动换行布局。

## 9. HTML 预览文件要求

HTML 预览文件必须支持：

- 输入关键词。
- 选择筛选项。
- 点击搜索刷新 mock 表格。
- 点击清空重置条件。
- 窄屏时搜索项自动换行。
- 搜索无结果时显示空状态。

## 10. AI 生成禁止项

- 禁止把搜索区做成大面积营销筛选卡片。
- 禁止让搜索区高度超过表格区域视觉重点。
- 禁止搜索项标题、输入框宽度混乱。
- 禁止按钮随意命名为“查询 / 重置 / 确认”等混合文案；默认使用“搜索 / 清空”。
- 禁止空间不足时把标题和输入控件拆开换行。

## 11. AI 生成强制验收清单

AI 生成列表页、HTML Demo 或 Vue 页面代码时，搜索区必须通过以下验收：

- [ ] 搜索区位于表格区域上方。
- [ ] 搜索项采用“标题 + 输入控件”结构。
- [ ] 输入控件宽度统一。
- [ ] 空间不足时搜索项整组换行。
- [ ] 输入类占位文案为 `请输入`。
- [ ] 选择类占位文案为 `请选择`。
- [ ] 操作按钮固定为 `搜索` / `清空`。
- [ ] 不使用 `查询` / `重置` / `确认` 等混合文案替代默认按钮文案。
- [ ] 点击搜索后刷新表格并展示 loading。
- [ ] 点击清空后清空条件并刷新表格。
- [ ] 搜索无结果时展示空状态。
- [ ] HTML Demo 中以上行为可被点击验证。

缺少任一适用项，视为搜索区生成失败。
