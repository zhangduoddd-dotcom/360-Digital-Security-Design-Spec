# 3Dicon 素材库

本目录是数据指标卡可使用的正式 3D 图标素材库。

使用规则：

- 仅允许在数据指标卡中使用。
- 只能引用本目录中已经存在的图片。
- 不允许自行绘制、生成、拼接、改色、裁切成新图标或替换为其他来源素材。
- 图标在指标卡中固定显示为 `40px × 40px`。
- 选图先查 `INDEX.md`，索引只维护名称和分组，不定义新素材。
- 完整组件规范见 `Basic UI component style/component-styles/data-metric-card.md`。

普通菜单、按钮、表格、状态和空状态图标继续使用 `Basic UI component style/component-styles/icon.md` 与 `assets/iconfont/`。
