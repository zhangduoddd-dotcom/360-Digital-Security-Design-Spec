# 后台管理系统页面容器搭建规范
## Background Management System Page Container Rules

Keywords: background system, page construction, layout structure, top navigation, sidebar, content container, html demo

本文定义后台管理系统页面的基础容器结构。AI 生成页面 HTML Demo 或 HTML 预览文件时，必须遵循「顶部导航栏 + 左侧边栏 + 主内容区」的三层嵌套结构，并优先继承指定 HTML 母版。

## 1. 整体结构

标准后台页面采用：

```text
全屏外层容器
→ 顶部单行导航栏
→ 下方主体区域
   → 左侧边栏
   → 主内容区
```

整体使用 Flex 水平 + 垂直嵌套布局。业务内容只允许进入母版指定的业务内容区。

## 2. 三大容器

| 模块 | 尺寸 / 定位 | 容器规则 |
|---|---|---|
| 顶部导航栏 | 高度固定 56px，宽度 100% | 深色背景，左侧品牌区，中间状态信息，右侧用户与功能区 |
| 左侧边栏 | 展开 184px，收起 56px，高度 100% | 白色背景，垂直菜单，支持二级选中和收起态浮层 |
| 主内容区 | 剩余宽高自适应 | 承载页面标题区、内容容器和业务模块 |

## 3. 顶部导航栏

顶部导航栏必须：

- 高度固定 56px。
- 宽度 100%。
- 内部元素垂直居中。
- 保持品牌、状态、功能、用户区的稳定位置。
- 不随业务内容变化挤压变形。

典型结构：

| 区域 | 内容 |
|---|---|
| 左侧 | Logo + 系统名称 + 本级中心下拉 |
| 中间 | 安全状态或运行状态提示 |
| 右侧 | 可视化入口、通知、设置、安全入口、用户头像 / 账号下拉 |

## 4. 左侧边栏

左侧边栏必须：

- 展开宽度固定 184px。
- 收起宽度固定 56px。
- 高度 100%。
- 使用白色背景。
- 支持垂直导航菜单。
- 支持当前菜单高亮。
- 支持收起态图标和级联浮层。
- 底部可固定版本号或辅助信息。

## 5. 主内容区

主内容区内部按以下结构排列：

```text
页面标题区
→ 内容容器
→ 业务子容器 / 业务模块
```

| 项目 | 规则 |
|---|---|
| 页面标题区 | 高度建议 48px，展示页面标题、返回入口、页级操作等 |
| 内容容器背景 | #F2F3F5 |
| 内容容器内边距 | 16px |
| 业务子容器背景 | #FFFFFF |
| 业务子容器圆角 | 8px |
| 业务子容器间距 | 16px |

页面标题应清晰表达当前对象和任务。页面级主操作可放在标题区右侧。

## 6. 页面类型组合

| 页面类型 | 主内容区常见组合 |
|---|---|
| 列表页 | 搜索区 + 工具栏 + 表格 + 分页 |
| 详情页 | 摘要区 + 信息分组 + 关联列表 / 操作记录 |
| 表单页 | 表单区 + 操作区 |
| 工作台 | 指标区 + 待办 / 风险区 + 图表 / 快捷入口 |

## 7. 响应式与滚动

- 顶部导航栏和左侧边栏尺寸固定，不随窗口缩放改变自身规格。
- 主内容区自适应窗口宽度。
- 主内容区内容过宽时显示水平滚动条。
- 顶部和侧边容器在横向滚动时不变形。
- 小屏或窄屏下，侧边栏可收起为 56px 图标态。

## 8. 弹窗与抽屉

弹窗、抽屉、浮层属于内容弹层，不替代主内容区。

- 高风险确认优先使用弹窗。
- 详情查看、轻量编辑、筛选配置可使用抽屉。
- 弹窗和抽屉必须有明确标题。
- 关闭前如有未保存内容，应提示用户确认。
- 弹层不应遮挡关键确认文案和主要操作按钮。

## 9. HTML Demo 要求

HTML Demo 必须能直接看出后台页面框架：

```text
顶部导航栏
+ 左侧边栏
+ 页面标题区
+ 内容容器
+ 业务子容器
```

必须优先继承固定 HTML 母版，不要只展示孤立表格、孤立表单或孤立卡片。

## 10. AI 生成禁止项

- 禁止缺少顶部导航栏。
- 禁止缺少左侧边栏。
- 禁止把主内容区做成纯白无层级页面。
- 禁止内容容器没有灰色背景和白色业务子容器。
- 禁止侧边栏宽度随内容随机变化。
- 禁止页面标题区高度和层级不稳定。
- 禁止只生成组件，不生成完整页面框架。

缺少任一框架关键结构，视为页面容器生成失败。
