# 列表页搜索与表格区域交互规范
## List Page Search and Table Interaction Rules

Keywords: list page, list search, filter, query, data overview, chart, table, toolbar, batch action, pagination, sorting, filtering, html demo

本文定义列表页中搜索区、数据概览图表区、工具栏、表格主体、操作列、分页、状态反馈以及搜索与表格联动的 HTML Demo 验收规则。AI 生成列表页 HTML Demo 或 HTML 预览文件时，必须遵循本文。

## 1. 整体定位

列表页用于帮助用户筛选、扫读、比较和处理结构化数据。搜索区用于缩小数据范围，表格区是主工作区；二者通常同时出现，并共同构成一个可查询、可操作、可反馈的数据闭环。

详情页、工作台或配置页中仅包含表格 / 列表模块时，也读取本文，并按实际出现的模块执行适用规则；未出现搜索区时，搜索区验收项不强制适用。

视觉上应保持轻量、克制、规整。搜索区不应比表格更抢眼，也不应占据过高首屏空间；表格区应优先保证数据可扫读、操作可判断、状态可反馈，不做营销卡片式装饰。

## 2. 标准结构

列表页标准结构：

```text
统一列表容器
├─ 顶部冻结区：搜索区 → 数据概览图表区（可选） → 工具栏 / 批量操作区 → 表格表头
├─ 可滚动内容区：数据行 / loading / empty / error 等状态内容
└─ 底部冻结区：分页区（仅正常非空数据态展示）

toast / confirm 等全局反馈（覆盖式 / 浮层，不占用列表容器结构）
```

- 搜索区、数据概览图表区、工具栏、表格主体和分页区合并在同一个统一列表容器内，不拆成多个独立白色容器。
- 统一列表容器内不额外预留表格标题、列表标题、表单名称或模块名称等内容；页面标题由母版页头承载。
- 搜索区通常位于统一列表容器顶部、工具栏上方。
- 数据概览图表区为可选模块，仅当页面需要展示与当前筛选条件联动的数据概览、趋势图、分布图或统计图时出现。
- 数据概览图表区通常位于搜索区下方、工具栏上方。
- 有搜索区且无数据概览图表区时，工具栏位于搜索区和表格主体之间；有数据概览图表区时，工具栏位于数据概览图表区和表格主体之间；无搜索区时，工具栏位于统一列表容器顶部、表格主体上方。
- 无数据概览需求时，不保留空图表区、空标题或额外间距。
- 表格主体承载表头、数据行、状态、操作列、排序和筛选。
- 表格主体正常加载并展示数据时，分页位于表格底部右对齐。
- loading、empty、error 等状态通常替换表格内容区，不与分页区同时展示；状态态一般保留表头，并隐藏分页区。
- toast、confirm 属于操作反馈层，不替代表格内容区，也不作为分页区后的固定页面结构。
- 搜索、数据概览图表、表头排序、表头列筛选、分页、批量操作均作用于同一份表格数据，并触发表格刷新反馈；清空仅清除搜索区条件，不触发表格刷新。

## 3. 统一列表容器与搜索区

### 3.1 容器与间距规则

| 项目 | 规则 |
|---|---|
| 背景 | #FFFFFF |
| 宽度 | 铺满外部内容容器 |
| 高度 / 布局 | 页面内容区可用高度 100% 自适应，内部按顶部冻结区 / 可滚动内容区 / 底部冻结区组织 |
| 容器内容 | 仅承载搜索区、数据概览图表区（可选）、工具栏 / 批量操作区、表格主体、分页区和状态内容，不额外增加表格标题、列表标题、表单名称或模块名称 |
| 圆角 | 8px |
| 内边距 | 24px，作为统一列表容器内所有区域的安全边距 |
| 内部区域宽度 | 搜索区、数据概览图表区、工具栏、表格主体、分页区和状态内容均在 24px 内边距安全区内左右铺满，不得贴住容器边缘 |
| 搜索项横向间距 | 32px |
| 搜索项纵向间距 | 16px |
| 响应式 | 空间不足时搜索项整组换行，禁止拆散标题和输入 / 选择控件 |
| 搜索区按钮间距 | 统一 8px |
| 搜索区与工具栏纵向间距 | 16px，无数据概览图表区时适用 |
| 工具栏左侧 / 右侧按钮间距 | 统一 8px |
| 工具栏与表格主体纵向间距 | 16px |
| 表格主体与分页区纵向间距 | 8px |

### 3.2 自适应与冻结规则

- 统一列表容器在页面内容区内自适应布局，宽度铺满外部内容容器，高度按内容区可用高度 100% 自适应。
- 搜索区、数据概览图表区、工具栏、表格主体、分页区和状态内容必须共同遵守统一列表容器 24px 内边距，在安全区内左右铺满，视觉上保持对齐和留白。
- 纵向滚动时，统一列表容器内部只有表格主体内容区响应滚动；搜索区、数据概览图表区、工具栏和表格表头保持顶部冻结。
- 正常非空数据态下，分页区保持底部冻结；loading、empty、error 等状态态下隐藏分页区。
- loading、empty、error 等状态内容展示在表格主体内容区内，不生成独立状态卡片，也不挤占搜索区、数据概览图表区、工具栏或分页区位置。
- 横向滚动时，只有表格主体内容区响应横向滚动；搜索区、数据概览图表区、工具栏和分页区不参与横向滚动。
- 表格列较多时，按表格主体首列规则固定左侧关键列；如存在操作列，操作列固定在右侧。
- 横向滚动时必须保证表头与数据列对齐，固定列与滚动内容之间层级清晰。

### 3.3 搜索项布局

所有搜索项采用：

```text
标题 + 输入 / 选择控件
```

- 标题与输入 / 选择控件横向组合，并垂直居中。
- 标题与输入 / 选择控件间距为 8px。
- 输入 / 选择控件默认宽度保持统一，建议 200px-260px。
- 标题建议不超过 8 个汉字；多行搜索区内标题宽度以最长标题对齐。
- 标题过长时优先优化字段命名，不建议强行展示长标题。

### 3.4 占位文案

| 控件类型 | 默认占位文案 | 补充说明 |
|---|---|---|
| 输入类 | `请输入` | 可追加业务说明，例如 `请输入，支持模糊搜索` |
| 选择类 | `请选择` | 多选、树选、级联选择仍使用该前缀 |
| 日期 / 时间范围 | `请选择` | 可按业务展示为开始时间 / 结束时间 |

占位文案过长时单行省略，hover 通过 Tooltip 展示完整内容。

### 3.5 操作按钮

| 按钮 | 样式 | 固定文案 | 说明 |
|---|---|---|---|
| 搜索 | 主按钮 | `搜索` | 触发查询并刷新表格 |
| 清空 | 辅助按钮 | `清空` | 仅清空搜索区条件，不刷新表格 |

规则：

- 按钮组跟随最后一行搜索项，并整体右对齐。
- 按钮间距统一 8px。
- 搜索区内不出现多个主按钮。
- 默认使用 `搜索 / 清空`，不要混用 `查询 / 重置 / 确认` 等近义文案。

### 3.6 换行规则

- 搜索项从左至右依次排列。
- 单行空间不足以容纳完整一组“标题 + 输入 / 选择控件”时，整组换行。
- 操作按钮默认跟随最后一行；若空间不足，按钮可单独换行但仍右对齐。
- 搜索项数量较少时整体跟随容器自适应排布。

### 3.7 查询联动

- 点击 `搜索` 后按搜索区当前筛选条件刷新表格数据，页码重置到第 1 页，并展示 loading。
- 点击 `清空` 后仅清空搜索区输入 / 选择条件，不触发表格刷新，不重置页码，不清空表头筛选或排序。
- 清空搜索区后，列表当前已生效筛选条件保持不变，直到下一次点击 `搜索`。
- 清空搜索区后，如需按清空后的筛选条件更新列表，必须再次点击 `搜索`。
- 搜索无结果时保留表头，表格内容区展示 empty，并提示用户调整筛选条件。
- 存在高级筛选展开 / 收起时，必须保留用户已输入条件。
- 搜索区条件变化不立即查询，必须点击 `搜索` 触发表格刷新。
- 搜索区条件与表头筛选、表头排序分区管理，互不默认清除。

### 3.8 数据概览图表区

当列表页需要在搜索区下方展示数据概览、统计图表、趋势图、分布图或风险概览时，可增加数据概览图表区。该区域用于帮助用户在进入表格明细前，先快速理解当前筛选条件下的数据分布和数量变化。

#### 3.8.1 使用场景

数据概览图表区适用场景：

- 搜索条件会影响图表中的数量、比例、趋势或分布。
- 用户需要先通过图表理解当前筛选结果，再查看下方表格明细。
- 页面存在风险数量、状态分布、类型占比、趋势变化、命中数量等概览信息。
- 图表与表格展示的是同一批筛选结果的不同视角。

数据概览图表区不适用场景：

- 仅为了装饰页面而增加图表。
- 图表数据与搜索条件、表格数据无明确关系。
- 页面首屏空间紧张，图表会明显挤压表格主工作区。
- 普通列表页没有概览分析诉求时，不强制增加图表区。

#### 3.8.2 位置与结构

数据概览图表区位于搜索区下方、工具栏上方。

结构如下：

```text
搜索区
分割线
数据概览图表区标题行
数据概览图表内容区
分割线
工具栏 / 批量操作区
表格主体
```

数据概览图表区由两部分组成：

```text
向上收起 / 向下展开 icon + 标题
下方数据图表
```

规则：

- 标题行必须展示明确标题，例如 `数据概览`、`风险概览`、`告警趋势`、`资产分布`。
- 展开态下，标题行展示向上收起 icon，标题下方展示数据图表。
- 收起态下，标题行展示向下展开 icon，仅保留标题行，不展示图表内容。
- 展开 / 收起操作不得清空搜索条件、表格数据、排序、筛选或分页状态。
- 收起后再次展开，应恢复当前筛选条件下的图表数据。

#### 3.8.3 高度规则

| 状态 | 高度规则 |
|---|---|
| 展开态 | 整体高度控制在 240px-300px 以内 |
| 收起态 | 仅保留标题行高度，不保留图表内容高度 |
| 小屏 / 内容较多 | 优先压缩图表内容，不得挤压表格主体为不可用状态 |

规则：

- 图表区展开态高度不得超过 300px。
- 图表内容较多时，应优化图表数量或图表密度，不得通过无限增高图表区解决。
- 图表区不应成为页面主工作区，表格仍然是列表页的主要操作区域。
- 不建议在图表区内部出现纵向滚动；如图表内容过多，应减少图表数量或改为更高层级的分析页。

#### 3.8.4 查询联动规则

数据概览图表区必须与搜索区、表格数据保持同源联动。

- 点击 `搜索` 后，图表区与表格同时按当前搜索条件刷新。
- 图表中的数量、比例、趋势、分布必须反映当前已生效筛选条件。
- 搜索后页码重置到第 1 页，图表同步进入 loading 状态。
- 点击 `清空` 后，仅清空搜索区条件，不立即刷新图表，也不刷新表格。
- 清空后如需按清空条件更新图表和表格，必须再次点击 `搜索`。
- 表头筛选、表头排序、分页等只影响表格展示时，不默认改变图表统计口径；如业务要求图表同步受表头筛选影响，必须在页面规则中明确说明。
- 图表为空时，应展示轻量 empty 状态，不得删除整个图表区结构导致页面跳动。

#### 3.8.5 分割线与间距规则

筛选区、数据概览图表区、工具栏 / 表格区之间必须使用轻量分割线建立层级关系。

分割线规则：

- 搜索区与数据概览图表区之间使用一条分割线。
- 数据概览图表区与工具栏 / 表格区之间使用一条分割线。
- 分割线宽度必须与统一列表容器内容区等宽。
- 分割线左右两侧必须与统一列表容器保持同样的 24px 安全边距。
- 分割线不得贴住容器左右边缘。
- 分割线不得做成整屏通栏，也不得超出统一列表容器内容区。
- 分割线颜色应轻量克制，不得使用高强调颜色。

视觉对齐规则：

```text
统一列表容器宽度
┌──────────────────────────────┐
│  24px                        │
│  搜索区内容                   │
│  ─────────────────────────   │ ← 分割线与内容区等宽
│  数据概览图表区               │
│  ─────────────────────────   │ ← 分割线与内容区等宽
│  工具栏 / 表格主体            │
│                        24px  │
└──────────────────────────────┘
```

#### 3.8.6 展开 / 收起交互规则

- 点击标题行或展开 / 收起 icon，可切换图表区展开状态。
- 展开 / 收起 icon 必须与当前状态一致。
- 展开态使用向上收起 icon。
- 收起态使用向下展开 icon。
- 鼠标 hover 标题行时，应有轻量可点击反馈。
- 展开 / 收起状态切换应保持平滑，不得造成页面明显跳动。
- 收起图表区后，工具栏和表格主体应自然上移。
- 展开图表区后，工具栏和表格主体应自然下移，但不得破坏统一列表容器内部结构。

### 3.9 弹出层层级与对齐

- 统一列表容器内如出现下拉选择、日期选择、列筛选弹层、更多菜单、字段配置、Tooltip 等弹出内容，弹出层必须展示在页面最上层可视区域。
- 弹出层根据触发控件自动匹配左对齐或右对齐；靠近右侧边界时优先右对齐，靠近左侧边界时优先左对齐。
- 弹出层不得被搜索区、数据概览图表区、工具栏、冻结表头、表格内容区、分页区或容器 overflow 裁切遮挡。
- 弹出层不得超出屏幕可视区域；空间不足时应自动调整方向、对齐方式或最大高度，并在弹层内部滚动。

## 4. 工具栏

有搜索区且无数据概览图表区时，工具栏位于搜索区下方、表格主体上方；有数据概览图表区时，工具栏位于数据概览图表区下方、表格主体上方；无搜索区时，工具栏位于统一列表容器顶部、表格主体上方。工具栏分为左侧操作区和右侧辅助区。

| 区域 | 内容 | 规则 |
|---|---|---|
| 左侧 | 新建、导入、导出、启用、停用、删除 | 承担高频新增操作和针对勾选项的数据操作 |
| 右侧 | 导出全部、字段配置、刷新、规则配置 | 承载全局辅助能力 |

规则：

- 左侧按钮间距统一 8px，右侧按钮间距统一 8px。
- `新建`、`导入` 放在左侧操作区最前面，保持默认状态，不依赖表格行勾选。
- `新建` 放在左侧最前，通常使用主按钮样式。
- 当没有 `新建` 且存在 `导入` 时，`导入` 可使用主按钮样式。
- 当同时存在 `新建` 和 `导入` 时，`导入` 仅可使用辅助按钮样式。
- `导出`、`启用`、`停用`、`删除` 等针对勾选项的数据操作根据操作优先级依次排列在左侧操作区，均使用辅助按钮样式。
- 不依赖表格行勾选项的操作按钮均放在右侧辅助区，使用辅助按钮样式。
- 未勾选表格数据时，针对勾选项的数据操作按钮为 disabled，并通过 Tooltip 说明原因。
- 勾选表格数据后，`导出`、`启用`、`停用`、`删除` 等针对勾选项的数据操作按钮从 disabled 恢复为默认可点击状态。
- `已选 N 项` 位于左侧操作区内，放在操作按钮的最后边，仅作为选中数量文本提示，不做成按钮或高强调标签。
- 左侧 `导出` 默认导出已勾选的数据；右侧 `导出全部` 默认导出当前已生效搜索条件、表头筛选和排序共同作用后的全部结果，不等同于仅导出当前页。
- 如果同时存在左侧 `导出` 和右侧 `导出全部`，必须通过 Tooltip 或按钮辅助说明区分 `导出已选数据` 与 `导出当前筛选结果全部数据`。
- 右侧 `导出全部`、`字段配置`、`刷新`、`规则配置` 等全局辅助能力均使用辅助按钮样式。
- 工具栏空间不足时，左侧操作区必须优先保留 `新建`、`导入`；针对勾选项的数据操作可保留 1-2 个高频操作，其余收纳到 `更多`。
- 右侧辅助区空间不足时，优先保留 `字段配置`，其余全局辅助操作收纳到 `更多`。

## 5. 表格主体

| 项目 | 规则 |
|---|---|
| 表头 | 浅灰背景，字段名称清晰；空数据和状态态仍保留表头；纵向滚动时保持顶部冻结；表头文本单行展示 |
| 行高 | 表头和普通行默认 40px |
| 单元格 | 高密度信息保持足够 padding，不拥挤；单元格文本单行展示 |
| 空值 | 统一显示 `-` |
| 空数据 | 保留表头，表格内容区显示空数据占位图标和提示文案 |
| 时间 | 使用 `YYYY-MM-DD HH:MM:SS` |
| 超长文本 | 表头和单元格均单行省略，hover 展示 Tooltip |
| 行 hover | 整行高亮 |
| 纵向滚动 | 仅表格主体内容区滚动，搜索区、数据概览图表区、工具栏、表格表头和分页区按状态冻结 |
| 多列场景 | 仅表格主体内容区支持横向滚动 |
| 首列 | 存在勾选列时，勾选列固定在最左侧，首个关键识别业务列紧随其后并固定；无勾选列时，首个关键识别业务列固定在最左侧 |
| 操作列 | 如有操作列，默认固定在最右侧 |

## 6. 列类型、排序与筛选

常见列类型必须按语义表达：

- 文本列：展示名称、编号、IP、账号等可识别信息。
- 状态列：使用状态标签或状态点，颜色和文字同时表达。
- 时间列：统一格式，不混用短日期与长日期。
- 数字列：右对齐或按业务统一对齐，单位明确。
- 风险列：使用标准风险等级文案和颜色。
- 操作列：只放与当前行直接相关的操作。

列拆分规则：

- 表头和单元格内容均按单行文本处理，禁止在一个单元格内生成上下两行信息样式。
- 如果需求原型把多个业务字段放在一个单元格内换行展示，AI 必须按字段语义拆成多列。
- 例如原型中一列同时展示 `姓名 / 工号`，且在单元格内上下行排布时，应拆成 `姓名`、`工号` 两列。
- 不得为了贴近原型而创造头像 + 主副标题、标题 + 描述、上下两行文本等复合单元格样式，除非组件库和当前业务规范显式定义了该列类型。

排序与筛选规则：

- 支持排序的列必须有明确排序图标。
- 排序状态包括升序、降序、取消排序。
- 当前排序方向需要高亮。
- 支持列筛选的列必须有筛选入口。
- 筛选弹层包含筛选项、确定、重置。
- 存在生效筛选条件时，筛选图标高亮。
- 表头筛选和表头排序与搜索区条件分区管理，搜索区 `清空` 不清除表头筛选或表头排序。
- 表头筛选和表头排序为失焦执行：完成选择、输入、排序方向切换，或关闭弹层并离开触发控件后刷新表格数据，页码重置到第 1 页，并展示 loading。
- 表头筛选和表头排序不因选项变化实时刷新，必须在交互完成并失焦后执行。

## 7. 行操作与批量操作

### 7.1 行操作

| 场景 | 规则 |
|---|---|
| 操作数量 <= 3 | 直接展示 |
| 操作数量 > 3 | 前 2 个直接展示，其余折叠到 `更多` |
| 高风险操作 | 必须二次确认 |
| 操作不可用 | disabled + Tooltip 说明原因 |
| 操作完成 | Toast / Message 反馈成功或失败 |

行操作应固定在最右侧操作列，不要散落在其他列中。

### 7.2 批量操作

- 勾选列位于表格最左侧。
- 支持全选、单选、跨页选择时需要说明范围。
- 已选数量实时更新。
- 未勾选时，`导出`、`启用`、`停用`、`删除` 等针对勾选项的数据操作按钮禁用。
- 勾选后，针对勾选项的数据操作按钮恢复默认可点击状态，并展示 `已选 N 项`。
- 批量删除、停用、还原等高风险操作必须二次确认。
- 批量操作成功或失败后刷新表格并给出反馈。

## 8. 分页

| 项目 | 规则 |
|---|---|
| 默认每页 | 20 条 |
| 可选条数 | 10 / 20 / 50 / 100 |
| 位置 | 表格底部右对齐 |
| 总数 | 非空数据时必须展示 |
| 空数据 | 保留表头，表格内容区展示 empty，固定隐藏分页器 |

分页必须支持页码切换和每页条数切换，并触发表格刷新。仅当表格主体处于正常数据态且存在非空数据时展示分页；loading、empty、error 等状态态下隐藏分页区。

## 9. 状态与反馈

列表页必须覆盖以下状态：

- loading：搜索、数据概览图表刷新、表头排序、表头筛选、分页、批量操作期间展示。
- empty：无数据时保留表头，表格内容区显示空数据占位图标和提示文案，并隐藏分页器。
- error：加载失败时保留表头，表格内容区展示错误原因和重试入口，并隐藏分页器。
- disabled：无权限或条件不足时禁用并说明原因。
- success / failure：操作完成后给出 Toast / Message 反馈。
- confirm：删除、停用、覆盖、还原等高风险操作必须确认。

规则：

- loading、empty、error 等状态内容替换表格内容区，不追加在分页区之后。
- loading、empty、error 状态下保留表头，隐藏分页区。
- loading 状态不保留旧数据行，不在旧数据上叠加遮罩。
- 初始无数据时 empty 文案使用 `暂无数据`。
- 搜索无结果时 empty 文案使用 `暂无匹配数据，请调整筛选条件`。
- 正常数据态恢复后重新展示数据行；存在非空数据时展示分页区。
- Toast / Message 和 confirm 是覆盖式或浮层反馈，不改变表格区域的结构层级。

## 10. HTML Demo 要求

交互适用层级：

- 分页、loading、empty、error 是列表页默认能力。
- 搜索区按页面是否存在搜索条件决定；无搜索条件时，统一列表容器顶部直接从工具栏开始，不保留空搜索区或搜索区间距。
- 数据概览图表区按页面是否存在概览分析诉求决定；无概览分析诉求时，不保留空图表区、空标题或图表区间距。
- 表头排序、列筛选、勾选、批量操作、行操作、导入、导出和更多菜单按当前业务是否提供对应字段或操作决定，不得为了凑交互而强行添加业务无关能力。

HTML Demo 必须按当前业务适用项支持点击验证：

- 输入关键词。
- 选择筛选项。
- 点击 `搜索` 按搜索区条件刷新 mock 表格，并重置到第 1 页。
- 点击 `清空` 仅清空搜索区条件，不刷新 mock 表格。
- 当页面存在数据概览图表区时，必须支持展开 / 收起点击验证。
- 点击 `搜索` 后，图表区数据与表格数据同步按当前搜索条件刷新。
- 图表区展开态高度控制在 240px-300px 以内。
- 图表区收起态仅保留“向上收起 / 向下展开 icon + 标题”标题行。
- 搜索区、图表区、工具栏 / 表格区之间的分割线必须与统一列表容器内容区等宽，并保持左右 24px 安全边距。
- 窄屏时搜索项整组换行。
- 表头排序切换后失焦执行刷新。
- 列筛选弹层打开、确定、重置，并在失焦后执行刷新。
- 行勾选与 `已选 N 项` 联动。
- 批量按钮禁用 Tooltip。
- 左侧 `导出` 与右侧 `导出全部` 的导出范围区分。
- 行 hover 高亮。
- `更多` 菜单展开。
- 工具栏空间不足时左侧和右侧操作按规则收纳到 `更多`。
- 分页切换和每页条数切换。
- 删除或停用二次确认。
- Toast 成功 / 失败反馈。
- loading、empty、error 状态切换。
- 统一列表容器内的纵向冻结和横向冻结效果。
- 下拉选择、列筛选、更多菜单、字段配置等弹出层不被遮挡、不出屏，并自动匹配左 / 右对齐。

## 11. AI 生成禁止项

- 禁止把搜索区做成大面积营销筛选卡片。
- 禁止把搜索区和表格区拆成两个独立白色容器。
- 禁止将数据概览图表区拆成独立白色卡片，破坏统一列表容器结构。
- 禁止为了装饰页面强行增加与搜索条件和表格数据无关的数据图表。
- 禁止在无概览分析诉求时保留空图表区、空标题或图表区间距。
- 禁止图表区高度超过 300px，导致表格主体被明显挤压。
- 禁止图表区收起后仍保留空白图表高度。
- 禁止图表数据与搜索条件、表格数据不同步。
- 禁止搜索区、图表区、工具栏 / 表格区之间的分割线贴住容器边缘或做成整屏通栏。
- 禁止在统一列表容器内额外增加表格标题、列表标题、表单名称、模块名称或类似占位标题。
- 禁止表格主体、表头、分页区、搜索区、数据概览图表区或工具栏贴住统一列表容器左右边缘。
- 禁止为了撑满视觉宽度而忽略统一列表容器 24px 内边距。
- 禁止无搜索条件时保留空搜索区或空白搜索区间距。
- 禁止让搜索区高度超过表格区视觉重点。
- 禁止搜索项标题、输入框宽度混乱。
- 禁止按钮文案混用 `查询 / 重置 / 确认` 替代默认 `搜索 / 清空`。
- 禁止点击 `清空` 时刷新表格、重置分页、清除表头筛选或清除表头排序。
- 禁止空间不足时把标题和输入 / 选择控件拆开换行。
- 禁止只生成静态表格截图式页面。
- 禁止只有“搜索 + 表格 + 分页”的粗结构，缺少排序、筛选、勾选、固定列和反馈。
- 禁止危险操作只有 Toast，没有二次确认。
- 禁止批量操作在未勾选时仍可点击。
- 禁止同时存在 `新建` 和 `导入` 时把 `导入` 做成主按钮。
- 禁止右侧全局辅助能力使用主按钮样式。
- 禁止把依赖勾选项的数据操作放到右侧辅助区，或把不依赖勾选项的操作放到左侧勾选项操作区。
- 禁止混淆左侧 `导出` 与右侧 `导出全部` 的导出范围。
- 禁止超长文本撑破列宽。
- 禁止表头或单元格出现多行文本、主副标题、上下两行信息等复合展示样式。
- 禁止把原型中同一单元格内的多个业务字段照搬为换行内容；必须拆成独立列。
- 禁止首列或操作列不固定，导致横向滚动后关键识别信息或操作不可见。
- 禁止纵向滚动时搜索区、数据概览图表区、工具栏、表格表头或正常数据态分页区跟随表格内容一起滚走。
- 禁止 loading 状态保留旧数据行或在旧数据上叠加遮罩。
- 禁止弹出层被统一列表容器、冻结区、表格内容区或分页区裁切遮挡，或超出屏幕可视区域。
- 禁止为了凑齐交互而强行添加当前业务不需要的排序、列筛选、勾选、批量操作、行操作、导入或导出能力。
- 禁止空数据时移除表头，或只显示空白表格。

## 12. 验收清单

AI 生成列表页 HTML Demo 或 HTML 预览文件时，列表页必须通过以下验收：

- [ ] 有搜索条件时，搜索区位于统一列表容器顶部、工具栏上方；无搜索条件时，不保留空搜索区或空白搜索区间距。
- [ ] 搜索区、数据概览图表区（如存在）、工具栏、表格主体和分页区处于同一个统一列表容器内。
- [ ] 统一列表容器内没有额外的表格标题、列表标题、表单名称、模块名称或类似占位标题。
- [ ] 统一列表容器背景、圆角、24px 内边距和内部间距符合容器与间距规则。
- [ ] 搜索区、数据概览图表区（如存在）、工具栏、表格主体、分页区和状态内容均在 24px 内边距安全区内左右铺满，未贴住容器边缘。
- [ ] 如存在数据概览图表区，图表区位于搜索区下方、工具栏上方。
- [ ] 图表区支持展开 / 收起。
- [ ] 展开态展示“向上收起 icon + 标题 + 图表内容”。
- [ ] 收起态仅保留“向下展开 icon + 标题”，不保留图表内容高度。
- [ ] 图表区展开态整体高度控制在 240px-300px 以内。
- [ ] 点击搜索后，图表数据与表格数据按当前搜索条件同步刷新。
- [ ] 搜索区、图表区、工具栏 / 表格区之间存在轻量分割线。
- [ ] 分割线与统一列表容器内容区等宽，左右两侧均保持 24px 安全边距。
- [ ] 搜索项采用 `标题 + 输入 / 选择控件` 结构。
- [ ] 同一页输入 / 选择控件宽度统一。
- [ ] 空间不足时搜索项整组换行。
- [ ] 输入类占位文案为 `请输入`。
- [ ] 选择类占位文案为 `请选择`。
- [ ] 有搜索区时，操作按钮固定为 `搜索 / 清空`。
- [ ] 点击搜索后按搜索区条件刷新表格、重置到第 1 页并展示 loading。
- [ ] 点击清空后仅清空搜索区条件，不刷新表格、不重置分页、不清除表头筛选或排序。
- [ ] 工具栏左侧主操作、右侧辅助操作分区清晰。
- [ ] `新建` / `导入` 的主按钮使用符合工具栏规则，右侧全局辅助能力均为辅助按钮样式。
- [ ] 依赖勾选项的数据操作位于左侧操作区；不依赖勾选项的操作位于右侧辅助区。
- [ ] 未勾选时针对勾选项的数据操作按钮禁用；勾选后恢复默认可点击状态并展示 `已选 N 项`。
- [ ] `已选 N 项` 位于左侧操作区内，放在操作按钮的最后边。
- [ ] 左侧 `导出` 导出已选数据，右侧 `导出全部` 导出当前已生效筛选结果全部数据，存在歧义时有 Tooltip 或辅助说明。
- [ ] 工具栏空间不足时，左侧优先保留 `新建`、`导入` 和 1-2 个高频勾选项操作，右侧优先保留 `字段配置`，其余操作收纳到 `更多`。
- [ ] 表格包含表头、数据行、状态标签、操作列。
- [ ] 表头和单元格文本均为单行展示，超长文本单行省略并可 hover 展示 Tooltip。
- [ ] 原型中同一单元格内的多个业务字段已按语义拆成独立列。
- [ ] loading、empty、error 状态替换表格内容区，不与分页区同时展示。
- [ ] loading 状态不保留旧数据行，不在旧数据上叠加遮罩。
- [ ] 空数据时保留表头，表格内容区显示空数据占位图标和提示文案，并隐藏分页器；初始无数据文案为 `暂无数据`，搜索无结果文案为 `暂无匹配数据，请调整筛选条件`。
- [ ] 正常数据态展示数据行；非空数据时分页区位于表格底部右对齐。
- [ ] 分页、loading、empty、error 为默认能力；数据概览图表区、排序、列筛选、勾选、批量操作、行操作、导入、导出等按当前业务适用，不强行添加业务无关能力。
- [ ] 表头筛选和表头排序与搜索区条件分区管理，失焦后执行刷新并重置到第 1 页。
- [ ] 纵向滚动时只有表格主体内容区滚动，搜索区、数据概览图表区（如存在）、工具栏、表格表头和正常数据态分页区保持冻结。
- [ ] 存在勾选列时，勾选列和首个关键识别业务列固定在左侧；无勾选列时，首个关键识别业务列固定在左侧；操作列固定在右侧。
- [ ] 横向滚动时只有表格主体内容区滚动，表头和数据列对齐。
- [ ] 下拉选择、列筛选、更多菜单、字段配置、Tooltip 等弹出层位于最上层可视区域，不被遮挡、不出屏，并按触发控件自动左 / 右对齐。
- [ ] disabled 操作有 Tooltip 说明。
- [ ] 高风险操作有二次确认。
- [ ] loading、empty、error、success、failure 状态完整。
- [ ] HTML Demo 中主要交互均可点击验证。

缺少任一当前业务适用项，视为列表页生成失败。
