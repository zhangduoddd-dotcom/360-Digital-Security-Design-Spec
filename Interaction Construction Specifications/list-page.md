# 列表页搜索与表格区域交互规范
## List Page Search and Table Interaction Rules

Keywords: list page, list search, filter, query, data overview, metric card, 3Dicon, chart, table, toolbar, batch action, pagination, sorting, filtering, html demo

本文定义列表页中搜索区、数据概览区（含数据指标卡与图表）、工具栏、表格主体、操作列、分页、状态反馈以及搜索与表格联动的 HTML Demo 验收规则。AI 生成列表页 HTML Demo 或 HTML 预览文件时，必须遵循本文。

## 1. 整体定位

列表页用于帮助用户筛选、扫读、比较和处理结构化数据。搜索区用于缩小数据范围，表格区是主工作区；二者通常同时出现，并共同构成一个可查询、可操作、可反馈的数据闭环。

详情页、工作台或配置页中仅包含表格 / 列表模块时，也读取本文，并按实际出现的模块执行适用规则；未出现搜索区时，搜索区验收项不强制适用。

视觉上应保持轻量、克制、规整。搜索区不应比表格更抢眼，也不应占据过高首屏空间；表格区应优先保证数据可扫读、操作可判断、状态可反馈，不做营销卡片式装饰。

## 2. 标准结构

列表页结构必须先判断是否存在数据概览图表区，以及图表是否跟随搜索区筛选条件联动。不同关系使用不同容器组合，不得混用。

### 2.1 容器组合模式

#### 模式 A：搜索区 + 联动数据概览区 + 表格区

当列表页存在“搜索区 + 数据概览区 + 表格区”，且概览区数据会跟随筛选条件联动时，三者必须拆成 2 个独立容器，纵向排列，容器间距 12px。数据概览区 + 表格区合成一个容器；概览区与表格操作行之间不用分割线，用 24px 间距分隔即可。

```text
搜索区容器
列表容器（数据概览区 + 工具栏 / 批量操作区 + 表格主体 + 分页区）
```

#### 模式 B：非联动数据概览区 + 搜索区 + 表格区

当列表页存在“数据概览区 + 搜索区 + 表格区”，且概览区数据不跟随筛选条件联动时，页面必须拆成 2 个独立容器，纵向排列，容器间距 16px。数据概览区作为第一个独立容器置顶；搜索区和表格区合并在第二个独立容器内，搜索区与表格区之间不用分割线，用 16px 间距分隔即可。

```text
数据概览区容器
列表容器（搜索区 + 工具栏 / 批量操作区 + 表格主体 + 分页区）
```

#### 模式 C：搜索区 + 表格区

当列表页仅存在“搜索区 + 表格区”时，搜索区和表格区必须放在 1 个独立容器内。两者之间不用分割线，用 16px 间距分隔即可。

```text
列表容器（搜索区 + 工具栏 / 批量操作区 + 表格主体 + 分页区）
```

### 2.2 表格区标准结构

表格区标准结构：

```text
表格区容器 / 列表容器
├─ 顶部冻结区：工具栏 / 批量操作区 → 表格表头
├─ 可滚动内容区：数据行 / loading / empty / error 等状态内容
└─ 底部冻结区：分页区（仅正常非空数据态展示）

toast / confirm 等全局反馈（覆盖式 / 浮层，不占用列表容器结构）
```

- 容器组合必须按 2.1 三种模式选择；不得在联动概览场景把搜索、概览、表格强行塞入同一个白色容器，也不得把联动概览区和表格区拆成两个独立白色容器；不得在无概览场景把搜索区和表格区拆成多个容器。
- 列表容器 / 表格区容器内不额外预留表格标题、列表标题、表单名称或模块名称等内容；页面标题由母版页头承载。
- 数据概览图表区为可选模块，仅当页面需要展示数据概览、趋势图、分布图、占比图或统计图时出现。
- 无数据概览需求时，不保留空图表区、空标题或额外间距。
- 表格主体承载表头、数据行、状态、操作列、排序和筛选。
- 表格主体正常加载并展示数据时，分页位于表格底部；左侧可承载跨页全选，右侧承载总数、每页条数、页码轨道和跳页。
- loading、empty、error 等状态通常替换表格内容区，不与分页区同时展示；状态态一般保留表头，并隐藏分页区。
- toast、confirm 属于操作反馈层，不替代表格内容区，也不作为分页区后的固定页面结构。
- 搜索、联动数据概览图表、表头排序、表头列筛选、分页、批量操作均作用于同一份表格数据，并触发表格刷新反馈；清空仅清除搜索区条件，不触发表格刷新。

## 3. 列表容器、表格区容器与搜索区

### 3.1 容器与间距规则

| 项目 | 规则 |
|---|---|
| 背景 | #FFFFFF |
| 宽度 | 铺满外部内容容器 |
| 高度 / 布局 | 页面内容区可用高度 100% 自适应，内部按顶部冻结区 / 可滚动内容区 / 底部冻结区组织 |
| 容器内容 | 按 2.1 容器组合模式承载搜索区、数据概览图表区、工具栏 / 批量操作区、表格主体、分页区和状态内容，不额外增加表格标题、列表标题、表单名称或模块名称 |
| 圆角 | 8px |
| 内边距 | 24px，作为业务容器内所有区域的安全边距；模式 A 中“数据概览区 + 表格区”合并容器上下左右均为 24px，不因高密度图表场景缩减 |
| 内部区域宽度 | 搜索区、数据概览图表区、工具栏、表格主体、分页区和状态内容均在各自容器安全区内左右铺满，不得贴住容器边缘 |
| 容器间距 | 模式 A 的 2 个独立容器纵向间距为 12px；模式 B 的 2 个独立容器纵向间距为 16px；同一容器内搜索区与表格区使用 16px 间距，联动概览区与表格操作行使用 24px 间距 |
| 搜索项横向间距 | 32px |
| 搜索项纵向间距 | 16px |
| 响应式 | 空间不足时搜索项整组换行，禁止拆散标题和输入 / 选择控件；复杂列表页可声明最小内容宽度，窗口不足时横向滚动 |
| 搜索区按钮间距 | 统一 8px |
| 搜索区与工具栏纵向间距 | 16px，无联动数据概览图表区时适用 |
| 工具栏左侧 / 右侧按钮间距 | 统一 8px |
| 工具栏与表格主体纵向间距 | 16px |
| 表格主体与分页区纵向间距 | 8px |
| 滚动条 | 表格主体横向 / 纵向滚动条统一 4px 宽度，使用中性弱色，不做粗重默认滚动条 |

### 3.2 自适应与冻结规则

- 列表容器 / 表格区容器在页面内容区内自适应布局，宽度铺满外部内容容器，高度按内容区可用高度自适应。
- 标准列表页应优先采用全高固定布局：搜索区、联动数据概览区、工具栏和分页区保持相对固定，只有表格主体内容区纵向滚动。
- 外层主内容区和列表容器不得因为表格数据、指标卡或分页下拉而出现第二层纵向滚动。
- 使用 Grid / Flex 实现列表页全高布局时，业务内容根容器、列表容器、表格区容器和表格滚动父级必须逐层设置 `min-height: 0`。
- 表格滚动容器高度应由剩余空间计算或 `minmax(0, 1fr)` 自适应，不建议写死 `max-height: 402px` 等固定高度。
- 搜索区、数据概览图表区、工具栏、表格主体、分页区和状态内容必须遵守各自容器安全边距，在安全区内左右铺满，视觉上保持对齐和留白。
- 纵向滚动时，只有表格主体内容区响应滚动；搜索区、联动数据概览图表区、工具栏和表格表头保持顶部冻结。
- 正常非空数据态下，分页区保持底部冻结；loading、empty、error 等状态态下隐藏分页区。
- loading、empty、error 等状态内容展示在表格主体内容区内，不生成独立状态卡片，也不挤占搜索区、数据概览图表区、工具栏或分页区位置。
- 横向滚动时，只有表格主体内容区响应横向滚动；搜索区、数据概览图表区、工具栏和分页区不参与横向滚动。
- 表格列较多时，按表格主体首列规则固定左侧关键列；如存在操作列，操作列固定在右侧。
- 横向滚动时必须保证表头与数据列对齐，固定列与滚动内容之间层级清晰。
- 当业务页声明最小内容宽度（例如日志、审计、认证记录、资产明细等复杂列表页常用 `1200px`）时，搜索区、工具栏、表格和分页共同遵守该最小宽度；浏览器或内容区宽度低于该值时，页面横向滚动，不继续压缩输入框、选择器或表格关键列。
- 业务容器宽度应铺满主内容区；声明 `1200px` 最小内容宽度时，低于该宽度只是不继续响应缩小，不得把业务容器做成内部横向滚动容器。
- 复杂列表页的最小内容宽度只能声明在业务内容根容器或统一的列表工作区容器上；搜索区、数据概览区、工具栏、表格区、分页区不得分别设置彼此冲突的固定宽度或最小宽度。
- 业务内容根容器必须保持 `width: 100%`；声明 `min-width` 时也不得把业务容器改成固定宽度。
- 表格内容多到超过可用高度时，表格主体内容区滚动，分页区在列表容器底部冻结。标准全高列表页中，即使表格内容不足以撑满剩余高度，分页区也应保持在列表容器底部，避免外层页面出现纵向滚动；只有嵌入式小表格或非全高局部表格可自然跟随表格主体排列。

### 3.3 搜索项布局

所有搜索项采用：

```text
标题 + 输入 / 选择控件
```

- 标题与输入 / 选择控件横向组合，并垂直居中。
- 标题与输入 / 选择控件间距为 8px。
- 同一搜索区内所有标题必须使用同一固定宽度，宽度取当前搜索项标题中最长文本的可读宽度；标题文字右对齐，标题右边界在多行搜索项中必须竖向对齐。
- 同一搜索区内输入框、选择器、日期范围等控件必须等宽，推荐宽度 200px-260px；控件左边界和右边界在多行搜索项中必须按列竖向对齐。
- 标题建议不超过 8 个汉字；标题过长时优先优化字段命名，不建议强行展示长标题。

#### 3.3.1 搜索区栅格

列表页存在 4 个及以上搜索项时，默认采用 4 列搜索栅格。

| 场景 | 规则 |
|---|---|
| 默认桌面宽度 | 4 列栅格，每列为完整的“标题 + 控件”搜索项 |
| 可用宽度不足 | 当 4 列布局会导致单个控件宽度低于 200px 时，降为 3 列栅格 |
| 最小内容宽度 | 已声明最小内容宽度的复杂列表页不继续压缩搜索控件，窗口不足时由页面产生横向滚动 |
| 操作按钮 | `搜索 / 清空` 跟随最后一行搜索项，整体右对齐；多行搜索项时首行应尽量排满，不得在首行留下可容纳搜索项的空洞 |

规则：

- 搜索项必须按栅格列线对齐，不得使用自由 `flex-wrap` 导致不同搜索项宽度随机变化。
- 同一行的搜索项应从左到右连续排列；除操作按钮占位外，不得出现前方列空缺而后方列有内容的布局。
- 当搜索项超过一行时，每一列内的标题、控件左边界、控件右边界必须与上一行同列搜索项对齐。

### 3.4 占位文案

| 控件类型 | 默认占位文案 | 补充说明 |
|---|---|---|
| 输入类 | `请输入` | 可追加业务说明，例如 `请输入，支持模糊搜索` |
| 选择类 | `请选择` | 多选、树选、级联选择仍使用该前缀 |
| 日期 / 时间范围 | `请选择` | 可按业务展示为开始时间 / 结束时间 |

占位文案过长时单行省略，hover 通过 Tooltip 展示完整内容。

### 3.5 操作按钮

| 按钮 | 样式 | 固定文案 | 说明 |
|---|---|---|---|
| 搜索 | 主按钮 | `搜索` | 触发查询并刷新表格 |
| 清空 | 辅助按钮 | `清空` | 仅清空搜索区条件，不刷新表格 |

规则：

- 按钮组跟随最后一行搜索项，并整体右对齐。
- 按钮间距统一 8px。
- 搜索区内不出现多个主按钮。
- 默认使用 `搜索 / 清空`，不要混用 `查询 / 重置 / 确认` 等近义文案。
- `搜索 / 清空` 默认使用纯文字按钮，不增加前置搜索 icon 或清空 icon。

### 3.6 换行规则

- 搜索项从左至右依次排列。
- 单行空间不足以容纳完整一组“标题 + 输入 / 选择控件”时，整组换行。
- 操作按钮默认跟随最后一行；若空间不足，按钮可单独换行但仍右对齐。
- 搜索项数量较少时整体跟随容器自适应排布。

### 3.7 查询联动

- 点击 `搜索` 后按搜索区当前筛选条件刷新表格数据，页码重置到第 1 页，并展示 loading。
- 点击 `清空` 后仅清空搜索区输入 / 选择条件，不触发表格刷新，不重置页码，不清空表头筛选或排序。
- 清空搜索区后，列表当前已生效筛选条件保持不变，直到下一次点击 `搜索`。
- 清空搜索区后，如需按清空后的筛选条件更新列表，必须再次点击 `搜索`。
- 搜索无结果时保留表头，表格内容区展示 empty，并提示用户调整筛选条件。
- 存在高级筛选展开 / 收起时，必须保留用户已输入条件。
- 搜索区条件变化不立即查询，必须点击 `搜索` 触发表格刷新。
- 搜索区条件与表头筛选、表头排序分区管理，互不默认清除。

### 3.8 数据概览图表区

当列表页需要展示数据概览、统计图表、趋势图、分布图、占比图或风险概览时，可增加数据概览图表区。该区域用于帮助用户在进入表格明细前，先快速理解数据分布和数量变化。数据概览区的位置和容器层级必须先按 2.1 判断是否与搜索条件联动。

#### 3.8.1 使用场景

数据概览图表区适用场景：

- 搜索条件会影响图表中的数量、比例、趋势或分布。
- 用户需要先通过图表理解当前筛选结果，再查看下方表格明细。
- 页面存在风险数量、状态分布、类型占比、趋势变化、命中数量等概览信息。
- 图表与表格展示的是同一批筛选结果的不同视角。

数据概览图表区不适用场景：

- 仅为了装饰页面而增加图表。
- 图表数据与搜索条件、表格数据无明确关系。
- 页面首屏空间紧张，图表会明显挤压表格主工作区。
- 普通列表页没有概览分析诉求时，不强制增加图表区。

#### 3.8.2 位置与结构

数据概览图表区由两部分组成：

```text
展开 / 收起 icon + 标题
下方数据图表
```

当概览区内包含多个指标或图表时，每个图表模块必须使用稳定结构：

```text
图表模块
├─ 图表标题
├─ 图表主体
└─ 图例 / 数值说明
```

规则：

- 联动概览区位于下方列表容器内部、工具栏 / 批量操作区上方，不作为独立容器存在。
- 非联动概览区位于页面最上方，并作为独立容器存在；搜索区和表格区合并在下方列表容器内。
- 标题行必须展示明确标题，例如 `概览`、`数据概览`、`风险概览`、`告警趋势`、`资产分布`。
- 标题行不固定高度，不预留 40px；高度由标题文字、meta 文案和 icon 自身行高自然撑开。
- 标题行与下方图表内容区间距为 16px。
- 模式 A 中概览区与表格区合并在一个容器内时，只预留概览标题文字本身的自然高度；不得为了对齐额外设置固定标题行高度。
- 展开 / 收起控件只使用 icon，放在标题文字前方；不得在标题行右侧额外放置 `展开`、`收起` 等文字按钮。
- 展开 / 收起 icon 样式应与 Select 下拉箭头一致：透明背景、无边框、无阴影；hover / focus / active 不改变背景，不增加阴影或底部投影，悬停时仅 icon 颜色变化。
- 标题字号为 14px，颜色与搜索区标题一致，使用正文主色或 `gray-9`。
- 展开态下，标题行展示向上收起 icon，标题下方展示数据图表。
- 收起态下，标题行展示向下展开 icon，仅保留标题行，不展示图表内容。
- 收起态下，概览标题行与下方工具栏 / 批量操作区仍保持 24px 间距。
- 展开 / 收起操作不得清空搜索条件、表格数据、排序、筛选或分页状态。
- 收起后再次展开，应恢复当前筛选条件下的图表数据。
- 概览区内各图表标题与搜索项标题保持一致：14px、常规字重、正文主色；不得随意使用更粗、更小或更浅的标题样式。
- 概览区内每个图表模块都必须有明确图表标题；只有纯数值指标卡可以不单独增加图表标题，但指标名称必须清晰可见。
- 图表标题、图表主体和图例不得共用同一行自由挤压；空间不足时应缩减图表数量、收起概览或触发页面级横向滚动。
- 图表标题右侧不要增加 `按日期`、`Top 5`、`分布` 等副标题，除非业务明确要求。

#### 3.8.2.1 数据指标卡

当概览区只展示关键统计数量，或以 3D 图标 + 指标名称 + 指标数值表达数据时，应使用数据指标卡。数据指标卡是数据概览区的一种固定组件，不按图表模块处理。

必须继续读取：

```text
Basic UI component style/component-styles/data-metric-card.md
assets/3Dicon/
```

规则：

- 3D 图标只能来自 `assets/3Dicon/` 已有素材，不允许自行创造或替换来源。
- 指标卡只承载“指标名称 + 指标数值”，不放趋势图、图例、按钮、Tag 堆叠或说明长文。
- 标准列表页概览建议一行 4 个指标卡，多个卡片在同一个容器内自适应等宽排列。
- 指标卡与工具栏之间遵守模式 A 的 24px 间距；收起概览后仍保留概览标题行与工具栏的 24px 间距。
- 指标卡不得撑高列表容器导致页面外层滚动；表格主体仍是主要滚动区域。

#### 3.8.3 高度规则

| 状态 | 高度规则 |
|---|---|
| 展开态 | 高度按内容自适应，常规高密度列表建议约 240px，最大不得超过 300px |
| 收起态 | 仅保留标题行高度，不保留图表内容高度 |
| 小屏 / 内容较多 | 优先压缩图表内容，不得挤压表格主体为不可用状态 |

规则：

- 图表区展开态高度不得超过 300px，不得为了填满页面而固定撑高。
- 图表内容较多时，应优化图表数量或图表密度，不得通过无限增高图表区解决。
- 图表区不应成为页面主工作区，表格仍然是列表页的主要操作区域。
- 不建议在图表区内部出现纵向滚动；如图表内容过多，应减少图表数量或改为更高层级的分析页。

#### 3.8.4 查询联动规则

联动数据概览图表区必须与搜索区、表格数据保持同源联动。

- 点击 `搜索` 后，图表区与表格同时按当前搜索条件刷新。
- 图表中的数量、比例、趋势、分布必须反映当前已生效筛选条件。
- 搜索后页码重置到第 1 页，图表同步进入 loading 状态。
- 点击 `清空` 后，仅清空搜索区条件，不立即刷新图表，也不刷新表格。
- 清空后如需按清空条件更新图表和表格，必须再次点击 `搜索`。
- 表头筛选、表头排序、分页等只影响表格展示时，不默认改变图表统计口径；如业务要求图表同步受表头筛选影响，必须在页面规则中明确说明。
- 图表为空时，应展示轻量 empty 状态，不得删除整个图表区结构导致页面跳动。
- 非联动数据概览图表区不受搜索区条件影响，必须在结构上置顶并与下方“搜索区 + 表格区”列表容器分离。

#### 3.8.5 图表类型与图例规则

- 趋势类图表用于展示数量随时间变化；占比类图表优先使用环形图。
- 图表用色必须使用设计系统色板 token，不得临时硬编码色值。
- 结果类占比图按语义色表达：成功用成功色，失败用错误色，待处理 / 二次认证用警告色，阻断或低优先级状态可用中性色。
- 占比图默认展示全量分类，不截断为 Top 5，不合并为 `其他`，除非业务明确要求聚合。
- 环形图图例竖向排列，一项一行。
- 图例文字列宽按当前图表实际最长文案预留，最大不超过 8 个中文字符宽度；超过时单行省略。
- 悬停图例项时必须能看到完整文案、数量和占比。
- 图例不应横向铺满剩余空间，避免名称与占比数值间距过大。

#### 3.8.6 间距规则

- 模式 A 中，搜索区容器与下方“概览区 + 表格区”列表容器之间用 12px 间距建立层级关系，不使用分割线。
- 模式 A 中，概览区与表格操作行在同一列表容器内，二者之间不用分割线，用 24px 间距分隔即可；概览收起后仍保持 24px 间距。
- 模式 A 展开态下，图表内容区底部与表格操作行之间保持 24px 间距；收起态下，概览标题行底部与表格操作行之间保持 24px 间距。
- 模式 B 中，独立容器之间用 16px 间距建立层级关系，不使用分割线。
- 模式 B 和模式 C 中，搜索区与表格区在同一列表容器内，二者之间不用分割线，用 16px 间距分隔即可。
- 当页面只有搜索区和表格区时，中间不得额外增加分割线。
- 当搜索区、数据概览区、表格区按模式拆分为独立容器时，容器自身的白色背景和外部间距承担结构分隔。

#### 3.8.7 展开 / 收起交互规则

- 点击标题前方展开 / 收起 icon，可切换图表区展开状态。
- 展开 / 收起 icon 必须与当前状态一致。
- 展开态使用向上收起 icon。
- 收起态使用向下展开 icon。
- 鼠标 hover icon 时，应有轻量可点击反馈。
- 展开 / 收起状态切换应保持平滑，不得造成页面明显跳动。
- 收起图表区后，下方容器应自然上移。
- 展开图表区后，下方容器应自然下移，但不得破坏当前容器组合模式。

### 3.9 弹出层层级与对齐

- 列表页内如出现下拉选择、日期选择、列筛选弹层、更多菜单、字段配置、Tooltip 等弹出内容，弹出层必须展示在页面最上层可视区域。
- 弹出层根据触发控件自动匹配左对齐或右对齐；靠近右侧边界时优先右对齐，靠近左侧边界时优先左对齐。
- 弹出层不得被搜索区、数据概览图表区、工具栏、冻结表头、表格内容区、分页区或容器 overflow 裁切遮挡。
- 弹出层不得超出屏幕可视区域；空间不足时应自动调整方向、对齐方式或最大高度，并在弹层内部滚动。
- 表格内列筛选、行操作更多菜单、字段配置、Tooltip 等浮层不得依赖表格单元格内部普通 absolute 定位；必须提升到页面级浮层、body 级浮层或使用 fixed / popover 定位。
- 表格相关浮层的层级必须高于表格 sticky 表头、左右固定列和表格滚动容器；不得被操作列、冻结列阴影或表格 `overflow` 压住。
- 行操作更多菜单靠近右侧时必须右对齐，并在可视区域内完整展示。

## 4. 工具栏

工具栏属于表格区，位于表格主体上方。模式 A 中工具栏位于同一列表容器内的联动概览区下方，与概览区保持 24px 间距；模式 B / C 中工具栏位于搜索区下方、表格主体上方；无搜索区时，工具栏位于列表容器顶部、表格主体上方。工具栏分为左侧操作区和右侧辅助区。

| 区域 | 内容 | 规则 |
|---|---|---|
| 左侧 | 新建、导入、导出、启用、停用、删除 | 承担高频新增操作和针对勾选项的数据操作 |
| 右侧 | 导出全部、字段配置、刷新、规则配置 | 承载全局辅助能力 |

规则：

- 左侧按钮间距统一 8px，右侧按钮间距统一 8px。
- `新建`、`导入` 放在左侧操作区最前面，保持默认状态，不依赖表格行勾选。
- `新建` 放在左侧最前，通常使用主按钮样式。
- 当没有 `新建` 且存在 `导入` 时，`导入` 可使用主按钮样式。
- 当同时存在 `新建` 和 `导入` 时，`导入` 仅可使用辅助按钮样式。
- `导出`、`启用`、`停用`、`删除` 等针对勾选项的数据操作根据操作优先级依次排列在左侧操作区，均使用辅助按钮样式。
- 不依赖表格行勾选项的操作按钮均放在右侧辅助区，使用辅助按钮样式。
- 未勾选表格数据时，针对勾选项的数据操作按钮为 disabled，并通过 Tooltip 说明原因。
- 勾选表格数据后，`导出`、`启用`、`停用`、`删除` 等针对勾选项的数据操作按钮从 disabled 恢复为默认可点击状态。
- `已选 N 项` 位于左侧操作区内，放在操作按钮的最后边，仅作为选中数量文本提示，不做成按钮或高强调标签。
- 左侧 `导出` 默认导出已勾选的数据；右侧 `导出全部` 默认导出当前已生效搜索条件、表头筛选和排序共同作用后的全部结果，不等同于仅导出当前页。
- 如果同时存在左侧 `导出` 和右侧 `导出全部`，必须通过 Tooltip 或按钮辅助说明区分 `导出已选数据` 与 `导出当前筛选结果全部数据`。
- 右侧 `导出全部`、`字段配置`、`刷新`、`规则配置` 等全局辅助能力均使用辅助按钮样式。
- 右侧全局辅助能力中，`刷新`、`字段配置 / 配置表格字段`、`规则配置` 等不需要长文案识别的低频辅助项优先使用辅助样式纯图标按钮；按钮必须有 `aria-label` 和 hover Tooltip。`导出全部` 这类需要区分导出范围的全局操作可保留文字按钮。
- `刷新` 图标使用 `icon-a-shuaxingengxinzhongzhi`；`字段配置 / 配置表格字段` 图标使用 `icon-a-shezhixitong`。
- 列表页中的 `新增`、`创建`、`新建` 等新增类功能统一命名为 `新建`；当前列表只有一个新建类别时，不追加业务类型名称，例如不写 `新建规则`、`创建规则`。
- 左侧工具栏文字按钮默认不带图标；只有纯图标按钮、下拉箭头或表头筛选 / 排序等功能性图标按对应规范保留。
- 工具栏必须保持左侧操作区和右侧辅助区在同一行内；右侧辅助区固定贴齐表格主体右上方，不得单独换到下一行。
- 工具栏左右操作区均不允许通过自然换行解决空间不足；空间不足时按收纳规则进入 `更多`。
- 工具栏空间不足时，左侧操作区必须优先保留 `新建`、`导入`；针对勾选项的数据操作可保留 1-2 个高频操作，其余收纳到 `更多`。
- 右侧辅助区空间不足时，优先保留 `字段配置`，其余全局辅助操作收纳到 `更多`。

## 5. 表格主体

| 项目 | 规则 |
|---|---|
| 表头 | 使用 `Gray 中性 / gray-2` 背景，文字使用 `gray-9 / 600`；空数据和状态态仍保留表头；纵向滚动时保持顶部冻结；表头文本单行展示 |
| 行高 | 默认小号：表头和普通行 40px；大号：48px |
| 外框 | 列表容器 / 表格区容器内表格不加外边缘框，不额外圆角 |
| 单元格 | 默认小号：12px / 20px / 400 / `gray-8`；大号：14px / 22px / 400 / `gray-8`；单元格文本单行展示 |
| 空值 | 统一显示 `-` |
| 空数据 | 保留表头，表格内容区显示空数据占位图标和提示文案 |
| 时间 | 使用 `YYYY-MM-DD HH:MM:SS` |
| 超长文本 | 表头和单元格均单行省略，hover 展示 Tooltip |
| 行 hover | 使用中性弱背景高亮，文字颜色不变化 |
| 纵向滚动 | 仅表格主体内容区滚动，搜索区、数据概览图表区、工具栏、表格表头和分页区按状态冻结 |
| 多列场景 | 仅表格主体内容区支持横向滚动 |
| 滚动条 | 表格主体横向 / 纵向滚动条宽度统一 4px，thumb 使用中性弱色，hover 可略加深 |
| 首列 | 存在勾选列时，勾选列固定在最左侧，首个关键识别业务列紧随其后并固定；无勾选列时，首个关键识别业务列固定在最左侧 |
| 操作列 | 如有操作列，默认固定在最右侧 |

补充规则：

- 列表页表格默认使用小号密度：表头和普通行 40px，普通单元格 12px / 20px / 400 / `gray-8`；只有页面明确需要舒展展示时才使用大号密度 48px + 14px / 22px。
- 表头字号跟随表格密度，小号为 12px / 20px / 600，大号为 14px / 22px / 600；表头背景必须为 `gray-2`，表头文字必须为 `gray-9`。
- 列表容器 / 表格区容器内表格默认无外边缘框，不能再包一层 table 私有 border 或圆角；独立展示型表格才允许使用带边框容器。
- 固定列不等于主要字段；不得因为某列被冻结就自动加粗。只有明确承担主对象名称或主识别信息的列，才允许使用主要字段样式。
- 存在勾选列时，勾选列表头和数据单元格必须固定在最左侧，首个关键识别业务列的表头和数据单元格必须使用相同 left 偏移紧随其后固定；横向滚动时两列位置不变。
- 冻结列按左侧和右侧分别形成连续冻结组；如果关键识别列前存在未冻结业务列，应调整列顺序让关键识别列紧随勾选列，或将其前面的业务列一并冻结。
- 存在操作列时，操作列默认固定在最右侧；如果右侧还有其他固定列，必须与操作列形成连续右侧冻结组。
- 左侧冻结阴影只允许出现在左侧冻结组最后一列的右边界，横向滚动距离大于 0 时显示，回到最左侧时隐藏。
- 右侧冻结阴影只允许出现在右侧冻结组最左一列的左边界，未滚到最右侧时显示，滚到最右侧时隐藏。
- 禁止把冻结阴影加在表格中间列或非冻结列上。

## 6. 列类型、排序与筛选

常见列类型必须按语义表达：

- 文本列：展示名称、编号、IP、账号等可识别信息。
- 状态列：使用状态标签或状态点，颜色和文字同时表达。
- 时间列：统一格式，不混用短日期与长日期。
- 数字列：右对齐或按业务统一对齐，单位明确。
- 风险列：使用标准风险等级文案和颜色。
- 操作列：只放与当前行直接相关的操作。

列拆分规则：

- 表头和单元格内容均按单行文本处理，禁止在一个单元格内生成上下两行信息样式。
- 如果需求原型把多个业务字段放在一个单元格内换行展示，AI 必须按字段语义拆成多列。
- 例如原型中一列同时展示 `姓名 / 工号`，且在单元格内上下行排布时，应拆成 `姓名`、`工号` 两列。
- 不得为了贴近原型而创造头像 + 主副标题、标题 + 描述、上下两行文本等复合单元格样式，除非组件库和当前业务规范显式定义了该列类型。

排序与筛选规则：

- 支持排序的列必须有明确排序图标。
- 排序状态包括升序、降序、取消排序。
- 当前排序方向需要高亮。
- 支持列筛选的列必须有筛选入口。
- 筛选弹层包含筛选项、确定、重置。
- 存在生效筛选条件时，筛选图标高亮。
- 表头筛选和表头排序与搜索区条件分区管理，搜索区 `清空` 不清除表头筛选或表头排序。
- 表头筛选和表头排序为失焦执行：完成选择、输入、排序方向切换，或关闭弹层并离开触发控件后刷新表格数据，页码重置到第 1 页，并展示 loading。
- 表头筛选和表头排序不因选项变化实时刷新，必须在交互完成并失焦后执行。

## 7. 行操作与批量操作

### 7.1 行操作

| 场景 | 规则 |
|---|---|
| 操作数量 <= 3 | 直接展示 |
| 操作数量 > 3 | 前 2 个直接展示，其余折叠到 `更多` |
| 高风险操作 | 必须二次确认 |
| 操作不可用 | disabled + Tooltip 说明原因 |
| 操作完成 | Toast / Message 反馈成功或失败 |

行操作应固定在最右侧操作列，不要散落在其他列中。

补充规则：

- 详情查看类操作统一命名为 `详情`，不要在安全告警、事件、日志等高密列表中混用 `查看`。
- 折叠入口必须展示 `更多 + 下拉箭头`，不得只使用省略号、三个点或无文字 icon 代替。
- 行内低风险操作优先使用文字按钮样式；禁用态应保留文字按钮的语义，不得误用辅助按钮实体禁用态造成视觉过重。
- 行操作禁用时必须在 hover 时提示具体业务原因；例如告警 `处置` 已不可用时提示 `当前告警已处置完成，无需重复处置`。
- 删除、忽略、停用、覆盖、处置完成等会改变业务状态的操作必须保留文字说明和确认机制，不得只放 icon。

### 7.2 批量操作

- 勾选列位于表格最左侧。
- 支持全选、单选、跨页选择时需要说明范围。
- 已选数量实时更新。
- 未勾选时，`导出`、`启用`、`停用`、`删除` 等针对勾选项的数据操作按钮禁用。
- 未勾选导致批量操作按钮禁用时，hover 默认提示 `请勾选内容后重试`。
- 勾选后，针对勾选项的数据操作按钮恢复默认可点击状态，并展示 `已选 N 项`。
- 针对勾选项的数据操作按钮文案只保留动词，例如 `导出`、`启用`、`停用`、`删除`；禁止写成 `导出已选`、`删除所选`、`批量导出`。操作范围通过 `已选 N 项`、Tooltip 或确认弹窗表达。
- 批量删除、停用、还原等高风险操作必须二次确认。
- 批量操作成功或失败后刷新表格并给出反馈。

## 8. 分页

| 项目 | 规则 |
|---|---|
| 默认每页 | 20 条 |
| 可选条数 | 10 / 20 / 50 / 100 |
| 位置 | 分页区位于表格底部；左侧承载跨页全选，右侧承载总数、每页条数、页码轨道和跳页 |
| 总数 | 非空数据时必须展示，文案统一为 `共计 X 条` |
| 空数据 | 保留表头，表格内容区展示 empty，固定隐藏分页器 |

分页必须支持页码切换和每页条数切换，并触发表格刷新。仅当表格主体处于正常数据态且存在非空数据时展示分页；loading、empty、error 等状态态下隐藏分页区。

分页区补充规则：

- 表格支持跨页批量选择时，分页区左侧必须展示 `跨页全选` 复选框；该复选框左边界必须与表格勾选列中的复选框左边界垂直对齐。
- `跨页全选` 后必须有 14px x 14px 的信息提示图标，hover 文案为 `勾选当前过滤条件下所有内容`。
- `跨页全选` 的作用范围是当前已生效搜索条件、表头筛选和排序共同作用后的全部结果，不只是当前页。
- 分页区右侧必须保留 `共计 X 条`、每页条数选择器、页码轨道和跳页输入，不得因为增加跨页全选而删除每页条数或分页组件。
- 内容少时，分页区紧跟表格主体底部；内容多时，分页区吸底冻结。

## 9. 状态与反馈

列表页必须覆盖以下状态：

- loading：搜索、数据概览图表刷新、表头排序、表头筛选、分页、批量操作期间展示。
- empty：无数据时保留表头，表格内容区显示空数据占位图标和提示文案，并隐藏分页器。
- error：加载失败时保留表头，表格内容区展示错误原因和重试入口，并隐藏分页器。
- disabled：无权限或条件不足时禁用并说明原因。
- success / failure：操作完成后给出 Toast / Message 反馈。
- confirm：删除、停用、覆盖、还原等高风险操作必须确认。

规则：

- loading、empty、error 等状态内容替换表格内容区，不追加在分页区之后。
- loading、empty、error 状态下保留表头，隐藏分页区。
- loading 状态不保留旧数据行，不在旧数据上叠加遮罩。
- 初始无数据时 empty 文案使用 `暂无数据`。
- 搜索无结果时 empty 文案使用 `暂无匹配数据，请调整筛选条件`。
- 正常数据态恢复后重新展示数据行；存在非空数据时展示分页区。
- Toast / Message 和 confirm 是覆盖式或浮层反馈，不改变表格区域的结构层级。

## 10. HTML Demo 要求

交互适用层级：

- 分页、loading、empty、error 是列表页默认能力。
- 搜索区按页面是否存在搜索条件决定；无搜索条件时，列表容器 / 表格区容器顶部直接从工具栏开始，不保留空搜索区或搜索区间距。
- 数据概览图表区按页面是否存在概览分析诉求决定；无概览分析诉求时，不保留空图表区、空标题或图表区间距。
- 页面容器结构必须按 2.1 三种模式选择；联动概览使用 2 个独立容器（搜索区容器 + 概览表格列表容器），非联动概览使用 2 个独立容器，无概览时搜索区和表格区在 1 个独立容器内。
- 表头排序、列筛选、勾选、批量操作、行操作、导入、导出和更多菜单按当前业务是否提供对应字段或操作决定，不得为了凑交互而强行添加业务无关能力。

HTML Demo 必须按当前业务适用项支持点击验证：

- 输入关键词。
- 选择筛选项。
- 点击 `搜索` 按搜索区条件刷新 mock 表格，并重置到第 1 页。
- 点击 `清空` 仅清空搜索区条件，不刷新 mock 表格。
- 当页面存在数据概览图表区时，必须支持展开 / 收起点击验证。
- 点击 `搜索` 后，图表区数据与表格数据同步按当前搜索条件刷新。
- 联动概览图表区展开态高度按内容自适应，常规建议约 240px，最大不得超过 300px。
- 图表区收起态仅保留标题行；展开 / 收起 icon 位于标题文字前方，不显示文字按钮。
- 模式 A 中搜索区容器与概览表格列表容器之间使用 12px 间距；概览区与表格操作行之间使用 24px 间距，不使用分割线。
- 占比图默认展示全量分类，优先使用环形图；图例竖向排列，名称列按最长文案预留且不超过 8 个中文字符宽度。
- 窄屏时搜索项整组换行。
- 表头排序切换后失焦执行刷新。
- 列筛选弹层打开、确定、重置，并在失焦后执行刷新。
- 行勾选与 `已选 N 项` 联动。
- 批量按钮禁用 Tooltip。
- 左侧 `导出` 与右侧 `导出全部` 的导出范围区分。
- 行 hover 高亮。
- `更多` 菜单展开。
- 工具栏空间不足时左侧和右侧操作按规则收纳到 `更多`。
- 分页切换和每页条数切换。
- 删除或停用二次确认。
- Toast 成功 / 失败反馈。
- loading、empty、error 状态切换。
- 表格区容器内的纵向冻结和横向冻结效果。
- 下拉选择、列筛选、更多菜单、字段配置等弹出层不被遮挡、不出屏，并自动匹配左 / 右对齐。

## 11. AI 生成禁止项

- 禁止把搜索区做成大面积营销筛选卡片。
- 禁止在只有“搜索区 + 表格区”时把二者拆成两个独立白色容器；必须放在同一个列表容器内。
- 禁止在“搜索区 + 联动数据概览区 + 表格区”时把三者强行合并为一个容器；必须拆成“搜索区容器 + 概览表格列表容器”2 个独立容器。
- 禁止在“搜索区 + 联动数据概览区 + 表格区”时把概览区和表格区拆成两个独立白色容器；二者必须合并在同一个列表容器内。
- 禁止在“非联动数据概览区 + 搜索区 + 表格区”时把三者拆成 3 个同级容器；必须为“概览区独立容器 + 搜索区和表格区合并容器”。
- 禁止为了装饰页面强行增加与搜索条件和表格数据无关的数据图表。
- 禁止在无概览分析诉求时保留空图表区、空标题或图表区间距。
- 禁止图表区高度超过 300px，导致表格主体被明显挤压。
- 禁止图表区收起后仍保留空白图表高度。
- 禁止联动图表数据与搜索条件、表格数据不同步。
- 禁止在搜索区、图表区、工具栏 / 表格区之间额外添加分割线；新版列表页用模式化容器间距和内部间距分隔。
- 禁止概览展开 / 收起 icon 使用按钮背景、hover 背景、active 背景、阴影或底部投影；该类内联 icon 悬停时只允许 icon 变色。
- 禁止在列表容器 / 表格区容器内额外增加表格标题、列表标题、表单名称、模块名称或类似占位标题。
- 禁止表格主体、表头、分页区、搜索区、数据概览图表区或工具栏贴住各自容器左右边缘。
- 禁止为了撑满视觉宽度而忽略业务容器安全内边距。
- 禁止图表标题右侧出现无业务必要的 `按日期`、`Top 5`、`分布` 等副标题。
- 禁止占比图默认只展示 Top 5 或合并为 `其他`；除非业务明确要求，必须展示全量分类。
- 禁止环形图图例横向铺满剩余空间，导致名称与占比数值间距过大。
- 禁止无搜索条件时保留空搜索区或空白搜索区间距。
- 禁止让搜索区高度超过表格区视觉重点。
- 禁止搜索项标题、输入框宽度混乱。
- 禁止多行搜索项的标题右边界、控件左边界或控件右边界不按列对齐。
- 禁止 4 列搜索栅格下控件宽度低于 200px；宽度不足时必须降为 3 列或遵守页面最小内容宽度产生横向滚动。
- 禁止按钮文案混用 `查询 / 重置 / 确认` 替代默认 `搜索 / 清空`。
- 禁止给默认文字按钮增加无业务必要的装饰图标，例如 `搜索`、`清空`、`新建`、`导出`、`处置`。
- 禁止在单一新建入口中混用 `新增`、`创建`、`新建XX`、`创建XX`；列表页新增类入口默认统一为 `新建`。
- 禁止 disabled 按钮没有 hover 禁用原因提示。
- 禁止点击 `清空` 时刷新表格、重置分页、清除表头筛选或清除表头排序。
- 禁止空间不足时把标题和输入 / 选择控件拆开换行。
- 禁止只生成静态表格截图式页面。
- 禁止只有“搜索 + 表格 + 分页”的粗结构，缺少排序、筛选、勾选、固定列和反馈。
- 禁止危险操作只有 Toast，没有二次确认。
- 禁止批量操作在未勾选时仍可点击。
- 禁止同时存在 `新建` 和 `导入` 时把 `导入` 做成主按钮。
- 禁止右侧全局辅助能力使用主按钮样式。
- 禁止右侧 `导出全部`、`刷新`、`字段配置` 等辅助操作换行到表格上方第二行；空间不足时必须收纳到 `更多`。
- 禁止把 `刷新`、`字段配置 / 配置表格字段` 等右侧全局辅助项做成长文字按钮；应使用辅助样式纯图标按钮，并提供 Tooltip / aria-label。
- 禁止把依赖勾选项的数据操作放到右侧辅助区，或把不依赖勾选项的操作放到左侧勾选项操作区。
- 禁止混淆左侧 `导出` 与右侧 `导出全部` 的导出范围。
- 禁止将批量操作按钮写成 `导出已选`、`删除所选`、`批量导出` 等带范围修饰的文案；按钮只保留操作动词。
- 禁止普通表格正文和主要字段、表头、状态标签混用字重导致层级混乱。
- 禁止列表容器 / 表格区容器内表格额外增加外边缘框、外层圆角或独立 table 卡片感。
- 禁止超长文本撑破列宽。
- 禁止表头或单元格出现多行文本、主副标题、上下两行信息等复合展示样式。
- 禁止把原型中同一单元格内的多个业务字段照搬为换行内容；必须拆成独立列。
- 禁止首列或操作列不固定，导致横向滚动后关键识别信息或操作不可见。
- 禁止左侧或右侧冻结列不是连续冻结组，或把冻结阴影加在表格中间列、非冻结列上。
- 禁止纵向滚动时搜索区、数据概览图表区、工具栏、表格表头或正常数据态分页区跟随表格内容一起滚走。
- 禁止页面低于最小内容宽度时让业务容器自身出现横向滚动；复杂列表页应由页面整体横向滚动，业务容器仍铺满内容宽度。
- 禁止表格横向 / 纵向滚动条使用浏览器默认粗滚动条，统一按 4px 细滚动条处理。
- 禁止分页区只保留 `共计 X 条` 而删除每页条数、页码轨道或跳页输入。
- 禁止跨页全选复选框与表格勾选列错位，或缺少 14px x 14px 信息提示图标。
- 禁止 loading 状态保留旧数据行或在旧数据上叠加遮罩。
- 禁止弹出层被业务容器、冻结区、表格内容区或分页区裁切遮挡，或超出屏幕可视区域。
- 禁止为了凑齐交互而强行添加当前业务不需要的排序、列筛选、勾选、批量操作、行操作、导入或导出能力。
- 禁止空数据时移除表头，或只显示空白表格。

## 12. 验收清单

AI 生成列表页 HTML Demo 或 HTML 预览文件时，列表页必须通过以下验收：

- [ ] 页面容器组合符合 2.1：联动概览为“搜索区容器 + 概览表格列表容器”2 个独立容器；非联动概览为“概览区容器 + 搜索表格列表容器”2 个独立容器；无概览为“搜索区 + 表格区”1 个列表容器。
- [ ] 模式 A 中两个独立容器纵向间距为 12px；模式 B 中两个独立容器纵向间距为 16px；同一列表容器内搜索区与表格区之间使用 16px 间距，联动概览区与表格操作行之间使用 24px 间距。
- [ ] 搜索区、概览区和表格区之间没有额外分割线。
- [ ] 列表容器 / 表格区容器内没有额外的表格标题、列表标题、表单名称、模块名称或类似占位标题。
- [ ] 业务容器背景、圆角、内边距和内部间距符合容器与间距规则。
- [ ] 模式 A 中“数据概览区 + 表格区”合并容器上下左右内边距均为 24px。
- [ ] 搜索区、数据概览图表区（如存在）、工具栏、表格主体、分页区和状态内容均在各自容器安全区内左右铺满，未贴住容器边缘。
- [ ] 图表区支持展开 / 收起。
- [ ] 图表区标题行不固定高度，不预留 40px；模式 A 合并容器内只预留概览标题文字本身的自然高度；标题行与下方图表内容区间距为 16px，展开 / 收起 icon 位于标题文字前方，不出现右侧文字按钮。
- [ ] 展开 / 收起 icon 透明底、无边框、无阴影；hover / focus / active 不改变背景，悬停时仅 icon 变色。
- [ ] 图表区标题和各图表标题使用 14px，颜色与搜索区标题一致。
- [ ] 展开态展示“icon + 标题 + 图表内容”。
- [ ] 收起态仅保留“icon + 标题”，不保留图表内容高度。
- [ ] 展开态下图表内容区底部与表格操作行保持 24px 间距；收起态下概览标题行底部与表格操作行仍保持 24px 间距。
- [ ] 联动图表区展开态整体高度按内容自适应，常规约 240px，最大不超过 300px。
- [ ] 点击搜索后，联动图表数据与表格数据按当前搜索条件同步刷新。
- [ ] 图表标题右侧没有无业务必要的 `按日期`、`Top 5`、`分布` 等副标题。
- [ ] 占比图优先使用环形图并展示全量分类；图例竖向排列，名称列按最长文案预留，最大不超过 8 个中文字符宽度，超长省略且 hover 显示完整文案、数量和占比。
- [ ] 搜索项采用 `标题 + 输入 / 选择控件` 结构。
- [ ] 同一页输入 / 选择控件宽度统一。
- [ ] 同一搜索区标题宽度取最长标题，标题文字右对齐；多行搜索项中标题右边界按列竖向对齐。
- [ ] 多行搜索项中控件左边界和右边界按列竖向对齐。
- [ ] 4 个及以上搜索项默认使用 4 列栅格；当 4 列会导致控件宽度低于 200px 时降为 3 列。
- [ ] 已声明最小内容宽度的复杂列表页在窄屏下产生横向滚动，不继续压缩搜索控件或表格关键列。
- [ ] 空间不足时搜索项整组换行。
- [ ] 输入类占位文案为 `请输入`。
- [ ] 选择类占位文案为 `请选择`。
- [ ] 有搜索区时，操作按钮固定为 `搜索 / 清空`。
- [ ] 点击搜索后按搜索区条件刷新表格、重置到第 1 页并展示 loading。
- [ ] 点击清空后仅清空搜索区条件，不刷新表格、不重置分页、不清除表头筛选或排序。
- [ ] 工具栏左侧主操作、右侧辅助操作分区清晰。
- [ ] `新建` / `导入` 的主按钮使用符合工具栏规则，右侧全局辅助能力均为辅助按钮样式。
- [ ] 依赖勾选项的数据操作位于左侧操作区；不依赖勾选项的操作位于右侧辅助区。
- [ ] 未勾选时针对勾选项的数据操作按钮禁用；勾选后恢复默认可点击状态并展示 `已选 N 项`。
- [ ] `已选 N 项` 位于左侧操作区内，放在操作按钮的最后边。
- [ ] 左侧 `导出` 导出已选数据，右侧 `导出全部` 导出当前已生效筛选结果全部数据，存在歧义时有 Tooltip 或辅助说明。
- [ ] 针对勾选项的数据操作按钮只保留动词文案，例如 `导出`、`启用`、`停用`、`删除`。
- [ ] 右侧 `导出全部`、`刷新`、`字段配置` 等辅助操作贴齐表格右上方并保持同一行；空间不足时收纳到 `更多`，不自然换行。
- [ ] 右侧 `刷新`、`字段配置 / 配置表格字段` 等全局辅助项使用辅助样式纯图标按钮，并提供 Tooltip / aria-label；`导出全部` 可保留文字按钮。
- [ ] 工具栏空间不足时，左侧优先保留 `新建`、`导入` 和 1-2 个高频勾选项操作，右侧优先保留 `字段配置`，其余操作收纳到 `更多`。
- [ ] 表格包含表头、数据行、状态标签、操作列。
- [ ] 表格默认小号密度：行高 40px，普通单元格 12px / 20px / 400；大号密度为 48px + 14px / 22px。
- [ ] 表头背景为 `gray-2`，表头文字为 `gray-9 / 600`；普通单元格文字为 `gray-8 / 400`。
- [ ] 列表容器 / 表格区容器内表格没有外边缘框或独立圆角。
- [ ] 固定列没有被误用为加粗主要字段；只有明确主对象名称或主识别信息才使用主要字段样式。
- [ ] 表头和单元格文本均为单行展示，超长文本单行省略并可 hover 展示 Tooltip。
- [ ] 原型中同一单元格内的多个业务字段已按语义拆成独立列。
- [ ] loading、empty、error 状态替换表格内容区，不与分页区同时展示。
- [ ] loading 状态不保留旧数据行，不在旧数据上叠加遮罩。
- [ ] 空数据时保留表头，表格内容区显示空数据占位图标和提示文案，并隐藏分页器；初始无数据文案为 `暂无数据`，搜索无结果文案为 `暂无匹配数据，请调整筛选条件`。
- [ ] 正常数据态展示数据行；非空数据时分页区位于表格底部，左侧可放跨页全选，右侧展示 `共计 X 条`、每页条数、页码轨道和跳页。
- [ ] 如支持跨页选择，分页区左侧 `跨页全选` 复选框与表格勾选列垂直对齐，提示图标为 14px x 14px，hover 文案为 `勾选当前过滤条件下所有内容`。
- [ ] 分页、loading、empty、error 为默认能力；数据概览图表区、排序、列筛选、勾选、批量操作、行操作、导入、导出等按当前业务适用，不强行添加业务无关能力。
- [ ] 表头筛选和表头排序与搜索区条件分区管理，失焦后执行刷新并重置到第 1 页。
- [ ] 纵向滚动时只有表格主体内容区滚动，搜索区、数据概览图表区（如存在）、工具栏、表格表头和正常数据态分页区保持冻结。
- [ ] 存在勾选列时，勾选列和首个关键识别业务列固定在左侧；无勾选列时，首个关键识别业务列固定在左侧；操作列固定在右侧。
- [ ] 勾选列和首个关键识别业务列的表头、数据单元格固定偏移一致，横向滚动后位置不变。
- [ ] 左右冻结列各自形成连续冻结组；左侧阴影只在左冻结组右边界，右侧阴影只在右冻结组左边界，并按横向滚动位置显示 / 隐藏。
- [ ] 横向滚动时只有表格主体内容区滚动，表头和数据列对齐。
- [ ] 表格主体横向 / 纵向滚动条宽度为 4px；低于声明最小内容宽度时，由页面整体横向滚动，业务容器自身不产生横向滚动。
- [ ] 下拉选择、列筛选、更多菜单、字段配置、Tooltip 等弹出层位于最上层可视区域，不被遮挡、不出屏，并按触发控件自动左 / 右对齐。
- [ ] 搜索区 Select 触发器、选中值、下拉项和分组标题字号行高与 Select 组件规范一致，默认使用 14px / 22px，不得回落到浏览器默认 16px。
- [ ] 搜索区 Select 下拉项 hover 使用 `gray-3 / --gray-3` 中性背景，文字颜色不因 hover 变为主色；选中项 hover 只改变背景，不改变选中文字色。
- [ ] disabled 操作有 Tooltip 说明。
- [ ] 高风险操作有二次确认。
- [ ] loading、empty、error、success、failure 状态完整。
- [ ] HTML Demo 中主要交互均可点击验证。

### 12.1 可执行检测建议

通过浏览器读取布局和样式时，建议至少检测以下项：

- 搜索区所有标题元素的 computed width 一致；多行搜索项中标题右边界误差不超过 1px。
- 搜索区所有输入框、选择器、日期控件的宽度一致且不低于 200px；多行搜索项中控件左边界和右边界误差不超过 1px。
- 按页面结构判断容器数量：联动概览应有 2 个独立业务容器，且搜索区容器与概览表格列表容器垂直间距为 12px；非联动概览应有 2 个独立业务容器，间距为 16px；无概览搜索列表应有 1 个独立业务容器。
- 模式 A 中“数据概览区 + 表格区”合并容器的 computed padding-top / right / bottom / left 应均为 24px。
- 搜索区、概览区和表格区之间不应存在额外 divider / border 形式的分割线。
- 概览标题行不应固定 40px 高度，应由文本和 icon 自然撑开；模式 A 合并容器内只预留概览标题文字本身的自然高度；标题行与图表内容区垂直间距应为 16px；展开 / 收起按钮应在标题文字前方且没有可见文字；按钮 hover / focus / active 背景应保持透明、box-shadow 为 none；图表标题 computed style 应与搜索项标题一致。
- 展开态下图表内容区底部与表格操作行的垂直间距应为 24px；概览收起后，概览标题行底部与表格操作行的垂直间距仍应为 24px。
- 概览区展开态高度不得超过 300px；常规高密度列表建议约 240px，收起态不得保留图表内容高度。
- 占比图图例应竖向排列；图例名称列宽不应超过 8 个中文字符宽度，超长文案应单行省略并存在完整 title / Tooltip。
- 4 列搜索栅格下首行搜索项连续排布；若控件宽度低于 200px，必须已切换为 3 列或页面已产生横向滚动。
- 工具栏左侧操作区和右侧辅助区的顶部坐标一致；右侧辅助区右边界与表格主体右边界对齐，且没有自然换行。
- 右侧 `刷新`、`字段配置 / 配置表格字段` 等全局辅助按钮的可见文本应为空，按钮为 32px x 32px 常规辅助图标按钮，并存在可读 Tooltip / aria-label。
- 窗口宽度低于声明最小内容宽度时，检测页面级 `scrollWidth > clientWidth`，业务容器的 `scrollWidth` 不应大于自身 `clientWidth`。
- 横向滚动表格主体后，勾选列和首个关键识别业务列的表头、数据单元格 left 偏移保持不变，表头与 body 固定列宽度一致。
- 如有操作列，横向滚动表格主体后，操作列表头和数据单元格 right 偏移保持不变，表头与 body 固定列宽度一致。
- 表头 computed style 默认小号为 12px / 20px / 600，普通单元格为 12px / 20px / 400；如使用大号表格，则表头为 14px / 22px / 600，普通单元格为 14px / 22px / 400；状态 Tag 按 Tag 组件规范单独检测。
- 表头背景色应等于 `gray-2`，表头文字色应等于 `gray-9`，普通单元格文字色应等于 `gray-8`，列表容器 / 表格区容器内表格外层边框宽度应为 0。
- 横向滚动表格主体后，左侧冻结阴影应只出现在左冻结组最后一列右边界，滚回最左侧后隐藏；右侧冻结阴影应只出现在右冻结组最左一列左边界，滚到最右侧后隐藏。
- Select Trigger、Select Value、Select Panel Item 的 computed font-size / line-height 默认应为 14px / 22px；下拉项 hover 后 background-color 应等于 `gray-3`，普通项 color 应保持 `popover-foreground`。
- 针对勾选项的数据操作按钮文本不得命中 `已选`、`所选`、`批量` 等范围修饰词；`已选 N 项` 只能作为独立数量提示出现。
- 分页区左侧跨页全选 checkbox 与表格勾选列 checkbox 的 `left` 坐标误差不超过 1px；信息提示图标外框为 14px x 14px；右侧必须同时存在总数、每页条数、页码轨道和跳页输入。
- 表格主体横向 / 纵向滚动条的 CSS `width / height` 应为 4px。

缺少任一当前业务适用项，视为列表页生成失败。
