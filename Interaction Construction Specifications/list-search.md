# 列表页搜索栏区域交互规范
## List Page Search Bar Interaction Rules

Keywords: list search, filter, query, search bar, layout, responsive, backend, html demo

本文定义列表页搜索栏区域的容器、搜索项、占位文案、操作按钮、换行、反馈和 HTML Demo 验收规则。AI 生成列表页 HTML Demo 或 HTML 预览文件时，必须遵循本文。

## 1. 搜索区定位

搜索区用于帮助用户缩小数据范围，提高查找效率。它通常位于页面标题区下方、表格区域上方，不应比表格更抢眼，也不应占据过高首屏空间。

## 2. 容器规则

| 项目 | 规则 |
|---|---|
| 背景 | #FFFFFF |
| 宽度 | 铺满外部内容容器 |
| 圆角 | 8px |
| 内边距 | 24px |
| 行间距 | 20px |
| 搜索项横向间距 | 32px |
| 响应式 | 空间不足时搜索项整组换行，禁止拆散标题和控件 |

## 3. 搜索项布局

所有搜索项采用：

```text
标题 + 输入控件
```

- 标题与输入控件横向组合，并垂直居中。
- 标题与输入控件间距为 8px。
- 输入控件默认宽度保持统一，建议 200px–260px。
- 标题建议不超过 8 个汉字；多行搜索区内标题宽度以最长标题对齐。
- 标题过长时优先优化字段命名，不建议强行展示长标题。

## 4. 占位文案

| 控件类型 | 默认占位文案 | 补充说明 |
|---|---|---|
| 输入类 | `请输入` | 可追加业务说明，例如 `请输入，支持模糊搜索` |
| 选择类 | `请选择` | 多选、树选、级联选择仍使用该前缀 |
| 日期 / 时间范围 | `请选择` | 可按业务展示为开始时间 / 结束时间 |

占位文案过长时单行省略，hover 通过 Tooltip 展示完整内容。

## 5. 操作按钮

| 按钮 | 样式 | 固定文案 | 说明 |
|---|---|---|---|
| 搜索 | 主按钮 | `搜索` | 触发查询并刷新列表 |
| 清空 | 辅助按钮 | `清空` | 清空条件并刷新列表 |

规则：

- 按钮组跟随最后一行搜索项，并整体右对齐。
- 按钮间距统一 8px。
- 搜索区内不出现多个主按钮。
- 默认使用 `搜索 / 清空`，不要混用 `查询 / 重置 / 确认` 等近义文案。

## 6. 换行规则

- 搜索项从左至右依次排列。
- 单行空间不足以容纳完整一组“标题 + 输入控件”时，整组换行。
- 操作按钮默认跟随最后一行；若空间不足，按钮可单独换行但仍右对齐。
- 搜索项数量较少时整体跟随容器自适应排布。

## 7. 查询交互

- 点击 `搜索` 后刷新表格数据，并展示 loading。
- 点击 `清空` 后清空所有查询条件，并刷新表格数据。
- 搜索无结果时展示空状态，并提示用户调整筛选条件。
- 高级筛选展开 / 收起时保留用户已输入条件。
- 默认不因筛选项变化立即查询，除非业务明确要求实时刷新。

## 8. HTML Demo 要求

HTML Demo 必须支持：

- 输入关键词。
- 选择筛选项。
- 点击搜索刷新 mock 表格。
- 点击清空重置条件。
- 窄屏时搜索项整组换行。
- 搜索中 loading。
- 搜索无结果 empty。

## 9. AI 生成禁止项

- 禁止把搜索区做成大面积营销筛选卡片。
- 禁止让搜索区高度超过表格区视觉重点。
- 禁止搜索项标题、输入框宽度混乱。
- 禁止按钮文案混用 `查询 / 重置 / 确认` 替代默认 `搜索 / 清空`。
- 禁止空间不足时把标题和输入控件拆开换行。

## 10. 验收清单

AI 生成列表页 HTML Demo 或 HTML 预览文件时，搜索区必须通过以下验收：

- [ ] 搜索区位于表格区域上方。
- [ ] 搜索项采用 `标题 + 输入控件` 结构。
- [ ] 同一页输入控件宽度统一。
- [ ] 空间不足时搜索项整组换行。
- [ ] 输入类占位文案为 `请输入`。
- [ ] 选择类占位文案为 `请选择`。
- [ ] 操作按钮固定为 `搜索 / 清空`。
- [ ] 点击搜索后刷新表格并展示 loading。
- [ ] 点击清空后清空条件并刷新表格。
- [ ] 搜索无结果时展示空状态。
- [ ] HTML Demo 中以上行为可被点击验证。

缺少任一适用项，视为搜索区生成失败。
