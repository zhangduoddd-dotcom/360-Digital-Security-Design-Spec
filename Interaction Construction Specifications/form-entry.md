# 表单页信息录入交互规范
## Form Page Information Entry Interaction Rules

Keywords: form entry, validation, conditional visibility, step structure, form state, operation priority, backend, html demo

本文定义企业级 B 端系统表单信息录入的交互规则。AI 生成表单页 HTML Demo 或 HTML 预览文件时，必须遵循本文，不得自创页面结构、交互模板、校验规则或文案格式。

## 1. 适用场景

适用于信息上报、基础配置、分析规则、处置策略、系统对接、账号权限、安全设置、参数配置、数据填报等 B 端表单页面。

## 2. 核心原则

- 表单目标必须明确：新增、编辑、配置、提交、审批或查询。
- 字段分组必须服务用户理解，不按接口字段机械平铺。
- 必填、错误、禁用、只读、说明、风险影响必须可识别。
- 操作路径必须稳定：保存、取消、上一步、下一步、提交位置清晰。
- 高风险配置必须说明影响范围，并在保存前二次确认。
- HTML Demo 必须可输入、可校验、可提交、可反馈。

## 3. 表单布局

| 场景 | 推荐布局 |
|---|---|
| 常规录入 | 单列纵向表单 |
| 字段较多 | 分组标题 + 单列字段 |
| 字段超过 12 个 | 分组或标签页 |
| 字段超过 20 个 | 分步流程或分区配置 |
| 轻量新增 / 编辑 | 右侧抽屉表单 |
| 高风险提交 | 独立页面或带确认弹窗的表单 |

基础规则：

- 标签位于左侧，控件位于右侧。
- 标签宽度统一，建议 120px–160px。
- 普通输入控件宽度统一，建议 360px–480px。
- 每行字段垂直间距一致。
- 提示说明放在字段下方，使用辅助文本色。
- 文本域可显示字数统计，例如 `0/100`。

## 4. 字段状态

表单控件必须覆盖以下状态：

| 状态 | 要求 |
|---|---|
| 默认 | 可输入、文案清晰 |
| 聚焦 | 有明确 focus ring |
| 必填 | 标签前或旁侧展示红色星号 |
| 错误 | 字段下方展示明确错误原因 |
| 禁用 | 降低对比度但仍可读 |
| 只读 | 不表现得像可编辑输入框 |
| loading | 提交或异步校验期间防止重复操作 |
| 成功 / 失败 | 保存后必须反馈结果 |

## 5. 校验规则

- 必填项不能为空。
- 格式类字段必须给出格式提示，例如 IP、端口、邮箱、URL、正则表达式。
- 错误文案必须说明原因，不只写“格式错误”。
- 提交时若存在错误，应定位到第一个错误字段。
- 异步校验需要 loading 或校验中状态。
- 保存失败时保留已填写内容。

## 6. 条件显隐与联动

- 条件字段变化后，可显示或隐藏后续字段。
- 被隐藏字段不应继续影响提交校验，除非业务明确要求。
- 联动变化必须可感知，例如字段出现、禁用、说明更新或选项刷新。
- 关键联动必须在 HTML Demo 中可点击验证。

## 7. 抽屉表单

抽屉表单适合从列表页、详情页或配置页快速新增、编辑或添加规则。

结构：

```text
背景页面 + 遮罩
→ 右侧抽屉
→ 抽屉标题 + 关闭按钮
→ 表单内容区
→ 底部操作区：取消 + 保存 / 确认
```

规则：

- 抽屉宽度统一为 560px / 880px / 80%。
- 标题固定在顶部，操作区固定在底部。
- 内容区可滚动。
- 关闭或取消时，如有未保存内容，必须二次确认。
- 复杂多步骤流程不应放入轻量抽屉。

## 8. 提交与取消

- 主按钮文案按场景使用 `保存`、`提交`、`确认`。
- 取消按钮与主按钮层级清晰。
- 提交期间主按钮展示 loading 并禁用重复点击。
- 保存成功展示成功反馈，并按业务返回、关闭抽屉或停留当前页。
- 保存失败展示失败原因，并保留用户输入。
- 离开页面或关闭抽屉前，如存在脏状态，必须确认。

## 9. HTML Demo 要求

HTML Demo 必须支持：

- 字段输入和清空。
- 必填校验和格式校验。
- 条件显隐或至少一种字段联动。
- 提交 loading。
- 保存成功提示。
- 保存失败提示。
- 取消 / 关闭时的未保存确认。
- 禁用和只读状态展示。
- mock 数据回填。

## 10. AI 生成禁止项

- 禁止字段无分组、无顺序地堆叠。
- 禁止复杂表单没有说明文案或影响范围提示。
- 禁止错误校验只有颜色，没有错误文案。
- 禁止保存失败后清空用户已填内容。
- 禁止高风险配置直接保存，没有二次确认。
- 禁止 HTML Demo 只展示静态表单，不能输入或提交。

## 11. 验收清单

- [ ] 表单类型明确：新增、编辑、配置、提交或审批。
- [ ] 字段按业务含义分组。
- [ ] 标签宽度、控件宽度、字段间距统一。
- [ ] 必填、错误、禁用、只读、loading 状态可识别。
- [ ] 至少一种字段联动可验证。
- [ ] 提交成功 / 失败反馈完整。
- [ ] 取消或关闭时存在未保存确认。
- [ ] 高风险配置有影响说明和二次确认。
- [ ] HTML Demo 中输入、校验、提交、反馈可点击验证。

缺少任一适用项，视为表单录入生成失败。
