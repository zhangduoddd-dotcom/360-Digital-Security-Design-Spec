# 权限与状态交互规范
## Permission and State Rules

Keywords: permission, disabled, loading, empty, error, backend

本文定义后台页面中的权限控制、禁用状态、加载状态、空状态和异常状态。

## 1. 权限控制方式

正常显示用于用户有权限操作；禁用显示用于用户需要知道能力存在但当前不可操作；隐藏用于用户不应感知该能力或完全无查看权限。

## 2. 禁用状态

禁用按钮不可点击。如果禁用原因不明显，应通过 Tooltip 或说明文案解释。禁用状态不应和 loading 状态混淆。

## 3. 加载状态

异步请求必须展示 loading。表单提交 loading 时应避免重复提交。超过 2 秒的任务建议说明当前阶段。加载失败必须提供重试入口。

## 4. 空状态和异常状态

空状态应说明没有数据的原因，并提供下一步动作。异常状态应说明发生了什么、对用户有什么影响、下一步能做什么。
