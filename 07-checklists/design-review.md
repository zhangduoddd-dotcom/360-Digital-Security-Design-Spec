# 设计走查清单
## Design Review Checklist

Keywords: design review, checklist, backend ui, consistency

本文用于设计稿自查、团队评审和规范一致性检查。

## 1. 页面结构

- [ ] 页面标题、导航、内容区、操作区层级清楚。
- [ ] 页面主任务明确，首屏能看出用户要做什么。
- [ ] 同类页面使用一致的布局骨架。
- [ ] 页面模块顺序符合用户任务路径。

## 2. 视觉一致性

- [ ] 页面背景、卡片背景、分割线符合基础规范。
- [ ] 字号、行高、字重符合字体规范。
- [ ] 间距遵循 4px 基准。
- [ ] 主色、功能色、状态色使用语义一致。

## 3. 交互可用性

- [ ] 高频操作显性化，低频操作合理收纳。
- [ ] 高风险操作有确认机制。
- [ ] 异步操作有 loading 和结果反馈。
- [ ] 空状态、异常状态有解释和下一步动作。
