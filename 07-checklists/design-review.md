# 设计走查清单
## Design Review Checklist

Keywords: design review, checklist, backend ui, consistency, ai scenario

本文用于设计稿自查、团队评审和规范一致性检查。

## 1. 全局一致性

- [ ] 页面是否使用统一画板和栅格。
- [ ] 间距是否为 4px 的倍数。
- [ ] 字号、行高、字重是否符合规范。
- [ ] 颜色是否来自统一 Token。
- [ ] 卡片、表格、表单、按钮是否使用统一组件。
- [ ] 页面层级是否清晰。

## 2. 页面架构

- [ ] 用户是否能一眼看懂当前页面任务。
- [ ] 页面标题是否清晰。
- [ ] 面包屑是否正确。
- [ ] 主操作是否明显。
- [ ] 筛选区、内容区、操作区是否分区清楚。
- [ ] 小屏下侧边栏是否能正确收起。
- [ ] 顶部导航、侧边导航、主内容区、弹层区关系是否稳定。

## 3. 表格

- [ ] 表头是否清晰。
- [ ] 单位是否放在表头。
- [ ] 对齐方式是否正确。
- [ ] 文本溢出是否有省略和 Tooltip。
- [ ] 是否有空状态。
- [ ] 是否有分页。
- [ ] 操作列是否过多。
- [ ] 横向滚动时是否冻结主列和操作列。
- [ ] 勾选行相关操作是否与勾选状态联动。
- [ ] 勾选后是否展示 `已选 N 项`。

## 4. 表单

- [ ] 标签是否简洁。
- [ ] 必填项是否清晰。
- [ ] 错误提示是否紧贴控件。
- [ ] 帮助说明是否必要且清楚。
- [ ] 输入框、选择器、日期等组件是否选型正确。
- [ ] 提交失败时是否说明原因。
- [ ] 字段超过 12 个时是否分组。
- [ ] 字段超过 20 个时是否步骤化。
- [ ] 脏状态离开是否有确认提示。

## 5. 按钮

- [ ] 一个操作区域是否只有一个主按钮。
- [ ] 按钮文案是否表达具体动作。
- [ ] 危险操作是否二次确认。
- [ ] 是否包含 hover / click / disabled / loading 状态。
- [ ] 多个操作是否按主次排列。
- [ ] 普通业务按钮是否没有误用 AI 渐变。

## 6. 反馈

- [ ] 成功、失败、警告是否使用正确反馈组件。
- [ ] Message 是否用于轻量反馈。
- [ ] Notification 是否用于系统主动通知。
- [ ] Alert 是否用于常驻警告。
- [ ] Modal 是否用于阻断式确认。
- [ ] 抽屉是否用于不离开当前页面的附加任务。
- [ ] 空状态、异常页是否有下一步操作。

## 7. AI 场景

- [ ] AI 操作是否说明生成内容和影响范围。
- [ ] AI 执行中是否有 loading 或进度反馈。
- [ ] AI 结果是否可编辑、可审核、可应用。
- [ ] AI 结果是否展示来源或依据。
- [ ] 高风险 AI 操作是否需要人工确认。
- [ ] 是否保留操作日志和审计信息。
- [ ] 多智能体协作时是否展示每个智能体的贡献或状态。

## 8. 布局、列表与适配检查

| 检查项 | 合格标准 |
|---|---|
| 布局画板 | 是否以 1440px 为常规设计稿基准 |
| 原子单位 | 布局、间距、尺寸是否使用 4px 倍数 |
| 主流分辨率 | 是否至少检查 1920 / 1440 / 1366 / 1280 |
| 侧边栏断点 | 是否设置 992px 默认断点 |
| 页面最小宽度 | 是否明确 768px 最小宽度和横向滚动策略 |
| 收起侧边栏 | 是否明确 56px 收起态宽度 |
| 列表行高 | 表头和单元格是否统一 40px |
| 列表字号 | 列表文字是否统一 12px |
| 列表间距 | 列表距操作区和分页是否为 8px |
| 操作按钮 | 列表页操作按钮间距是否为 8px |
| Dashboard 图表 | 是否为环形、趋势、柱形等图表定义最小宽度 |
| 图表压缩 | 宽度不足时是否横向滚动，而不是强行压缩 |
| 表格横向滚动 | 是否固定关键列 / 操作列并保证表头内容对齐 |

## 9. CSS Token 检查

| 检查项 | 验收标准 |
|---|---|
| 主色 | 普通主操作是否使用 `p6 #00AB7A`，hover 是否使用 `p5`，active 是否使用 `p7` |
| AI 按钮 | AI 功能入口是否使用 AI 默认 / AI 悬停 / AI 按下三态渐变 |
| AI 与普通按钮区分 | 普通保存、提交、筛选、导出按钮是否没有误用 AI 渐变 |
| 中性色 | 背景、hover、边框、分割线、正文、标题是否分别调用正确 `gray-*` |
| 功能色 | 成功、警告、错误、信息是否使用对应 Green / Orange / Red / Blue Token |
| 安全等级 | 致命、严重、高危、中危、低危、安全是否按 Deep red / Red / Orange red / Orange / Yellow / Green 映射 |
| Focus ring | 表单聚焦、错误、成功、警告状态是否使用 2px 外描边 Token |
| 投影 | 卡片是否用一级投影；弹窗 / 抽屉是否用二级投影；AI 超级输入框 hover 是否用专门阴影 |
| 工程命名 | 是否为中文 Token 建立英文 alias，避免工程兼容问题 |
