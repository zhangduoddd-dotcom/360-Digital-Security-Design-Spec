# 通用组件规范
## General Component Specification
Keywords: component, UI, button, form, modal, table

## 按钮规范

### 按钮类型

| 类型 | 用途 |
|---|---|
| 主按钮 | 引导用户完成当前最重要操作 |
| 次按钮 | 与主按钮配合，执行次级操作 |
| 辅助按钮 | 弱化操作、辅助功能 |
| 文字按钮 | 最次级操作，常用于表格行操作 |
| 链接按钮 | 跳转到其他页面或位置 |
| 图标按钮 | 空间有限或轻量操作 |
| 下拉按钮 | 收纳多个同类或低频操作 |
| AI 按钮 | 触发 AI 生成、智能分析、自动填充、智能推荐等能力 |

### 按钮层级

#### 基本规则

- 一个操作区域只保留一个主按钮。
- 页面级主按钮一般放在页头右侧。
- 弹窗内主按钮放在右侧，取消按钮放在左侧。
- 多个按钮组合时，推荐 `1 个主操作 + N 个次操作`。
- 6 个以上操作时，应把低频操作放入“更多”下拉。

#### 示例

```text
[取消] [保存草稿] [确定发布]
```

其中：

- `确定发布` 为主操作。
- `保存草稿` 为次操作。
- `取消` 为辅助操作。

### 按钮状态

按钮必须至少包含以下状态：

| 状态 | 说明 |
|---|---|
| Default | 默认可点击状态 |
| Hover | 鼠标移入状态 |
| Active / Click | 点击状态 |
| Disabled | 不可用状态 |
| Loading | 操作处理中状态 |
| Danger | 危险操作状态 |

### 图标按钮

#### 使用场景

- 表格行内操作。
- 工具栏中的轻量操作。
- 空间有限的表单项操作。
- 需要快速识别的功能入口。

#### 规则

- 图标语义必须清晰。
- 不易理解的图标必须加 Tooltip。
- 一个页面避免过多带图标的强引导按钮。
- 图标按钮不应替代关键文字说明。

### AI 按钮规范

#### 使用场景

| AI 按钮文案 | 使用场景 |
|---|---|
| 智能生成 | 生成文案、报告、任务方案 |
| AI 分析 | 对数据、日志、风险进行分析 |
| 智能推荐 | 推荐专家、策略、模板 |
| 自动填充 | 根据上下文填充表单 |
| 重新生成 | 对 AI 结果进行迭代 |
| 应用结果 | 将 AI 生成结果写入业务流程 |

#### AI 按钮视觉状态

| 状态 | Token | CSS 值 | 说明 |
|---|---|---|---|
| Default | `AI 默认` | `linear-gradient(307deg, #004DFF 0%, #1093FF 65%, #1AFFAF 100%)` | 默认可点击状态 |
| Hover | `AI 悬停` | `linear-gradient(0deg, rgba(255,255,255,0.20), rgba(255,255,255,0.20)), linear-gradient(126deg, #1AFFAF 0%, #1093FF 37%, #004DFF 100%)` | 悬停时叠加 20% 白色蒙层 |
| Active / Click | `AI 按下` | `linear-gradient(0deg, rgba(0,0,0,0.20), rgba(0,0,0,0.20)), linear-gradient(309deg, #004DFF 0%, #1093FF 54%, #1AFFAF 100%)` | 按下时叠加 20% 黑色蒙层 |

#### AI 按钮设计要求

- AI 按钮必须和普通主按钮区分：普通主按钮走 `p6/p5/p7`，AI 按钮走三态渐变。
- AI 按钮应说明执行后会产生什么结果。
- 涉及写入、发布、删除、变更配置的 AI 操作，不能直接自动执行，必须由用户确认。
- AI 生成中必须有 loading 状态。
- AI 结果必须支持查看、修改、应用和撤销。
- 关键 AI 操作应保留日志，便于审计。
- 不要把所有主要按钮都做成 AI 渐变；否则用户无法判断哪些操作真的调用 AI 能力。

## 数据录入规范

### 表单

#### 使用场景

- 创建、编辑、配置、审批、提交数据。
- 由输入框、选择器、单选框、多选框等控件组成。
- 需要收集、校验、提交数据。

#### 表单标签规则

| 项目 | 规范 |
|---|---|
| 标签长度 | 建议单行，不超过 10 个中文字符 |
| 标签表达 | 简洁、准确、业务可理解 |
| 必填项 | 使用统一必填标识 |
| 非必填项 | 不建议大量标注“选填”，避免视觉噪音 |
| 帮助说明 | 放在标签旁或输入框下方 |
| 错误说明 | 紧贴出错控件展示 |

#### 表单布局

| 类型 | 使用场景 |
|---|---|
| 单列表单 | 简单创建、编辑 |
| 多列表单 | 字段较多但信息结构清晰 |
| 分组表单 | 字段多且有明显类别 |
| 分步表单 | 流程长、需要逐步确认 |
| 抽屉表单 | 在不离开当前页面的情况下完成附加编辑 |
| 弹窗表单 | 轻量创建或确认，不适合复杂录入 |

### 输入框

#### 使用场景

- 用户需要输入文本、数字、符号。
- 单行或多行文本输入。
- 搜索、自动完成、提及、带单位输入等。

#### 状态

| 状态 | 说明 |
|---|---|
| 常规 | 默认状态 |
| Hover | 鼠标移入 |
| Focus | 输入中 |
| Filled | 输入完成 |
| Disabled | 不可输入 |
| Error | 校验失败 |

#### 占位文案

- 默认使用“请输入”。
- 需要具体说明时使用“请输入 XX”。
- 有格式要求时写明示例，例如“请输入邮箱地址”。
- 有字数限制时可提示“不超过 18 个字符”。

#### 长文本框

- 右下角显示字数限制与当前字数，例如 `0/100`。
- 超出字数限制时应阻止继续输入或明确提示。
- 内容超过默认高度时可出现滚动条。
- 可拖拽改变高度时需要限制最大高度。

### 选择器 Select

#### 使用场景

- 弹出下拉菜单供用户选择。
- 选项较多，不适合平铺展示。
- 支持单选、多选、搜索。

#### 规则

- 选项少于 5 个时，优先考虑 Radio 或 Checkbox。
- 单选可支持搜索。
- 多选应支持标签展示和清除。
- 无结果时展示“暂无数据”。
- 加载时展示“加载中”。

### 单选框 Radio

#### 使用场景

- 多个备选项中选择一个。
- 所有选项默认可见。
- 用户需要对比后选择。

#### 规则

- 选项不宜过多。
- 横向排列间距建议 24px。
- 纵向排列间距建议 12px。
- 如果选项超过 5 个，建议改用 Select。

### 多选框 Checkbox

#### 使用场景

- 在一组选项中选择一个或多个。
- 单独使用时也可表示两种状态之间的标记。

#### Checkbox 与 Switch 区别

| 组件 | 区别 |
|---|---|
| Checkbox | 通常作为状态标记，需要配合提交按钮生效 |
| Switch | 切换后立即生效 |

### 开关 Switch

#### 使用场景

- 表示开启 / 关闭。
- 两种互斥状态之间切换。
- 用户选择后系统立即执行。

#### 规则

- 适合简单、直观的状态切换。
- 对高风险开关，切换前应二次确认。
- 切换后必须反馈结果。
- 禁用态需要说明原因。

### 日期选择器

#### 使用场景

- 选择单个日期。
- 选择日期范围。
- 日期与时间组合选择。
- 使用预设范围。

#### 设计原则

- 标识当天日期。
- 明确选中日期或范围。
- 必要时标注周末、节假日或特殊日期。
- 支持键盘输入时必须容错。
- 日期范围应明确开始和结束。

### 时间选择器

#### 使用场景

- 选择小时、分钟、秒。
- 避免用户手动输入格式错误。
- 配合日期选择器形成完整时间范围。

#### 规则

- 时间格式必须统一。
- 禁用不可选时间。
- 错误格式需要即时提示。
- 默认值应符合业务场景。

### 级联选择

#### 使用场景

- 从关联数据集合中选择。
- 典型场景：省市区、公司层级、分类体系、组织结构。

#### 规则

- 层级关系必须清晰。
- 支持搜索时应提示匹配路径。
- 如果只选择最终节点，应避免误选中间层。
- 层级过深时建议改为树选择。

### 树选择

#### 使用场景

- 文件夹、组织架构、分类、地区等树形结构。
- 需要展开、收起、选择层级节点。

#### 规则

- 建议最多 4 级。
- 支持单选和多选。
- 多选时应明确父子节点联动关系。
- 节点过多时必须支持搜索。

### 穿梭框

#### 使用场景

- 在两栏之间移动元素。
- 需要从候选集合中选择一个或多个对象。

#### 规则

- 左侧为来源 Source。
- 右侧为目标 Target。
- 支持搜索。
- 支持已选数量展示。
- 移动按钮必须有禁用态。

### 上传

#### 使用场景

- 文件上传。
- 图片上传。
- 拖拽上传。
- 展示上传进度。

#### 规则

- 明确支持的扩展名。
- 明确文件大小限制。
- 上传中显示进度。
- 上传失败说明原因。
- 涉及敏感文件时应提示安全风险。

## 数据展示规范

### 表格

表格用于展示多条结构类似的数据，可支持排序、筛选、对比、自定义操作。

#### 使用场景

- 大量结构化数据。
- 需要排序、搜索、分页、筛选。
- 需要批量操作。
- 需要行级操作。

#### 表格规则

| 项目 | 规范 |
|---|---|
| 布局 | 默认采用百分比布局，适配多分辨率 |
| 表头 | 单位统一放在表头内，表头文本不建议换行 |
| 排列 | 按业务重要程度和强相关性从左到右排列 |
| 首列 | 通常为主信息列 |
| 对齐 | 名称、链接、信息、日期、姓名、操作左对齐；数据类右对齐 |
| 冻结 | 横向滚动时冻结主信息列和操作列 |
| 树形层级 | 树形表格节点不得超过 3 层 |
| 排序 | 数据类型列可排序，默认按业务逻辑排序 |
| 筛选 | 类别属性列可筛选 |
| 文本溢出 | 单行文本超出后用 `...`，Hover 出现 Tooltip |
| 空数据 | 显示“暂无数据”，保留表头，不显示分页 |
| 操作列 | 操作过多时使用“更多”或下拉，不建议超过 5 个 |

#### 表格筛选区

推荐结构：

```text
[搜索框] [筛选项] [日期范围] [更多筛选]       [重置] [查询]
```

规则：

- 高频筛选项放在表格上方。
- 低频筛选项放入“更多筛选”。
- 表头筛选适合轻量类别过滤。
- 搜索条件复杂时应提供“重置”。

### 卡片

#### 使用场景

- Dashboard 概览。
- 信息聚合。
- 任务列表。
- 专家卡片。
- 项目卡片。

#### 规则

- 卡片承载一组相关信息或类似任务。
- 卡片标题要明确。
- 卡片内操作不要过多。
- 卡片之间间距保持一致。
- 可点击卡片必须有 Hover 状态。
- 卡片内信息应遵循“标题 → 状态 → 关键指标 → 描述 → 操作”的顺序。

### 统计数值

#### 使用场景

- 突出展示一个或一组数字。
- Dashboard 指标。
- 请求次数、成功率、风险数量、任务数等。

#### 规则

- 数字应明显大于说明文字。
- 单位必须清晰。
- 同组指标的格式保持一致。
- 对比数据应说明变化方向。
- 重要异常指标可结合功能色。

### 标签 Tag

#### 使用场景

- 标记属性。
- 状态分类。
- 等级展示。
- 可删除筛选条件。
- 多彩标签。

#### 规则

- 标签文字简短。
- 标签颜色必须和语义一致。
- 状态标签和等级标签不要混用。
- 可删除标签需要明确关闭图标。
- 风险等级标签必须使用统一安全等级色。

### 徽标数 Badge

#### 使用场景

- 通知数量。
- 待办数量。
- 告警数量。
- 状态点。

#### 规则

- 数量过大使用 `999+`。
- 状态点用于在线、离线、异常、处理中等状态。
- 徽标不能遮挡主体图标识别。

### 描述列表

#### 使用场景

- 详情页只读字段展示。
- 成组展示对象属性。
- 审批详情、项目详情、专家详情。

#### 规则

- 字段名称和字段值分区清晰。
- 字段过多时分组展示。
- 可使用带边框样式强化结构。
- 空字段统一显示 `--` 或“暂无”。

### 时间轴

#### 使用场景

- 操作记录。
- 审批流程。
- 任务进度。
- 日志事件。

#### 规则

- 可正序或倒序，但同一产品内应统一。
- 状态点颜色必须表达进度或结果。
- 重要节点可加入图标。
- 时间、操作者、动作、结果应完整展示。

### Tooltip 文字提示

#### 使用场景

- 对图标、按钮、术语进行解释。
- 表格文本溢出展示完整内容。
- 轻量辅助说明。

#### 规则

- 不承载复杂内容。
- 不承载操作。
- 不用于主体内容展示。
- 文案必须短。

### Popover 气泡卡片

#### 使用场景

- 目标元素有进一步说明和相关操作。
- 需要承载链接、按钮、简短详情。
- 用户可与浮层内容交互。

#### Tooltip 与 Popover 区别

| 组件 | 是否可操作 | 内容复杂度 |
|---|---|---|
| Tooltip | 不可操作 | 简短文字 |
| Popover | 可操作 | 文本、链接、按钮、简短列表 |

### 折叠面板

#### 使用场景

- 复杂区域分组。
- 隐藏低频信息。
- 保持页面整洁。

#### 规则

- 标题必须概括内容。
- 只允许单项展开时使用手风琴模式。
- 默认展开项应符合用户主要任务。
- 不要把高频信息默认折叠。

## 反馈与异常规范

### 全局提示 Message

#### 使用场景

- 用户主动操作后的轻量反馈。
- 只需要阅读，不需要后续操作。
- 加载完成、保存成功、删除失败等。

#### 规则

- 位于页面顶部居中。
- 约 3 秒后自动消失。
- 不打断用户操作。
- 类型仅保留常规、成功、预警、失败。
- 文案尽量短，例如“保存成功”“删除失败，请重试”。

### 通知提醒框 Notification

#### 使用场景

- 系统主动推送。
- 后台任务完成。
- 工作流结果通知。
- 复杂内容提醒。

#### 规则

- 出现在页面角落。
- 不遮挡关键内容。
- 内容比 Message 更复杂。
- 可包含标题、说明和操作入口。
- 不重要通知应进入消息中心，不要弹出打扰用户。

### 警告提示 Alert

#### 使用场景

- 页面级重要提示。
- 用户需要持续关注的警告信息。
- 常驻展示，不自动消失。

#### 规则

- 可关闭，但关闭前不应影响理解。
- 用于整个页面或模块提示。
- 不适合直接用于弹窗内复杂提示，弹窗内应改为轻量文字说明。
- 文案应说明问题、影响和建议操作。

### 弹窗 Modal

#### 使用场景

- 用户必须确认后才能继续。
- 高风险操作确认。
- 短表单或结果反馈。
- 阻断当前流程的关键动作。

#### 规则

- 弹窗必须有明确标题。
- 标题要说明动作和对象。
- 描述要说明后果。
- 主按钮文案不要只写“确定”，应尽量写明动作，如“确认删除”。
- 不可逆操作使用危险按钮。

#### 高风险操作反馈模板

```text
标题：确定 {动作} {对象} 吗？
说明：{动作} 后 {结果}，请谨慎操作。
增强说明：{进一步业务影响或恢复方式}
按钮：[取消] [确认{动作}]
```

示例：

```text
标题：确定删除客户端策略吗？
说明：删除后将无法恢复，请谨慎操作。
增强说明：删除后客户端将无法执行该策略，请确认后继续。
按钮：[取消] [确认删除]
```

### 气泡确认框 Popconfirm

#### 使用场景

- 目标元素附近的轻量二次确认。
- 表格行内删除、停用、移除等操作。
- 操作风险较低，但需要用户确认。

#### 规则

- 只用于确认操作。
- 不承载复杂表单。
- 不承载详细说明。
- 高风险不可逆操作应使用 Modal，而不是 Popconfirm。

### 抽屉 Drawer

#### 使用场景

- 在不离开当前页面的情况下插入附加任务。
- 查看详情。
- 编辑辅助信息。
- 配置筛选条件。
- 表格行详情。

#### 规则

- 从页面边缘滑出。
- 覆盖部分父页面。
- 用户完成后能平滑回到原任务。
- 不适合承载特别复杂的多步骤流程。
- 抽屉宽度要根据内容复杂度设置。

### 加载中 Loading

#### 使用场景

- 页面或区块异步加载。
- 数据渲染等待。
- AI 生成中。
- 文件上传中。

#### 规则

- 加载时间较短时使用轻量 Loading。
- 超过 2 秒的任务建议显示进度或说明。
- AI 生成类任务应说明当前状态，例如“正在分析日志”“正在生成报告”。
- 加载失败必须给出重试入口。

### 进度条 Progress

#### 使用场景

- 操作耗时较长。
- 需要显示完成百分比。
- 后台任务执行。
- 上传、扫描、生成、部署。

#### 规则

- 超过 2 秒的任务建议显示进度。
- 支持成功、失败、处理中状态。
- 不能准确计算进度时，可以使用阶段进度或环形进度。
- 完成后需要结果反馈。

### 空状态 Empty

#### 使用场景

- 数据为空。
- 搜索无结果。
- 暂无任务。
- 暂无通知。
- 暂无权限下的数据入口。

#### 规则

- 不要只显示空白。
- 需要包括：插图、标题、说明、可选操作。
- 如果用户可以创建数据，应提供创建入口。
- 如果用户无权限，应说明原因和申请方式。
- 图标插图建议使用统一画板，例如 120×120。

### 异常页面

#### 使用场景

- 无权限。
- 网络不可用。
- 系统维护。
- 加载失败。
- 404。
- 500。

#### 规则

- 由插图、标题、说明、建议操作组成。
- 标题最多一行。
- 说明解释发生了什么。
- 操作给出下一步，如“返回首页”“刷新重试”“联系管理员”。
- 不同异常类型使用统一视觉风格。

### 按钮与图标按钮规范

#### 按钮类型

基础按钮组件包含四类按钮：

- **主按钮**：页面主操作、表单提交、关键流程确认。
- **次要按钮**：与主按钮并列的次级操作，如取消、返回、普通筛选。
- **辅助按钮**：低权重辅助动作，如更多配置、次级入口。
- **文字按钮**：表格行内操作、轻量链接动作、局部次级操作。

#### 按钮尺寸

| 尺寸 | 推荐高度 | 典型使用场景 | 字体 | 圆角 |
|---|---:|---|---|---:|
| 紧凑 | 24px | 表格行内操作、筛选区轻量按钮、空间受限区域 | 12px / 20px | 4px |
| 常规 | 32px | 页面主要按钮、表单按钮、工具栏按钮 | 14px / 22px | 6px |
| 宽松 | 40px | 强视觉主按钮、表单底部主操作、引导型按钮 | 16px / 28px | 8px |

按钮支持前置图标、后置图标、纯图标、纯文字以及图标+文字组合。图标按钮应优先使用 24px 或 32px 正方形容器，避免在高密度表格中使用 40px 图标按钮。

#### 按钮状态

| 状态 | 使用规则 |
|---|---|
| 默认 | 正常可点击状态 |
| 悬停 | 鼠标 hover 时强化边框、填充或文字颜色 |
| 按下 | 点击瞬间状态，颜色应比 hover 更深或更收敛 |
| 禁用 | 不可点击，使用禁用灰阶，禁止 hover 反馈 |
| 加载 | 提交、保存、上传、AI 生成等等待场景，按钮需阻止重复点击 |

AI 能力按钮仍按第 6.5 节使用 AI 渐变三态；普通业务按钮不要滥用 AI 渐变。

### 单选与多选规范

#### 胶囊单选 `radio-btn`

胶囊单选适合在筛选条件、模式切换、周期切换、视图切换中使用。单项标准尺寸为 **74 × 32px**，内边距为 **5px 16px**，文字为 **14px / 22px**。

| 方位 | 圆角规则 |
|---|---|
| 左 | 左上、左下圆角 6px；右侧为直角 |
| 中 | 左右均为直角 |
| 右 | 右上、右下圆角 6px；左侧为直角 |

状态必须包含：默认、hover、选中、未选禁用、已选禁用。

#### 基础单选 `radio` 与单选组 `radio-group`

基础单选适合表单中二选一或少量互斥选项。常见选项高度为 **22px**，文字为 **14px / 22px**。单选组支持：

- 常规横向排列；
- 常规纵向排列；
- 胶囊样式排列。

#### 多选框 `checkbox-basic` 与多选项 `checkbox-group`

基础多选框控件尺寸为 **16 × 16px**，控件圆角为 **4px**。必须包含以下状态：

- 默认；
- 悬浮；
- 选中；
- 半选；
- 未选失效；
- 已选失效；
- 半选失效。

多选项组的文字高度为 **22px**，文字为 **14px / 22px**。在树选择、权限配置、批量选择场景中，半选状态不能省略。

### 输入框族规范

#### 普通输入框 `input-basic`

输入框支持小、中、大三种尺寸，默认宽度常见为 **200px**。中号输入框是 B 端表单默认规格，高度为 **32px**，内边距常见为 **5px 12px**。

| 尺寸 | 高度 | 字号/行高 | 圆角 | 使用场景 |
|---|---:|---|---:|---|
| 小 | 24px | 12px / 20px | 4px | 表格筛选、紧凑工具栏、行内编辑 |
| 中 | 32px | 14px / 22px | 6px | 常规表单、搜索、筛选 |
| 大 | 40px | 16px / 28px | 8px | 重点输入、引导页、低密度表单 |

输入框状态统一为：默认、悬停、激活、禁用、输入完成、失败。失败状态必须配合错误文案，例如“输入错误原因”，不要只改变边框颜色。

输入框支持以下组合：

- 纯文字输入；
- 前置标签；
- 后置标签；
- 前置图标；
- 后置图标；
- 字数统计，例如 `0/10`。

#### 文本域 `input-textarea`

文本域常见默认尺寸为 **200 × 100px**；启用字数控制时常见尺寸为 **200 × 122px**。文本域支持常规文字尺寸、字数控制、可拖拽、滚动条。

| 状态 | 规则 |
|---|---|
| 默认 | 显示占位文案“请输入...” |
| 悬停 | 边框或背景轻微反馈 |
| 激活 | 使用主色边框或 focus ring |
| 输入完成 | 显示输入内容，必要时保留字数统计 |
| 失败 | 显示错误边框和错误说明 |
| 禁用 | 文本与边框进入禁用灰阶 |

文本域中滚动条宽度示例为 **4px**，应使用弱视觉灰阶，避免抢占输入内容注意力。

#### 数字输入框 `inputnumber`

数字输入框宽度常见为 **200px**，三档高度为 **24 / 32 / 40px**。它不是普通输入框的简单替代，应包含数值范围、增减控制、错误提示和禁用态。

必须包含的状态包括：默认、hover、键入、输入中、输入完成、报错、禁用、悬浮增减图标。

典型提示文案：

- `0-100`；
- `请输入0-100之间的数值`。

#### IPv4 输入框 `input-ipv4`

IPv4 输入框是专用输入组件，默认尺寸为 **188 × 32px**。当出现格式错误时，组件高度可扩展到约 **52px**，用于承载错误提示。

输入结构应按四段 IP 地址组织：

```text
0 . 0 . 0 . 0
192 . 168 . 1 . 1
```

校验规则：每段只允许 **0–255 的正整数**。错误提示可使用：

```text
格式错误，请输入0-255的正整数
```

### 选择器族规范

#### Select 选择器 `select`

Select 选择器的输入框外观与普通输入框保持一致，但状态复杂度更高。它必须支持单选、多选、加载、禁用、选中、清空和删除图标悬浮等交互。

| 尺寸 | 高度 | 常见宽度 | 使用场景 |
|---|---:|---:|---|
| 小 | 24px | 200px | 紧凑筛选、表格内筛选 |
| 中 | 32px | 200px | 常规表单选择器 |
| 大 | 40px | 200px | 低密度表单、引导式配置 |

状态包含：默认、hover、激活-未选下拉、激活-选中、选择完成、选择后 hover、鼠标再次悬浮、悬浮删除图标、选项加载中、禁用、多选-选择、多选-选择完成、多选-禁用、级联-选择完成。

下拉选项需要区分：默认、悬浮、选中、禁用、加载中。选项文字默认 **14px / 22px**。

#### Cascader 级联选择器 `cascader`

级联选择器适合选择具有父子层级的数据，例如地区、组织、权限分类、业务对象分类。面板宽度按层级扩展：

| 层级 | 面板尺寸 |
|---|---|
| 一级 | 120 × 160px |
| 二级 | 240 × 160px |
| 三级 | 360 × 160px |

级联选择器支持单选与多选。每一级选项文字为 **14px / 22px**，面板圆角为 **6px**。

#### TreeSelect 树选择 `treeselect`

树选择用于层级结构更深、需要展开/折叠节点的选择场景。组件支持基本样式和多选框样式。

| 样式 | 面板尺寸 | 使用场景 |
|---|---|---|
| 基本样式 | 约 267 × 232px | 单选层级对象 |
| 多选框样式 | 约 239 × 232px | 权限、组织、分类多选 |

树节点状态至少包含：父级默认、父级禁用、子级默认、子级悬浮、子级选中、子级禁用、三级子级。展开图标尺寸示例为 **12 × 12px**。

### 日期与时间选择器规范

#### DatePicker 日期选择器 `datepicker-basic`

日期选择器支持三类核心类型：

- 选日期/日期时间；
- 日期区间；
- 终端自定义日期选择。

| 类型 | 常见尺寸 | 说明 |
|---|---|---|
| 单日期中号 | 240 × 32px | 默认表单日期选择 |
| 日期区间中号 | 400 × 32px | 开始日期 + 结束日期 |
| 大号日期输入 | 高度 40px | 低密度表单或重点输入 |
| 小号日期输入 | 高度 24px | 紧凑筛选区 |

状态分为两个层级：

1. **填写状态**：未填写完成、已填写完成。
2. **交互状态**：默认、悬停、聚焦、输入中、禁用、悬停清空图标。

日期单元格支持标题、周几、年份/月、日期、时间等类型。日期格常见 **24 × 24px**，面板标题行常见 **280 × 40px**。日期下拉面板支持日、月、年、日+时、日-双月、双月+时间范围等结构；常见面板宽度为 **280px、560px、657px**。

#### TimePicker 时间选择器 `timepicker`

时间选择器支持单时间与时间区间。输入框尺寸与普通输入框一致，默认中号高度为 **32px**。

| 类型 | 常见尺寸 |
|---|---|
| 单时间中号 | 240 × 32px |
| 时间区间大号 | 320 × 40px |
| 小号时间输入 | 高度 24px |

时间下拉面板常见尺寸：

| 面板类型 | 尺寸 |
|---|---|
| 单列 | 112 × 248px |
| 双列/复合列 | 168 × 248px |
| 区间或多列 | 340 × 248px |

时间选项示例为 `01`、`02`、`03` 等，列表需要支持悬停、选中、禁用与滚动。

### 上传组件规范

#### 文件上传 `upload-basic`

文件上传组件支持点击上传、上传过程、上传中、暂停、上传完成、上传失败六类状态。

| 状态 | 尺寸/表现 |
|---|---|
| 点击上传 | 常见 306 × 40px，通常由按钮和说明组成 |
| 上传中/暂停/完成 | 保留文件名、进度、状态图标或操作按钮 |
| 上传失败 | 显示失败原因，例如“上传失败！失败原因xxx” |
| 上传过程 | 可扩展为更高容器，用于显示多个文件进度 |

说明文案示例：

```text
支持扩展名：.rar .zip .doc .docx .pdf .jpg...
```

#### 图片上传 `upload-image`

图片上传基础格尺寸为 **80 × 80px**，圆角为 **8px**。适合头像、封面、素材图、证件图等上传场景。

必须包含状态：默认、hover、上传中、上传成功、上传失败、上传成功后鼠标悬浮、上传失败后鼠标悬浮。

说明文案示例：

```text
建议尺寸 900*400，最多 9 张，单个图片不超过 20M。
```

#### 拖拽上传 `upload-drag`

拖拽上传默认尺寸为 **384 × 194px**，带上传文件列表时可扩展到 **384 × 346px**。圆角为 **8px**。

状态包含：默认、hover、禁用、上传文件。

主文案示例：

```text
点击或将文件拖拽到这里上传
```

#### 上传/导入对话框 `upload-dialog-group`

上传对话框以 **560px 宽** 为主要规格，与前文弹窗标准宽度一致。高度根据内容变化，常见为 **346 / 372 / 384 / 399 / 400px**。

必须包含以下状态：默认、拖拽、上传中、上传成功、上传成功 hover、导入失败、格式错误、文件大小不符合导入失败。

常见文案：

```text
单次仅支持上传 1 个文件，支持文件格式：Excel、CSV
下载模版
请下载模版完成填写后上传
上传文件格式错误！
上传失败！文件大小不超过x
导入中
已完成进度 4   65%
文件总数: 4   已上传: 1   上传中: 1   暂停: 1   上传失败: 1
```

### 投影规范补充

投影不是装饰项，而是层级表达工具。

| 投影层级 | 方向 | 应用场景 |
|---|---|---|
| 一级投影 | 向上 / 向下 / 向左 / 向右 | 浮起投影，主要用于卡片背景浮起状态 |
| 二级投影 | 向上 / 向下 / 向左 / 向右 | 浮层投影，主要用于侧拉抽屉、遮罩弹窗等 |

投影颜色基准为 **#242933**。普通卡片不要使用二级投影；抽屉、弹窗、浮层不要只使用一级投影，否则层级不够明确。

### 组件使用验收清单

| 检查项 | 必须满足的标准 |
|---|---|
| 尺寸 | 输入、选择、按钮等基础控件是否优先使用 24 / 32 / 40px 三档高度 |
| 字体 | 常规表单控件是否使用 14px / 22px；紧凑控件是否使用 12px / 20px |
| 圆角 | 小/中/大控件是否对应 4 / 6 / 8px，不随意新增圆角值 |
| 状态 | 每个交互控件是否至少包含默认、hover、激活/按下、禁用；输入类是否适配失败和输入完成 |
| 错误提示 | 失败态是否有明确错误文案，而不仅仅是红色边框 |
| 选择器 | Select / Cascader / TreeSelect 是否包含面板、选项 hover、选中、禁用、加载等状态 |
| 日期时间 | DatePicker / TimePicker 是否包含区间、清空悬浮、禁用、聚焦、输入中等状态 |
