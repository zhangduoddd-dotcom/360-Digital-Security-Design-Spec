## 一、基础规范

### 1\. 文档用途

本规范为**企业级 B 端系统表单信息录入唯一交互标准**，所有 AI 生成的 B 端表单页面必须 100% 遵循本规范，不可私自修改规则、自创交互、变更文案格式。

### 2\. 适用场景

信息上报、基础配置、分析规则、处置策略、系统对接、账号权限、安全设置、后台管理、参数配置、数据填报等所有B端表单类页面，覆盖全场景复杂交互表单。

### 3\. 核心设计原则

- 易理解：降低用户学习与操作门槛，无专业壁垒，直白易懂

- 准录入：必填项完整无遗漏、输入格式合规、无无效非法数据

- 强引导：全程动态提示、分步流程引导、错误即时反馈、问题可追溯

- 统一化：全局组件样式、交互逻辑、提示文案、布局排版完全统一

## 二、AI自动选择页面结构・决策树

### 逻辑规则

```Plain Text
if 无需按顺序填写：
   if 仅单一维度 → 线性结构-不分组
   if 多维度需分类 → 线性结构-分组

if 必须按顺序填写：
   if 存在动态显示/隐藏/切换 → 条件可见结构
   if 需前后对照查看 → 单页面步骤结构
   if 无需前后对照 → 多页面步骤结构
```

### 模板与场景映射

|模板名称|启用条件|典型业务场景|
|---|---|---|
|线性结构 \- 不分组|单一维度、无分组、可乱序填写|基础信息上报、简单表单|
|线性结构 \- 分组|多维度、可分组、可乱序填写|服务器配置、系统基础设置|
|条件可见结构|开关 / 单选 / 复选控制内容显隐 / 切换|告警配置、通知方式、规则类型选择|
|单页面步骤结构|强顺序 \+ 需前后对照查看|分析规则、处置策略配置|
|多页面步骤结构|强顺序 \+ 无需前后对照|账号注册、服务开通、复杂流程|

## 三、五大范式模板・AI生成标准

### 1\. 线性结构 \- 不分组

- 所有录入项同级垂直排列，无层级、无分组、无折叠

- 按照业务常规逻辑、常用填写顺序依次展示

- 必填项强制标注 `\*`，星标紧跟字段标题后方

- 无分组标题、无步骤导航、无动态显隐、无关联联动

- 支持用户任意顺序填写，无先后强制约束，提交统一校验

### 2\. 线性结构 \- 分组

- 按业务维度、功能模块拆分分组，层级最多2级，严禁超3级

- 组内可乱序填写，组与组之间无先后依赖、无强制联动

- 必填项统一标 `\*`，分组标题加粗突出，层级清晰

- 每组独立排布，间距统一，不可跨组混搭排布

### 3\. 条件可见结构

- 由开关、单选框、复选框作为触发控件，控制对应模块显隐/切换

- 未满足触发条件，关联配置模块默认隐藏，不占用页面布局

- 禁用置灰选项，鼠标hover悬浮气泡提示禁用原因，不可无提示

- 切换选项后，界面无抖动、无错乱，对应模块即时刷新

- 隐藏模块不参与前端实时校验，激活显示后再开启校验规则

### 4\. 单页面步骤结构

- 固定步骤流程，严禁跳跃步骤、跳过前置模块直接填写后续

- 全程单页面展示，上下滚动查看所有步骤，无需跳转页面

- 支持前后配置内容对照查看，适配复杂规则联动配置

- 修改前置步骤内容，导致后续模块数据清空，必须弹出二次确认弹窗

- 顶部固定步骤导航，当前步骤高亮，未完成步骤置灰不可编辑

### 5\. 多页面步骤结构

- 每一步单独独立页面，每页只展示当前步骤内容，无冗余信息

- 底部固定「上一步 / 下一步」操作按钮，逻辑清晰

- 步骤间无需对照查看，内容相互独立，无页面内联动

- 返回修改上一步内容，影响后续数据时，强制二次确认

- 当前页所有校验全部通过，下一步按钮才可点击，否则置灰禁用

## 四、录入组件与校验规则

### 4\.1 通用全局规则

1. 必填项未填写，输入框失焦即时提示：`请输入\{字段名称\}`

2. 输入格式不符合要求，失焦即时提示：`格式错误，请输入\{格式要求\}`

3. 所有错误提示，固定展示在输入框正下方，靠左对齐，红色标注

4. 全局操作提示，顶部居中展示，默认停留3秒，自动关闭，文案≤50字

5. 所有输入框禁止非法字符自动过滤，不符合规则内容无法录入

### 4\.2 输入框类型标准

- **普通输入框**：字符超限无法继续录入，文本域随内容自动增高，带滚动条

- **数字输入框**：仅允许录入数字，自带上下调节箭头，超出数值范围自动修正为边界值

- **IP输入框**：4段式拆分输入，单段输满3位自动跳转，粘贴完整IP自动填充，数值0\~255

- **手机号输入框**：仅限11位数字，超出不录入，自动校验手机号号段格式

- **MAC地址**：固定格式`XX:XX:XX:XX:XX:XX`，非法字符直接拦截，不支持录入

- **MD5**：仅限32位英文\+数字，禁止中文、特殊符号，超长超限拦截

- **身份证**：15/18位，支持末尾大写X，自动校验地址、生日合规格式

- **密码**：支持明文/密文一键切换，高密级场景不暴露密码规则，安全合规

### 4\.3 选择类组件标准

- 单选 / 复选框：不可用选项置灰禁用，hover悬浮提示原因，选中状态高亮统一

- 下拉选择器：单选选中自动关闭弹窗，多选展示标签，超出数量数字角标展示，支持一键清除

- 选择器默认占位文案规范，无默认选中值，禁止默认选中非法选项

### 4\.4 信息密度规范

- 单屏可见字段数建议 ≤ 8 个，保障用户操作舒适度，避免信息过载

- 字段数超过12个：必须进行分组处理，按业务维度拆分，提升可读性

- 字段数超过20个：必须采用步骤化结构（单页面步骤/多页面步骤），拆分复杂流程

- 高频使用字段：优先放置在首屏，减少用户滚动操作，提升录入效率

- 低频高级配置：默认折叠展示，需用户主动展开查看，避免占用首屏空间、干扰核心操作

### 4\.5 布局栅格规范

- 标题与输入框优先采用同行组合，提升页面空间利用率

- 内容较少时，标题与输入框默认垂直排列，结构清晰、不易错乱

- 内容较多时，短文本类输入项可采用2\~3列栅格排布；长文本（如文本域、备注）需独占一行，保障输入体验

- 所有输入框需保持左右垂直对齐，标题统一右对齐，视觉上整齐统一

- 标题占位宽度保持一致，避免布局抖动；标题字数控制在8字以内，复杂标题可增加注解icon，点击icon展示详细解释，不占用标题空间

### 4\.6 表单状态体系

- **草稿态**：表单未完成填写，可自由编辑、修改，无锁定限制，未提交至审核或发布流程

- **审核中**：表单已提交，处于审核流程中，页面为只读状态，不可编辑、不可修改任何内容

- **已发布**：表单已审核通过并发布，页面部分锁定；如需编辑，需先判断修改影响范围，若影响较大，需增加“取消发布”操作，取消发布后才可进行编辑

- **脏状态**：表单内容已变更但未保存，此时触发离开页面操作（如跳转、关闭），需弹出提示弹窗，文案固定为：
标题：确定离开当前页面吗？
说明：离开后已配置内容将被清除请谨慎操作

- **自动保存中**：无需手动点击保存按钮，系统将通过定时、输入框失焦、输入停顿三种触发方式，自动将表单数据同步至后台；优先采用异步自动保存，触发保存后发送请求即放行，不等待后台响应结果，页面可继续操作，不阻塞用户行为；当业务有特殊要求时，可采用同步自动保存，同步期间页面处于不可操作状态，出现阻塞或卡住效果

### 4\.7 操作优先级体系

- **主操作**：采用品牌色实心按钮，页面内仅可存在1个；常用操作动词包括：保存、发布、应用、保存并启用、提交、上报等，对应表单核心操作需求

- **次操作**：采用品牌色描边按钮，可根据业务需求设置1\-2个；当页面存在“保存并启用”主操作时，次操作固定显示为“仅保存”；其他场景可根据需求配置对应次操作，一般情况下不使用次操作样式

- **其他操作**：采用无品牌色的辅助按钮，无需突出显示；常用操作包括：取消、保存草稿、作为主、次操作的补充；默认不显示清空、删除操作，如有业务需要可显示。

- **低频操作**：采用文字按钮样式，或作为辅助配置关系的跳转链接；主要用于快速跳转至关联页面，属于非核心操作，不占用页面主要操作区域

## 五、提示文案与符号规范

### 全局提示文案

- 操作成功（无后续）：`\{操作\}成功`

- 操作成功（带跳转）：`\{操作\}成功，可前往【路径】查看`

- 操作失败：`\{操作\}失败，\{原因\}，\{解决方案\}`

- 输入错误：`\{字段\}\{问题\}，请重新输入`

### 符号规范

- 目录层级分隔：`\&gt;`

- 页面 / 功能模块：`【】`

- 按钮 / 操作指令：`「」`

- 变量占位符：`\{\}`

- 全文符号统一，禁止混用、自创符号格式

## 六、AI生成页面・强制输出标准

AI生成任何B端表单页面，必须完整包含以下内容，缺一不可，严格按照规范输出：

1. 页面结构类型（五大模板五选一，严禁自创）

2. 分组规划 / 步骤流程规划，层级清晰

3. 完整录入项清单（字段名称、是否必填、对应组件类型）

4. 专项校验规则（为空校验、格式校验、数值范围校验）

5. 条件显隐触发逻辑、关联模块（有联动场景必填）

6. 步骤流转、前后关联逻辑（步骤类表单必填）

7. 底部操作按钮（确定、取消、上一步、下一步）

8. 全套提示文案（默认占位、错误提示、操作成功提示）

### AI禁止行为

- 禁止自创页面结构、交互模板，仅限使用五大标准模板

- 禁止自创校验规则、输入限制规则，完全遵循本文档

- 禁止自创文案风格、语气、格式，统一官方严谨话术

- 禁止随意跳跃步骤、无理由显隐模块、破坏流程逻辑

- 禁止表单层级超过3级，严控层级复杂度

- 禁止模糊、缺失、不明确的错误提示、操作引导

- 禁止更改组件样式、排布位置、提示展示位置

- 禁止违反信息密度规范（如字段超12个不分组、超20个不步骤化）

- 禁止违反布局栅格规范（如标题与输入框排布混乱、对齐不一致）

- 禁止违反表单状态体系规则（如审核中可编辑、脏状态离开无提示）

- 禁止违反操作优先级体系规则（如主操作多个、出现重置/删除操作）

- 禁止自创页面结构、交互模板，仅限使用五大标准模板

## 七、标准实践案例（含完整落地规则）

本章对应前文五大模板，每个案例配套**适用业务、页面布局规则、交互执行细则、校验落地要求、AI生成约束**，同时严格遵循信息密度规范、布局栅格规范、表单状态体系、操作优先级体系，AI可直接照搬学习、复刻生成页面，无歧义、可直接落地，贴合B端真实业务场景。

### 7\.1 线性结构\-不分组 实践案例

**对应模板**：线性结构\-不分组

**业务场景**：日常基础信息上报、人员信息登记、简单数据填报、基础台账录入

**落地布局规则**：全屏单列垂直排布，无分组、无模块拆分，字段依次排列；必填字段标\*，选填字段无标记；无任何联动、显隐、步骤逻辑。

**交互校验规则**：任意顺序填写，失焦单独校验，提交时全局统一校验；无步骤切换、无分组折叠，全程单一层级页面。

**AI生成要求**：不许加分组标题、不许加步骤条、不许做联动交互，纯平铺简单表单，适配极简录入场景。

### 7\.2 线性结构\-分组 实践案例

**对应模板**：线性结构\-分组

**业务场景**：系统基础配置、服务器参数配置、设备信息配置、后台基础设置

**落地布局规则**：按功能拆分为2级分组，每组独立区块，标题加粗区分；组内字段平铺排布，组间间距统一，无先后填写限制。

**交互校验规则**：组内字段单独校验，组间互不影响；必填项标\*，支持打乱顺序填写，无需按组顺序操作。

**AI生成要求**：严格控制2级层级，不超层级，无动态交互，仅模块分组整理，适合多维度基础配置。

### 7\.3 条件可见结构 实践案例

**对应模板**：条件可见结构

**业务场景**：告警策略配置、通知方式选择、规则类型切换、参数开关配置

**落地布局规则**：顶部放置开关/单选/复选触发控件，下方默认隐藏对应配置模块；选中对应选项，自动展示专属配置项。

**交互校验规则**：隐藏模块不校验，显示模块实时校验；禁用选项hover提示，无空跳转、无界面错乱。

**AI生成要求**：明确触发控件\+受控模块对应关系，不可多模块混乱联动，适配有条件筛选的复杂配置。

### 7\.4 单页面步骤结构 实践案例

**对应模板**：单页面步骤结构

**业务场景**：数据分析规则配置、风险处置策略配置、复杂流程参数配置

**落地布局规则**：单页面顶部步骤导航，全程不跳转新页面，滚动展示所有步骤；前置步骤完成，解锁后续步骤。

**交互校验规则**：按顺序一步步填写，不可跳步；修改前置步骤，二次确认清空后续数据，前后内容可对照查看。

**AI生成要求**：单页面展示，步骤高亮清晰，无页面跳转，适配需要前后对照的强逻辑复杂配置。

### 7\.5 多页面步骤结构 实践案例

**对应模板**：多页面步骤结构

**业务场景**：企业账号注册、服务开通、资质认证、分步闭环复杂流程

**落地布局规则**：每一步独立页面，每页只展示当前步骤内容，简洁无冗余；底部配上一步、下一步按钮。

**交互校验规则**：单页校验通过，才可进入下一步；返回修改需二次确认，步骤状态同步更新。

**AI生成要求**：分页展示，流程闭环，无页面冗余信息，适配长流程、无需对照的分步表单。
