# 列表页-表格区域交互规范
## List Page Table Interaction Specification
Keywords: table, interaction, list page, operation, data

# 一、整体设计原则

表格区域需遵循「功能关联明确、操作优先级清晰、视觉层次统一、交互反馈精准」原则，整体采用轻量化企业级 SaaS 风格，打造简洁高效的视觉与交互体验。

视觉层面，表格无外边框、无圆角，仅通过行底部分隔线区分数据层级（分隔线颜色【Gray 中性/gray-4-分割线】#E8EAED），摒弃冗余装饰，突出核心数据内容；结构层面，操作栏、表头、内容区形成稳定统一的信息架构，全程遵循全站设计一致性，最大限度降低用户学习成本，大幅提升高频操作的执行效率，适配企业级后台系统的日常使用场景。

表格区域整体由五大核心部分组成，各模块分工明确、联动顺畅：

1. **表格顶部操作栏**：承载表格全量操作入口，是用户核心操作区域
2. **表头区域**：定义数据列属性，支持排序、筛选等基础功能
3. **数据内容区域**：展示核心业务数据，是表格核心展示区
4. **操作列区域**：针对单条数据的操作入口，实现单行数据精细化操作
5. **分页区域**：控制数据分页展示，优化大数据量下的加载与浏览体验

### 1.1 外部容器规范

表格区域需嵌入一个固定样式的外部容器内，容器规范如下：容器圆角为8px，容器与表格区域的上下左右间距均固定为24px，确保表格区域与页面其他元素边界清晰、布局规整，适配企业级后台整体视觉风格。

### 1.2容器内冻结规范

- 固定冻结规则：表格顶部操作栏、表头固定冻结于表格内容区域顶部，分页器固定冻结于表格内容区域底部，形成上下固定、中间可滚动的稳定布局。
- 内容较少适配：当表格内容较少、不足以充满内容区容器时，分页器紧贴最后一行表格内容排布，避免出现无效空白间距，保证布局紧凑规整。
- 多列数据适配：当表格内容列较多时，默认固定首列（数据标识列）和尾列（操作列），仅中间核心数据区域可进行横向/纵向滚动。
- 滚动交互逻辑：表格滚动时，操作栏、表头、分页器、首列、尾列均相对外部容器冻结，确保用户浏览任意位置数据时，可随时触发操作、查看数据标识与操作入口，无需回滚页面，提升操作便捷性与浏览体验。

# 二、内容规范

## 2.1 表格顶部操作栏规范

### 2.1.1 布局原则

操作栏统一布局在表格表头正上方，整体布局严格遵循四大原则：功能关联分区、操作优先级排序、高频操作显性化、全站一致性布局，杜绝随意排布，保证全平台操作逻辑统一。

操作栏横向划分为三大功能区域，各区域边界清晰、功能互不交叉，具体划分规则如下：

| 区域      | 功能属性               | 对齐方式 |
| ------- | ------------------ | ---- |
| 左侧核心操作区 | 数据新增类操作，属于表格核心入口操作 | 左对齐  |
| 中间批量操作区 | 勾选数据后的批量处理操作       | 左对齐  |
| 右侧全局配置区 | 表格整体维度的配置与操作       | 右对齐  |

区域内所有按钮水平间距统一为 **8px**，禁止随意调整间距，保证视觉整齐统一。

### 2.1.2 左侧核心操作区

本区域仅承载与表格数据新增强关联的操作，是表格数据录入的核心入口，优先级最高。

#### 排序规则

1. **新建**：固定排布在区域最左侧，采用主按钮样式，作为表格核心新增入口，视觉辨识度最高，引导用户优先操作
2. **导入**：紧邻“新建”按钮右侧排布，采用辅助按钮样式，专门用于批量数据导入，补充单条新建的效率短板

#### 特殊规则

若页面不支持单条数据“新建”能力，仅开放批量导入权限时，“导入”按钮自动升级为主按钮样式，作为唯一的数据新增入口，保证核心操作入口的突出性。

### 2.1.3 中间批量操作区

本区域仅承载勾选多条数据后的批量处理操作，未勾选数据时无实际操作意义，需做好状态联动控制。

#### 排序规则

所有操作按钮严格按照用户使用频率从左至右排列，核心高频操作靠左，固定规则为：导出 → 批量编辑 → 其他批量操作 → 删除，其中**删除按钮固定在区域最右侧**，规避误操作风险。

#### 状态联动

默认无数据勾选状态下，所有批量操作按钮统一置为禁用状态，不可点击；用户勾选任意一条或多条数据后，按钮自动解除禁用，可正常操作，从根源避免误操作与空操作。

#### 特殊规则

当批量操作按钮数量超过3个时，执行折叠规则：保留导出、删除等高频核心操作直接展示，其余低频操作统一折叠至“操作”下拉菜单中，避免操作栏过于拥挤。同时，按钮命名仅保留核心动词，如删除、导出、编辑，不额外增加“批量”前缀，防止与全局操作混淆，保持命名简洁统一。

### 2.1.4 右侧全局配置区

本区域承载整个表格维度的全局操作与配置，不针对单条或多条数据，服务于表格整体浏览与配置需求。

#### 排序规则

按钮从左至右固定排序为：刷新 → 打印 → 全屏 → 导出全部 → 配置表格字段，其中**配置表格字段按钮固定在区域最后一位**。

#### 样式规则

低频辅助操作可采用纯图标按钮，节省横向空间；高频操作保留文字+图标或纯文字样式，确保用户一眼识别功能，兼顾美观与实用性。

#### 响应式规则

当页面宽度不足、操作栏出现挤压时，非核心按钮自动折叠至“更多”下拉菜单，仅保留“导出全部”“配置表格字段”两个核心功能按钮可见，保证小屏设备下核心操作不受影响。

## 2.2 表格基础视觉规范

### 2.2.1 表格整体

- 无外边框、无圆角，整体视觉极简干练
- 背景色统一为 【Gray 中性/gray-1】#FFFFFF，适配企业后台浅色视觉体系
- 仅通过行底部分隔线区分单行数据，分隔线纤细不突兀（分隔线颜色【Gray 中性/gray-4-分割线】#E8EAED），不干扰数据阅读
- 数据区域支持横向滚动，适配多列数据的展示场景

#### 横向滚动规则

表格横向滚动时，执行固定规则：表头区域全程固定、首列数据固定、操作列固定，仅中间核心数据区域横向滚动，确保用户滚动时始终能看到数据标识列与操作列，不会丢失数据对应关系。

### 2.2.2 分页器规范

分页器仅在表格非空、存在数据时显示，无数据时隐藏，避免无效组件展示。

#### 使用组件

统一采用【分页栏-大】组件，确保全站分页样式一致；默认选中分页器为 20条/页，常规下拉可选数量为：10/20/50/100。

#### 布局规则

分页器固定位于表格底部正下方，整体右对齐排布，与表格底部间距统一为8px，布局紧凑规整。

### 2.2.3 表头规范

#### 2.2.3.1 基础样式

表头作为数据列的标识区，样式统一规范，具体参数如下：

| 属性   | 规范参数                      |
| ---- | ------------------------- |
| 行高   | 40px                      |
| 内边距  | 上下10px；左右16px             |
| 字号   | 12px                      |
| 字重   | Medium                    |
| 文本颜色 | #242933（【Gray 中性/gray-9】） |
| 背景色  | #F8F9FA（【Gray 中性/gray-2】） |

表头文本统一规则：强制单行显示，超出文本宽度时自动省略（…），鼠标hover表头时，通过Tooltip完整展示全部文本，兼顾布局整洁与信息完整性。

#### 2.2.3.2 表头 Hover 规则

##### 可操作表头

具备排序、筛选功能的表头为可操作表头，鼠标hover时，背景色切换为 【Gray 中性/gray-3白背景hover】#F2F3F5，给出明确的可交互反馈；鼠标移开后，自动恢复默认背景色。

##### 不可操作表头

仅做数据标识、无排序筛选功能的表头，鼠标hover时无任何背景与样式变化，避免误导用户。

### 2.2.4 排序图标规范

#### 2.2.4.1 基础规则

排序图标参数统一，确保视觉大小、颜色、间距完全一致，具体规范如下：

| 属性      | 规范参数                      |
| ------- | ------------------------- |
| 尺寸      | 14×14px                   |
| 与文字间距   | 4px                       |
| 默认颜色    | #8A9099（【Gray 中性/gray-7】） |
| hover颜色 | #1DB887（【Brand 品牌/p5】）    |
| 激活颜色    | #00AB7A（【Brand 品牌/p6】）    |

图标统一采用上下双向箭头样式，直观体现升序、降序两种排序模式。

#### 2.2.4.2 交互规则

点击排序图标，循环切换排序状态：升序 → 降序 → 取消排序，循环往复。精准点击上箭头时，直接触发升序；精准点击下箭头时，直接触发降序，当前生效的排序方向对应图标高亮显示，清晰反馈当前排序状态。

### 2.2.5 筛选图标规范

#### 2.2.5.1 基础规则

筛选图标基础参数与排序图标保持一致，保证表头内图标视觉统一，具体规范如下：

| 属性      | 规范参数                      |
| ------- | ------------------------- |
| 尺寸      | 14×14px                   |
| 与文字间距   | 4px                       |
| 默认颜色    | #8A9099（【Gray 中性/gray-7】） |
| hover颜色 | #1DB887（【Brand 品牌/p5】）    |
| 激活颜色    | #00AB7A（【Brand 品牌/p6】）    |

若单个表头同时存在排序与筛选功能，筛选图标固定位于排序图标右侧，两者间距统一为4px，排布紧凑有序。

#### 2.2.5.2 交互规则

点击筛选图标，立即弹出对应列的筛选菜单，菜单内包含当前列全部可筛选项、确定按钮、重置按钮，操作逻辑清晰。

##### 按钮行为

- 确定：应用当前所选筛选条件，刷新表格数据
- 重置：一键清除当前列所有筛选条件，恢复默认数据展示

当表头存在生效筛选条件时，筛选图标自动高亮显示，直观提示用户当前列已筛选。

### 2.2.6 内容单元格规范

#### 2.2.6.1 基础样式

数据内容单元格样式统一，保证数据阅读舒适，具体参数如下：

| 属性   | 规范参数                      |
| ---- | ------------------------- |
| 行高   | 40px                      |
| 内边距  | 上下10px；左右16px             |
| 字号   | 12px                      |
| 字重   | Regular                   |
| 文本颜色 | #525966（【Gray 中性/gray-8】） |
| 对齐方式 | 左对齐                       |

#### 2.2.6.2 文本规则

普通文本：强制单行显示，超出单元格宽度时自动省略，鼠标hover单元格时，通过Tooltip完整展示全部文本，避免多行文本导致表格高度错乱。

时间字段：格式强制统一为 YYYY-MM-DD HH:MM:SS，全程完整展示，不做省略处理，保证时间信息精准无误。

#### 2.2.6.3 行背景与交互

##### 默认状态

单元格背景色为 【Gray 中性/gray-1】#FFFFFF，行底部分隔线颜色为 【Gray 中性/gray-4-分割线】#E8EAED，线条纤细，清晰区分各行数据。

##### Hover 状态

鼠标hover任意数据单元格时，对应整行背景色统一切换为 【Gray 中性/gray-3白背景hover】#F2F3F5，包含内容列与操作列，实现整行高亮，方便用户快速定位单行数据，避免误操作。

### 2.2.7 操作列规范

#### 2.2.7.1 基础规则

操作列内所有按钮统一采用【文字按钮-常规】样式，禁止随意更换按钮样式，保证全站操作列视觉一致。

#### 2.2.7.2 展示规则

##### 操作项 ≤ 3

所有操作项直接横向展示，无需折叠，方便用户一键点击，提升操作效率。

##### 操作项 \&gt; 3

执行折叠规则：前2个高频核心操作项直接展示，第3个及以后的操作项统一折叠，显示为“更多”文字按钮+下箭头图标；鼠标hover“更多”按钮时，自动展开下拉菜单，展示剩余所有操作项。

#### 2.2.7.3 行联动规则

鼠标hover操作列任意位置时，对应数据整行同步高亮，效果与hover数据单元格一致（背景色切换为【Gray 中性/gray-3白背景hover】#F2F3F5），强化行关联，让用户清晰感知操作对应的单行数据。

# 三、权限与状态规范

## 3.1 权限控制

所有操作按钮需根据用户角色权限，动态做三种处理：正常显示、隐藏、禁用，严格遵循权限管控规则，杜绝越权操作。例如：普通用户默认隐藏“删除”按钮、隐藏“配置表格字段”按钮；仅管理员账号开放对应高权限操作。

## 3.2 禁用状态

处于禁用状态的按钮，需明确置灰处理，完全不可点击；鼠标hover禁用按钮时，自动弹出Tooltip提示禁用原因，让用户清晰知晓无法操作的缘由，提升体验。

## 3.3 操作反馈

表格内所有操作均需具备即时反馈，杜绝无响应操作：核心操作触发Toast提示、异步操作展示Loading状态、操作完成给出明确的成功/失败反馈；所有可点击按钮hover时，需具备明确的高亮、变色反馈，清晰提示可交互状态，保障交互闭环。针对删除、停用/启用等关键操作，需根据业务情景增加二次确认拦截功能，避免对系统造成不可逆影响，示例：点击删除按钮时，弹出确认对话框，反馈文案规范如下——「标题」确定删除所选内容吗？「内容」删除后将无法恢复，请谨慎操作。
