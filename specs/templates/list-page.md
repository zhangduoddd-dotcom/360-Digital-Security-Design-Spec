# 列表页模板
## List Page Template
Keywords: list page, data list, filter, table, operation area

## 列表页页面模板规范

列表页用于承载数据检索、筛选、批量操作、状态识别、单行处理和分页浏览。列表页的核心目标是提升查找效率、判断效率和处理效率，视觉上应保持克制、清晰、规整，不应被设计成数据看板或营销页面。

### 列表页通用结构

标准列表页应遵循以下结构：

```text
页面标题 / 面包屑 / 顶部标签
  ↓
查询区 / 高级筛选区
  ↓
工具栏 / 批量操作区 / 右侧功能按钮
  ↓
表格主体
  ↓
分页区
```

复杂列表页可扩展为：

```text
页面标题 / 标签页
  ↓
查询区
  ↓
左侧分类筛选栏 + 右侧结果表格
  ↓
表格工具栏 / 字段配置
  ↓
分页区
```

通用规则：
- 页面背景使用浅灰，主体卡片使用白色。
- 查询区、工具栏、表格区、分页区应分层清楚。
- 表格始终是列表页的核心主体。
- 列表页不应加入大面积图表或装饰插图。
- 首屏应保证搜索、筛选、表头、核心字段、操作列和分页可见。
- 表格信息密度中高，但不应拥挤。

### 列表页类型

#### 标准表格列表页

适用于常规记录、配置项、对象列表。

页面结构：
```text
页面标题
  ↓
工具栏
  ↓
表格
  ↓
分页
```

典型元素：
- 主操作按钮
- 次级操作按钮
- 搜索框
- 表格字段
- 行操作
- 分页

#### 查询结果列表页

适用于事件查询、日志检索、任务记录、风险结果。

页面结构：
```text
查询条件区
  ↓
结果总数 / 导出按钮
  ↓
结果表格
  ↓
分页
```

典型元素：
- 输入框
- 下拉选择器
- 日期范围
- 查询按钮
- 重置按钮
- 导出按钮
- 结果总数

#### 左筛选 + 右列表页

适用于分类、类型、层级或资产目录明显的业务。

页面结构：
```text
顶部快捷筛选
  ↓
左侧分类筛选栏 + 右侧结果表格
```

左侧筛选可包含：
- 类别
- 类型
- 层级
- 数量
- 展开 / 收起
- 当前选中项

右侧表格可包含：
- IP
- 域名
- 协议
- 端口
- 状态码
- 产品应用
- 发现时间
- 操作

#### 高级搜索列表页

适用于字段多、查询条件复杂、支持 HQL 或字段配置的列表。

页面结构：
```text
高级查询表单
  ↓
展开 / 收起
  ↓
查询 / 清空 / HQL
  ↓
工具栏
  ↓
表格
  ↓
字段配置浮层
  ↓
分页
```

典型元素：
- 多行筛选条件
- 展开收起按钮
- 下载按钮
- 字段配置按钮
- 字段勾选浮层
- 横向滚动条
- 多选表格

#### 标签切换列表页

适用于按状态或集合切换的数据列表。

页面结构：
```text
页面标题
  ↓
标签页
  ↓
表格
  ↓
分页
```

规则：
- 标签数量建议 2–5 个。
- 当前标签使用科技绿高亮。
- 标签用于切换顶层集合，不替代复杂筛选。

### 查询区规范

查询区用于缩小结果范围，应保持整齐、清晰、低干扰。

常见控件：
- 输入框
- 下拉选择器
- 日期范围选择器
- 时间范围选择器
- 搜索按钮
- 重置按钮
- 展开 / 收起
- HQL 入口

布局规则：
- 简单查询一行展示 3–5 个字段。
- 复杂查询可使用 2–3 列栅格。
- 查询按钮使用主按钮。
- 重置按钮使用次按钮。
- 展开高级查询时应保持字段对齐。
- 查询区不应占据过多首屏空间。
- 日期范围应采用“开始日期 ～ 结束日期”结构。

### 工具栏规范

工具栏用于承载批量操作、页面级操作和表格配置。

常见操作：
- 联动处置
- 联动记录
- 导出列表
- 下载
- 刷新
- 字段配置
- 批量选择
- 删除
- 复制
- 新建

规则：
- 左侧优先放批量操作。
- 右侧优先放创建、导出、设置、刷新等页面操作。
- 主操作按钮最多 1 个。
- 次级操作建议 2–4 个。
- 批量操作在未选择数据时应为禁用态。
- 工具栏与表格之间应有清晰分隔。

### 表格主体规范

表格是列表页最核心的信息区。

基本规则：
- 表头使用浅灰底。
- 行高默认 40px。
- 字号建议 12px 或 14px。
- 文字左对齐优先。
- 数字、状态、操作可按需要居中。
- 表格分割线使用浅灰细线。
- 空值使用 `-`。
- 操作列置于最右侧。
- 超长内容使用省略号，必要时配合 tooltip。
- 列较多时支持横向滚动。

常见字段：
- 选择框
- 序号
- 名称
- 类型
- 状态
- 风险等级
- IP
- 域名
- 端口
- 协议
- 时间
- 标签
- 操作

### 状态与标签规范

状态应同时依靠颜色和文字表达。

处理状态：
- 已处理：绿色
- 未处理：橙色 / 黄色
- 未接通：灰色
- 处理中：蓝色或科技绿弱态
- 已失败：红色

风险等级：
- 高风险 / 严重：红色
- 中风险 / 警告：橙色
- 低风险 / 提醒：黄色
- 安全 / 正常：绿色

标签规则：
- 标签文字建议 2–6 字。
- 同一状态在同一产品内颜色保持一致。
- 一个单元格内不宜堆叠过多彩色标签。
- 普通类型标签使用灰色描边或浅色底。

### 行操作规范

常见行操作：
- 查看
- 查看详情
- 编辑
- 处理
- 删除
- 启用
- 停用
- 复制
- 下载

规则：
- 行操作置于最右侧。
- 单行高频操作建议 1–3 个。
- 低频操作收进更多菜单。
- 删除、停用、取消等危险操作应弱化或二次确认。
- 操作链接颜色以主色为主，不要多色混用。

### 批量操作规范

- 表格首列使用复选框。
- 支持全选当前页。
- 选中后应展示“已选 N 个”。
- 未选中数据时批量操作禁用。
- 批量删除、禁用、导出等操作需有反馈。
- 高风险批量操作应确认影响数量。

### 字段配置浮层规范

复杂列表可提供字段配置能力。

字段配置结构：
```text
字段配置入口
  ↓
下拉浮层 / 抽屉
  ↓
全选 / 重置
  ↓
字段勾选列表
```

规则：
- 字段配置入口位于表格右上方。
- 浮层应靠近触发按钮。
- 支持全选、重置、勾选、禁用字段。
- 默认不可关闭字段应展示禁用态。
- 字段名称应与表头一致。
- 配置变更后即时影响表格列展示。

### 左侧分类筛选规范

左侧分类筛选用于快速缩小结果范围。

结构：
```text
分类组标题
  ↓
分类项 + 数量
  ↓
展开 / 收起
```

规则：
- 分组标题如类别、类型、层级。
- 每组支持展开 / 收起。
- 当前选中项使用主色或浅绿色高亮。
- 数量右对齐。
- 内容过长使用省略号。
- 左筛选栏与右侧表格之间使用竖向分隔。

### 分页规范

分页位于表格底部，通常靠右。

分页应包含：
- 总条数
- 每页条数
- 上一页 / 下一页
- 页码
- 跳页输入

规则：
- 当前页使用主色高亮。
- 每页条数建议支持 10 / 20 / 50。
- 总条数格式如 `共计 4568 条`。
- 列表页不应缺少分页，除非数据量极少。
- 分页与表格之间应留出清晰间距。

### 列表页信息密度规范

推荐值：
- 表格列数：6–10 列
- 首屏行数：8–12 行
- 查询字段：3–8 个
- 标签页数量：2–5 个
- 工具按钮：2–5 个
- 单行操作：1–3 个

控制原则：
- 表格可密，但不能乱。
- 查询区不应比表格更抢眼。
- 普通列表不应加入复杂图表。
- 主信息与辅助信息应有层级差异。

### 列表页文案与假数据规范

- 页面标题：4–12 字。
- 查询标签：2–6 字。
- 按钮文案：2–6 字。
- 表头字段：2–8 字。
- 行操作文案：2–6 字。
- 标签文案：2–6 字。
- 数量格式：`11,360 条`。
- 时间格式：`2024/05/29 15:30:12`。
- IP 格式：`172.171.49.45`。
- 域名格式：`example.global.pr`。
- 状态示例：`已处理 / 未处理 / 未接通`。
- 风险示例：`高风险 / 中风险 / 低风险`。

### 列表页 AI 生图约束

- 必须明确列表页类型后再生成。
- 表格面积应明显大于查询区。
- 不要把列表页做成 Dashboard。
- 不要在列表页中加入大面积图表。
- 查询区必须整齐排列。
- 工具栏主次操作必须清楚。
- 表格必须包含表头、数据行、状态/标签、操作列。
- 分页必须完整显示。
- 如果有左侧筛选，必须展示分类分组和选中状态。
- 如果有字段配置，必须展示浮层或抽屉配置面板。
- 不要使用过重阴影、粗边框或厚重黑色分割线。

## 列表页基础原则补充

> 列表页是 B 端产品中最高频的信息浏览与处理页面之一，应优先考虑屏效、阅读效率和批量操作效率。

### 列表页定义

列表页用于查看和处理大量条目，常承担导航至详情页的作用。列表也是组织和整理数据的重要手段，便于用户对数据进行筛选、对比、新增、分析，并下钻至条目完整详情页。

典型场景包括：

- 安全事件列表页
- 策略列表页
- 日志列表页
- 任务列表页
- 智能体列表页
- 审批列表页
- 项目列表页

### 列表页当前痛点

| 痛点 | 说明 |
|---|---|
| 布局间距不一致 | 不同产品、页面、模块中的列表间距存在差异，导致视觉节奏不统一 |
| 屏效较低 | 列表承载客户浏览、查找、管理数据的核心任务，低屏效会直接影响操作效率 |
| 信息布局松散 | 操作区、筛选区、表格、分页之间距离过大，会降低单位屏幕的信息承载能力 |
| 字号和行高不统一 | 12px / 14px、40px / 48px 并存，影响列表阅读节奏 |

### 列表页设计目标

| 目标 | 说明 |
|---|---|
| 统一列表布局间距 | 保持不同页面和功能模块的列表在视觉上保持一致 |
| 优化列表屏效 | 在有限屏幕空间内容纳更多有效信息 |
| 提升信息获取效率 | 帮助用户快速浏览、查找、定位和处理条目 |
| 降低认知负荷 | 通过清晰的信息分层和操作分组，减少用户反复判断成本 |

### 列表页设计原则

| 原则 | 说明 | 执行方式 |
|---|---|---|
| 易读性 | 提取用户需要感知的重点信息优先展示 | 重点字段前置，弱化次要字段；复杂信息通过交互分层展示 |
| 高效性 | 符合用户浏览的视觉逻辑顺序，支持快速筛选、新增、删除、处置 | 操作区固定位置；筛选与批量操作清晰；列表密度更紧凑 |

### 列表页类型与适用场景

| 类型 | 构成 | 使用场景 |
|---|---|---|
| 列表-基础类 | 基础表格 + 常规操作按钮 + 少量筛选条件 | 全场景通用；适合常规数据管理 |
| 列表-筛选 | 表格 + 筛选项 + 分类/状态/来源等条件 | 需要对数据进行分类筛选、溯源和寻找原因 |
| 列表-卡片 | 多列卡片布局，信息聚合展示 | 资源列表、模板列表、智能体/专家列表、项目列表 |
| 列表-分析 | 统计分析组件 + 列表，呈上下结构 | 列表数据需要统计和分析 |
| 列表-说明引导 | 顶部带场景说明或引导说明 | 场景复杂、用户需要先理解规则或流程 |
| 列表-分组 | 左右分组或树形分组 + 列表 | 组织架构树、虚拟组树、分类资源管理 |
| 列表-展开列表 | 行内展开扩展信息 | 系统版本较老或只需快速查看当前数据条的扩展信息 |

### 列表尺寸与间距

#### 纵向屏效优化

| 项目 | 标准 |
|---|---|
| 表头行高 | 40px |
| 单元格行高 | 40px |
| 列表文字字号 | 12px |
| 卡片间距 | 由 16px 统一压缩为 12px；部分卡片列表可使用 16px |
| 列表与上方操作区间距 | 8px |
| 列表与下方分页间距 | 8px |

#### 横向屏效优化

| 项目 | 标准 |
|---|---|
| 操作区按钮高度 | 32px |
| 操作区按钮左右间距 | 8px |
| 筛选项紧凑间距 | 无标题筛选项左右间距 8px |
| 带小标题筛选项 | 小标题字号 12px；小标题距离选项 12px；筛选项左右间距 32px，上下间距 16px |

### 基础列表默认样式

| 元素 | 标准 |
|---|---|
| 表头高度 | 40px |
| 单元格高度 | 40px |
| 列表字号 | 12px |
| 操作按钮高度 | 32px |
| 操作按钮间距 | 8px |
| 表格距操作区 | 8px |
| 表格距分页 | 8px |

**执行说明：**

- 基础列表应优先保证信息扫描效率，不应使用过大的行高。
- 操作区应与列表形成明确关系，不能距离过远。
- 分页应紧贴列表底部，但需保留 8px 呼吸空间。
- 如果列表承载大量数据，应优先使用 40px 行高，而不是 48px 行高。

### 筛选区规范

| 场景 | 标准 |
|---|---|
| 无标题筛选项 | 筛选项左右间距 8px |
| 有小标题筛选项 | 小标题字号 12px |
| 小标题与选项距离 | 12px |
| 筛选项左右间距 | 32px |
| 筛选项上下间距 | 16px |

**设计要求：**

- 筛选项不宜堆叠得过松，否则会吞噬列表首屏空间。
- 高频筛选项前置，低频筛选项可收纳到“更多筛选”。
- 筛选区与操作区需要区分，不要把筛选、批量操作、主按钮混在一起。

### 卡片列表规范

| 项目 | 标准 |
|---|---|
| 卡片间距 | 12px / 16px |
| 卡片内容区 | 应保持信息聚合，不应把表格字段机械搬进卡片 |
| 卡片操作 | 高频操作可外露，低频操作收纳 |
| 适用对象 | 项目、模板、智能体、专家、数据资产、策略包 |

**AI 原生平台补充：**

在多智能体平台中，“我的专家”“专家市场”“项目模板”等页面更适合使用卡片列表。卡片应突出：名称、来源、状态、能力标签、使用次数、成功率、最近更新时间、主要操作。

### 分析型列表规范

| 项目 | 标准 |
|---|---|
| 统计分析区与上下卡片间距 | 12px |
| 分析区位置 | 列表上方 |
| 分析区内容 | 关键指标、趋势、分类统计、风险分布 |
| 列表关系 | 分析区用于概览，列表用于下钻处理 |

**执行要求：**

- 统计分析区不能过高，避免挤压列表首屏。
- 图表只展示与列表筛选和数据判断相关的指标。
- 分析区和列表应共享同一筛选上下文。

### 说明引导型列表规范

| 项目 | 标准 |
|---|---|
| 说明引导距离下方内容 | 12px |
| 使用场景 | 场景复杂、规则较多、用户需要理解任务背景 |
| 展示方式 | 顶部说明卡片、轻量提示条、步骤说明 |

**执行要求：**

- 说明引导不能替代页面标题。
- 引导内容应解释任务规则，而不是写产品宣传语。
- 引导卡片可折叠，避免长期占用首屏空间。

### 分组列表规范

| 项目 | 标准 |
|---|---|
| 列表与分组间距 | 16px |
| 适用场景 | 组织架构树、虚拟组树、分类资源、项目频道 |
| 布局方式 | 左侧分组树 + 右侧列表，或顶部分类 + 下方列表 |

**执行要求：**

- 分组区应帮助用户缩小数据范围。
- 分组树宽度不宜过大，避免挤压表格。
- 分组切换后，右侧列表应即时刷新并保留清晰的当前筛选状态。

### 展开列表规范

| 项目 | 标准 |
|---|---|
| 展开方式 | 当前行向下展开 |
| 展开内容 | 当前数据条的扩展数据 |
| 使用条件 | 快速查看补充信息，不需要进入详情页 |
| 限制 | 不适合承载复杂编辑流程 |
