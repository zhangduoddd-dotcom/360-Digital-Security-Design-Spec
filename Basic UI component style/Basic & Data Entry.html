使用规则

  • 同一区域只保留一个主按钮，避免操作优先级混乱。

输入框体系用于承载短文本、长文本、IPv4 地址与高级搜索等录入任务；尺寸统一按高度分为大、中、小三档。

通用规范

输入框家族共享尺寸、状态、Token 与校验规则；各组件章节只展示默认样式和自身变体。

尺寸

Small高度 24px，字号 / 行高 12px / 20px，圆角 4px。
Default高度 32px，字号 / 行高 14px / 22px，圆角 6px，默认内边距 5px 12px。
Large高度 40px，字号 / 行高 16px / 28px，圆角 8px。

状态

请输入字段名称
默认白底，边框使用 gray-5 #DFE1E6，占位文字使用 gray-6 #AEB2B8。
悬停仅 border-color 使用 p5 #1DB887，占位文字样式与默认态一致。
激活与输入中状态同态；border-color 使用 p6 #00AB7A，focus ring 使用 0 0 0 2px #D9F4EE，内容输入使用 gray-9 #242933。
输入完成恢复默认边框，内容文字使用 gray-9 #242933。
禁用浅灰背景，文字使用 gray-6，不响应 hover 与输入。
报错border-color 使用 Red-6 #F0131E；错误文案固定在控件正下方左对齐。

Token

p6 #00AB7A p5 #1DB887 p7 #039972 p1 #D9F4EE Red-6 #F0131E Red-1 #FFE8E6 gray-5 #DFE1E6 gray-6 #AEB2B8 gray-9 #242933

校验规则

  • 必填未填写，失焦提示：请输入{字段名称}。
  • 格式错误，失焦提示：格式错误，请输入{格式要求}。
  • 非法字符应直接拦截，不能录入到控件内。
  • 失败状态必须同时展示红色边框和错误文案，不能只改变边框颜色。

尺寸使用原则

  • 实际业务中只允许选择 Small、Default、Large 三档高度。
  • 宽度由表单栅格、搜索区布局或业务字段长度决定，不作为组件尺寸档位。
  • 不得新增 28px、36px 等仓库未定义高度。

组件选择规则

生成业务页面前必须先判断输入内容类型，再选择输入框体系下的正确组件。

输入任务应使用组件选择规则
名称、账号、编号、关键字、域名等短文本Input使用常规输入框；可按需要启用前后置图标、前后置标签、allowClear、showCount。
备注、描述、说明、处置意见等多行文本TextArea作为独立组件使用，不作为 Input 变体；可启用字数统计。
IPv4 地址InputIPv4使用四段式专用输入框，每段只允许 0-255 的正整数。
列表筛选区、多字段组合查询AdvancedSearch用于承载搜索项、查询、重置、展开收起等搜索容器能力。

常规输入框 Input

Input 用于普通单行短文本录入，是输入框体系中的基础组件。

组件定位

  • 承载单行短文本输入，不承载数字、IP、多行备注和搜索容器。
  • 常用于名称、账号、编号、关键字、域名、轻量搜索词。

使用场景

  • 表单录入、表格筛选区单字段查询、行内编辑。
  • 需要清除、字数统计、前后缀辅助内容的短文本字段。

默认样式

  • 页面默认只展示基础样式。
  • hover、focus、输入、禁用、失败等反馈遵循通用状态规则。

API

sizesmall | default | large
statusdefault | error
allowClear显示清除按钮。
prefix / suffix前后置图标或内容。
addonBefore / addonAfter前后置标签。
showCount / maxLength字数统计与最大长度。

代码示例

import { Input } from '360euxd';

export default () => (
  <>
    <Input placeholder="请输入名称" />
    <Input allowClear placeholder="请输入关键词" />
    <Input showCount maxLength={10} placeholder="请输入策略名称" />
  </>
);

AI 生成规则

  • 短文本优先使用 Input，不要使用 TextArea 或 InputNumber 替代。
  • 可清空字段启用 allowClear；有长度限制时启用 showCount 与 maxLength。
  • 错误态必须同时给出 status="error" 和错误文案。

Input 变体

Input 变体用于承载图标或固定前后缀，不扩展为独立组件。

带前置图标

  • 图标表达输入语义，如搜索、用户、位置。
  • 鼠标悬浮、聚焦和输入时按输入框状态规则反馈。

带后置图标

  • 用于清除、复制、查看等输入后操作。
  • 鼠标悬浮、聚焦和输入时按输入框状态规则反馈。

带前置标签

https://
  • 用于协议、币种、固定前缀等不可编辑内容。
  • 前置标签不参与用户输入内容。

带后置标签

GB
  • 用于单位、域名后缀等固定后缀。
  • 数值字段应使用 InputNumber，不要仅靠后置单位包装 Input。

文本域 TextArea

TextArea 是多行文本录入组件，适用于备注、描述、说明等长文本，不作为 Input 的变体。

组件定位

  • 承载多行文本输入，支持高度扩展、字数统计和最大长度限制。
  • 最小高度建议不低于 100px，宽度由表单或页面布局决定。

使用场景

  • 备注、描述、处置说明、告警说明、审批意见。
  • 需要用户输入较长自然语言内容的表单字段。

默认样式

  • 默认文本域不展示字数统计。
  • 适用于无明确长度限制的备注、描述、说明。

带字数限制

8 / 200
  • 字数统计固定展示在文本域内部右下角。
  • 字数统计不遮挡输入内容，文本域需预留底部内边距。

API

rows控制默认行数。
showCount显示字数统计。
maxLength最大可输入字符数。
autoSize按内容自动调整高度。
statusdefault | error。

代码示例

import { TextArea } from '360euxd';

export default () => (
  <TextArea
    rows={4}
    showCount
    maxLength={200}
    placeholder="请输入处置说明"
  />
);

AI 生成规则

  • 字段名包含备注、描述、说明、意见时，优先使用 TextArea。
  • 超过一行的自然语言内容不要使用 Input。
  • 有长度限制时必须展示内部字数统计。

IPv4 输入框

IPv4 输入框是 IP 地址专用输入组件，采用四段式结构并内置 0-255 的正整数约束。

组件定位

  • 专用于 IPv4 地址录入，不使用普通 Input 拼接或正则提示替代。
  • 每段独立输入，段间以点号分隔。

使用场景

  • 源 IP、目的 IP、网关、DNS、资产地址等 IPv4 字段。
  • 安全、网络、资产管理等后台业务配置。

默认样式

...
  • 四段式结构：0 . 0 . 0 . 0。
  • hover、focus、输入、禁用、失败等反馈遵循通用状态规则。

API

valueIPv4 字符串，例如 192.168.1.1。
onChange返回合法 IPv4 字符串或分段值。
disabled禁用全部分段。
statusdefault | error。

代码示例

import { InputIPv4 } from '360euxd';

export default () => (
  <InputIPv4
    value="192.168.1.1"
    errorMessage="格式错误，请输入0-255的正整数"
  />
);

AI 生成规则

  • 字段语义为 IP、IPv4、源地址、目的地址时必须使用 InputIPv4。
  • 每段只允许录入 0-255 的正整数，非法字符直接拦截。
  • 不要使用普通 Input + placeholder 模拟 IP 地址。

高级搜索 AdvancedSearch

AdvancedSearch 是搜索筛选容器组件，用于组合多个查询字段和操作按钮，不是 Input 的视觉变体。

组件定位

  • 承载列表页、表格页的多条件查询、重置、展开收起。
  • 容器内部可组合 Input、Select、DatePicker、InputIPv4 等录入控件。

使用场景

  • 列表筛选区、资产查询、告警查询、日志检索。
  • 搜索字段超过 3 项，或存在高级筛选折叠需求。

默认样式

  • 页面只展示默认状态。
  • hover、focus、输入、禁用、失败等反馈遵循通用状态规则。

API

fields搜索字段配置。
onSearch点击查询或回车触发。
onReset重置为默认筛选条件。
collapsible是否支持展开收起。
defaultCollapsed默认是否收起高级项。

代码示例

import { AdvancedSearch, Input, Select, DateRangePicker } from '360euxd';

export default () => (
  <AdvancedSearch
    onSearch={handleSearch}
    onReset={handleReset}
    collapsible
    fields={[
      { name: 'keyword', label: '策略名称', component: <Input allowClear /> },
      { name: 'level', label: '风险等级', component: <Select /> },
      { name: 'time', label: '发生时间', component: <DateRangePicker /> },
    ]}
  />
);

AI 生成规则

  • 列表页存在多个筛选条件时优先生成 AdvancedSearch。
  • 单个关键词搜索可使用 Input 或 Search，不必使用 AdvancedSearch。
  • 搜索区内的字段组件仍需遵循各自组件规范。

禁止用法

以下规则用于约束 AI 和研发生成页面时的组件选择，避免把展示页样式或错误组件带入业务代码。

禁止组件误用

  • 禁止用 Input 录入数字、金额、百分比、数量，应使用 InputNumber。
  • 禁止用 Input 模拟 IPv4，应使用 InputIPv4。
  • 禁止把 TextArea、IPv4、AdvancedSearch 归类为 Input 变体。
  • 禁止只改变红色边框而不展示错误文案。

禁止代码写法

// 错误：业务文档和示例中禁止从 antd 导入或暴露原组件
// 请统一从 360euxd 导入输入框体系组件

// 错误：展示页视觉类名不能作为真实业务组件使用
<div className="x-input">请输入名称</div>

// 错误：IP 地址不能使用普通 Input
<Input placeholder="请输入 IP 地址" />
