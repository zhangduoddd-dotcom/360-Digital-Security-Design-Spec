  </>
);

Message 全局提醒规范页

全局提醒用于页面顶部中心的轻量反馈，提示当前操作结果，不打断用户流程。

Ant: Message

参考 Ant Design Message 静态方法和配置项，限制为操作反馈而非页面内容说明。

组件样式

提醒反馈，提示信息提示信息，提示信息提示

规则

  • 用于保存成功、提交失败、删除完成等操作反馈。
  • 默认 3s 自动关闭，重要长信息应使用 Notification 或 Modal。
  • 可附带一个查看链接，链接文字使用对应状态色。
  • 文字保持简短，避免超过 50 字。

代码示例

支持静态方法，也支持对象配置 duration、key、icon。

import { message } from '360euxd';

message.success('保存成功');
message.warning({ content: '请先选择一条数据', duration: 3 });
message.error({ key: 'submit', content: '提交失败，请重试' });

规则

  • 系统异步通知、任务完成、后台失败等使用 Notification。
  • 标题建议 10 字以内，描述用于补充原因或下一步动作。

  type: 'error',
  title: '通知提醒框',
  description: '请查看网络连接后刷新页面重试',
  placement: 'topRight',
});

规则

简约样式

简约样式用于空间较紧凑的列表或卡片区域，尺寸固定为 24×24。

简约-线性（24×24）
简约-面性（24×24）

规则

分页需要明确总数、当前页和可用操作。

  • 基础样式和更多页码的按钮及单个数字大小固定 32×32px。
  • 简约样式的按钮及单个数字大小固定 24×24px。
  • 线性样式使用描边表达当前页，面性样式使用浅绿色背景表达当前页。
  • 超过 5 页时保留当前页附近页码、上一页、下一页和最后一页。
  • 下拉选择、前后箭头和页码点击需要可交互，并保持 Ant Design Pagination 的切换逻辑。

代码示例

能力参考 Ant Design Pagination，视觉样式按本规范实现。

import { Pagination } from '360euxd';

<Pagination total={50} variant="linear" />
<Pagination total={50} variant="filled" />
<Pagination simple size="small" total={50} />
<Pagination showSizeChanger showQuickJumper total={4568} />

Tabs 标签页规范页

标签页用于同一层级内容之间切换，帮助用户在有限区域内浏览并切换相关信息。

Ant: Tabs

基本样式与规则

参考 Ant Design Tabs 的基础、可滑动、附加操作、卡片式和竖列样式；每组页签均可交互。

组件样式

基本样式

基础、简洁的标签页，用于容器内部的主功能切换。

页签个数建议 5 个左右较为合适，最多 7 个；各页签文案不超过 8 个字符。

中字号 14px

大字号 16px

水平与可滑动标签

附加操作

卡片式

用于容器顶部；每个 Tab 标签文字最多 6 个字，标签数量最多 7 个，建议出现 4 个以内。

某特定环境下 Tab 标签可能为禁用状态。

竖列样式

用于分类较多的选项，可以不限制分类数量，具备更好的扩展性；每个标签文字最多 7 个字。

某特定环境下标签可能为禁用状态。

规则

  • 基础标签页用于容器内部的主功能切换，建议 5 个左右，最多 7 个。
  • 中字号标签使用 14px，大字号标签使用 16px，颜色沿用规范文本与主色变量。
  • 禁用标签不可点击，不参与键盘切换。
  • 滑动标签的左右箭头用于在可用标签之间前后切换。
  • 附加操作放在页签栏右侧，不挤压标签文字。
  • 卡片式用于容器顶部，竖列样式用于分类较多且需要更强扩展性的场景。

代码示例

能力参考 Ant Design Tabs，视觉样式按本规范实现。

import { Tabs } from '360euxd';

const items = [
  { key: 'one', label: '标签一', children: '当前标签页内容区域' },
  { key: 'two', label: '标签二', children: '标签二内容区域' },
  { key: 'three', label: '标签三', disabled: true }
];

<Tabs defaultActiveKey="one" items={items} onChange={(key) => console.log(key)} />
<Tabs type="card" items={items} />
<Tabs tabPlacement="left" items={items} />
<Tabs tabBarExtraContent={<Button>附加操作</Button>} items={items} />

Page Header 页头规范页

页头用于承载页面标题、返回入口、辅助说明和右侧操作，是页面级导航与操作的起点。

Ant: PageHeader

基本样式与规则

页头组件样式先保留纯标题和带返回两种基础形态。

组件样式

页面头部标题
页面头部标题

规则

  • 页头标题应直接表达当前页面或对象名称。
  • 需要返回上一级时使用返回箭头 + 标题。
  • 基础页头内不放置多余按钮或辅助说明。
  • 标题文字保持简洁，避免超过一行。

代码示例

能力参考 Ant Design PageHeader，视觉样式按本规范实现。

import { PageHeader } from '360euxd';

<PageHeader title="页面头部标题" />
<PageHeader title="页面头部标题" onBack={() => history.back()} />
