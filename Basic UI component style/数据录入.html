Input 输入框

Input Family 输入框体系

输入框体系用于承载短文本、长文本、IPv4 地址与高级搜索等录入任务；尺寸统一按高度分为大、中、小三档。

360euxd: Input Family
体系定位
文本类数据录入
独立组件
Input / TextArea / IPv4 / AdvancedSearch
尺寸规则
仅按高度分大中小
核心 Token
p6 / gray-5 / Red-6

通用规范

输入框家族共享尺寸、状态、Token 与校验规则；各组件章节只展示默认样式和自身变体。

尺寸

Small高度 24px，字号 / 行高 12px / 20px，圆角 4px。
Default高度 32px，字号 / 行高 14px / 22px，圆角 6px，默认内边距 5px 12px。
Large高度 40px，字号 / 行高 16px / 28px，圆角 8px。

状态

请输入字段名称
默认白底，边框使用 gray-5 #DFE1E6，占位文字使用 gray-6 #AEB2B8。
悬停仅 border-color 使用 p5 #1DB887，占位文字样式与默认态一致。
激活与输入中状态同态；border-color 使用 p6 #00AB7A，focus ring 使用 0 0 0 2px #D9F4EE，内容输入使用 gray-9 #242933。
输入完成恢复默认边框，内容文字使用 gray-9 #242933。
禁用浅灰背景，文字使用 gray-6，不响应 hover 与输入。
报错border-color 使用 Red-6 #F0131E；错误文案固定在控件正下方左对齐。

Token

p6 #00AB7A p5 #1DB887 p7 #039972 p1 #D9F4EE Red-6 #F0131E Red-1 #FFE8E6 gray-5 #DFE1E6 gray-6 #AEB2B8 gray-9 #242933

校验规则

  • 必填未填写，失焦提示：请输入{字段名称}。
  • 格式错误，失焦提示：格式错误，请输入{格式要求}。
  • 非法字符应直接拦截，不能录入到控件内。
  • 失败状态必须同时展示红色边框和错误文案，不能只改变边框颜色。

尺寸使用原则

  • 实际业务中只允许选择 Small、Default、Large 三档高度。
  • 宽度由表单栅格、搜索区布局或业务字段长度决定，不作为组件尺寸档位。
  • 不得新增 28px、36px 等仓库未定义高度。

组件选择规则

生成业务页面前必须先判断输入内容类型，再选择输入框体系下的正确组件。

输入任务应使用组件选择规则
名称、账号、编号、关键字、域名等短文本Input使用常规输入框；可按需要启用前后置图标、前后置标签、allowClear、showCount。
备注、描述、说明、处置意见等多行文本TextArea作为独立组件使用，不作为 Input 变体；可启用字数统计。
IPv4 地址InputIPv4使用四段式专用输入框，每段只允许 0-255 的正整数。
列表筛选区、多字段组合查询AdvancedSearch用于承载搜索项、查询、重置、展开收起等搜索容器能力。

常规输入框 Input

Input 用于普通单行短文本录入，是输入框体系中的基础组件。

组件定位

  • 承载单行短文本输入，不承载数字、IP、多行备注和搜索容器。
  • 常用于名称、账号、编号、关键字、域名、轻量搜索词。

使用场景

  • 表单录入、表格筛选区单字段查询、行内编辑。
  • 需要清除、字数统计、前后缀辅助内容的短文本字段。

默认样式

  • 页面默认只展示基础样式。
  • hover、focus、输入、禁用、失败等反馈遵循通用状态规则。

API

sizesmall | default | large
statusdefault | error
allowClear显示清除按钮。
prefix / suffix前后置图标或内容。
addonBefore / addonAfter前后置标签。
showCount / maxLength字数统计与最大长度。

代码示例

import { Input } from '360euxd';

export default () => (
  <>
    <Input placeholder="请输入名称" />
    <Input allowClear placeholder="请输入关键词" />
    <Input showCount maxLength={10} placeholder="请输入策略名称" />
  </>
);

AI 生成规则

  • 短文本优先使用 Input，不要使用 TextArea 或 InputNumber 替代。
  • 可清空字段启用 allowClear；有长度限制时启用 showCount 与 maxLength。
  • 错误态必须同时给出 status="error" 和错误文案。

Input 变体

Input 变体用于承载图标或固定前后缀，不扩展为独立组件。

带前置图标

  • 图标表达输入语义，如搜索、用户、位置。
  • 鼠标悬浮、聚焦和输入时按输入框状态规则反馈。

带后置图标

  • 用于清除、复制、查看等输入后操作。
  • 鼠标悬浮、聚焦和输入时按输入框状态规则反馈。

带前置标签

https://
  • 用于协议、币种、固定前缀等不可编辑内容。
  • 前置标签不参与用户输入内容。

带后置标签

GB
  • 用于单位、域名后缀等固定后缀。
  • 数值字段应使用 InputNumber，不要仅靠后置单位包装 Input。

文本域 TextArea

TextArea 是多行文本录入组件，适用于备注、描述、说明等长文本，不作为 Input 的变体。

组件定位

  • 承载多行文本输入，支持高度扩展、字数统计和最大长度限制。
  • 最小高度建议不低于 100px，宽度由表单或页面布局决定。

使用场景

  • 备注、描述、处置说明、告警说明、审批意见。
  • 需要用户输入较长自然语言内容的表单字段。

默认样式

  • 默认文本域不展示字数统计。
  • 适用于无明确长度限制的备注、描述、说明。

带字数限制

8 / 200
  • 字数统计固定展示在文本域内部右下角。
  • 字数统计不遮挡输入内容，文本域需预留底部内边距。

API

rows控制默认行数。
showCount显示字数统计。
maxLength最大可输入字符数。
autoSize按内容自动调整高度。
statusdefault | error。

代码示例

import { TextArea } from '360euxd';

export default () => (
  <TextArea
    rows={4}
    showCount
    maxLength={200}
    placeholder="请输入处置说明"
  />
);

AI 生成规则

  • 字段名包含备注、描述、说明、意见时，优先使用 TextArea。
  • 超过一行的自然语言内容不要使用 Input。
  • 有长度限制时必须展示内部字数统计。

IPv4 输入框

IPv4 输入框是 IP 地址专用输入组件，采用四段式结构并内置 0-255 的正整数约束。

组件定位

  • 专用于 IPv4 地址录入，不使用普通 Input 拼接或正则提示替代。
  • 每段独立输入，段间以点号分隔。

使用场景

  • 源 IP、目的 IP、网关、DNS、资产地址等 IPv4 字段。
  • 安全、网络、资产管理等后台业务配置。

默认样式

...
  • 四段式结构：0 . 0 . 0 . 0。
  • hover、focus、输入、禁用、失败等反馈遵循通用状态规则。

API

valueIPv4 字符串，例如 192.168.1.1。
onChange返回合法 IPv4 字符串或分段值。
disabled禁用全部分段。
statusdefault | error。

代码示例

import { InputIPv4 } from '360euxd';

export default () => (
  <InputIPv4
    value="192.168.1.1"
    errorMessage="格式错误，请输入0-255的正整数"
  />
);

AI 生成规则

  • 字段语义为 IP、IPv4、源地址、目的地址时必须使用 InputIPv4。
  • 每段只允许录入 0-255 的正整数，非法字符直接拦截。
  • 不要使用普通 Input + placeholder 模拟 IP 地址。

高级搜索 AdvancedSearch

AdvancedSearch 是搜索筛选容器组件，用于组合多个查询字段和操作按钮，不是 Input 的视觉变体。

组件定位

  • 承载列表页、表格页的多条件查询、重置、展开收起。
  • 容器内部可组合 Input、Select、DatePicker、InputIPv4 等录入控件。

使用场景

  • 列表筛选区、资产查询、告警查询、日志检索。
  • 搜索字段超过 3 项，或存在高级筛选折叠需求。

默认样式

  • 页面只展示默认状态。
  • hover、focus、输入、禁用、失败等反馈遵循通用状态规则。

API

fields搜索字段配置。
onSearch点击查询或回车触发。
onReset重置为默认筛选条件。
collapsible是否支持展开收起。
defaultCollapsed默认是否收起高级项。

代码示例

import { AdvancedSearch, Input, Select, DateRangePicker } from '360euxd';

export default () => (
  <AdvancedSearch
    onSearch={handleSearch}
    onReset={handleReset}
    collapsible
    fields={[
      { name: 'keyword', label: '策略名称', component: <Input allowClear /> },
      { name: 'level', label: '风险等级', component: <Select /> },
      { name: 'time', label: '发生时间', component: <DateRangePicker /> },
    ]}
  />
);

AI 生成规则

  • 列表页存在多个筛选条件时优先生成 AdvancedSearch。
  • 单个关键词搜索可使用 Input 或 Search，不必使用 AdvancedSearch。
  • 搜索区内的字段组件仍需遵循各自组件规范。

禁止用法

以下规则用于约束 AI 和研发生成页面时的组件选择，避免把展示页样式或错误组件带入业务代码。

禁止组件误用

  • 禁止用 Input 录入数字、金额、百分比、数量，应使用 InputNumber。
  • 禁止用 Input 模拟 IPv4，应使用 InputIPv4。
  • 禁止把 TextArea、IPv4、AdvancedSearch 归类为 Input 变体。
  • 禁止只改变红色边框而不展示错误文案。

禁止代码写法

// 错误：业务文档和示例中禁止从 antd 导入或暴露原组件
// 请统一从 360euxd 导入输入框体系组件

// 错误：展示页视觉类名不能作为真实业务组件使用
<div className="x-input">请输入名称</div>

// 错误：IP 地址不能使用普通 Input
<Input placeholder="请输入 IP 地址" />

数据录入组件库 / InputNumber 数字输入框规范页

InputNumber 用于数字、金额、百分比、数量等数值录入，必须具备范围、步进、修正和校验反馈能力。

360euxd: InputNumber
组件定位
数值类数据录入
尺寸规则
24 / 32 / 40px
关键能力
范围 / 步进 / 单位
图标规则
反馈态显示步进

通用规范

数字输入框继承输入框体系的尺寸、Token 与校验规则，额外约束右侧加减图标的展示时机。

尺寸

Small高度 24px，用于紧凑表格筛选和行内编辑。
Default高度 32px，用于常规表单与筛选。
Large高度 40px，用于重点输入或低密度页面。

状态

请输入0-100之间的数值
默认默认边框，不显示右侧加减图标。
悬停border-color 使用 p5，不显示右侧加减图标。
激活激活与输入中状态一致，显示右侧加减图标。
输入完成 / 禁用不显示右侧加减图标。
报错显示右侧加减图标，红色边框和错误文案同时出现。

Token

p6 #00AB7Ap5 #1DB887p1 #D9F4EERed-6 #F0131Egray-5 #DFE1E6gray-9 #242933

校验规则

  • 仅允许录入数字，非法字符直接拦截。
  • 必须定义 min、max、step，超出范围需要提示或修正。
  • 错误提示固定展示在输入框正下方，靠左对齐。
  • 金额、百分比、数量等字段不得使用普通 Input。

组件定位与使用场景

InputNumber 只承载数值输入，不承载普通文本、IP、密码和多行说明。

组件定位

  • 用于数值录入、数值调整和需要范围校验的字段。
  • 支持键盘输入、步进加减、单位展示和格式化展示。

使用场景

  • 数量、次数、阈值、端口、排序、下载限速。
  • 金额、百分比、折扣、容量、时间间隔等带单位数值。

API

InputNumber API 必须能表达数值范围、步进、格式化、单位、精度和校验状态。

属性说明规则
min / max最小值 / 最大值业务数值字段必须明确边界。
step每次加减的步长默认 1；金额、百分比等可按业务定义。
precision小数精度金额、比例等需要明确小数位。
formatter / parser展示格式与真实值解析金额、百分比、千分位场景使用。
prefix / suffix前后单位单位只做辅助展示，不参与数值本身。
status / help错误状态与提示文案错误状态必须展示文案。

代码示例

示例使用 360euxd 占位包名，覆盖范围、步进、精度、单位、错误和禁用。

import { InputNumber } from '360euxd';

export default () => (
  <>
    <InputNumber min={0} max={100} step={1} placeholder="0-100" />
    <InputNumber min={0} max={10000} step={100} suffix="元" />
    <InputNumber min={0} max={100} precision={2} suffix="%" />
    <InputNumber status="error" value={120} help="请输入0-100之间的数值" />
    <InputNumber disabled value={0} />
  </>
);

AI 生成规则

生成业务页面时，先判断字段是否为数值语义，再选择 InputNumber。

字段类型应使用组件规则
数量、次数、阈值、端口、排序InputNumber必须设置 min、max、step。
金额、价格、费用InputNumber设置 precision、formatter 或 suffix。
百分比、比例、折扣InputNumber设置范围 0-100 或业务允许范围，并展示 %。
普通名称、账号、关键字Input禁止误用 InputNumber。

禁止用法

避免用普通文本输入框模拟数值能力，也避免缺失边界和错误提示。

禁止组件误用

  • 禁止用 Input 录入数字、金额、百分比、数量。
  • 禁止只有 placeholder 中写 0-100，却不设置真实 min / max。
  • 禁止错误状态只改变边框，不展示错误文案。
  • 禁止默认、输入完成、禁用状态展示加减图标。

错误示例

// 错误：数字字段不应使用普通 Input
<Input placeholder="请输入数量" />

// 错误：只有占位符，没有真实范围
<InputNumber placeholder="0-100" />

// 错误：错误态缺少错误提示
<InputNumber status="error" value={120} />

Date Family 日期选择体系

日期选择体系用于承载单日期、日期区间和日历面板选择；各组件共享日期状态、面板和校验规则。

360euxd: Date Family
体系定位
日期类数据录入
独立组件
DatePicker / DateRangePicker / CalendarPicker
面板宽度
280 / 560 / 657px
日期格
24 × 24px

通用规范

日期选择器共享数据录入控件的尺寸、状态、Token 与校验反馈，并补充日期面板的选中范围规则。

尺寸

单日期默认宽度 240px，按 Small / Default / Large 三档高度使用。
日期区间默认宽度 400px，需要完整展示开始和结束日期。
日期格面板日期格尺寸 24 × 24px。

状态

请选择日期
默认未选择时展示占位文字和日历图标。
悬停仅边框进入 hover 反馈，内容保持默认展示。
激活聚焦、键盘输入和面板展开时使用激活反馈。
输入完成控件回到默认边框，保留已选日期。
禁用不可选择、不可输入，不响应面板展开。
报错红色边框和错误文案同时展示。

Token

p6 #00AB7Ap5 #1DB887p7 #039972p1 #D9F4EERed-6 #F0131Egray-5 #DFE1E6gray-6 #AEB2B8

校验规则

  • 必填日期未选择时，失焦后在控件下方展示错误提示。
  • 支持键盘输入时必须容错，并校验日期格式和可选范围。
  • 日期区间需要校验开始时间与结束时间顺序。
  • 不可选日期应在面板中禁用，避免用户先选后报错。

面板规则

  • 当天、悬停日期、已选日期和区间范围需要可区分。
  • 单日期面板默认宽度 280px，区间面板按双面板宽度展示。
  • 必要时标注周末、节假日或业务特殊日期。

组件选择规则

生成页面前先判断用户选择的是单日期、日期区间、日历面板还是纯时间。

录入任务应使用组件选择规则
单个日期DatePicker用于发生日期、生效日期、截止日期等单日期字段。
开始日期到结束日期DateRangePicker用于筛选区间、有效期和统计周期。
直接在日历面板选择日期CalendarPicker用于需要常驻日历视图或在面板中辨识日期的场景。
只选择时刻TimePicker不要用日期选择组件代替纯时间选择。

日期选择器 DatePicker

DatePicker 用于一个日期字段的选择和回填，是日期选择体系中的基础控件。

组件定位

  • 用于选择或输入一个符合日期语义的值。
  • 支持按业务需要扩展日期时间，但不承载日期区间。

使用场景

  • 生效日期、过期日期、计划日期、截止日期。
  • 需要精确到时分秒的单个发生时间可启用 showTime。

默认样式

2020年 7月
日一二三四五六
今天
2022年
2022年
2020-2029
  • 日历图标固定作为日期语义提示。
  • 激活日期选择器时展开日历面板，反馈样式遵循通用规范。

API

value当前已选日期。
format日期展示和输入格式。
showTime启用日期时间选择。
disabledDate禁用不可选日期。
status / help错误状态与提示文案。

代码示例

import { DatePicker } from '360euxd';

<DatePicker placeholder="请选择日期" />
<DatePicker showTime placeholder="请选择日期时间" />
<DatePicker disabled value="2026-05-20" />

AI 生成规则

  • 日期、生效日、截止日等单日期字段使用 DatePicker。
  • 纯时间字段使用 TimePicker，不要开启 DatePicker。
  • 错误态必须同时展示控件状态和提示文案。

日期区间选择器 DateRangePicker

DateRangePicker 用于成对录入开始日期和结束日期，区间逻辑由组件统一承载。

组件定位

  • 用于选择连续日期范围，不拆成两个无联动单日期控件。
  • 需要表达开始、结束和范围有效性。

使用场景

  • 列表查询时间范围、统计周期、有效期。
  • 任务开始与结束、策略生效区间。

默认样式

  • 开始与结束日期需要同时可见。
  • 区间面板需要连续表达已选范围。

API

value开始与结束日期值。
format范围展示格式。
