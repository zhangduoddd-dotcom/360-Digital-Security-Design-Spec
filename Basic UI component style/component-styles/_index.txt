# Component Styles — 组件样式规范索引

> 本目录定义各交互组件的标准样式、尺寸、状态及用法，确保全站组件视觉一致。

> 使用顺序：先看 [motion.txt](motion.txt) 的全局动效约束，再按需查具体组件文档；组件文件只补差异，不重复抄整套动效规则。

## 设计原则

1. **一致性优先**：同类组件在不同页面必须保持相同的视觉表现
2. **语义化色值**：所有颜色使用 `Green Theme-Global Style.css` 中的稳定变量；文字层级只使用 `--text-title / --text-body / --text-secondary / --text-tertiary / --text-disabled`，描边区分 `--border` 分割线与 `--border-strong` 组件描边，禁止硬编码色值
3. **状态完备**：每个组件必须定义 default / hover / focus / disabled / error 等状态
4. **尺寸统一**：组件遵循紧凑 / 常规 / 宽松三档，但具体高度以组件文档为准；`Input` 使用 `24 / 32 / 40px`，不要强套 `32 / 36 / 40px`
5. **动效收口**：组件级动效统一遵循 `motion.txt`，单个组件文档只记录特殊时长、特殊方向或禁用项

## 通用尺寸节奏

| 尺寸 | 高度 | 内边距 | 字号 | 适用场景 |
|------|------|--------|------|---------|
| `sm` | 24-32px | `px-3` | 12px (`text-xs`) | 紧凑型表格、密集筛选区 |
| `default` | 32-36px | `px-3` ~ `px-4` | 14px (`text-sm`) | 大多数场景默认，具体以组件文档为准 |
| `lg` | 40px (`h-10`) | `px-5` | 14px (`text-sm`) | 表单主操作、突出按钮 |

## 状态色值速查

| 状态 | 边框色 | 背景色 | 文字色 |
|------|--------|--------|--------|
| Default | `--border-strong` | `--card-bg` | `--text-body` |
| Hover | `--primary` | `--gray-3` | — |
| Focus | `--primary` | — | 外环使用 `--focus-default` |
| Disabled | `--gray-5` | `--gray-2` | `--text-disabled` |
| Error | `--error` | `--error-bg` | `--error` |
| Success | `--success` | `--success-bg` | `--success` |

## 颜色收口说明

- 中性弱化表面使用 `--gray-2` 或 `--gray-3`，不要再新增 `muted` 类别变量
- 表单控件禁用底统一使用 `--gray-2`
- 文字层级统一收口到标题 / 正文 / 二级 / 三级 / 禁用五档，组件不要再自行发明“默认文字色”语义
- 只有状态语义允许跳出常规文字层级，例如 `--primary`、`--error`、`--success`、`--warning`、`--info`
