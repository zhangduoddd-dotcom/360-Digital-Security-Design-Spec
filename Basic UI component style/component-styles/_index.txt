# Component Styles — 组件样式规范索引

> 本目录定义各交互组件的标准样式、尺寸、状态及用法，确保全站组件视觉一致。

> 使用顺序：先看 [motion.txt](motion.txt) 的全局动效约束，再按需查具体组件文档；组件文件只补差异，不重复抄整套动效规则。

## 设计原则

1. **一致性优先**：同类组件在不同页面必须保持相同的视觉表现
2. **语义化色值**：所有颜色使用 CSS Variables；文字层级只使用 `text-foreground / text-muted-foreground / text-tertiary-foreground / text-disabled-foreground` 四档，描边区分 `border-border` 分割线、`border-input` 组件描边、`border-input-disabled` 禁用描边，禁止硬编码色值
3. **状态完备**：每个组件必须定义 default / hover / focus / disabled / error 等状态
4. **尺寸统一**：组件遵循紧凑 / 常规 / 宽松三档，但具体高度以组件文档为准；`Input` 使用 `24 / 32 / 40px`，不要强套 `32 / 36 / 40px`
5. **动效收口**：组件级动效统一遵循 `motion.txt`，单个组件文档只记录特殊时长、特殊方向或禁用项

## 通用尺寸节奏

| 尺寸 | 高度 | 内边距 | 字号 | 适用场景 |
|------|------|--------|------|---------|
| `sm` | 24-32px | `px-3` | 12px (`text-xs`) | 紧凑型表格、密集筛选区 |
| `default` | 32-36px | `px-3` ~ `px-4` | 14px (`text-sm`) | 大多数场景默认 |
| `lg` | 40px (`h-10`) | `px-5` | 14px (`text-sm`) | 表单主操作、突出按钮 |

## 状态色值速查

| 状态 | 边框色 | 背景色 | 文字色 |
|------|--------|--------|--------|
| Default | `border-input` | `bg-background` | `text-foreground` |
| Hover | `border-primary/50` | — | — |
| Focus | `ring-2 ring-ring` | — | — |
| Disabled | `border-input-disabled` | `bg-field-disabled` | `text-disabled-foreground` |
| Error | `border-destructive` | — | `text-destructive` |
| Success | `border-brand-green-500` | — | `text-brand-green-600` |

## 颜色收口说明

- `secondary` 仅作为兼容别名保留，不再作为新规范的独立语义
- `muted` 用于弱化但非禁用的表面，例如表头、hover、浅辅助区
- `bg-muted` 表示一层明确可见的弱化实底，`bg-muted/50` 表示更轻的一层弱化表面
- 表单控件禁用底统一收口到 `bg-field-disabled`
- 文字层级统一收口到一级 / 二级 / 三级 / 禁用四档，组件不要再自行发明“默认文字色”语义
- 只有状态语义允许跳出四档文字层级，例如 `text-primary`、`text-destructive`、`text-brand-green-600`
