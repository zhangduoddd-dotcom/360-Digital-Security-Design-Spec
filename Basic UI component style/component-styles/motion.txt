# Motion 动效基础规范

> 本文件定义 **全局通用动效规则**，并且是交互输出的**必读必做规范**。各组件文档只补充“本组件的特殊约束”，不要重复抄整套动效说明，避免 skill context 膨胀。

## 适用范围

- 默认适用于中后台里的按钮、输入框、下拉、开关、标签页、Toast、表格行反馈、弹层开合
- 不默认覆盖营销页、3D 场景、强叙事型长页面过场
- 若用户只问样式，不主动展开本文件；只有涉及 hover / active / open / close / enter / leave / transition 时再按需读取

## 验收口径

- 只要输出里包含交互元素，本文件就是必需项，不是建议项
- 缺少 hover / focus / active / open / close 等基础状态过渡的交互组件，视为未完成还原
- 若某组件暂时没有单独文档，直接按本文件的时长、缓动和组合方式落地，不得因为“没查到专属规范”而省略动效

### 必须覆盖的基础交互

- Button：hover / active / focus 的颜色、边框、阴影或 ring 反馈
- Input / Textarea：hover / focus / error / disabled 的边框、ring、文字或背景反馈
- Select / Combobox / DatePicker Trigger：hover / active / open / close 反馈，箭头开合反馈，面板进出反馈
- Switch / Checkbox / Radio：checked 与 unchecked 切换反馈，必要时含图标或文案显隐
- Tabs / Tag / 表格行 hover / 分页按钮：轻量状态过渡
- Popover / Dialog / Drawer / Toast：出现与消失的进出反馈

## 三条原则

### 1. 自然

- 动效要符合用户对物体运动的直觉
- 默认优先使用 `opacity`、`transform`、`background-color`、`border-color`、`color`、`box-shadow`
- 进入和离开都要有轻微缓冲，不做突兀的瞬时跳变

### 2. 高效

- 中后台动效的目标是帮助理解状态变化，不是展示技巧
- 同一动作尽量在短时间内完成，避免拖慢操作节奏
- 离场动效应普遍快于或不慢于进场动效

### 3. 克制

- 不使用弹跳、果冻、夸张回弹、长距离飞入等强表演性效果
- 不要让图标旋转、背景扫光、元素漂浮抢走信息焦点
- 未发生变化的内容尽量保持稳定，作为上下文锚点

## 默认时间分级

| Token | 时长 | 适用场景 |
|------|------|---------|
| `motion-instant` | `100ms` | 箭头旋转、勾选显隐、图标/文字轻量切换 |
| `motion-fast` | `150ms` | hover / active / focus / 行 hover / 按钮按压反馈 |
| `motion-base` | `200ms` | Select 面板、Popover、局部切换、错误提示显隐 |
| `motion-slow` | `300ms` | Dialog / Drawer / Toast / 明显容器进出 |
| `motion-page` | `450ms` | 极少数页面级切换上限，默认不主动使用 |

**落地规则**：

- 当前仓库若未统一抽 token，允许直接写 `0.1s / 0.15s / 0.2s / 0.3s`
- 组件级微交互优先使用 `100ms` 或 `150ms`
- 常规中后台页面不要超过 `300ms`
- 若无法一次性做完整弹层编排，也至少要保留颜色、透明度、位移这三类基础反馈中的合适组合

## 默认缓动规则

| 场景 | 缓动 |
|------|------|
| 进入可视区 | `ease-out` |
| 离开可视区 | `ease-in` |
| 可视区内位置切换 | `ease-in-out` |
| 单纯颜色 / 边框 / 阴影过渡 | `ease` |

**补充**：

- 默认优先使用 CSS 原生 `ease / ease-in / ease-out / ease-in-out`
- 没有明确品牌要求时，不额外引入复杂 `cubic-bezier`

## 默认位移与缩放

### 位移

- 浮层、Toast、下拉面板默认位移距离：`4px ~ 8px`
- 容器级侧滑（Drawer）按组件自身宽度滑入，不额外叠加大幅位移
- 表格行、标签、辅助提示的轻微位移默认不超过 `4px`

### 缩放

- 默认只允许轻微缩放：`0.96 ~ 1` 或 `1 ~ 0.98`
- 缩放只用于弹层、卡片呼出、局部强调
- 普通按钮、输入框、表格行不默认使用缩放反馈

## 组合方式

### 单元素

默认组合：

- `opacity + translateY`
- 必要时加轻微 `scale`

不推荐默认组合：

- `rotate + scale + blur`
- 长链式多段关键帧

### 多元素队列

- 只用于卡片组、菜单组、结果卡片、轻量列表首屏进入
- 默认 `stagger` 控制在 `20ms ~ 40ms`
- 数据表格、密集列表、频繁刷新的后台区域，不默认加逐条排队动效

### 聚散 / 视差

- 不作为中后台默认规范
- 只有在层级关系本身就是设计重点时才使用，如多层抽屉、主次卡片呼出

## 转场语义

### 新增（Adding）

- 要让用户感知“有新内容出现”
- 默认用 `fade in + 轻微位移`

### 移除（Receding）

- 要让用户感知“内容已离开”
- 默认更快、更干脆，不拖尾

### 修改（Modifying）

- 重点是解释“哪一项刚刚变了”
- 优先使用局部高亮、状态色变化、轻微淡入淡出

### 上下文保持（Normal）

- 未变化元素尽量不动
- 页面切换、标签切换、抽屉展开时，保留足够稳定的参照物

## 组件落地约束

### 默认允许的动效

- 背景色过渡
- 边框色过渡
- 文字色过渡
- 阴影 / ring 过渡
- 透明度变化
- 轻微位移
- 轻微缩放

### 默认禁止的动效

- 无限循环装饰动画
- hover 触发的大幅位移或旋转
- 与业务无关的弹跳回弹
- 大面积视差背景
- 为了“显得快”而故意制造强干扰动画

## 可访问性与性能

- 优先动画 `transform` 和 `opacity`，减少布局抖动
- 对 `height / width` 动画保持克制，只在折叠区、抽屉、行增删这类必要场景使用
- 支持 `prefers-reduced-motion: reduce` 时，应关闭位移和缩放，保留最小必要的淡入淡出或直接切换
- 键盘焦点反馈优先保证可见性，不要为了动效移除 `focus-visible`
