# Switch 开关

> 用于即时生效的二元状态切换。适合“开启 / 关闭”“启用 / 停用”这类无需二次提交的场景，不适合承载提交后统一保存的表单选择。

## 组件变体

| 属性 | 可选值 | 说明 |
|------|--------|------|
| 尺寸 | 常规、紧凑 | 常规用于设置页 / 表单，紧凑用于表格或密集列表 |
| 状态 | `on`、`off` | 表示当前开关结果 |
| 禁用 | `off`、`on` | 禁用后只展示状态，不可切换 |
| 描述 | 无、文字、图标 | 轨道内部是否附加状态提示 |

**规范说明**：
- 组件集共 `24` 个变体
- 由 `尺寸 × 状态 × 禁用 × 描述` 四个属性组合生成
- 默认推荐：`常规 + state=off + disabled=off + 描述=无`
- `hover / focus` 属于交互态说明，不单独作为组件变体维度

## 动效补充

Switch 动效统一继承 [motion.txt](motion.txt)；本组件只补充以下差异：

- 轨道颜色过渡与 thumb 位移默认使用 `motion-fast`（`150ms`）
- 轨道内图标 / 文案显隐默认使用 `motion-instant`（`100ms`）
- 开关切换只允许线性位移，不使用 overshoot、弹跳或回弹
- `off → on` 与 `on → off` 的节奏保持一致，不通过不同夸张动效强化某一状态

## 尺寸规范

### 常规尺寸（默认）

| 元素 | 尺寸 | Tailwind / 说明 |
|------|------|-----------------|
| 轨道 | `48px × 24px` | `h-6 w-12 rounded-full` |
| 内边距 | `4px` | `p-1` |
| 圆点（thumb） | `16px × 16px` | `size-4 rounded-full` |
| `on` 位移 | `24px` | `translate-x-6` |
| 图标占位尺寸 | `16px × 16px` | 仅用于 `描述=图标` |
| 文字字号 | `12px / 20px` | `text-xs leading-5` |

```tsx
<Switch className="h-6 w-12 p-1" />
```

### 紧凑尺寸

| 元素 | 尺寸 | Tailwind / 说明 |
|------|------|-----------------|
| 轨道 | `36px × 18px` | `h-[18px] w-9 rounded-full` |
| 内边距 | `3px` | `p-[3px]` |
| 圆点（thumb） | `12px × 12px` | `size-3 rounded-full` |
| `on` 位移 | `18px` | `translate-x-[18px]` |
| 图标占位尺寸 | `12px × 12px` | 仅用于 `描述=图标` |
| 文字字号 | `12px / 20px` | `text-xs leading-5` |

```tsx
<Switch className="h-[18px] w-9 p-[3px]" />
```

**尺寸规则**：
- 一个页面内只保留一种主尺寸，避免同一区块混用
- 表格列、筛选工具条、批量配置面板统一用紧凑尺寸
- 带外部标签时，Switch 自身宽高固定，不因文案长度拉伸
- `Switch` 的视觉尺寸独立于常规输入控件的 `32 / 36 / 40` 高度档位，不强行对齐输入框高度

## 颜色与状态规范

### 轨道颜色

| 状态 | 推荐 Tailwind 类 | 对应变量 / 色阶 | 说明 |
|------|------------------|------------------|------|
| `on` + 可用 | `bg-primary` | `--primary` | 激活状态主色 |
| `on` + hover | `bg-primary-hover` | `--primary-hover` | Hover 只增强当前激活态，不改变语义 |
| `on` + 禁用 | `bg-primary-bg` | 开启弱化态 | 禁用但仍保留“已开启”语义 |
| `off` + 可用 | `bg-tertiary-foreground` | `--tertiary-foreground` | 关闭状态默认底色 |
| `off` + hover | `bg-muted-foreground` | `--muted-foreground` | Hover 略增强存在感，但不能变成开启态主色 |
| `off` + 禁用 | `bg-brand-gray-300` | 中性灰弱化态 | 关闭且禁用 |

### 圆点与内部描述

| 元素 | 推荐 Tailwind 类 | 说明 |
|------|------------------|------|
| 圆点（thumb） | `bg-primary-foreground` | 所有状态保持高对比白色圆点 |
| 轨道内文字 / 图标 | `text-primary-foreground` | 仅用于 `描述=文字 / 图标`，与圆点保持统一前景 |
| 聚焦描边 | `focus-visible:ring-2 focus-visible:ring-ring focus-visible:ring-offset-2` | 保留键盘可访问性 |

**颜色规则**：
- 轨道颜色必须直接表达当前状态，不能只靠文字说明
- 禁用态不改变状态语义，只降低可操作感
- `off` 态禁止继续使用开启态主色，避免误导为已开启
- 当前全局 `../Green Theme-Global Style.css` 没有 Switch 专用禁用语义 token，本规范先使用品牌扩展色阶落地，不额外扩散修改全局 token
- 开启弱化态和中性弱化态应通过语义 token 映射，不需要额外再写一套 `dark:` 色值

## 描述变体

### 1. 无（默认）

适用于绝大多数业务场景，状态语义由外部标签或上下文承担。

```tsx
<div className="flex items-center justify-between">
  <div>
    <Label htmlFor="push-notice">推送通知</Label>
    <p className="text-xs text-muted-foreground">接收系统推送消息</p>
  </div>
  <Switch id="push-notice" />
</div>
```

### 2. 文字

适用于开关本体需要自解释，且页面空间有限的场景。当前规范默认使用固定单字：`on=开`、`off=关`。

**使用规则**：
- 默认使用 `开 / 关`，不要随意替换成长文案
- 外部已经有明确标签时，不要再把长文案塞进轨道
- 文案只承担辅助识别，不替代状态颜色
- 文案始终放在与 thumb 相对的一侧空槽中

### 3. 图标

适用于状态更依赖图形识别的轻量场景。当前规范默认使用固定图标对：`on=check`、`off=close`。落地到本 skill 时，图标必须统一映射到 [SKILL.md](../../SKILL.md) 中的图标规则。

**使用规则**：
- React 工程中使用 `lucide-react`，推荐映射为 `Check` / `X`
- HTML Demo 中使用 Lucide CDN，推荐映射为 `data-lucide="check"` / `data-lucide="x"`
- 图标占位尺寸与当前尺寸档一致：常规 `16px`、紧凑 `12px`
- 图标始终放在与 thumb 相对的一侧空槽中
- 不使用手写内联 SVG，避免偏离 skill 统一图标库
- 图标式开关只适合熟悉型功能，不适合高风险配置项

## 状态详解

### `on`

```tsx
<Switch checked />
```

规则：
- 圆点停靠右侧
- 轨道使用品牌激活色
- 若使用内部描述，文字 / 图标位于左侧空槽

### `off`

```tsx
<Switch checked={false} />
```

规则：
- 圆点停靠左侧
- 轨道使用中性灰，不保留品牌色暗示
- 若使用内部描述，文字 / 图标位于右侧空槽

### `disabled`

```tsx
<Switch disabled checked />
<Switch disabled checked={false} />
```

规则：
- 禁用态保留当前状态位置与颜色语义
- 禁用后不可只用 `opacity-50` 粗暴处理，应切换到禁用专用轨道色
- 所有禁用状态都必须同时带 `disabled` 与业务说明文本

### `focus-visible`

```tsx
<Switch className="focus-visible:ring-2 focus-visible:ring-ring focus-visible:ring-offset-2" />
```

规则：
- 键盘聚焦时必须有清晰的外环提示
- 不要移除 `focus-visible` 描边
- `ring` 是可访问性状态，不算业务语义色

## React 落地建议（shadcn/ui）

**重要**：
- shadcn 默认 `Switch` 尺寸与本规范不一致
- 生成代码时必须覆写轨道尺寸、内边距、thumb 尺寸和 thumb 位移
- 禁用态不要沿用默认 `disabled:opacity-50`

```tsx
import * as React from "react"
import * as SwitchPrimitives from "@radix-ui/react-switch"
import { Check, X } from "lucide-react"

import { cn } from "@/lib/utils"

type SwitchSize = "default" | "compact"

function Switch({
  className,
  size = "default",
  ...props
}: React.ComponentProps<typeof SwitchPrimitives.Root> & {
  size?: SwitchSize
}) {
  return (
    <SwitchPrimitives.Root
      data-slot="switch"
      data-size={size}
      className={cn(
        "peer inline-flex shrink-0 rounded-full border-0 transition-colors outline-none",
        "focus-visible:ring-2 focus-visible:ring-ring focus-visible:ring-offset-2",
        "data-[state=checked]:bg-primary data-[state=unchecked]:bg-tertiary-foreground",
        "data-[state=checked]:hover:bg-primary-hover data-[state=unchecked]:hover:bg-muted-foreground",
        "disabled:cursor-not-allowed disabled:opacity-100",
        "disabled:data-[state=checked]:bg-primary-bg",
        "disabled:data-[state=unchecked]:bg-brand-gray-300",
        size === "default" ? "h-6 w-12 p-1" : "h-[18px] w-9 p-[3px]",
        className
      )}
      {...props}
    >
      <SwitchPrimitives.Thumb
        data-slot="switch-thumb"
        className={cn(
          "pointer-events-none block rounded-full bg-primary-foreground transition-transform",
          size === "default"
            ? "size-4 data-[state=checked]:translate-x-6"
            : "size-3 data-[state=checked]:translate-x-[18px]"
        )}
      />
    </SwitchPrimitives.Root>
  )
}
```

**实现规则**：
- 外部有可见标签时，优先使用 `描述=无`
- 纯开关场景必须补 `aria-label`
- 文字描述变体默认使用 `开 / 关`
- 图标描述变体默认使用 Lucide `Check / X`
- 如果点击后会立刻写库或触发高风险动作，业务层应增加二次确认或撤销能力

### React 图标描述变体示例

```tsx
<SwitchPrimitives.Root className="relative h-6 w-12 rounded-full bg-primary p-1">
  <Check className="absolute left-2 top-1/2 size-4 -translate-y-1/2 text-primary-foreground" />
  <X className="absolute right-2 top-1/2 size-4 -translate-y-1/2 text-primary-foreground opacity-0" />
  <SwitchPrimitives.Thumb className="block size-4 rounded-full bg-primary-foreground transition-transform data-[state=checked]:translate-x-6" />
</SwitchPrimitives.Root>
```

## HTML Demo 落地建议

**图标来源**：
- 必须使用 Lucide CDN + `data-lucide`
- 不使用手写内联 SVG
- 生成完成后执行 `lucide.createIcons()`

```html
<script src="https://unpkg.com/lucide@latest"></script>
<label class="switch-wrapper">
  <input type="checkbox" class="switch-input" checked />
  <span class="switch-track size-default">
    <i data-lucide="check" class="switch-icon switch-icon-on"></i>
    <i data-lucide="x" class="switch-icon switch-icon-off"></i>
    <span class="switch-thumb"></span>
  </span>
  <span class="switch-label">自动备份</span>
</label>
<script>lucide.createIcons()</script>
```

### HTML 文字描述变体示例

```html
<label class="switch-wrapper">
  <input type="checkbox" class="switch-input" />
  <span class="switch-track size-compact">
    <span class="switch-text switch-text-on">开</span>
    <span class="switch-text switch-text-off">关</span>
    <span class="switch-thumb"></span>
  </span>
</label>
```

**HTML 结构规则**：
- 统一使用 `input.switch-input + span.switch-track > span.switch-thumb` 结构
- 图标描述变体在轨道内放置 `.switch-icon-on` 和 `.switch-icon-off`
- 文字描述变体在轨道内放置 `.switch-text-on` 和 `.switch-text-off`
- 生成单文件 HTML Demo 时应内联复用上述基础类

## 使用场景

### 1. 设置列表

```tsx
<div className="flex items-center justify-between rounded-lg border border-border p-4">
  <div className="space-y-0.5">
    <Label htmlFor="message-push" className="text-sm font-medium">
      推送通知
    </Label>
    <p className="text-xs text-muted-foreground">接收系统推送消息</p>
  </div>
  <Switch id="message-push" checked />
</div>
```

**规范说明**：
- 主标签使用 `text-sm font-medium`
- 说明文字使用二级文字 `text-xs text-muted-foreground`
- 一行只放一个开关，避免多开关并排造成扫描负担

### 2. 表格中的启停控制

```tsx
<TableCell className="text-right">
  <Switch
    aria-label="启用此规则"
    size="compact"
  />
</TableCell>
```

**规范说明**：
- 表格内统一使用紧凑尺寸
- 没有可见标签时必须补 `aria-label`
- 高风险开关建议点击后补二次确认，不要直接落库

### 3. 批量配置卡片

```tsx
<div className="flex items-center gap-3 rounded-lg border border-border p-3">
  <Switch checked />
  <div>
    <div className="text-sm font-medium">自动分配</div>
    <div className="text-xs text-muted-foreground">
      开启后新任务自动匹配负责人
    </div>
  </div>
</div>
```

## 交互与无障碍

| 按键 | 行为 |
|------|------|
| `Tab` | 聚焦到 Switch |
| `Space` | 切换开 / 关 |
| `Enter` | 仅在业务封装层明确接管时作为补充触发 |

**无障碍要求**：
- 必须绑定可见 `Label`，或补充 `aria-label`
- 使用 `disabled` 表达禁用，不只做样式置灰
- 开关若会立即生效，旁边要有足够明确的功能说明
- 只表达二元状态，不承载三态或多态逻辑

---

## 使用建议

| 场景 | 推荐 | 不推荐 |
|------|------|--------|
| 即时启停某个功能 | Switch | Checkbox |
| 提交表单后才统一保存 | Checkbox | Switch |
| 需要在多个选项中多选 | Checkbox | Switch |
| 高风险行为（删除、清空、批量发布） | 确认弹窗 / 按钮 | 直接用 Switch |

## Checklist

生成 Switch 规范或代码时检查：

- [ ] 使用清晰的 `on / off` 二元语义，不承载多状态逻辑
- [ ] 默认尺寸为 `48 × 24`，紧凑尺寸为 `36 × 18`
- [ ] 常规尺寸使用 `16px` 圆点，紧凑尺寸使用 `12px` 圆点
- [ ] 图标描述变体占位尺寸与对应尺寸档一致：常规 `16px`，紧凑 `12px`
- [ ] `on` 可用态使用 `bg-primary`
- [ ] `on` hover 使用 `bg-primary-hover`
- [ ] `off` 可用态使用 `bg-tertiary-foreground`
- [ ] `off` hover 只能增强中性色，不可切成开启态主色
- [ ] 禁用态不可只依赖 `opacity-50`
- [ ] 文字描述变体默认使用 `开 / 关`
- [ ] 图标描述变体默认使用 Lucide `Check / X` 或 HTML `check / x`
- [ ] 描述内容始终位于 thumb 对侧空槽
- [ ] 有外部标签时，优先使用 `描述=无`
- [ ] 表格或无可见文案场景补齐 `aria-label`
- [ ] shadcn 默认尺寸必须覆写，不可直接沿用默认 Switch
- [ ] HTML Demo 使用模板内置 `.switch-*` 类，不手写额外 SVG
- [ ] 仅在“即时生效”场景使用 Switch
