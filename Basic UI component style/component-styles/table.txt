# Table 表格

> 包含：数据表格、可编辑表格、带操作列表格。当前 table 规范只允许在仓库现有组件与 token 上组合，不为 table 单独发明新控件、新颜色或私有状态语义。

## 组件定位

- Table 是**组合型组件**，不是单一原子组件
- Table 自身只定义：行列结构、密度、信息层级、行状态、容器关系
- 只要表格里出现 `Checkbox / Tag / Switch / Input / Select / Pagination / Button / DropdownMenu`，都必须回到各自现有组件规范，不在 table 中另起一套视觉语言
- 当前规范的目标不是“把所有子元素画成看起来差不多”，而是“把现有组件按 table 场景重新编排”

## 组合原则

- 如果仓库中已经存在可直接复用的子组件，就优先继承该组件的尺寸、状态、图标、圆角和 token，不在 table 内再做“差不多”的平替
- 如果 table 某个局部只是组合关系，而不是新的原子组件，就用本仓库已有组件组合实现，不额外抽离新的 table-only 组件
- 颜色只允许来自现有 token：表格行分隔走 `border-border`，表内交互控件外框走 `border-input / border-input-disabled`，状态色走 `primary / destructive / brand-*`

## 组件拆解

Table 组件拆成以下子模块：

| 模块 | 组件命名 | 变体轴 |
|------|----------|-------|
| 表头文本 | `元素/表头/文本` | `尺寸 / 对齐 / 分割线 / 排序 / 筛选 / 搜索` |
| 表头操作 | `元素/表头/可操作` | `尺寸 / 可操作项` |
| 文本列 | `列/文本` | `尺寸 / 对齐 / 分割线 / 固定` |
| 链接列 | `列/链接` | `尺寸 / 对齐 / 分割线 / 固定` |
| 文本图标列 | `列/文本+图标`、`元素/单元格/图标+文本` | `尺寸 / 状态` |
| 标签列 | `列/标签`、`元素/单元格/标签` | `尺寸 / 对齐 / 分割线 / 固定 / 标签数量` |
| 开关列 | `列/开关`、`元素/单元格/开关` | `尺寸 / 对齐 / 分割线 / 固定 / 状态` |
| 状态列 | `列/状态` | `尺寸 / 对齐 / 分割线 / 固定` |
| 表单列 | `元素/单元格/表单` | `尺寸 / 状态` |
| 操作列 | `列/操作`、`元素/单元格/操作` | `尺寸 / 对齐 / 分割线 / 固定 / 更多 / 操作数量` |
| 复选列 | `列/复选`、`元素/单元格/复选` | `尺寸 / 状态` |
| 单选列 | `列/单选`、`元素/单元格/单选` | `尺寸 / 状态` |
| 可展开列 | `列/可展开`、`元素/单元格/可展开` | `尺寸 / 状态 / 展开` |
| 可拖拽列 | `列/可拖拽`、`元素/单元格/可拖拽` | `尺寸 / 状态` |

这意味着：

- table 规范不能只覆盖“文本列 + 状态列 + 操作列”三种基础场景
- 表头上的排序、筛选、搜索、列设置都应视为已定义的 table 子模块，不是页面级随手拼的图标按钮
- 复选、单选、展开、拖拽列在 table 体系内已经有独立尺寸与状态位，代码侧仍优先复用现有原子组件，但规范文案要承认它们是 table 官方组成部分

## 复用边界

| 表格区域 | 优先复用 | Table 只补什么 | 不要做什么 |
|---------|---------|---------------|-----------|
| 选择列 | [checkbox.txt](checkbox.txt) | 列宽、对齐、批量选择关系 | 重新画一套 table 专用 checkbox |
| 状态列 | [tag.txt](tag.txt) | 列内摆放和状态映射 | 临时发明新的 Badge 色板 |
| 行内启停 | [switch.txt](switch.txt) | 紧凑摆位、无文案 `aria-label` | 为表格单独改开关尺寸/颜色 |
| 工具栏筛选 | [input.txt](input.txt)、[select.txt](select.txt)、[button.txt](button.txt) | 与表格的间距和组合关系 | 把筛选条写成另一套表单控件 |
| 操作列 | [button.txt](button.txt) + DropdownMenu | 左对齐、更多操作分组 | 给操作列单独发明 icon button 皮肤 |
| 页尾翻页 | [pagination.txt](pagination.txt) | 与表格容器的衔接关系 | 只写一排页码按钮冒充分页规范 |

## Token 边界

- 表格分割线、外层容器描边统一使用 `border-border`
- 表头弱化底、行 hover 弱化底统一使用 `bg-muted/50`
- 行选中背景统一使用 `bg-muted`
- `bg-field-disabled` 只用于表内**禁用控件**，不要拿来做整行 hover、选中或斑马纹
- `border-input` / `border-input-disabled` 只属于 `Checkbox / Input / Select / Switch / Button` 这类交互控件，不属于表格行分隔线
- 不要在 table 文档里新造 `gray-100 / gray-200 / 固定浅色值` 这类脱离 token 的局部色名；直接引用现有语义 token 或品牌扩展 token

## 动效补充

Table 动效统一继承 [motion.txt](motion.txt)；本组件只补充以下差异：

- 数据行 hover 背景过渡默认使用 `motion-fast`（`150ms`）
- 表格不默认做整表逐行排队入场，避免影响扫读效率
- 新增 / 删除 / 修改行时，优先用局部语义反馈解释变化：
  - 新增：`opacity + 轻微位移` 进入
  - 删除：更快的 `opacity` 离场，可按需配合高度收起
  - 修改：单元格或整行短暂高亮，不用闪烁
- 自动刷新场景里，未变化行保持稳定，不因刷新统一重放入场动画

## 基础样式

```tsx
import {
  Table,
  TableBody,
  TableCell,
  TableHead,
  TableHeader,
  TableRow,
} from "@/components/ui/table"

<Table>
  <TableHeader>
    <TableRow>
      <TableHead>名称</TableHead>
      <TableHead>状态</TableHead>
      <TableHead>创建时间</TableHead>
      <TableHead className="text-left">操作</TableHead>
    </TableRow>
  </TableHeader>
  <TableBody>
    {data.map((item) => (
      <TableRow key={item.id}>
        <TableCell className="font-medium">{item.name}</TableCell>
        <TableCell>{item.status}</TableCell>
        <TableCell>{item.createdAt}</TableCell>
        <TableCell className="text-left">...</TableCell>
      </TableRow>
    ))}
  </TableBody>
</Table>
```

## 尺寸规范

| 元素 | 尺寸 | 类名 | 说明 |
|------|------|------|------|
| 紧凑行高 | 32px | `h-8` | 紧凑密度 |
| 常规行高 | 40px | `h-10` | 默认列表密度 |
| 宽松行高 | 48px | `h-12` | 宽松密度 |
| 单元格内边距 | 16px | `px-4` | 左右内边距 |
| 选择/单选/展开/拖拽列宽 | 32 / 40 / 48px | `w-8 / w-10 / w-12` | 跟随三档尺寸联动 |

```tsx
// 紧凑表格
<Table className="[&_td]:h-8 [&_th]:h-8">
  ...
</Table>
```

```tsx
// 常规表格（默认）
<Table className="[&_td]:h-10 [&_th]:h-10">
  ...
</Table>
```

```tsx
// 宽松表格
<Table className="[&_td]:h-12 [&_th]:h-12">
  ...
</Table>
```

**尺寸补充**：

- 当前主密度体系是 `32 / 40 / 48`
- 个别文本、链接、标签单元格出现 `54px` 高示例，说明某些宽松态单元格允许因内容结构产生更高展示块；这不应改写 table 的主密度基线
- 可展开行、嵌套表、附加说明区会突破基础行高，属于结构扩展，不属于基础尺寸轴

## 表头样式

```tsx
// 表头默认样式
<TableHead className="h-10 px-4 text-left align-middle font-medium text-tertiary-foreground [&:has([role=checkbox])]:pr-0">
  列名
</TableHead>
```

**表头规范**：
- 字号：14px (`text-sm`，默认)
- 字重：`font-medium`
- 颜色：三级文字 `text-tertiary-foreground`
- 背景：`bg-muted/50`（可选，用于视觉分隔，属于轻量弱化表面）
- 表头轴包括 `排序 / 筛选 / 搜索 / 分割线 / 对齐`，代码侧要把它视为表头规范的一部分，而不是页面里自由添加的小图标

### 表头能力边界

| 能力 | 规范 |
|------|------|
| 排序 | 复用现有排序图标语义，状态为 `默认 / 升序 / 降序 / 悬停` |
| 筛选 | 复用现有筛选图标与弹层，不单独为 table 重画图标 |
| 搜索 | 复用现有搜索图标与搜索弹层，不把搜索输入直接塞进表头文案轨道 |
| 列设置 | 复用表头可操作单元和下拉/弹层体系 |
| 分割线 | 属于表头变体轴，不是靠页面额外补一根 border 去模拟 |

### 可排序表头

```tsx
import { ArrowUpDown, ArrowUp, ArrowDown } from "lucide-react"
import { Button } from "@/components/ui/button"

<TableHead>
  <Button 
    variant="ghost" 
    className="-ml-2 h-8 px-2 text-muted-foreground hover:bg-transparent hover:text-primary"
    onClick={() => handleSort("name")}
  >
    名称
    {sortColumn === "name" ? (
      sortDirection === "asc" ? (
        <ArrowUp className="ml-2 size-4" />
      ) : (
        <ArrowDown className="ml-2 size-4" />
      )
    ) : (
      <ArrowUpDown className="ml-2 size-4" />
    )}
  </Button>
</TableHead>
```

**排序图标规范**：
- 未排序：中性排序图标
- 升序：向上排序图标
- 降序：向下排序图标
- 图标尺寸：16px (`size-4`)
- 默认颜色使用二级文字 `text-muted-foreground`；排序状态变化时再通过方向和强调态表达，不要默认上主色
- 默认保持表头文字样式，hover 主要作用在排序图标；不要把整段表头文案做成按钮主色态

### 表头图标操作位

- 表头中的筛选、搜索、列设置图标位跟随 table 尺寸轴联动：
  - 紧凑：`32px`
  - 常规：`40px`
  - 宽松：`48px`
- 图标位里的实际图标默认统一使用 `16px`（`size-4`）；不要因为壳体是 `32 / 40 / 48px` 就把图标一并放大
- 默认颜色统一使用二级文字 `text-muted-foreground`
- 只有 hover / active / open 等状态才做颜色变化；不要让表头操作位在静态态就带主色倾向
- 默认不铺底色；若需要 hover 反馈，优先使用透明背景上的文字色变化或极轻量反馈
- 它们是 table 内部操作位，不要退化成按钮尺寸体系与表头脱节的普通工具栏按钮
- React 中优先继续复用 `Button variant="ghost"` 或项目 icon button；HTML Demo 中继续复用 `.btn btn-ghost btn-icon`

## 数据行样式

```tsx
// 数据行默认样式
<TableRow className="border-b transition-colors hover:bg-muted/50 data-[state=selected]:bg-muted">
  ...
</TableRow>
```

**数据行规范**：
- 分隔线：`border-b border-border`
- 悬停：`hover:bg-muted/50`，属于轻量弱化反馈
- 选中：`data-[state=selected]:bg-muted`，属于明确可见的弱化实底
- 行 hover 与行选中优先保持真实交互，不建议在 demo 中额外摆一套静态状态样本
- 行选中应与选择列 `Checkbox` 联动，而不是单独造一层平行状态
- 选中态只保留整行底色差异，不额外添加左侧色条、强调边线或其他新标记

### 行选择

```tsx
import { Checkbox } from "@/components/ui/checkbox"

<Table>
  <TableHeader>
    <TableRow>
      <TableHead className="w-[50px]">
        <Checkbox
          checked={selectedRows.length === data.length}
          onCheckedChange={(checked) => {
            setSelectedRows(checked ? data.map(d => d.id) : [])
          }}
        />
      </TableHead>
      <TableHead>名称</TableHead>
      ...
    </TableRow>
  </TableHeader>
  <TableBody>
    {data.map((item) => (
      <TableRow key={item.id} data-state={selectedRows.includes(item.id) ? "selected" : undefined}>
        <TableCell>
          <Checkbox
            checked={selectedRows.includes(item.id)}
            onCheckedChange={(checked) => {/* ... */}}
          />
        </TableCell>
        <TableCell>{item.name}</TableCell>
        ...
      </TableRow>
    ))}
  </TableBody>
</Table>
```

**行选择规范**：
- 复选框列宽跟随密度联动：紧凑 `32px`、常规 `40px`、宽松 `48px`
- 选中行背景：`bg-muted`
- 选择列本身不重新定义 Checkbox 视觉，直接复用 [checkbox.txt](checkbox.txt)；表格里默认走纯方框或紧凑场景，不额外补标签文本
- 全选列必须支持 `indeterminate`，不能用两个独立视觉态冒充半选
- 没有可见文案时必须补 `aria-label`

### 单选、展开、拖拽列

- `单选列` 直接复用 [radio.txt](radio.txt) 的原子能力，但列宽、居中方式和行态跟随 table
- `可展开列` 复用现有图标体系与展开状态，不单独设计另一套 caret
- `可拖拽列` 复用现有拖拽图标与 hover 态，只把它约束在 table 列宽和居中规则里
- 这三类列都属于 table 已定义子模块，文档里不能再把它们归类为“页面自由扩展”

## 单元格内容样式

### 主要字段

```tsx
// 主要字段（如名称）加粗
<TableCell className="font-medium">{item.name}</TableCell>
```

### 状态标签

```tsx
import { Badge } from "@/components/ui/badge"

<TableCell>
  <Badge variant={item.status === "active" ? "default" : "secondary"}>
    {item.status === "active" ? "运行中" : "已停止"}
  </Badge>
</TableCell>
```

状态列优先复用 [tag.txt](tag.txt) 中的 `solid` Tag 规范。若项目暂时仍使用 `Badge` 原语，也要保持与 Tag 一致的颜色和高度。

| 状态 | 推荐样式 | 颜色 |
|------|----------|------|
| 成功/运行中 | `solid success` | 绿色 |
| 待处理/草稿 | `solid neutral` | 灰色 |
| 警告 | `solid warning` | 橙色 |
| 失败/错误 | `solid danger` | 红色 |

**补充规则**：
- Table 不单独定义状态色板；直接吃 Tag 现有语义映射
- 若已有业务层 `Tag` 组件，优先直接复用；若只有 `Badge` 原语，则用 class 约束成 `22px` 高的 Tag 结构
- 不要把状态列退化成一段裸文字 + 随手写背景色

### 时间字段

```tsx
<TableCell className="text-tertiary-foreground">{item.createdAt}</TableCell>
```

### 操作列

```tsx
import { MoreHorizontal, Pencil, Trash2, Copy } from "lucide-react"
import { Button } from "@/components/ui/button"
import {
  DropdownMenu,
  DropdownMenuContent,
  DropdownMenuItem,
  DropdownMenuSeparator,
  DropdownMenuTrigger,
} from "@/components/ui/dropdown-menu"

<TableCell className="text-left">
  <DropdownMenu>
    <DropdownMenuTrigger asChild>
      <Button variant="ghost" className="size-8 p-0">
        <span className="sr-only">打开菜单</span>
        <MoreHorizontal className="size-4" />
      </Button>
    </DropdownMenuTrigger>
    <DropdownMenuContent align="start">
      <DropdownMenuItem>
        <Pencil className="mr-2 size-4" />
        编辑
      </DropdownMenuItem>
      <DropdownMenuItem>
        <Copy className="mr-2 size-4" />
        复制
      </DropdownMenuItem>
      <DropdownMenuSeparator />
      <DropdownMenuItem>
        <Trash2 className="mr-2 size-4" />
        删除
      </DropdownMenuItem>
    </DropdownMenuContent>
  </DropdownMenu>
</TableCell>
```

**操作列规范**：
- 对齐：`text-left`
- 触发按钮：`size-8 p-0` + `MoreHorizontal` 图标
- 菜单对齐：`align="start"`
- 菜单项图标：`mr-2 size-4`
- 操作列按钮与菜单继续复用 Button / DropdownMenu 规范，不再单独定义 table 专属按钮视觉
- 行内编辑、删除、复制、更多等操作图标默认统一使用 `16px`（`size-4`），避免按钮壳体与图标一起变大
- 操作列存在 `更多=on/off` 与 `操作数量=1 / 2 / 3 / 4 / 4+` 轴
- 代码建议同步遵守这条收口：
  - `1~3` 个高频操作可直接平铺
  - `4` 个操作开始评估收纳
  - `4+` 默认进入“更多”菜单，不继续横向拉长操作列

## 结构扩展场景

当前规范将这些场景定义为“标准扩展”，不是特殊 case：

- 多选
- 单选
- 可搜索
- 可筛选
- 列设置
- 不同尺寸
- 带边框
- 可拖拽
- 可展开
- 嵌套表
- 固定列表头和列尾

**文档约束**：

- 这些场景优先通过现有 table 子模块组合实现
- 不为每个场景单独发明新的列表骨架
- 如果业务页面只命中其中一个能力，例如“仅列设置”或“仅可搜索”，也要继续沿用 table 组件页已有子结构

## HTML Demo 落地规范

### 结构基线

```html
<div class="table-shell">
  <table class="table">
    <thead class="table-head">
      <tr class="table-row">
        <th class="table-head-cell table-check-col">
          <input type="checkbox" class="checkbox" aria-label="全选">
        </th>
        <th class="table-head-cell">名称</th>
        <th class="table-head-cell">状态</th>
        <th class="table-head-cell">创建时间</th>
        <th class="table-head-cell table-cell--actions">操作</th>
      </tr>
    </thead>
    <tbody>
      <tr class="table-row table-row--selected">
        <td class="table-cell table-check-col">
          <input type="checkbox" class="checkbox" checked aria-label="选择项目 Alpha">
        </td>
        <td class="table-cell table-cell--primary">项目 Alpha</td>
        <td class="table-cell">
          <span class="tag tag--solid tag--success">运行中</span>
        </td>
        <td class="table-cell table-cell--muted">2024-01-15</td>
        <td class="table-cell table-cell--actions">
          <div class="table-actions">
            <button class="btn btn-ghost btn-icon" type="button" aria-label="编辑">
              <i data-lucide="pencil"></i>
            </button>
            <button class="btn btn-ghost btn-icon" type="button" aria-label="更多操作">
              <i data-lucide="more-horizontal"></i>
            </button>
          </div>
        </td>
      </tr>
    </tbody>
  </table>
</div>
```

### HTML 复用规则

- 外层优先复用模板中的 `.table-shell + .table`
- 表头、行、单元格优先使用 `.table-head / .table-head-cell / .table-row / .table-cell`
- 选择列复用现有 `.checkbox`
- 状态列复用现有 `.tag`
- 操作列按钮复用 `.btn btn-ghost btn-icon`
- 表头图标位、行内操作位、分页箭头里的图标默认继续使用 `16px`
- 表格下方分页复用 `.pagination-bar / .pagination-track / .pagination-page / .pagination-arrow / .pagination-jump`
- 不要在 HTML Demo 里再手写一套 table 专用 checkbox、table 专用 badge、table 专用分页按钮

## 表格容器

```tsx
// 在 Card 中使用表格
<Card glass>
  <CardHeader>
    <CardTitle>用户列表</CardTitle>
  </CardHeader>
  <CardContent className="p-0">
    <Table>...</Table>
  </CardContent>
</Card>

// 带边框的独立表格
<div className="rounded-md border">
  <Table>...</Table>
</div>
```

**容器规范**：
- Card 内表格：CardContent 加 `p-0` 让表格撑满
- 独立表格：外层 `rounded-md border border-border`

## Checklist

生成表格时检查：

- [ ] 使用 shadcn Table 组件
- [ ] Table 只负责布局与行状态，子控件继续复用现有组件规范
- [ ] 表头颜色 `text-tertiary-foreground` + `font-medium`
- [ ] 数据行有 hover 效果
- [ ] 表格分割线使用 `border-border`，不要误用 `border-input`
- [ ] 主要字段 `font-medium`
- [ ] 时间字段 `text-tertiary-foreground`
- [ ] 状态列优先使用 Tag 规范；若暂用 Badge，也已对齐 `tag.txt`
- [ ] 操作列左对齐，使用 DropdownMenu
- [ ] 选择列复用 Checkbox，并支持全选/半选逻辑
- [ ] 单选 / 展开 / 拖拽列如出现，已按 table 子模块处理，而不是页面私有组件
- [ ] 表头中的排序 / 筛选 / 搜索 / 列设置按 table 子模块落地
- [ ] 空状态有图标和提示文字
- [ ] 分页在表格下方
- [ ] 每页条数 / 跳页输入已分别回看 Select / Input 规范
- [ ] Card 内表格 CardContent 加 `p-0`
