# 终端安全管理系统框架模板
## Terminal Security Frame Template

本目录是“终端安全管理系统 / 终端”类产品专用的固定框架模板。它适用于顶部不展示一级导航、通过顶部中心切换选择本级中心或区域子集、左侧使用 184px 窄导航的终端安全管理类页面。

该模板不是通用平台框架的替代品，而是主线平台框架中的特定产品变体。

## 0. 调用条件

只有当用户明确提出以下需求时，AI 才能调用本模板：

```text
基于终端安全管理系统框架设计页面
基于终端框架设计页面
终端安全管理系统页面
终端产品页面
使用终端安全管理系统顶部导航
使用本级中心 / 区域中心切换
```

其他后台页面默认仍然调用：

```text
06-vue-code/templates/platform-frame/
03-interaction/platform-frame.md
```

禁止在用户未明确指定“终端安全管理系统 / 终端”时，默认使用本模板。

## 1. 固定结构

```text
终端固定框架
├── 56px 顶部导航
│   ├── 终端安全管理系统 Logo
│   ├── 本级中心 / 区域中心切换
│   └── 右侧功能区
│       ├── 全网安全大脑订阅状态
│       ├── 可视化大屏
│       ├── 设置 / 信息 / 权限 / 组织 / 邮件
│       └── 用户下拉
└── 页面主体：左右结构
    ├── 左侧：184px / 56px 窄导航
    └── 右侧：上下结构
        ├── 48px 基础页头
        └── 业务内容区
```

## 2. 核心固定规则

| 区域 | 固定规则 |
|---|---|
| 顶部导航 | 56px 高；不展示一级导航；Logo 后为中心切换 |
| 中心切换 | icon、文字、下箭头为一体；hover 只变白，不增加底色；hover 直接展开下拉列表 |
| 可视化大屏 | 点击后从顶部导航下方展开，`top: 56px`，横向撑满屏幕 |
| 左侧导航 | 展开态固定 184px；收起态固定 56px；与本脑窄导航规则保持一致 |
| 页面结构 | 顶部导航下方是左右结构；左侧为菜单；右侧为上下结构：页头 + 内容区 |
| 基础页头 | 位于右侧内容区上方，不横跨左侧导航；高度 48px |
| 最小宽度 | 页面最小宽度 1280px，与本脑框架保持一致 |

## 3. 允许替换

```text
Logo 图片

右侧功能区文案和用户名称
订阅服务数据

页头标题与操作按钮
```

```text
顶部导航高度和结构
中心切换交互规则
可视化大屏抽屉展开位置和横向撑满规则
184px / 56px 左侧窄导航宽度
右侧页头所在层级
48px 基础页头高度
页面最小宽度 1280px
```

## 6. AI 使用要求

生成终端类页面时，必须直接复制本模板，然后只替换：

```text
左侧菜单数据
页头标题和操作按钮
.platform-page-content 内部业务内容
```

不要重新按规范拼装框架，避免顶部导航、中心切换、可视化大屏抽屉、184px 窄导航和右侧页头层级出现偏差。

生成非终端类页面时，必须继续使用主线通用框架：

```text
06-vue-code/templates/platform-frame/
03-interaction/platform-frame.md
```
