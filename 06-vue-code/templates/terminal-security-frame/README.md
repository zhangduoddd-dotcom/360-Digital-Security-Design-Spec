# 终端框架 HTML 母版调用规则

本目录用于存放“终端安全管理系统 / 终端”类产品的固定 HTML 母版。

核心原则：终端框架不是一组可重新推导的文字规范，而是一个必须原样套用的 HTML 母版。

当用户明确说“基于终端框架 / 基于终端安全管理系统框架”生成页面时，AI 必须直接使用本目录中的 HTML 母版作为唯一结构来源，只替换业务内容，不允许重新拼装框架。

## 0. 调用条件

只有当用户明确提出以下需求时，AI 才能调用本模板：

```text
基于终端安全管理系统框架设计页面
基于终端框架设计页面
终端安全管理系统页面
终端产品页面
使用终端框架
使用本级中心 / 区域中心切换
```

其他后台页面默认仍然调用：

```text
06-vue-code/templates/platform-frame/
03-interaction/platform-frame.md
```

禁止在用户未明确指定“终端安全管理系统 / 终端”时，默认使用本模板。

## 1. 唯一结构来源

```text
source.html
```

`source.html` 是终端框架的唯一母版来源。AI 生成页面时不得根据 README、INDEX 或其他文字规范重新推导框架结构。

如果 `source.html` 与文字说明存在差异，以 `source.html` 为准。

## 2. 必须原样保留

```text
56px 顶部导航
Logo 区
本级中心 / 区域中心切换
右侧功能区
订阅状态 Popover
可视化大屏横向抽屉
184px / 56px 左侧窄导航
左侧菜单展开 / 收起交互
右侧 48px 基础页头
右侧业务内容区
页面最小宽度与自适应规则
字体渲染规则
所有框架内置 hover / active / disabled / open 状态
```

以上区域禁止重写、禁止重新设计、禁止重新按规则拼装。

## 3. 允许替换

```text
Logo 图片或 Logo 文案
中心切换选项
右侧功能区文案和用户名称
订阅服务数据
可视化大屏入口文案和图片
左侧菜单业务文案和路由
页头标题与页头操作按钮
.platform-page-content 内部业务内容
mock 数据
iconfont 映射
```

## 4. 禁止替换

```text
顶部导航高度和结构
中心切换交互规则
可视化大屏抽屉展开位置和横向撑满规则
184px / 56px 左侧窄导航宽度
右侧页头所在层级
48px 基础页头高度
页面最小宽度 1280px
字体渲染规则
框架 CSS 类名和 JS 交互逻辑
```

## 5. AI 使用方式

生成终端类页面时，按以下顺序执行：

```text
1. 读取 source.html
2. 完整复制 source.html 作为页面底座
3. 只在允许替换区域填充业务内容
4. 保留所有框架结构、样式、脚本和交互
5. 输出可直接打开预览的 HTML
```

不要根据文字描述重新写顶部导航、中心切换、可视化大屏抽屉或左侧菜单；不要把终端框架拆成新的结构；不要将终端框架与通用 platform-frame 混用。

## 6. 与主线默认框架的关系

```text
默认后台页面：使用 06-vue-code/templates/platform-frame/
明确终端场景：使用 06-vue-code/templates/terminal-security-frame/source.html
```

本模板是主线中的特定产品 HTML 母版，不替代默认通用框架。
