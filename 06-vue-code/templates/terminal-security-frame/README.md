# 单层导航框架 HTML 母版调用规则

本目录用于存放“单层导航框架”的固定 HTML 母版。

核心原则：单层导航框架不是一组可重新推导的文字规范，而是一个必须原样套用的 HTML 母版。

当用户明确说“基于单层导航框架 / 基于单层顶部导航 / 单层导航页面”生成页面时，AI 必须直接使用本目录中的 HTML 母版作为唯一结构来源，只替换业务内容，不允许重新拼装框架。

当用户明确说“基于本套 GitHub 生成页面 / 按本仓库规范生成页面 / 使用本套设计规范生成页面”，且没有明确要求自定义导航框架，也没有明确要求基于双层导航框架时，也必须使用本目录中的单层导航框架母版。

> 说明：当前目录名仍为 `terminal-security-frame`，但调用语义已更新为“单层导航框架”。AI 不应再把本模板理解为终端业务专属框架。

## 0. 调用条件

出现以下任一场景时，AI 必须调用本模板：

```text
基于单层导航框架设计页面
基于单层顶部导航设计页面
单层导航页面
单层顶部导航页面
使用单层导航框架
基于本套 GitHub 生成页面，且未明确指定双层导航框架
基于本仓库规范生成页面，且未明确指定双层导航框架
使用本套设计规范生成页面，且未明确指定双层导航框架
```

只有用户明确提出以下需求时，才不调用本模板：

```text
明确要求自定义导航框架
明确要求基于双层导航框架
明确要求基于双层顶部导航
明确要求使用 double-top-navigation-frame
```

此时应根据用户要求调用：

```text
06-vue-code/templates/double-top-navigation-frame/source.html
```

## 1. 唯一结构来源

```text
index.html
```

`index.html` 是单层导航框架的唯一母版来源。AI 生成页面时不得根据 README、INDEX 或其他文字规范重新推导框架结构。

如果 `index.html` 与文字说明存在差异，以 `index.html` 为准。

## 2. 必须原样保留

```text
单层顶部导航
Logo 区
组织 / 中心切换
右侧功能区
订阅状态 Popover
可视化大屏横向抽屉
左侧导航展开 / 收起交互
右侧基础页头
右侧业务内容区
页面最小宽度与自适应规则
字体渲染规则
所有框架内置 hover / active / disabled / open 状态
```

以上区域禁止重写、禁止重新设计、禁止重新按规则拼装。

## 3. 允许替换

```text
Logo 图片或 Logo 文案
组织 / 中心切换选项
右侧功能区文案和用户名称
订阅服务数据
可视化大屏入口文案和图片
左侧菜单业务文案和路由
页头标题与页头操作按钮
.platform-page-content 内部业务内容
mock 数据
iconfont 映射
```

## 4. 禁止替换

```text
顶部导航高度和结构
组织 / 中心切换交互规则
可视化大屏抽屉展开位置和横向撑满规则
左侧导航宽度、颜色、状态和展开收起交互
右侧页头所在层级
基础页头高度
页面最小宽度
字体渲染规则
框架 CSS 类名和 JS 交互逻辑
```

## 5. AI 使用方式

生成单层导航类页面时，按以下顺序执行：

```text
1. 读取 index.html
2. 完整复制 index.html 作为页面底座
3. 只在允许替换区域填充业务内容
4. 保留所有框架结构、样式、脚本和交互
5. 输出可直接打开预览的 HTML
```

不要根据文字描述重新写顶部导航、组织切换、可视化大屏抽屉或左侧菜单；不要把单层导航框架拆成新的结构；不要将单层导航框架与通用 platform-frame 混用。

## 6. 与主线默认框架的关系

```text
默认基于本套 GitHub 生成页面：使用 06-vue-code/templates/terminal-security-frame/index.html
明确单层导航场景：使用 06-vue-code/templates/terminal-security-frame/index.html
明确双层导航场景：使用 06-vue-code/templates/double-top-navigation-frame/source.html
```

本模板是主线中的默认 HTML 母版。除非用户明确指定双层导航框架或自定义导航框架，否则基于本套 GitHub 的页面生成都应优先使用本模板。
