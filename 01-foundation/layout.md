# 布局与间距规范
## Layout and Spacing

Keywords: layout, spacing, grid, responsive, sidebar, backend

本文定义后台页面的布局骨架、响应式策略、栅格系统和间距规则。

## 1. 布局基准

| 项目 | 标准 |
|---|---|
| 默认设计画板 | 1440px |
| 主流适配宽度 | 1920px、1440px、1366px、1280px |
| 最小原子单位 | 4px |
| 间距计算方式 | 间距 = x × 4px |
| 栅格体系 | 12 栅格 |
| 页面最小宽度 | 768px |

## 2. 页面四层框架

| 层级 | 内容 | 说明 |
|---|---|---|
| 背景区域 | 页面底色、背景纹理、全局背景 | 提供环境氛围 |
| 内容层 | 表格、列表、卡片、图表、表单、工作区 | 用户完成任务的主要区域 |
| 全局控制层 | 顶部导航、侧边导航、全局搜索、通知、账户入口 | 全局跳转和系统级操作 |
| 内容弹层 | 弹窗、抽屉、气泡确认框、浮层详情 | 临时任务、确认、说明和局部编辑 |

## 3. 响应式与侧边栏

- 小于 768px：页面不再继续压缩，出现横向滚动条。
- 768px 到 991px：侧边栏自动收起为图标态。
- 992px 到 1199px：侧边栏可点击收起。
- 大于等于 1200px：常规展开布局。
- 展开态侧边栏建议 184px，收起态建议 56px。

## 4. 间距建议

| 场景 | 建议 |
|---|---|
| 页面边距 | 24px |
| 常规卡片内边距 | 24px |
| 高密度列表卡片内边距 | 16px |
| 列表页卡片间距 | 12px / 16px |
| 标题与内容 | 8px / 12px / 16px |
| 操作按钮之间 | 8px |
| 模块分组之间 | 16px / 24px |

## 5. 栅格与卡片

Dashboard 可使用 1 列、2 列、3 列、4 列等栅格。卡片不能无限缩小，图表卡片必须有最小宽度。页面宽度不足时，通过换行、堆叠、横向滚动处理。
