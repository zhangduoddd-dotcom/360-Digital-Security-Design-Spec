# 基础规范总览
## Foundation Overview

Keywords: foundation, principles, backend design, consistency, enterprise saas

本文定义后台设计规范的基础原则。所有页面、组件、AI 生图和 Vue 代码生成都必须遵循这些原则。

## 1. 规范目标

本规范用于企业级 SaaS / B 端管理后台 / AI 原生协作平台，目标是形成一套可直接用于设计、AI 生图、前端开发和验收的界面标准。

## 2. 一致性原则

- 同类页面使用同一布局骨架。
- 同类操作使用同一按钮层级。
- 同类状态使用同一颜色和提示方式。
- 同类表单使用同一标签、校验和帮助信息规则。
- 同类风险操作使用同一弹窗反馈模板。

## 3. 可适配原则

- 设计输出默认以 1440px 画板为基准。
- 适配 1920 / 1440 / 1366 / 1280 等常见宽度。
- 内容区域使用响应式布局。
- 栅格、卡片、表格、图表应根据视窗宽度自适应。
- 表格列过多时使用横向滚动，不强行压缩到不可读。

## 4. 可控性原则

- 页面主任务必须明确。
- 一个操作区域只保留一个最重要的主按钮。
- 高频操作显性化，低频操作合理收纳。
- 复杂任务应拆分为步骤、分组或局部任务。
- loading、empty、error、disabled 状态不能缺失。

## 5. 业务安全性原则

删除、断开、禁用、覆盖、重置、发布、审批驳回等敏感操作必须说明后果并二次确认。

高风险操作模板：

```text
标题：确定 {动作} {对象} 吗？
说明：{动作} 后 {结果}，请谨慎操作。
按钮：[取消] [确认{动作}]
```
