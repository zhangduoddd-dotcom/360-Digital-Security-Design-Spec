# 投影规范
## Shadow Rules

Keywords: shadow, elevation, card shadow, modal shadow, drawer shadow, ai input

本文定义后台产品中的投影层级。投影不是装饰，而是表达层级关系：卡片浮起用一级投影，抽屉 / 弹窗 / 遮罩浮层用二级投影，AI 超级输入框使用专门 hover 阴影。

## 1. 一级投影：卡片与模块浮起

| Token | CSS 值 | 使用场景 |
|---|---|---|
| 一级-向上 | `0px -4px 16px 0px rgba(36,41,51,0.05)` | 顶部浮起卡片、向上投影模块 |
| 一级-向下 | `0px 4px 16px 0px rgba(36,41,51,0.05)` | 常规卡片、Dashboard 模块、白底容器浮起 |
| 一级-向右 | `4px 0px 16px 0px rgba(36,41,51,0.05)` | 左侧卡片、侧栏轻量浮起 |
| 一级-向左 | `-4px 0px 16px 0px rgba(36,41,51,0.05)` | 右侧卡片、右栏轻量浮起 |

## 2. 二级投影：抽屉、弹窗、遮罩浮层

| Token | CSS 值 | 使用场景 |
|---|---|---|
| 二级-向上 | `0px -8px 80px 0px rgba(36,41,51,0.08)` | 底部抽屉、底部浮层 |
| 二级-向下 | `0px 8px 80px 0px rgba(36,41,51,0.08)` | 弹窗、Popover、大型浮层 |
| 二级-向右 | `6px 0px 80px 0px rgba(36,41,51,0.08)` | 左侧抽屉、左侧浮层 |
| 二级-向左 | `-8px 0px 80px 0px rgba(36,41,51,0.08)` | 右侧抽屉、右侧浮层 |

## 3. 通用投影与特殊 hover 投影

| Token | CSS 值 | 使用场景 |
|---|---|---|
| 投影-默认 | `0px 3px 6px -4px rgba(0,0,0,0.12), 0px 6px 16px 0px rgba(0,0,0,0.08), 0px 9px 28px 8px rgba(0,0,0,0.04)` | 标准浮层、卡片、下拉面板默认阴影 |
| 投影-悬停 | `0px 1px 2px -2px rgba(0,0,0,0.16), 0px 3px 6px 0px rgba(0,0,0,0.12), 0px 5px 12px 4px rgba(0,0,0,0.08)` | 卡片 hover、可点击模块 hover |
| 超级框 hover 阴影 | `0px 4px 12px 0px rgba(183,179,255,0.50)` | AI 超级输入框、智能搜索框、AI 主输入区 hover |

## 4. 使用原则

- 卡片浮起优先使用一级投影，不要直接套用二级投影。
- 弹窗、抽屉、遮罩浮层必须明显高于普通卡片，使用二级投影。
- Dashboard 卡片可以使用一级-向下，hover 时可切换为投影-悬停。
- AI 超级输入框、智能搜索框这类核心入口可以使用超级框 hover 阴影，但不要用于普通输入框。
- 表格、表单等高密度内容区域不应滥用强投影，否则会降低阅读效率。

## 5. Vue / HTML 生成要求

- Vue 和 HTML 预览文件中，卡片、弹窗、抽屉、下拉面板的层级必须通过投影区分。
- 不要给所有卡片都使用强投影。
- 表格容器优先保持轻量，不使用大面积强阴影。
- AI 输入入口如果使用特殊阴影，必须只在 hover 或聚焦状态出现。
