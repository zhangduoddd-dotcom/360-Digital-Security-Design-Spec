# 颜色与状态规范
## Color and Status

Keywords: color, status, semantic color, risk level, tag, backend

本文定义后台产品中的主色、中性色、语义色、风险色、状态标签和 AI 渐变色规则。

## 1. 主色

主色为科技绿，推荐 `#00AB7A`。主按钮默认使用 `#00AB7A`，hover 使用 `#1DB887`，active 使用 `#039972`。

## 2. 中性色

| 场景 | 色值 |
|---|---|
| 页面背景 | #F8F9FA |
| 卡片背景 | #FFFFFF |
| hover 背景 | #F2F3F5 |
| 分割线 | #E8EAED |
| 边框 | #DFE1E6 |
| 禁用 / 占位 | #AEB2B8 |
| 辅助文字 | #8A9099 |
| 正文 | #525966 |
| 标题 | #242933 |

## 3. 语义色

| 状态 | 推荐色系 | 典型场景 |
|---|---|---|
| 成功 / 正常 / 安全 | 绿色 | 完成、通过、连接正常、开启 |
| 进行中 / 待处理 / 信息 | 蓝色 | 待处理、审批中、流转中、信息提示 |
| 警告 / 异常 | 橙色 | 轻微异常、预警、不阻断流程 |
| 错误 / 失败 / 阻断 | 红色 | 失败、不可用、严重异常 |
| 未知 / 禁用 / 草稿 | 灰色 | 草稿、停止、未知 |

## 4. 风险等级

致命用深红，高危用红色 / 橙红，中危用橙色，低危用黄色，安全用绿色，未知用灰色。

## 5. 标签与状态点

- 状态必须同时使用文字和颜色表达。
- 表格中多个标签同时出现时，只保留最重要标签为面性标签，其余使用线性标签或状态点。
- 状态点尺寸建议 6px × 6px，与文字间距 4px。
- 状态点必须保留文案，不只展示圆点。

## 6. AI 渐变

AI 渐变只用于智能生成、AI 分析、智能推荐等能力入口。普通提交、保存、删除、筛选、导出等业务按钮禁止使用 AI 渐变。
