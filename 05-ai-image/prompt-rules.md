# Prompt 编写规则
## Prompt Writing Rules

Keywords: prompt rules, ai image, backend ui, page generation

本文用于约束 AI 生图 Prompt 的写法，避免生成结果只追求视觉效果而忽略后台页面的可用性。

## 1. 推荐结构

```text
生成目标
+ 业务场景
+ 页面类型
+ 布局结构
+ 核心模块
+ 组件与状态
+ 视觉风格
+ 交互约束
+ Negative Prompt
```

## 2. 必须说明的信息

页面类型、业务对象、核心任务、布局结构、组件清单、数据密度、视觉风格、禁止项。

## 3. 编写原则

先写业务目标，再写视觉风格。先写页面结构，再写组件细节。必须明确页面类型和禁止项。不要只写“高级、科技、好看”，要写清楚可验证的结构和组件。
