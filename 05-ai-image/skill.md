# AI 生图 Skill
## AI Image Generation Skill

Keywords: ai image, prompt, ui generation, backend, negative prompt

本文用于约束 AI 生成后台 UI 效果图或 Prompt 的读取方式和输出要求。

## 1. 适用范围

适用于生成高保真 UI 效果图、页面视觉方案、AI 生图 Prompt 和 Negative Prompt。不用于生成前端代码。

## 2. 默认读取顺序

```text
SKILL.md
→ INDEX.md
→ 当前页面规范
→ 05-ai-image/prompt-rules.md
→ 05-ai-image/page-prompts.md
→ 05-ai-image/negative-prompts.md
→ 07-checklists/ai-output.md
```

## 3. 输出要求

必须明确页面类型、业务对象、核心任务、页面结构、主要模块、组件、状态和数据密度。必须附带 Negative Prompt。不要把后台页面生成成营销页、海报或概念图。
