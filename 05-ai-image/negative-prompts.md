# Negative Prompt 规范
## Negative Prompt Rules

Keywords: negative prompt, ai image, backend ui, constraints

本文用于约束 AI 生图时禁止出现的方向，避免后台页面生成成营销页、概念图或不可用界面。

## 1. 通用 Negative Prompt

```text
不要生成营销页风格，不要使用大面积插画，不要使用强透视设备外框，不要使用夸张玻璃拟态，不要使用过重阴影，不要使用高饱和大面积渐变，不要文字乱码，不要按钮层级混乱，不要缺少导航结构，不要缺少页面标题，不要缺少关键操作反馈。
```

## 2. 页面专项

列表页不要做成 Dashboard，不要加入大面积图表，不要让查询区比表格更抢眼。表单页不要随机堆叠字段，不要缺少必填标识、错误提示和底部操作区。详情页不要缺少对象摘要和状态标识。工作台不要堆砌无意义图表，不要使用过多炫光背景。
