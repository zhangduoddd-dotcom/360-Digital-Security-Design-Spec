# 页面 Prompt 模板
## Page Prompt Templates

Keywords: page prompt, ui generation, list page, form page, dashboard

本文提供常用后台页面的 AI 生图 Prompt 骨架。使用前应替换业务对象、字段和具体模块。

## 1. 列表页 Prompt

```text
生成一张企业级 B 端后台标准列表页高保真界面，简体中文，16:9，正视角平面 UI。页面用于【业务对象】管理，核心任务是查询、筛选、批量操作、查看状态和进入详情。页面包含顶部导航、左侧导航、页面标题、搜索筛选区、表格操作栏、数据表格和分页。整体采用浅灰背景、白色内容卡片、科技绿主色、中高信息密度、企业级 SaaS 风格。
```

## 2. 表单页 Prompt

```text
生成一张企业级 B 端后台表单页高保真界面，简体中文，16:9，正视角平面 UI。页面用于【创建 / 编辑】【业务对象】，核心任务是录入基础信息、配置参数并提交。页面包含顶部导航、左侧导航、页面标题、表单分组、字段说明、校验提示和底部操作区。
```

## 3. 详情页 Prompt

```text
生成一张企业级 B 端后台详情页高保真界面，简体中文，16:9，正视角平面 UI。页面用于查看【业务对象】详情，核心任务是理解对象状态、查看关键属性、浏览关联记录并执行必要操作。页面包含返回入口、页面标题、状态标签、摘要卡片、基础信息区、关联列表、操作记录和操作区。
```

## 4. 工作台 Prompt

```text
生成一张企业级 B 端后台工作台首页高保真界面，简体中文，16:9，正视角平面 UI。页面用于展示系统状态、关键指标、待办任务、风险概览和快捷入口。页面包含顶部导航、左侧导航、欢迎摘要区、核心指标卡片、待办任务列表、风险概览、趋势图表、快捷入口和最近动态。
```
