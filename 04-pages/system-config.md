# 系统配置页规范
## System Config Page Standard

Keywords: system config, configuration, list page, form page, backend

本文定义后台系统中的通用配置页面。

## 1. 页面类型

系统配置页可能是列表页、表单页、详情页或多级配置页，需要按具体业务选择页面模式。

## 2. 常见结构

```text
页面标题
→ 分类 / 标签 / 左侧树
→ 搜索或配置表单
→ 表格 / 配置项 / 详情区
→ 操作区
```

## 3. 使用规则

配置对象较多时优先使用列表页模式；配置项较少且需要保存时优先使用表单页模式；需要查看单对象完整信息时使用详情页模式；有组织层级或分类树时，可使用左侧树 + 右侧内容结构。

## 4. 代码与预览要求

Vue 代码必须先判断页面模式，再生成对应结构。HTML 预览文件支持当前页面的核心配置操作。
