# 系统配置页规范
## System Config Page Standard

Keywords: system config, configuration, list page, form page, modal, backend, ai readable, html preview

本文定义后台系统中的通用管理配置页面，覆盖组织管理、任务管理、告警中心、告警配置、系统日志、邀请管理、备份恢复、应用管理、网络配置、检测配置、多级配置和配置类弹窗。AI 生成系统配置 HTML Demo 时，应按实际页面模式选择列表、树表、表单、弹窗或组合结构。

## 1. 页面定位

系统配置页属于平台后台中的通用管理配置模板，特点是结构稳定、信息密度中高、操作明确、规则导向强。它偏管理后台，不是数据分析看板。

## 2. 页面模式

| 模式 | 适用场景 | 结构 |
|---|---|---|
| 列表配置 | 告警、日志、任务、应用等对象管理 | 搜索区 + 工具栏 + 表格 + 分页 |
| 树表配置 | 组织、分组、节点、目录管理 | 左侧树 + 右侧表格 / 详情 |
| 表单配置 | 全局参数、策略、规则 | 分组表单 + 保存操作 |
| 弹窗配置 | 轻量新增、编辑、确认 | 弹窗 / 抽屉 + 表单 + 操作区 |
| 混合配置 | 多模块配置中心 | 标签页 / 分组导航 + 对应内容 |

## 3. 通用结构

```text
页面标题 / 页级说明
→ 搜索或分组导航（按模式）
→ 主配置区：表格 / 树表 / 表单 / 卡片
→ 操作区：新建 / 编辑 / 删除 / 保存 / 导入 / 导出
→ 确认弹窗 / Toast / loading / empty / error
```

## 4. 列表配置规则

- 必须包含搜索、清空、表格、分页。
- 工具栏区分主操作和辅助操作。
- 行操作超过 3 个时使用 `更多`。
- 删除、停用、覆盖、恢复等高风险操作必须二次确认。
- 批量操作与勾选状态联动。
- loading、empty、error、success、failure 状态完整。

## 5. 树表配置规则

- 左侧树用于定位对象，右侧展示配置内容。
- 当前选中节点必须高亮。
- 树节点过长时省略并支持 Tooltip。
- 节点数量可右对齐展示。
- 左右分栏宽度稳定。
- 新增、编辑、删除节点必须有反馈，高风险删除需要确认。

## 6. 表单配置规则

- 配置字段必须按业务含义分组。
- 开关、输入框、选择器、上传、文本域等控件状态完整。
- 关键字段必须有说明、单位、范围或格式提示。
- 保存时展示 loading。
- 保存成功 / 失败给出明确反馈。
- 高风险配置保存前必须说明影响范围并二次确认。

## 7. 弹窗与抽屉

- 轻量新增 / 编辑优先使用抽屉或弹窗。
- 弹窗和抽屉必须有明确标题。
- 表单内容较多时使用抽屉，不用小弹窗强塞。
- 关闭前如有未保存内容，必须确认。
- 底部操作区固定，主次按钮层级明确。

## 8. HTML Demo 要求

HTML Demo 必须先判断页面模式，再生成对应结构。根据当前模式至少支持：

- 搜索、清空、分页、排序或筛选。
- 新建 / 编辑表单打开关闭。
- 字段输入、校验、保存 loading。
- 行操作、批量操作、危险操作确认。
- 树节点选择或分组切换。
- empty、error、disabled、success、failure 状态。
- mock 数据和 Toast / Message 反馈。

## 9. AI 生成禁止项

- 禁止不判断页面模式就套用单一结构。
- 禁止把配置页做成 Dashboard。
- 禁止高风险操作没有确认和影响说明。
- 禁止表单配置无分组、无保存反馈。
- 禁止树表配置左侧树不可选或无高亮。
- 禁止 HTML Demo 只有静态展示，不能操作或反馈。

## 10. 验收清单

| 检查项 | 要求 |
|---|---|
| 页面模式 | 列表、树表、表单、弹窗或混合模式明确 |
| 主结构 | 搜索 / 树 / 表格 / 表单与当前模式匹配 |
| 操作完整 | 新建、编辑、删除、保存、导入、导出按需具备 |
| 状态反馈 | loading、empty、error、success、failure 完整 |
| 风险控制 | 删除、覆盖、恢复、停用等操作有二次确认 |
| 预览交互 | 搜索、切换、表单、确认、Toast 可验证 |

缺少任一当前业务适用项，视为系统配置 HTML Demo 生成失败。
