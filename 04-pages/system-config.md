# 系统配置页规范
## System Config Page Standard

Keywords: system config, configuration, list page, form page, modal, backend, ai readable, html preview, vue codegen

> 本文件定义后台系统中的通用管理配置页面，覆盖组织管理、任务管理、告警中心、告警配置、系统日志、邀请管理、备份恢复、应用管理、网络配置、检测配置、多级配置和配置类弹窗。
>
> 系统配置页通常由列表、树表、表单、分页、弹窗和批量操作组成。通用规则应同时参考 `04-pages/list-page.md`、`04-pages/form-page.md` 和 `04-pages/detail-page.md`。

## 1. 页面定位

系统通用配置页属于平台后台中的“通用管理配置模板”，共同特点是结构稳定、信息密度中高、操作明确、规则导向强，偏管理后台而非数据分析看板。

设计重点：

- 让用户快速完成配置、检索、批量操作、查看状态。
- 保证复杂系统参数的层级清晰与操作可控。
- 通过列表、状态、表单、分页、弹窗等组件形成统一的管理体验。

## 2. 页面分类

```text
系统通用配置模板
├── 树形组织与层级管理：组织管理
├── 列表型任务与状态管理：任务管理
├── 告警与事件管理：告警中心 / 告警配置
├── 日志与记录管理：系统日志
├── 邀请与码类管理：邀请管理
├── 资产/数据恢复类管理：备份与恢复
├── 应用接入与应用列表管理：应用管理
├── 网络与设备基础配置：网络配置
├── 检测能力配置：文件检测配置
├── 多级节点与上下级接入配置：多级配置
└── 弹窗表单模板：新增节点 / 编辑节点
```

## 3. 通用页面骨架

```text
深色顶部导航
→ 浅色左侧一级导航
→ 页面标题 / 页签 / 二级切换
→ 筛选区 / 检索区
→ 工具栏 / 批量操作区
→ 主内容区（表格 / 树表 / 长表单 / 配置分组）
→ 分页 / 底部操作 / 保存按钮
```

基础规则：

- 顶部导航承载平台全局信息、一级站点导航、消息、用户信息。
- 左侧导航承载系统模块入口，当前项高亮。
- 内容区采用白底卡片或白底容器，置于浅灰页面背景中。
- 筛选区与表格区分开，避免混在一层。
- 列表页默认采用“筛选区 + 工具栏 + 表格 + 分页”的成熟模式。
- 配置页默认采用“局部 tabs + 分组表单 + 保存按钮”的模式。
- 所有“删除、禁用、还原、同步、取消”等具有风险的操作应保留明确语义。

## 4. 组织管理页模板

组织管理页用于维护树形组织结构、规则入组信息及组织的增删改查。

```text
筛选区（组织名称 + 搜索）
→ 工具栏（启用、禁用、全选、已选数量）
→ 右上操作（创建组织、导入/导出）
→ 树形表格
```

表格字段建议包括复选框、展开/收起箭头、组织名称、规则入组和操作。操作项可包含新增、编辑、删除、更多。

树形表格规则：

- 支持多层级缩进展示。
- 父节点需带展开/收起箭头。
- 子级通过缩进表达层级关系。
- 勾选支持批量操作。
- “已选 N 个”应在工具栏中明确展示。
- 右侧操作文案需统一、间距稳定。
- 当层级较深时，应优先保证名称列可读性。

## 5. 任务管理页模板

任务管理页用于展示系统任务状态、执行进度、时间与操作。

```text
筛选区（功能模块、发布人、状态）
→ 搜索按钮
→ 任务列表表格
```

表格字段建议包括任务、发布人、下发时间、终端完成比例、状态、截止时间和操作。

状态展示规则：

- 状态表现形式建议为进度条 + 百分比、状态圆点 + 文案、颜色区分任务状态。
- 示例状态包括执行中、执行完成、已取消、已失败。
- 状态文案不要只依赖颜色，必须带文字。
- 进行中状态支持“查看详情 / 取消”。
- 已完成状态通常仅保留“查看详情”。

## 6. 告警中心页模板

告警中心页用于查看系统告警事件，并支持按级别、状态、类型进行识别与处理。

```text
告警概览统计卡
→ 搜索区（告警名称）
→ 右上操作（告警配置、快捷入口）
→ 告警列表表格
→ 分页
```

顶部概览建议展示全部告警事件、紧急待处理、待处理、已处理、已忽略。

规则：

- 数值是核心视觉焦点。
- 状态类指标可配合语义色。
- 概览卡应支持点击筛选或联动列表。
- 不宜使用复杂图表，保持轻量。
- 表格字段建议包括告警名称、告警级别、状态、告警类型、告警方式、告警时间、告警内容和操作。
- 告警级别建议采用标签样式。
- 状态建议采用小圆点 + 文案组合。
- 告警内容过长时可截断显示。

## 7. 告警配置页模板

告警配置页用于维护告警策略与启停状态。

```text
返回标题区（如：告警配置）
→ 搜索区（告警名称 / 创建人）
→ 右上操作（新增策略、快捷入口）
→ 配置表格
```

表格字段建议包括告警名称、告警级别、状态、告警类型、告警方式、创建时间和操作。

规则：

- 告警策略页面应更偏配置管理，不强调统计信息。
- “新增策略”应放在表格上方右侧。
- 状态需清楚区分已启用 / 已停用。
- 配置类表格的操作文案通常比事件表格更多。
- 操作项可包含复制、删除、编辑、启用 / 停用。

## 8. 系统日志页模板

系统日志页用于查看管理员操作日志与系统运行日志。

```text
顶部局部 Tabs（管理员操作日志 / 系统运行日志）
→ 筛选区（时间、操作人、操作内容）
→ 搜索按钮
→ 日志表格
```

表格字段建议包括操作人、IP 地址、操作类型、操作内容、危险程度、操作时间和操作。

规则：

- 日志页面必须支持时间筛选。
- 适合通过 tabs 切换不同日志类型，而不是多个页面跳转。
- 危险程度应使用标签或状态色展示。
- 操作项一般为“详情”。
- 日志表格应强调可追溯性和清晰检索。

## 9. 邀请管理页模板

邀请管理页用于管理邀请码、邀请状态和申请列表。

```text
顶部局部 Tabs（邀请加入 / 申请列表）
→ 筛选区（组织名称/邀请码、状态）
→ 工具栏（删除、刷新邀请码、下载邀请码）
→ 右上操作（创建邀请码、导出全部）
→ 邀请列表表格
→ 分页
```

字段建议包括复选框、状态、组织名称、有效期、邀请码、审批类型和操作。

规则：

- 邀请码类页面要突出“复制”和“导出”。
- 状态文案应明确，如已过期、有效中、待审批。
- 批量操作按钮应置于表格上方左侧。
- 分页信息需包含总数、每页数量、页码跳转。

## 10. 备份与恢复页模板

备份与恢复页用于查看备份记录并执行备份、还原、下载等操作。

```text
右上功能按钮（手动备份 / 自动备份 / 导入备份 / 刷新）
→ 备份记录表格
```

表格字段建议包括备份时间、备份内容、文件大小、备份形式、备份状态、创建者、完成时间、备注和操作。

规则：

- 状态建议包括备份成功、备份中、备份失败。
- 备份成功可用绿色状态点。
- 还原与删除属于高风险操作，应有确认提示。
- 表格应突出“备份时间”“状态”“操作”。

## 11. 应用管理页模板

应用管理页用于维护应用接入信息与应用识别图标。

```text
筛选区（应用名称/URL、所属应用组、创建人）
→ 搜索 / 重置 / 展开
→ 工具栏（删除、导出、复制）
→ 右上操作（新建应用、管理默认图标、快捷入口）
→ 应用列表表格
→ 分页
```

表格字段建议包括复选框、应用名称、URL、图标、开放共享和操作。

规则：

- 图标列适合用固定尺寸小图标展示。
- URL 过长时使用省略号和 tooltip。
- 新建应用应使用主按钮。
- 删除、开放共享变更应确认影响范围。

## 12. 网络配置 / 检测配置 / 多级配置

### 网络配置

用于配置 IP、端口、网络节点、连接状态和基础网络参数。页面可使用分组表单 + 表格结构。危险变更如端口修改、节点删除、连接断开需要确认。

### 检测配置

用于配置文件检测、扫描策略、检测能力开关、规则集和白名单。页面应强调配置项分组、启停状态、检测范围和保存反馈。

### 多级配置

用于上下级节点、级联接入、多级同步和节点管理。页面应表达节点层级、连接状态、同步状态、接入配置和操作反馈。

## 13. 弹窗表单模板

弹窗表单适用于新增节点、编辑节点、简单配置和确认类操作。

结构：

```text
居中弹窗 + 遮罩
→ 弹窗标题
→ 表单字段
→ 底部按钮：取消 + 确认
```

规则：

- 弹窗宽度建议 480px / 560px / 720px。
- 必填项使用红色星号。
- 输入框宽度统一。
- 底部按钮右对齐。
- 关闭或取消时如存在未保存内容，应确认。
- 弹窗不适合承载长流程，复杂流程应使用抽屉或独立页面。

## 14. AI 生图要求

- 系统配置页应偏管理后台，不要生成成数据大屏。
- 树形组织应体现缩进、展开收起、勾选和操作列。
- 任务管理应体现进度条、状态和操作。
- 告警中心应体现概览统计、级别标签、状态和列表。
- 日志页必须体现时间筛选和可追溯表格。
- 邀请码页面应突出复制、刷新、下载、导出。
- 备份恢复页应突出备份状态和高风险还原操作。
- 弹窗必须居中、有遮罩、标题、表单和底部按钮。

## 15. Vue / HTML 生成要求

Vue 代码必须先判断页面模式，再生成对应结构。必须包含 mock 数据、loading、empty、error、搜索、重置、表格分页、行操作、批量操作、危险操作确认和反馈提示。

HTML 预览文件应支持当前页面的核心配置操作，例如搜索、tabs 切换、展开树节点、勾选、分页、新增弹窗、编辑弹窗、删除确认、状态切换和保存反馈。

## 16. 验收检查清单

| 检查项 | 要求 |
|---|---|
| 页面类型 | 明确属于组织、任务、告警、日志、邀请、备份、应用、网络等配置类型 |
| 骨架 | 顶部导航、左侧导航、标题、筛选、工具栏、主内容区完整 |
| 表格 | 字段、状态、操作、分页完整 |
| 树表 | 缩进、展开收起、勾选、层级关系清晰 |
| 表单 | 必填、校验、说明、保存反馈完整 |
| 弹窗 | 居中、遮罩、必填项、底部按钮齐全 |
| 风险操作 | 删除、禁用、还原、同步、取消等有确认逻辑 |
| 风格 | 浅色、极简、安全后台风格统一 |
