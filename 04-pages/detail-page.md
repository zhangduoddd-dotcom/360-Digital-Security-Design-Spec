# 详情页规范
## Detail Page Standard

Keywords: detail page, object detail, record, audit, backend

本文定义后台系统中的对象详情、记录详情、审批详情、日志详情等页面。

## 1. 标准结构

```text
页面标题 / 返回入口 / 状态标识
→ 对象摘要区
→ 基础信息 / 关键属性
→ 关联信息 / 明细表格 / 操作记录
→ 操作区
```

## 2. 必须模块

返回入口、页面标题、对象摘要、状态或风险标识、基础信息区、关联信息或操作记录、必要操作区。

## 3. 设计规则

首屏必须能识别对象身份、状态和关键判断信息。信息分组按用户理解路径组织，不按接口字段顺序平铺。高风险操作必须二次确认。

## 4. 代码与预览要求

Vue 代码必须包含对象摘要、信息分组、关联列表或操作记录、状态标签、loading、error 和必要操作反馈。HTML 预览可支持标签页切换、展开收起、抽屉或弹窗查看详情。
