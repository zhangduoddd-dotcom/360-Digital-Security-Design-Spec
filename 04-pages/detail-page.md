# 详情页规范
## Detail Page Standard

Keywords: detail page, drawer detail, object detail, timeline, audit, backend, ai readable, html preview

本文定义后台系统中的对象详情、记录详情、审批详情、日志详情、分析详情和抽屉详情页面。AI 生成详情页 HTML Demo 时，应优先遵循 `03-interaction/page-container.md`、`01-foundation/tokens.md` 和 `02-components/component-size.md`。

## 1. 页面定位

详情页用于承载单个对象、事件、任务、资产、模型、风险、报告或分析结果的完整信息。核心目标是帮助用户看清对象状态、理解关键原因、定位关联信息并执行下一步操作。

## 2. 页面类型

| 类型 | 适用场景 | 结构要点 |
|---|---|---|
| 抽屉式详情 | 从列表、告警、事件、监控卡片快速查看 | 背景页面 + 遮罩 + 右侧详情抽屉 |
| 独立详情页 | 信息量大、层级深、需要持续阅读 | 对象摘要 + 分组模块 + 关联数据 |
| 分析详情 | 安全评估、模型评分、检测结果 | 指标摘要 + 图表 / 表格 + 结论建议 |
| 对比详情 | 模型对比、检测结果对比 | 基础信息 + 横向对比表 |
| 时间轴详情 | 风险行为、事件过程、操作记录 | 时间节点 + 事件摘要 + 展开详情 |

## 3. 通用信息结构

详情页应按以下顺序组织信息：

```text
标题区 / 对象名称 / 状态标签 / 操作区
→ 摘要信息 / 关键指标 / 风险判断
→ 核心分析区 / 对比区 / 图表区 / 时间线区
→ 详细字段 / 描述表格 / 关联数据
→ 操作建议 / 处置动作 / 导出 / 返回
```

规则：

- 首屏必须能识别对象身份、状态和关键判断。
- 信息分组按用户理解路径组织，不按接口字段顺序平铺。
- 关联信息与主对象关系必须清晰。
- 高风险操作必须二次确认。
- 长详情页使用标签页、锚点或分组标题降低阅读压力。
- 风险色、状态标签、评分表达必须一致。

## 4. 抽屉式详情

抽屉式详情适合快速查看且不打断主流程。

- 抽屉从页面右侧滑出。
- 宽度可按复杂度设置为 560px / 880px / 80%。
- 背景页面添加半透明遮罩，保留来源上下文。
- 顶部固定标题、状态标签和关闭按钮。
- 内容区纵向滚动。
- 底部如有处置、导出、确认操作，可使用固定底部操作栏。
- 关闭前如存在未保存内容，应确认。

## 5. 独立详情页

独立详情页通常由母版页头、对象摘要、分组模块、图表、表格和操作建议组成。

```text
顶部导航 / 侧边导航
→ 母版页头页面标题
→ 对象摘要区
→ 标签页 / 锚点导航 / 分组导航
→ 详情内容区
→ 关联数据 / 表格 / 日志 / 空状态
```

详情页不得在母版业务内容区内重新生成面包屑或替代母版页头的顶层页头；对象名称、状态标签和业务操作应作为内容区内的对象摘要或模块标题出现。

## 6. 时间轴详情

时间轴详情适用于风险行为、事件过程、攻击链、操作记录、异常轨迹。

- 时间轴左侧使用时间点标记。
- 每个节点使用卡片承载事件摘要。
- 关键节点可使用风险色或状态图标。
- 节点可展开查看详情表格。
- 时间线不应过度装饰，重点是过程可追溯。

## 7. 图表与分析

- 分析型详情可包含图表，但数量应克制。
- 图表必须服务判断，不做装饰。
- 热力图、雷达图、条形图等应与表格或结论互相支撑。
- 对比表必须严格横向对齐，便于比较。
- 评分、等级、风险色和标签文案应统一。

## 8. HTML Demo 要求

HTML Demo 必须包含：

- 对象摘要。
- 信息分组。
- 关联列表或操作记录。
- 状态标签。
- loading、error、empty 状态。
- 必要操作反馈。

HTML Demo 应支持：

- 标签页切换。
- 展开 / 收起。
- 抽屉打开 / 关闭。
- 弹窗查看详情。
- 导出 / 处置等基础交互。
- 高风险操作二次确认。

## 9. AI 生成禁止项

- 禁止把详情页生成成列表页或 Dashboard。
- 禁止信息按接口字段无分组平铺。
- 禁止对象状态、风险等级和关键摘要缺失。
- 禁止关联表格堆叠无关信息。
- 禁止抽屉详情缺少遮罩、标题或关闭入口。
- 禁止 HTML Demo 只静态展示，无法切换、展开或查看反馈。

## 10. 验收清单

| 检查项 | 要求 |
|---|---|
| 对象识别 | 标题、对象名称、状态、关键摘要清晰 |
| 信息结构 | 摘要、基础信息、分析区、关联记录顺序合理 |
| 抽屉体验 | 宽度、遮罩、固定标题、关闭按钮完整 |
| 分析模块 | 图表、表格、标签和评分互相支撑 |
| 时间轴 | 时间、节点、事件、展开详情清晰 |
| 操作反馈 | 处置、导出、返回、关闭、确认等反馈完整 |
| 风险表达 | 风险色、状态标签、评分表达一致 |
| 生成质量 | 文字可读，无明显乱码、变形、错位 |

缺少任一当前业务适用项，视为详情页 HTML Demo 生成失败。
