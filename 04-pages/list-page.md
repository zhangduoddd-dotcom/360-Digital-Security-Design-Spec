# 列表页规范
## List Page Standard

Keywords: list page, search, table, pagination, batch action, backend

本文定义后台系统中的列表页结构、搜索区、表格区、操作栏和分页规则。

## 1. 适用场景

列表页用于数据检索、筛选、批量操作、状态识别、单行处理和分页浏览。典型场景包括用户管理、资产管理、日志查询、告警列表、策略列表、任务列表、审批列表和系统配置项列表。

## 2. 标准结构

```text
页面标题 / 面包屑 / 顶部标签
→ 搜索 / 筛选区
→ 表格顶部操作栏
→ 表格主体
→ 分页区
```

## 3. 必须模块

页面标题区、搜索或筛选区、表格操作栏、数据表格、状态标签、行操作列、分页区、loading、empty、error 状态。

## 4. 设计规则

搜索区用于缩小数据范围，不应比表格更抢眼。表格是列表页核心主体。批量操作必须和勾选状态联动。行操作放在最右侧，风险操作必须确认。状态标签必须文字和颜色同时表达。

## 5. AI 生图要求

表格面积应明显大于搜索区。不要加入大面积图表，不要把列表页做成 Dashboard，不要让按钮层级混乱。

## 6. 代码与预览要求

生成列表页代码时，必须包含搜索表单、表格、分页、勾选、批量操作、行操作、loading、empty、error、mock 数据和反馈提示。HTML 预览需支持搜索、重置、分页、行操作和删除确认。
