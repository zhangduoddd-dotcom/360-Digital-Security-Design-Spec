# 列表页规范
## List Page Standard

Keywords: list page, search, table, pagination, batch action, backend, ai readable, html preview, vue codegen

> 本文件是 `04-pages/` 页面规范的一部分，用于约束 AI 生成后台列表页、HTML 预览和 Vue 3 + TypeScript + Ant Design Vue 页面代码。
>
> 全局框架、导航、页面容器、颜色、间距、圆角、投影、组件尺寸等通用规则，应优先遵循 `03-interaction/platform-frame.md`、`03-interaction/page-container.md`、`01-foundation/tokens.md`、`02-components/component-size.md`。

## 1. 页面定位

列表页用于承载数据检索、筛选、批量操作、状态识别、单行处理和分页浏览。核心目标是提升查找效率、判断效率和处理效率，视觉上应保持克制、清晰、规整，不应被设计成数据看板或营销页面。

## 2. 通用结构

标准列表页应遵循：

```text
固定 ReturnHeader 页面标题
→ 查询区 / 高级筛选区
→ 工具栏 / 批量操作区 / 右侧功能按钮
→ 表格主体
→ 分页区
```

复杂列表页可扩展为：

```text
固定 ReturnHeader 页面标题
→ 页面内容区顶部标签页
→ 查询区
→ 左侧分类筛选栏 + 右侧结果表格
→ 表格工具栏 / 字段配置
→ 分页区
```

通用规则：

- 列表页不得在 `.platform-page-content` 内重新生成面包屑或额外顶层页头。
- 页面标题由固定 ReturnHeader 承载，业务模块标题只能出现在内容区内部。
- 页面背景使用浅灰，主体卡片使用白色。
- 查询区、工具栏、表格区、分页区应分层清楚。
- 表格始终是列表页的核心主体。
- 列表页不应加入大面积图表或装饰插图。
- 首屏应保证搜索、筛选、表头、核心字段、操作列和分页可见。
- 表格信息密度中高，但不应拥挤。

## 3. 列表页类型

### 3.1 标准表格列表页

适用于常规记录、配置项、对象列表。

```text
页面标题
→ 工具栏
→ 表格
→ 分页
```

典型元素包括主操作按钮、次级操作按钮、搜索框、表格字段、行操作和分页。

### 3.2 查询结果列表页

适用于事件查询、日志检索、任务记录、风险结果。

```text
查询条件区
→ 结果总数 / 导出按钮
→ 结果表格
→ 分页
```

典型元素包括输入框、下拉选择器、日期范围、查询按钮、重置按钮、导出按钮和结果总数。

### 3.3 左筛选 + 右列表页

适用于分类、类型、层级或资产目录明显的业务。

```text
顶部快捷筛选
→ 左侧分类筛选栏 + 右侧结果表格
```

左侧筛选可包含类别、类型、层级、数量、展开 / 收起和当前选中项；右侧表格可包含 IP、域名、协议、端口、状态码、产品应用、发现时间和操作。

### 3.4 高级搜索列表页

适用于字段多、查询条件复杂、支持 HQL 或字段配置的列表。

```text
高级查询表单
→ 展开 / 收起
→ 查询 / 清空 / HQL
→ 工具栏
→ 表格
→ 字段配置浮层
→ 分页
```

典型元素包括多行筛选条件、展开收起按钮、下载按钮、字段配置按钮、字段勾选浮层、横向滚动条和多选表格。

### 3.5 标签切换列表页

适用于按状态或集合切换的数据列表。

```text
页面标题
→ 标签页
→ 表格
→ 分页
```

标签数量建议 2–5 个；当前标签使用主色高亮；标签用于切换顶层集合，不替代复杂筛选。

## 4. 查询区规范

查询区用于缩小结果范围，应保持整齐、清晰、低干扰。

常见控件：输入框、下拉选择器、日期范围选择器、时间范围选择器、搜索按钮、重置按钮、展开 / 收起、HQL 入口。

布局规则：

- 简单查询一行展示 3–5 个字段。
- 复杂查询可使用 2–3 列栅格。
- 查询按钮使用主按钮。
- 重置按钮使用次按钮。
- 展开高级查询时应保持字段对齐。
- 查询区不应占据过多首屏空间。
- 日期范围应采用“开始日期 ～ 结束日期”结构。

## 5. 工具栏规范

工具栏用于承载批量操作、页面级操作和表格配置。

常见操作包括联动处置、联动记录、导出列表、下载、刷新、字段配置、批量选择、删除、复制、新建。

规则：

- 左侧优先放批量操作。
- 右侧优先放创建、导出、设置、刷新等页面操作。
- 主操作按钮最多 1 个。
- 次级操作建议 2–4 个。
- 批量操作在未选择数据时应为禁用态。
- 工具栏与表格之间应有清晰分隔。

## 6. 表格主体规范

表格是列表页最核心的信息区。

基本规则：

- 表头使用浅灰底。
- 行高默认 40px。
- 字号建议 12px 或 14px。
- 文字左对齐优先。
- 数字、状态、操作可按需要居中。
- 表格分割线使用浅灰细线。
- 空值使用 `-`。
- 操作列置于最右侧。
- 超长内容使用省略号，必要时配合 tooltip。
- 列较多时支持横向滚动。

常见字段：选择框、序号、名称、类型、状态、风险等级、IP、域名、端口、协议、时间、标签、操作。

## 7. 状态与标签规范

状态应同时依靠颜色和文字表达。

处理状态：

- 已处理：绿色。
- 未处理：橙色 / 黄色。
- 未接通：灰色。
- 处理中：蓝色或科技绿弱态。
- 已失败：红色。

风险等级：

- 高风险 / 严重：红色。
- 中风险 / 警告：橙色。
- 低风险 / 提醒：黄色。
- 安全 / 正常：绿色。

标签规则：

- 标签文字建议 2–6 字。
- 同一状态在同一产品内颜色保持一致。
- 一个单元格内不宜堆叠过多彩色标签。
- 普通类型标签使用灰色描边或浅色底。

## 8. 行操作与批量操作

常见行操作包括查看、查看详情、编辑、处理、删除、启用、停用、复制、下载。

规则：

- 行操作置于最右侧。
- 单行高频操作建议 1–3 个。
- 低频操作收进更多菜单。
- 删除、停用、取消等危险操作应弱化或二次确认。
- 操作链接颜色以主色为主，不要多色混用。

批量操作规则：

- 表格首列使用复选框。
- 支持全选当前页。
- 选中后应展示“已选 N 个”。
- 未选中数据时批量操作禁用。
- 批量删除、禁用、导出等操作需有反馈。
- 高风险批量操作应确认影响数量。

## 9. 字段配置浮层规范

复杂列表可提供字段配置能力。

```text
字段配置入口
→ 下拉浮层 / 抽屉
→ 全选 / 重置
→ 字段勾选列表
```

规则：

- 字段配置入口位于表格右上方。
- 浮层应靠近触发按钮。
- 支持全选、重置、勾选、禁用字段。
- 默认不可关闭字段应展示禁用态。
- 字段名称应与表头一致。
- 配置变更后即时影响表格列展示。

## 10. 左侧分类筛选规范

```text
分类组标题
→ 分类项 + 数量
→ 展开 / 收起
```

规则：

- 分组标题如类别、类型、层级。
- 每组支持展开 / 收起。
- 当前选中项使用主色或浅绿色高亮。
- 数量右对齐。
- 内容过长使用省略号。
- 左筛选栏与右侧表格之间使用竖向分隔。

## 11. 分页规范

分页位于表格底部，通常靠右。

分页应包含总条数、每页条数、上一页 / 下一页、页码、跳页输入。

规则：

- 当前页使用主色高亮。
- 每页条数建议支持 10 / 20 / 50。
- 总条数格式如 `共计 4568 条`。
- 列表页不应缺少分页，除非数据量极少。
- 分页与表格之间应留出清晰间距。

## 12. 信息密度规范

推荐值：

- 表格列数：6–10 列。
- 首屏行数：8–12 行。
- 查询字段：3–8 个。
- 标签页数量：2–5 个。
- 工具按钮：2–5 个。
- 单行操作：1–3 个。

控制原则：表格可密，但不能乱；查询区不应比表格更抢眼；普通字段不要和状态字段争抢视觉焦点。

## 13. 展开行规范

列表可使用展开行快速查看补充信息。

| 项目 | 规范 |
|---|---|
| 展开入口 | 表格首列或名称附近 |
| 展开方式 | 当前行向下展开 |
| 展开内容 | 当前数据条的扩展数据 |
| 使用条件 | 快速查看补充信息，不需要进入详情页 |
| 限制 | 不适合承载复杂编辑流程 |

## 14. AI 生图要求

- 表格面积应明显大于搜索区。
- 不要加入大面积图表。
- 不要把列表页做成 Dashboard。
- 不要让按钮层级混乱。
- 主要中文标题、字段和状态应可读。
- 状态标签需文字与颜色共同表达。
- 复杂列表应体现横向滚动、字段配置或左侧筛选等结构。

## 15. Vue / HTML 生成要求

生成列表页代码时，必须包含：

- 搜索表单。
- 表格。
- 分页。
- 勾选。
- 批量操作。
- 行操作。
- loading。
- empty。
- error。
- mock 数据。
- 反馈提示。
- 删除或高风险操作确认。

HTML 预览需支持搜索、重置、分页、行操作、删除确认、勾选联动和基础字段配置切换。

## 16. 验收检查清单

| 检查项 | 要求 |
|---|---|
| 页面类型 | 明确是列表页，不被做成看板或营销页 |
| 查询区 | 字段对齐，按钮层级清晰，支持展开收起 |
| 工具栏 | 批量操作和页面操作分区清楚 |
| 表格主体 | 字段、状态、操作、分页完整 |
| 行操作 | 高频操作可见，低频操作收起，危险操作确认 |
| 批量操作 | 已选数量、禁用态、确认反馈完整 |
| 状态标签 | 颜色和文字同时表达 |
| 分页 | 总数、页码、每页条数和跳页完整 |
| 预览交互 | 搜索、重置、分页、删除确认可操作 |
