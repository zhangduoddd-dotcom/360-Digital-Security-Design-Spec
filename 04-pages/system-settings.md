# 系统设置页规范
## System Settings Page Standard

Keywords: system settings, configuration, form page, backend

本文定义后台系统中的全局参数、密码规则、通知策略、安全策略等系统设置页面。

## 1. 页面类型

系统设置通常是表单页或分组配置页。

## 2. 标准结构

```text
页面标题
→ 设置分组导航 / 标签页
→ 当前设置表单
→ 高级配置或说明区
→ 底部操作区
```

## 3. 设计规则

设置项必须按业务含义分组。高风险设置应说明影响范围。保存前应有校验，保存后应有成功或失败反馈。危险配置变更应二次确认。

## 4. 代码与预览要求

Vue 代码必须包含设置分组、表单字段、校验规则、保存 loading、成功 / 失败反馈、权限状态和 mock 数据。HTML 预览需支持切换设置分组、修改字段、校验、保存 loading 和保存成功提示。
