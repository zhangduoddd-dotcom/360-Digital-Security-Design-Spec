# 系统设置页规范
## System Settings Page Standard

Keywords: system settings, configuration, form page, backend, ai readable, html preview

本文定义后台系统中的全局参数、账号安全策略、数据导出、数据清理、CDN、系统工具等系统设置页面。AI 生成系统设置 HTML Demo 时，应强调清晰分组、低干扰配置、安全提示和明确保存反馈。

## 1. 页面定位

系统设置用于配置平台级全局参数，通常影响范围广、风险较高。页面必须帮助用户理解配置含义、影响范围、保存状态和回滚风险。

## 2. 通用结构

```text
页面标题 / 说明
→ 设置分组导航 / 标签页 / 左侧目录
→ 当前设置分组
→ 表单字段 / 开关 / 选择器 / 上传 / 文本域
→ 保存 / 取消 / 恢复默认
→ 风险确认 / Toast 反馈
```

## 3. 设置分组

常见分组：

- 基础设置。
- 账号安全。
- 登录与会话。
- 数据导出。
- 日志与存储。
- 通知与消息。
- 系统工具。
- 高风险操作。

规则：

- 分组数量较多时使用左侧目录或标签页。
- 当前分组高亮。
- 每组字段只承载相关配置，不跨组混放。
- 高风险分组应有说明和确认机制。

## 4. 字段与状态

- 开关类设置必须说明开启 / 关闭影响。
- 数字类设置必须展示单位和范围。
- 文本类设置需要格式提示。
- 上传类设置需要展示文件格式和大小限制。
- 禁用字段必须说明原因。
- 只读字段与可编辑字段视觉区分。
- 保存前后应清晰表达未保存、保存中、保存成功、保存失败状态。

## 5. 高风险设置

以下操作必须二次确认：

- 清理数据。
- 恢复默认配置。
- 关闭安全策略。
- 变更密码复杂度。
- 修改会话有效期。
- 删除或覆盖全局配置。

确认弹窗必须说明操作对象、影响范围和是否可恢复。

## 6. HTML Demo 要求

HTML Demo 必须支持：

- 切换设置分组。
- 修改字段、开关或选择器。
- 必填 / 范围 / 格式校验。
- 保存 loading。
- 保存成功 / 失败提示。
- 恢复默认或取消时的确认。
- 至少一个高风险操作确认。
- disabled、readonly、empty / error 中的必要状态。

## 7. AI 生成禁止项

- 禁止所有配置无分组平铺。
- 禁止高风险设置没有影响范围说明。
- 禁止保存没有 loading 和反馈。
- 禁止禁用项不说明原因。
- 禁止把系统设置做成指标看板。
- 禁止 HTML Demo 只展示静态配置，不能切换、修改或保存。

## 8. 验收清单

| 检查项 | 要求 |
|---|---|
| 分组结构 | 设置分组清晰，当前分组可识别 |
| 字段表达 | 单位、范围、说明、禁用原因完整 |
| 保存反馈 | 未保存、保存中、成功、失败状态完整 |
| 风险确认 | 高风险配置有影响说明和二次确认 |
| 权限状态 | 无权限或只读状态清晰 |
| 预览交互 | 切换、修改、校验、保存、确认可验证 |

缺少任一当前业务适用项，视为系统设置 HTML Demo 生成失败。

## 9. 系统设置页交付总控规则

系统设置页交付不得只满足“配置项展示完整”。生成系统设置 HTML Demo 前，必须建立当前页面执行契约。

当前页面执行契约必须明确：

- 设置类型与分组：基础设置、账号安全、登录与会话、数据导出、日志与存储、通知与消息、系统工具或高风险操作。
- 使用母版与业务内容写入区域。
- 当前组件映射：分组导航、标签页、输入框、选择器、开关、上传、文本域、按钮、Confirm、Toast、Alert 等对应的 manifest key 和 snippetFile。
- 字段规则：单位、范围、格式提示、必填项、禁用原因、只读说明、开启 / 关闭影响。
- 保存规则：未保存提示、保存 loading、保存成功、保存失败、恢复默认、取消确认。
- 高风险清单：清理数据、恢复默认、关闭安全策略、修改会话有效期、删除或覆盖全局配置等。
- 状态清单：default、focus、disabled、readonly、error、dirty、saving、success、failure、confirm。
- 布局风险点：分组过多、字段无说明、保存按钮位置不稳定、高风险配置与普通配置混放、长说明文案压缩控件。

生成完成后，必须按执行契约逐项自检。只完成静态配置展示、字段可编辑或页面可打开，不等于通过系统设置页规范验收。
