# 系统设置页规范
## System Settings Page Standard

Keywords: system settings, configuration, form page, backend, ai readable, html preview, vue codegen

> 本文件定义后台系统中的全局参数、账号安全策略、数据导出、数据清理、CDN、系统工具等系统设置页面。
>
> 系统设置通常影响全局系统行为，应强调清晰分组、低干扰配置、强安全提示、明确保存反馈。通用表单规则应同时参考 `04-pages/form-page.md`。

## 1. 页面定位

系统设置用于配置平台级全局参数，包括密码复杂度规则、账号安全策略、数据导出方式、日志存储策略、CDN 节点配置、界面显示设置、远程托管服务、虚拟节点管理、系统工具下载等。

系统设置页面应避免过度装饰，优先保证可读性、准确性和操作安全。

## 2. 页面类型

系统设置模块通常包含以下页面类型：

```text
基础设置页
→ 用于配置服务参数、任务管理、密码规则、SSO、SMTP、时间同步、外部访问、AI 服务、界面定制等全局参数

数据导出设置页
→ 用于配置数据导出开关、外发方式、IP / 端口、转发配置和业务日志范围

数据清理设置页
→ 用于展示日志存储分布，并设置不同日志类型的保留时间

CDN 设置页
→ 用于配置 CDN 下载节点、存储节点、流控开关、IP 与端口

系统工具页
→ 用于展示外联靶机、离线升级工具、升级服务器等工具下载入口
```

## 3. 通用页面骨架

```text
深色顶部导航
→ 左侧系统导航
→ 系统设置二级标签页
→ 白色配置内容区
→ 配置分组 / 表单项 / 表格 / 工具卡
→ 应用 / 保存按钮
```

通用规则：

- 顶部导航保持全局一致。
- 左侧导航用于一级功能模块切换。
- 系统设置内部使用横向标签页区分子模块。
- 内容区采用白色背景，外层为浅灰页面背景。
- 配置项应按业务含义分组，不应无序堆叠。
- 每个配置分组应有明确标题，可使用主色竖线强调。
- 操作按钮应靠近对应分组，避免用户不清楚保存范围。
- 全局保存类按钮可固定在页面底部或内容区底部。
- 高风险配置应配合说明、tooltip 或二次确认。

## 4. 横向标签页规范

常见标签包括基本设置、数据导出、数据清理、CDN 设置和系统工具。

规则：

- 激活标签使用主色文字与底部指示线。
- 标签数量建议 3–7 个。
- 标签区应位于顶部导航下方、内容区上方。
- 标签页切换时仅替换主内容区，不应改变左侧导航结构。
- 标签命名应短而明确，建议 4–6 字。

## 5. 基础设置页模板

基础设置页用于承载大量全局配置项，适合采用长页面分组结构，并提供右侧锚点目录辅助跳转。

```text
顶部导航 + 左侧系统导航
→ 系统设置横向标签页
→ 基础设置内容区
→ 右侧锚点目录
→ 多个配置分组
```

基础设置页可包含服务管理、任务管理设置、分组管理设置、升级文件上传账号、安全大脑行为分析、密码加密设置、SSO 配置、SMTP 服务器设置、客户端通信设置、企业微信机器人告警配置、时间同步设置、外部访问中心配置、远程托管服务、360GPT、管控中心界面定制等分组。

分组规则：

- 每个分组顶部使用标题 + 主色竖线。
- 分组之间使用浅灰分割线。
- 每个分组内只放与当前主题相关的配置。
- 配置项较少时，按钮可放在该分组底部。
- 配置项较多时，按钮可放在分组右侧或底部统一区域。
- 每个分组的保存按钮文案建议使用 `应用`。
- 不同分组的保存范围应明确。

## 6. 右侧锚点目录

当配置项较多时，应提供右侧锚点目录。

规则：

- 固定在内容区右侧。
- 展示所有主要配置分组名称。
- 当前分组使用主色圆点或主色文字高亮。
- 点击锚点可滚动到对应分组。
- 锚点目录应悬浮于内容区上方，但不遮挡主表单。
- 长页面滚动时锚点目录可保持固定。

## 7. 配置项控件

基础设置页可使用以下控件：

- 单选框：开启 / 关闭、统一设置 / 分别设置。
- 开关：SSO 开关、流控开关、自定义界面开关。
- 滑块：下载速率、阈值、限速。
- 数字输入框：任务有效期、端口、天数。
- 输入框：用户名、IP、地址、URL、appid、appkey。
- 密码输入框：密钥、密码、token。
- 下拉选择器：认证方式、安全连接、回调方式。
- 复选框：勾选启用某配置项。
- 上传或图片展示：界面定制 logo、图标、系统名称。

控件规则：

- 表单标签左对齐。
- 必填项使用红色星号。
- 输入框宽度统一。
- 控件说明可放在控件右侧或下方。
- 长说明建议使用浅蓝信息提示块。
- 高风险说明可用 tooltip，不应大段堆叠在表单中。
- 禁用态输入框应使用浅灰底并降低文字对比度。
- 密码和密钥字段默认脱敏显示。

## 8. 界面定制配置

界面定制区域适合展示品牌相关内容。

可配置项：登录界面图标、管控界面图标、浏览器页面图标、管控产品名称、是否开启自定义界面。

规则：

- Logo 图片应以预览形式展示。
- 图片旁应说明适用位置、支持格式和尺寸限制。
- 系统名称输入框应限制长度。
- 品牌配置保存后应提示可能需要刷新页面生效。
- 不同 logo 类型应保持独立配置，不应混用。

## 9. 数据导出设置页模板

数据导出设置页用于配置数据导出开关、外发方式、外发地址和业务日志范围。

```text
顶部导航 + 左侧导航
→ 系统设置标签页：数据导出
→ 数据导出方式
→ IP / 端口配置
→ 可导出的 IP 列表表格
→ 转发配置
→ 外发业务配置
→ 底部应用按钮
```

规则：

- 开启 / 关闭使用单选框。
- 外发方式使用下拉选择器。
- IP 和端口输入框横向排列。
- 添加按钮使用描边按钮。
- 配置列表为空时展示空状态。
- 可导出列表表格包含 IP 列表、端口列表和操作。
- 转发配置使用单选框表达互斥配置。
- 外发业务配置可使用“业务类型 + 业务日志标签”结构。
- 标签数量较多时可换行展示。

## 10. 数据清理设置页模板

数据清理设置页用于展示日志存储分布，并配置不同业务日志的保留时间。

```text
顶部导航 + 左侧导航
→ 系统设置标签页：数据清理
→ 日志存储分布图表
→ 设置日志保留时间
→ 业务分类配置表单
→ 终端连接策略
→ 底部应用按钮
```

规则：

- 日志存储分布适合使用柱状图、进度条或存储卡片。
- 保留时间使用数字输入框 + 单位。
- 不同日志类型应分组展示。
- 清理策略属于高风险设置，应说明影响范围。
- 保存前应有确认或明确反馈。

## 11. CDN 设置页模板

CDN 设置页用于配置 CDN 下载节点、存储节点、流控开关、IP 和端口。

建议结构：

```text
CDN 基础配置
→ 下载节点列表
→ 存储节点列表
→ 流控配置
→ 应用按钮
```

规则：

- 节点表格应包含节点名称、IP、端口、状态和操作。
- 新增或编辑节点可使用弹窗或抽屉。
- 流控开关应配合限速输入框。
- 节点删除或禁用应二次确认。

## 12. 系统工具页模板

系统工具页用于展示外联靶机、离线升级工具、升级服务器等工具下载入口。

规则：

- 工具以卡片形式展示。
- 每张卡片包含工具名称、说明、版本、下载按钮。
- 存在多个版本时可使用下拉菜单。
- 下载按钮应靠近工具说明。
- 工具卡片不宜过度装饰，应突出可用性。

## 13. 安全与反馈规则

- 高风险配置必须说明影响范围。
- 保存前应有校验。
- 保存后应有成功或失败反馈。
- 危险配置变更应二次确认。
- 权限不足时应隐藏或禁用保存按钮，并说明原因。
- 不同分组的保存范围必须明确。

## 14. AI 生图要求

- 系统设置页必须体现标签页、分组配置和保存按钮。
- 基础设置长页面应体现右侧锚点目录。
- 数据导出应体现开关、IP/端口、表格和业务标签。
- 数据清理应体现存储分布和保留时间配置。
- CDN 设置应体现下载节点、存储节点、节点表格和保存按钮。
- 系统工具应体现工具卡片、说明、下载按钮和下拉菜单。
- 不要把系统设置页做成数据看板。

## 15. Vue / HTML 生成要求

Vue 代码必须包含设置分组、表单字段、校验规则、保存 loading、成功 / 失败反馈、权限状态、mock 数据、危险操作确认。HTML 预览需支持切换设置分组、修改字段、校验、保存 loading、保存成功提示和至少一个高风险确认。

## 16. 验收检查清单

| 检查项 | 要求 |
|---|---|
| 页面结构 | 顶部导航、左侧导航、横向标签页、内容区完整 |
| 配置分组 | 分组标题清晰，保存范围明确 |
| 控件状态 | 默认、禁用、只读、错误、保存中状态完整 |
| 高风险提示 | 高风险配置有说明和二次确认 |
| 长页导航 | 配置项较多时有锚点目录 |
| 反馈 | 保存成功 / 失败 / 权限不足提示完整 |
| 生成质量 | 文字可读，无明显乱码、错位和控件变形 |
