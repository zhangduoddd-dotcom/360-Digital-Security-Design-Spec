# 工作台规范
## Dashboard Standard

Keywords: dashboard, workspace, metrics, overview, backend

本文定义后台系统中的首页、概览页、运营看板和 AI 协同工作台。

## 1. 标准结构

```text
欢迎 / 当前状态摘要
→ 关键指标区
→ 待办 / 风险 / 核心任务
→ 趋势图表 / 分类统计 / 快捷入口
→ 最近动态 / 推荐动作
```

## 2. 必须模块

页面标题或欢迎区、核心指标卡片、待办 / 风险 / 异常入口、快捷入口、近期动态或任务列表。

## 3. 设计规则

工作台不是装饰页，应服务于看状态、找问题、进任务。指标数量应克制，优先展示可行动指标。图表应解释业务状态，不堆砌视觉复杂度。AI 能力入口可以使用 AI 渐变，但数量应克制。

## 4. 代码与预览要求

Vue 代码必须包含指标卡片、待办 / 风险入口、快捷入口、动态列表、loading 和 error 状态。HTML 预览可支持卡片 hover、快捷入口点击、简单筛选或标签切换。
