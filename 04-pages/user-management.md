# 用户管理页规范
## User Management Page Standard

Keywords: user management, account, role, permission, list page

本文定义后台系统中的用户、账号、角色、组织相关管理页面。

## 1. 页面类型

用户管理通常是列表页 + 表单弹窗 / 抽屉的组合页面。

## 2. 标准结构

```text
页面标题
→ 搜索筛选区
→ 用户表格操作栏
→ 用户数据表格
→ 分页区
→ 新建 / 编辑用户弹窗或抽屉
```

## 3. 常见字段与操作

字段包括用户名、账号、角色、部门 / 组织、状态、最近登录时间、创建时间、操作。操作包括新建用户、导入用户、编辑用户、启用 / 停用、重置密码、分配角色、删除用户。

## 4. 代码与预览要求

Vue 代码必须包含搜索、表格、分页、新建 / 编辑表单、启停、删除确认、mock 数据、loading、empty、error。HTML 预览至少支持搜索、重置、新建用户弹窗、编辑、启停和删除确认。
