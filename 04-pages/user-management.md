# 用户管理页规范
## User Management Page Standard

Keywords: user management, account, role, permission, organization, backend, ai readable, html preview, vue codegen

> 本文件定义后台系统中的用户、账号、角色、组织、用户组及相关权限管理页面。
>
> 用户管理通常由列表页、组织树、详情抽屉、编辑抽屉和用户组管理组成。通用列表、表单、详情规则应同时参考 `04-pages/list-page.md`、`04-pages/form-page.md` 和 `04-pages/detail-page.md`。

## 1. 页面定位

用户管理用于支撑用户注册登录、信息增删改查、权限与角色分配、状态管控、组织归属维护等功能。该类页面应通过合理的数据结构、清晰的组织关系表达和严格的安全操作控制，保障用户数据准确完整、访问权限安全有序，并与权限、授权、组织架构、角色管理等模块协同，为各业务模块提供稳定支撑。

## 2. 页面类型

用户管理模块通常包含以下页面类型：

```text
用户列表页
→ 用于查询、查看、创建、编辑、启用、禁用、重置密码、转移组织等操作

组织架构联动用户列表页
→ 用于根据组织树筛选用户，支持组织策略和用户数据联动管理

用户详情抽屉
→ 用于查看单个用户的基础信息、登录日志、设备绑定、策略管理、应用导航等信息

编辑用户抽屉
→ 用于修改用户基础资料、所属组织、账号、手机号、邮箱等信息

用户组管理页
→ 用于维护用户组树结构、子用户组、新建用户组、二维码、删除等操作
```

## 3. 通用页面骨架

```text
深色顶部导航
→ 左侧分级导航
→ 页面标题 / 当前模块
→ 查询区 / 组织树 / 工具栏
→ 用户表格 / 用户组表格
→ 分页 / 操作反馈
```

页面背景应采用浅灰色，核心内容区采用白色卡片。查询区、工具栏、表格区之间应有清晰分隔，不应将查询控件和批量操作混在同一视觉层级中。

## 4. 用户列表页模板

用户列表页用于展示用户基础信息，并支持用户数据的查询、批量处理和单行操作。

```text
顶部导航 + 左侧导航
→ 查询区：关键词输入 + 用户状态选择 + 搜索 + 重置
→ 表格工具栏：批量操作 + 创建 + 导出 / 设置
→ 用户表格
→ 分页区
```

### 查询区规范

常用查询字段包括姓名、账号、手机号、电子邮箱、用户状态、所属组织、角色和创建时间。

规则：

- 关键词输入框 placeholder 可写为 `姓名/账号/手机号/电子邮箱`。
- 用户状态使用下拉选择器。
- 搜索按钮使用主按钮。
- 重置按钮使用次按钮。
- 查询区字段数量较少时采用横向排列。
- 查询区高度应控制在一行或两行内，避免占据过多首屏空间。

### 工具栏规范

左侧批量操作可包含启用、禁用、重置密码、禁用并删除、转移组织。右侧页面操作可包含创建、导出、字段设置 / 表格设置。

规则：

- 批量操作按钮在未选中用户时应为禁用态。
- 创建按钮应置于工具栏右侧。
- 导出与设置可使用图标按钮。
- 删除类操作必须二次确认。
- 重置密码属于高风险操作，应有确认提示或结果反馈。

### 用户表格规范

用户表格字段建议包括勾选框、姓名、账号、电子邮箱、用户状态、手机号、所属组织和操作。

规则：

- 用户状态使用状态点 + 文案。
- 启用状态使用绿色圆点。
- 禁用状态使用灰色或红色弱提示。
- 操作列固定在最右侧。
- 单行操作建议为 `查看 / 编辑`。
- 用户列表默认展示 8–12 行。
- 分页区应展示总条数、每页条数、页码、跳页。

## 5. 组织架构联动用户列表页

组织架构联动用户列表用于根据组织树筛选用户，并在右侧展示对应组织下的用户列表。

```text
顶部查询区
→ 左侧组织架构栏 + 右侧用户表格
→ 右侧工具栏
→ 右侧用户列表
→ 分页区
```

组织架构栏应包含顶部标签页、组织搜索框、多级组织树、当前选中组织高亮、展开 / 收起图标和可选滚动条。

规则：

- 一级组织使用较强字重。
- 子级组织缩进展示。
- 当前选中项使用主色或浅绿色背景。
- 组织名称过长时使用省略号。
- 组织树区域应与右侧表格有清晰分隔。
- 可使用竖向拖拽分隔控件调整左右宽度。
- 右侧表格应随组织树选中项刷新。
- 当组织无用户时，应展示空状态。

## 6. 用户详情抽屉模板

用户详情抽屉用于快速查看单个用户信息，不打断用户列表上下文。

```text
背景列表页 + 半透明遮罩
→ 右侧大抽屉
→ 抽屉标题：用户详情 + 关闭按钮
→ 标签页：基本信息 / 登录日志 / 设备绑定 / 策略管理 / 应用导航
→ 详情内容区
```

基本信息字段建议包括所属组织、账号、姓名、手机号、电子邮箱、职位和身份证号。

规则：

- 抽屉从右侧滑出。
- 背景用户列表页应添加遮罩。
- 抽屉顶部固定显示标题和关闭按钮。
- 标签页位于标题下方。
- 当前标签使用主色高亮和底部指示线。
- 标签数量建议 3–6 个。
- 登录日志和设备绑定可使用简化表格展示。
- 用户详情中不应出现可编辑输入框，除非处于编辑态。

## 7. 编辑用户抽屉模板

编辑用户抽屉用于修改用户基础资料，适合从用户列表中的“编辑”操作触发。

```text
背景列表页 + 半透明遮罩
→ 右侧编辑抽屉
→ 抽屉标题：编辑用户 + 关闭按钮
→ 表单内容区
→ 底部操作区：取消 + 确认
```

表单字段建议包括所属组织、账号、姓名、手机号、电子邮箱、职位和身份证号。

规则：

- 必填项使用红色星号。
- 所属组织使用选择器。
- 账号、姓名、手机号、电子邮箱为常见必填项。
- 职位、身份证号可为选填。
- 输入框宽度应统一。
- 标签与输入框左右排列。
- 表单字段垂直间距保持一致。
- 输入框 placeholder 使用 `请输入` 或明确的选择提示。
- 可在表单下方提供弱提示说明，例如默认密码、登录验证或通知说明。

## 8. 用户组管理页模板

用户组管理页用于维护用户组树结构、子用户组、新建用户组、二维码、删除等操作。

建议结构：

```text
页面标题
→ 查询区 / 用户组搜索
→ 工具栏：新建用户组 / 批量操作
→ 用户组树表格
→ 分页或滚动容器
```

规则：

- 用户组层级通过缩进、展开收起箭头表达。
- 当前操作行应有明确 hover 或选中状态。
- 新建子用户组应体现父子关系。
- 二维码、删除、编辑等低频操作可收进更多菜单。
- 删除用户组前应提示影响范围。

## 9. 安全操作规则

- 删除、禁用、重置密码、转移组织属于高风险操作。
- 高风险操作必须二次确认。
- 批量高风险操作应明确影响数量。
- 禁用用户应说明影响登录和权限。
- 重置密码应提示通知方式或重置结果。
- 无权限操作应隐藏或禁用，并给出原因。

## 10. AI 生图要求

- 用户管理页必须体现查询区、工具栏、用户表格、分页。
- 组织联动页必须体现左侧组织树和右侧用户表格。
- 用户详情 / 编辑必须体现右侧抽屉和背景遮罩。
- 状态必须使用文字 + 状态点表达。
- 不要把用户管理页做成 Dashboard。
- 主要中文字段和按钮文案应可读。

## 11. Vue / HTML 生成要求

Vue 代码必须包含搜索、表格、分页、新建 / 编辑表单、启停、删除确认、重置密码确认、mock 数据、loading、empty、error。HTML 预览至少支持搜索、重置、新建用户抽屉、编辑、查看详情、启停和删除确认。

## 12. 验收检查清单

| 检查项 | 要求 |
|---|---|
| 用户列表 | 查询、工具栏、表格、分页完整 |
| 组织联动 | 左侧组织树和右侧表格联动清晰 |
| 用户详情 | 抽屉、标签页、字段展示完整 |
| 编辑表单 | 必填项、输入框、说明文案、取消确认按钮完整 |
| 用户组层级 | 展开收起、缩进、行操作清晰 |
| 安全控制 | 删除、禁用、重置密码等高风险操作有弱化或确认逻辑 |
