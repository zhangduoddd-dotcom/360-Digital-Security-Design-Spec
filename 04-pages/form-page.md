# 表单页规范
## Form Page Standard

Keywords: form page, form entry, validation, submit, backend

本文定义后台系统中的新增、编辑、配置、提交类页面。

## 1. 适用场景

表单页适用于新建用户、新建策略、编辑配置、系统参数设置、任务创建、审批提交和安全规则配置等场景。

## 2. 标准结构

```text
页面标题 / 面包屑
→ 基础信息区
→ 配置项分组
→ 高级设置 / 可选设置
→ 底部操作区
```

## 3. 必须模块

页面标题区、表单分组、字段控件、必填标识、校验提示、帮助说明、底部操作区、提交 loading、成功或失败反馈。

## 4. 设计规则

字段按业务含义分组。高风险配置应说明影响范围。长表单应支持分组、步骤、锚点或折叠。底部主操作必须稳定可见。

## 5. 代码与预览要求

Vue 代码必须包含表单模型、校验规则、字段分组、提交 loading、成功 / 失败反馈和取消操作。HTML 预览需支持字段输入、校验失败、提交 loading 和成功提示。
