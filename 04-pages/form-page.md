# 表单页规范
## Form Page Standard

Keywords: form page, form entry, validation, submit, drawer form, configuration, backend, ai readable, html preview, vue codegen

> 本文件定义后台系统中的新增、编辑、配置、提交、规则编辑、策略设置等表单页面。
>
> 全局框架、页面容器、颜色、间距、组件尺寸等通用规则，应优先遵循 `03-interaction/platform-frame.md`、`03-interaction/page-container.md`、`01-foundation/tokens.md` 和 `02-components/component-size.md`。

## 1. 页面定位

表单页面用于完成数据录入、参数配置、规则编辑、策略设置、对象新增与对象修改。核心目标是降低填写成本、减少配置错误、明确保存范围，并在复杂场景中通过分组、步骤、标签页、抽屉和条件构建器保持清晰的操作路径。

表单页面分为两大类：

```text
独立页面表单
→ 适合字段较多、配置层级较深、需要完整页面承载的场景

抽屉式表单
→ 适合新增、编辑、添加规则、轻量参数配置等局部操作场景
```

## 2. 通用结构

```text
页面路径 / 页面标题 / 返回入口
→ 标签页 / 步骤条 / 左侧对象树
→ 表单内容区
→ 分组标题 / 字段区 / 条件配置区 / 卡片配置区
→ 底部操作栏
```

通用规则：

- 表单内容应以白色容器承载，页面背景使用浅灰色。
- 字段标签左对齐，输入控件宽度统一。
- 必填项使用红色星号。
- 复杂表单必须分组，不应把所有字段无序堆叠。
- 保存、取消、上一步、下一步等操作应固定或靠近表单底部。
- 影响范围较大的配置应提供提示说明。
- 表单控件状态需包含默认、聚焦、禁用、错误、已选、只读。
- 表单页不应被设计成 Dashboard，不应加入大量图表。

## 3. 标准单栏表单页

适用于常规信息录入、基础配置、终端管理配置等。

```text
顶部导航 + 左侧导航
→ 页面标题
→ 白色表单卡片
→ 顶部标签页
→ 单栏字段纵向排列
→ 底部保存按钮
```

字段类型可包含单行输入框、下拉选择器、日期 / 时间选择器、单选框、复选框、IPv4 输入框、数字输入框、文件上传、开关、多行文本域。

布局规则：

- 表单标签位于左侧，输入控件位于右侧。
- 标签宽度应统一，建议 120–160px。
- 控件宽度应统一，普通输入框建议 360–480px。
- 每行字段垂直间距保持一致。
- 提示说明放在字段下方，使用浅灰文字。
- 文本域右下角可显示字数计数，如 `0/100`。
- 保存按钮位于底部左侧或底部操作区左侧。

## 4. 多层级导航表单页

适用于页面层级较深、左侧存在多级菜单或打开多个检测报告页签的场景。

```text
顶部导航
→ 左侧多级导航
→ 顶部页签 / 报告标签
→ 主表单区域
→ 底部保存按钮
```

规则：

- 左侧导航最多展示到 4–5 级，当前项高亮。
- 顶部可使用打开页签表示当前任务。
- 表单区仍采用单栏纵向布局。
- 当层级较深时，应通过面包屑或顶部页签帮助用户定位。
- 底部保存按钮应固定在内容区底部，避免长页面中找不到保存入口。

## 5. 左树右表单配置页

适用于按终端分组、组织、设备、策略对象进行配置的页面。

```text
页面标题 / 副标题
→ 左侧对象树 / 分组树
→ 右侧标签页
→ 右侧配置表单 / 卡片式配置区
```

左侧树可包含分组标题、搜索框、新增按钮、展开 / 收起箭头、节点名称、节点数量和当前选中项高亮。

规则：

- 左侧树宽度应稳定。
- 当前选中节点使用浅绿色背景。
- 节点过长时使用省略号。
- 节点数量右对齐。
- 左右分栏之间使用竖向分隔线。
- 左树用于定位对象，右侧用于配置内容。

右侧配置区可包含标签页、分组标题、logo / 图标预览、输入框、按钮、版本卡片、功能菜单卡片和场景菜单卡片。右侧内容应跟随左侧选中对象变化。

## 6. 卡片式配置选择表单页

适用于版本选择、功能套餐、菜单模板、策略模板等。

```text
左侧对象树
→ 右侧配置卡片容器
→ 版本选项卡片
→ 功能菜单 / 场景菜单卡片
→ 底部操作按钮
```

规则：

- 当前选中卡片使用主色边框或浅绿色背景。
- 未选中卡片使用白底浅边框。
- 卡片内文字层级为：标题 > 描述 > 标签。
- 多组卡片之间保持明显分区。
- 卡片不宜过度装饰，保持后台配置属性。

## 7. 条件组合查询表单页

适用于高级查询、规则条件、筛选表达式、字段组合判断等场景。

```text
页面标题
→ 基础类型单选区
→ 条件组合容器
→ 多选条件区
→ 查询按钮
```

条件组合区可包含分组标题、关系选择器、字段选择器、运算符选择器、值选择器和新增条件按钮。

规则：

- 条件容器使用浅灰边框卡片。
- 每组条件内部控件横向排列。
- 逻辑关系与字段选择应有清晰顺序。
- 新增按钮使用主色方形按钮。
- 多个条件组之间保持一致宽度和间距。
- 条件组支持展开 / 收起。
- 查询按钮应位于条件区下方，靠左或靠右保持统一。

## 8. 抽屉式表单模板

抽屉式表单适用于从列表页、详情页或配置页中快速新增、编辑或添加规则。

结构：

```text
背景页面 + 半透明遮罩
→ 右侧抽屉
→ 抽屉标题 + 关闭按钮
→ 表单内容区
→ 底部操作区：取消 + 确认
```

规则：

- 抽屉从右侧滑出，宽度建议 560px / 720px / 880px。
- 抽屉标题固定在顶部。
- 表单内容区可滚动。
- 底部操作区固定，主按钮为确认 / 保存。
- 关闭抽屉时如存在未保存内容，应二次确认。
- 抽屉不适合承载过深层级的复杂流程，复杂流程应使用独立页面或分步流程页。

## 9. 表单校验与状态

- 必填项必须展示红色星号。
- 校验错误应在字段下方给出明确原因。
- 提交中展示 loading，避免重复提交。
- 保存成功应展示成功反馈。
- 保存失败应说明原因，并保留已填写内容。
- 禁用态应降低对比度，但文字仍可读。
- 只读态不能表现得像可编辑输入框。
- 高风险配置需要说明影响范围，并在保存前二次确认。

## 10. 分步表单关系

表单页中涉及明确前后顺序、流程状态、上一步 / 下一步 / 提交的内容，应优先读取并遵循 `04-pages/step-flow-page.md`。本文件只描述表单字段和配置结构，流程控制以分步流程页为准。

## 11. AI 生图要求

- 表单页必须展示标题、字段标签、输入控件、必填标识和操作按钮。
- 复杂表单必须分组，不允许字段无序堆叠。
- 抽屉式表单必须体现背景遮罩和右侧抽屉结构。
- 条件组合表单必须展示关系、字段、运算符、值和新增条件。
- 表单页不应生成大量图表或数据看板。
- 主要中文字段和按钮文案应可读。

## 12. Vue / HTML 生成要求

Vue 代码必须包含表单模型、校验规则、字段分组、提交 loading、成功 / 失败反馈、取消操作、禁用 / 只读状态和 mock 数据。HTML 预览需支持字段输入、校验失败、提交 loading、成功提示、取消确认和至少一种字段联动。

## 13. 验收检查清单

| 检查项 | 要求 |
|---|---|
| 页面类型 | 独立表单、抽屉表单或配置表单类型明确 |
| 表单分组 | 复杂字段按业务含义分组 |
| 控件一致 | 标签宽度、输入宽度、间距统一 |
| 校验表达 | 必填、错误、禁用、只读等状态可识别 |
| 操作区 | 保存、取消、提交、返回位置稳定 |
| 风险提示 | 高风险配置有说明和二次确认 |
| 预览交互 | 输入、校验、提交、成功 / 失败反馈完整 |
