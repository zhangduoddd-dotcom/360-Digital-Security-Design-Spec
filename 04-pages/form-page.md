# 表单页规范
## Form Page Standard

Keywords: form page, form entry, validation, submit, drawer form, configuration, backend, ai readable, html preview

本文定义后台系统中的新增、编辑、配置、提交、规则编辑、策略设置等表单页面。AI 生成表单页 HTML Demo 时，应优先遵循 `03-interaction/page-container.md`、`03-interaction/form-entry.md`、`01-foundation/tokens.md` 和 `02-components/component-size.md`。

## 1. 页面定位

表单页用于完成数据录入、参数配置、规则编辑、策略设置、对象新增与对象修改。核心目标是降低填写成本、减少配置错误、明确保存范围，并通过分组、步骤、标签页、抽屉和条件构建器保持清晰操作路径。

## 2. 页面类型

| 类型 | 适用场景 | 结构要点 |
|---|---|---|
| 独立页面表单 | 字段较多、配置层级深、需要完整页面承载 | 页面标题 + 表单容器 + 分组字段 + 底部操作 |
| 抽屉式表单 | 新增、编辑、添加规则、轻量参数配置 | 背景页面 + 右侧抽屉 + 固定底部操作 |
| 分步表单 | 有明确前后顺序、需要逐步校验 | 步骤条 + 当前步骤字段 + 上一步 / 下一步 / 提交 |
| 左树右表单 | 按组织、终端、设备、策略对象配置 | 左侧对象树 + 右侧配置内容 |
| 条件组合表单 | 高级查询、规则条件、筛选表达式 | 条件组 + 字段 / 运算符 / 值 + 新增条件 |

## 3. 通用结构

```text
页面标题 / 返回入口
→ 标签页 / 步骤条 / 左侧对象树（按需）
→ 表单内容区
→ 分组标题 / 字段区 / 条件配置区 / 卡片配置区
→ 底部操作栏
```

通用规则：

- 表单内容应以白色容器承载，页面背景使用浅灰色。
- 字段标签宽度统一，输入控件宽度统一。
- 必填项展示红色星号。
- 复杂表单必须分组，不应无序堆叠字段。
- 保存、取消、上一步、下一步等操作位置稳定。
- 高风险配置提供影响范围说明。
- 表单控件状态包含默认、聚焦、禁用、错误、已选、只读。

## 4. 字段组织

- 6 个以内字段可使用单组表单。
- 7–12 个字段建议按业务含义分组。
- 超过 12 个字段必须分组、标签页或步骤化。
- 超过 20 个字段优先使用分步流程。
- 字段顺序按用户填写路径组织，不按接口字段顺序机械排列。

## 5. 抽屉表单

抽屉表单适用于从列表页、详情页或配置页快速新增、编辑或添加规则。

```text
背景页面 + 遮罩
→ 右侧抽屉
→ 抽屉标题 + 关闭按钮
→ 表单内容区
→ 底部操作区：取消 + 保存 / 确认
```

- 抽屉宽度建议 560px / 720px / 880px。
- 标题固定在顶部，底部操作区固定。
- 内容区可滚动。
- 关闭前若存在未保存内容，应二次确认。
- 复杂多步骤流程应使用独立页面或分步流程页。

## 6. 校验与状态

- 必填项必须展示红色星号。
- 校验错误在字段下方给出明确原因。
- 提交中展示 loading，避免重复提交。
- 保存成功展示成功反馈。
- 保存失败说明原因，并保留已填写内容。
- 禁用态降低对比度但保持可读。
- 只读态不能表现得像可编辑输入框。
- 高风险配置保存前必须二次确认。

## 7. HTML Demo 要求

HTML Demo 必须支持：

- 字段输入和 mock 数据回填。
- 必填校验和格式校验。
- 校验失败定位与错误文案。
- 提交 loading。
- 成功 / 失败反馈。
- 取消或关闭时的未保存确认。
- 禁用 / 只读状态展示。
- 至少一种字段联动或条件显隐。

## 8. AI 生成禁止项

- 禁止把表单页生成成 Dashboard。
- 禁止字段无分组、无顺序堆叠。
- 禁止复杂表单缺少说明和影响范围。
- 禁止错误状态只有颜色没有文案。
- 禁止高风险保存没有二次确认。
- 禁止 HTML Demo 只展示静态字段，不能输入、校验或提交。

## 9. 验收清单

| 检查项 | 要求 |
|---|---|
| 页面类型 | 独立表单、抽屉表单或配置表单类型明确 |
| 表单分组 | 复杂字段按业务含义分组 |
| 控件一致 | 标签宽度、输入宽度、间距统一 |
| 校验表达 | 必填、错误、禁用、只读等状态可识别 |
| 操作区 | 保存、取消、提交、返回位置稳定 |
| 风险提示 | 高风险配置有说明和二次确认 |
| 预览交互 | 输入、校验、提交、成功 / 失败反馈完整 |

缺少任一当前业务适用项，视为表单页 HTML Demo 生成失败。
