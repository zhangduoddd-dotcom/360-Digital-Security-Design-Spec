# 数据展示组件规范
## Data Display Component Rules

Keywords: table, data table, card, statistic, tag, badge, descriptions, timeline, tooltip, popover, collapse

本文定义后台页面中的表格、卡片、统计数值、标签、徽标数、描述列表、时间轴、Tooltip、Popover 和折叠面板等数据展示组件规则。

## 1. 表格 Table

表格用于展示多条结构类似的数据，可支持排序、筛选、对比、自定义操作。

### 1.1 使用场景

- 大量结构化数据。
- 需要排序、搜索、分页、筛选。
- 需要批量操作。
- 需要行级操作。

### 1.2 表格规则

| 项目 | 规范 |
|---|---|
| 布局 | 默认采用百分比布局或弹性布局，适配多分辨率 |
| 表头 | 单位统一放在表头内，表头文本不建议换行 |
| 排列 | 按业务重要程度和强相关性从左到右排列 |
| 首列 | 通常为主信息列 |
| 对齐 | 名称、链接、信息、日期、姓名、操作左对齐；数据类右对齐 |
| 冻结 | 横向滚动时冻结主信息列和操作列 |
| 树形层级 | 树形表格节点不得超过 3 层 |
| 排序 | 数据类型列可排序，默认按业务逻辑排序 |
| 筛选 | 类别属性列可筛选 |
| 文本溢出 | 单行文本超出后用 `...`，hover 出现 Tooltip |
| 空数据 | 显示“暂无数据”，保留表头，不显示分页 |
| 操作列 | 操作过多时使用“更多”或下拉，不建议超过 5 个 |

### 1.3 表格筛选区

推荐结构：

```text
[搜索框] [筛选项] [日期范围] [更多筛选]       [重置] [查询]
```

规则：

- 高频筛选项放在表格上方。
- 低频筛选项放入“更多筛选”。
- 表头筛选适合轻量类别过滤。
- 搜索条件复杂时应提供“重置”。

更详细的表格区域交互、操作栏和分页规则见：

```text
03-interaction/list-table.md
```

## 2. 卡片 Card

### 2.1 使用场景

- Dashboard 概览。
- 信息聚合。
- 任务列表。
- 专家卡片。
- 项目卡片。

### 2.2 规则

- 卡片承载一组相关信息或类似任务。
- 卡片标题要明确。
- 卡片内操作不要过多。
- 卡片之间间距保持一致。
- 可点击卡片必须有 hover 状态。
- 卡片内信息应遵循“标题 → 状态 → 关键指标 → 描述 → 操作”的顺序。
- 普通卡片优先使用一级投影，不使用二级投影。

## 3. 统计数值 Statistic

### 3.1 使用场景

- 突出展示一个或一组数字。
- Dashboard 指标。
- 请求次数、成功率、风险数量、任务数等。

### 3.2 规则

- 数字应明显大于说明文字。
- 单位必须清晰。
- 同组指标的格式保持一致。
- 对比数据应说明变化方向。
- 重要异常指标可结合功能色。
- 不要只展示数字而不说明含义。

## 4. 标签 Tag

### 4.1 使用场景

- 标记属性。
- 状态分类。
- 等级展示。
- 可删除筛选条件。
- 多彩标签。

### 4.2 规则

- 标签文字简短。
- 标签颜色必须和语义一致。
- 状态标签和等级标签不要混用。
- 可删除标签需要明确关闭图标。
- 风险等级标签必须使用统一安全等级色。
- 等级、状态、风险命名必须遵循 `01-foundation/color.md` 中的标准命名。

## 5. 徽标数 Badge

### 5.1 使用场景

- 通知数量。
- 待办数量。
- 告警数量。
- 状态点。

### 5.2 规则

- 数量过大使用 `999+`。
- 状态点用于在线、离线、异常、处理中等状态。
- 徽标不能遮挡主体图标识别。
- 状态点必须保留文字说明，不只展示颜色。

## 6. 描述列表 Descriptions

### 6.1 使用场景

- 详情页只读字段展示。
- 成组展示对象属性。
- 审批详情、项目详情、专家详情。

### 6.2 规则

- 字段名称和字段值分区清晰。
- 字段过多时分组展示。
- 可使用带边框样式强化结构。
- 空字段统一显示 `--` 或“暂无”。
- 字段顺序应符合用户理解路径，不按接口字段机械平铺。

## 7. 时间轴 Timeline

### 7.1 使用场景

- 操作记录。
- 审批流程。
- 任务进度。
- 日志事件。

### 7.2 规则

- 可正序或倒序，但同一产品内应统一。
- 状态点颜色必须表达进度或结果。
- 重要节点可加入图标。
- 时间、操作者、动作、结果应完整展示。
- 异常节点应使用语义色强调，并保留说明。

## 8. Tooltip 文字提示

### 8.1 使用场景

- 对图标、按钮、术语进行解释。
- 表格文本溢出展示完整内容。
- 轻量辅助说明。

### 8.2 规则

- 不承载复杂内容。
- 不承载操作。
- 不用于主体内容展示。
- 文案必须短。
- 图标按钮语义不清时必须添加 Tooltip。

## 9. Popover 气泡卡片

### 9.1 使用场景

- 目标元素有进一步说明和相关操作。
- 需要承载链接、按钮、简短详情。
- 用户可与浮层内容交互。

### 9.2 Tooltip 与 Popover 区别

| 组件 | 是否可操作 | 内容复杂度 |
|---|---|---|
| Tooltip | 不可操作 | 简短文字 |
| Popover | 可操作 | 文本、链接、按钮、简短列表 |

## 10. 折叠面板 Collapse

### 10.1 使用场景

- 复杂区域分组。
- 隐藏低频信息。
- 保持页面整洁。

### 10.2 规则

- 标题必须概括内容。
- 只允许单项展开时使用手风琴模式。
- 默认展开项应符合用户主要任务。
- 不要把高频信息默认折叠。

## 11. Vue / HTML 生成要求

- Vue 代码使用 Ant Design Vue 对应数据展示组件。
- 表格必须包含 loading、empty、pagination、rowKey、操作列和状态标签。
- 卡片、统计数值、标签、徽标、描述列表、时间轴应使用统一 Token 和语义色。
- HTML 预览文件必须模拟文本溢出 Tooltip、卡片 hover、空状态、状态标签和分页等基础交互。
