# 按钮规范
## Button Rules

Keywords: button, icon button, primary action, danger action, ai button, backend

本文定义后台页面中的按钮类型、层级、尺寸、状态、图标按钮和 AI 按钮规则。AI 生成页面、Vue 代码或 HTML 预览文件时，必须遵循本文。

## 1. 按钮类型

| 类型 | 用途 |
|---|---|
| 主按钮 | 引导用户完成当前最重要操作 |
| 次按钮 | 与主按钮配合，执行次级操作 |
| 辅助按钮 | 弱化操作、辅助功能 |
| 文字按钮 | 最次级操作，常用于表格行操作 |
| 链接按钮 | 跳转到其他页面或位置 |
| 图标按钮 | 空间有限或轻量操作 |
| 下拉按钮 | 收纳多个同类或低频操作 |
| AI 按钮 | 触发 AI 生成、智能分析、自动填充、智能推荐等能力 |

## 2. 按钮层级

### 2.1 基本规则

- 一个操作区域只保留一个主按钮。
- 页面级主按钮一般放在页头右侧或表格操作栏左侧。
- 弹窗内主按钮放在右侧，取消按钮放在左侧。
- 多个按钮组合时，推荐 `1 个主操作 + N 个次操作`。
- 6 个以上操作时，应把低频操作放入“更多”下拉。

示例：

```text
[取消] [保存草稿] [确定发布]
```

其中：

- `确定发布` 为主操作。
- `保存草稿` 为次操作。
- `取消` 为辅助操作。

## 3. 按钮尺寸

基础按钮支持三档高度。

| 尺寸 | 推荐高度 | 典型使用场景 | 字体 | 圆角 |
|---|---:|---|---|---:|
| 紧凑 | 24px | 表格行内操作、筛选区轻量按钮、空间受限区域 | 12px / 20px | 4px |
| 常规 | 32px | 页面主要按钮、表单按钮、工具栏按钮 | 14px / 22px | 6px |
| 宽松 | 40px | 强视觉主按钮、表单底部主操作、引导型按钮 | 16px / 28px | 8px |

规则：

- 常规后台页面默认使用 32px 按钮。
- 高密度表格行内操作可使用 24px 或文字按钮。
- 图标按钮应优先使用 24px 或 32px 正方形容器。
- 不要在高密度表格中使用 40px 图标按钮。

## 4. 按钮状态

按钮必须至少包含以下状态：

| 状态 | 说明 |
|---|---|
| Default | 默认可点击状态 |
| Hover | 鼠标移入状态 |
| Active / Click | 点击状态 |
| Disabled | 不可用状态 |
| Loading | 操作处理中状态 |
| Danger | 危险操作状态 |

加载状态适用于提交、保存、上传、AI 生成等等待场景，按钮需阻止重复点击。

## 5. 图标按钮

### 5.1 使用场景

- 表格行内操作。
- 工具栏中的轻量操作。
- 空间有限的表单项操作。
- 需要快速识别的功能入口。

### 5.2 规则

- 图标语义必须清晰。
- 不易理解的图标必须加 Tooltip。
- 一个页面避免过多带图标的强引导按钮。
- 图标按钮不应替代关键文字说明。
- 右侧全局配置区可使用纯图标按钮，但 hover 时必须显示操作名称。

## 6. AI 按钮规范

### 6.1 使用场景

| AI 按钮文案 | 使用场景 |
|---|---|
| 智能生成 | 生成文案、报告、任务方案 |
| AI 分析 | 对数据、日志、风险进行分析 |
| 智能推荐 | 推荐专家、策略、模板 |
| 自动填充 | 根据上下文填充表单 |
| 重新生成 | 对 AI 结果进行迭代 |
| 应用结果 | 将 AI 生成结果写入业务流程 |

### 6.2 AI 按钮视觉状态

| 状态 | Token | CSS 值 | 说明 |
|---|---|---|---|
| Default | `AI 默认` | `linear-gradient(307deg, #004DFF 0%, #1093FF 65%, #1AFFAF 100%)` | 默认可点击状态 |
| Hover | `AI 悬停` | `linear-gradient(0deg, rgba(255,255,255,0.20), rgba(255,255,255,0.20)), linear-gradient(126deg, #1AFFAF 0%, #1093FF 37%, #004DFF 100%)` | 悬停时叠加 20% 白色蒙层 |
| Active / Click | `AI 按下` | `linear-gradient(0deg, rgba(0,0,0,0.20), rgba(0,0,0,0.20)), linear-gradient(309deg, #004DFF 0%, #1093FF 54%, #1AFFAF 100%)` | 按下时叠加 20% 黑色蒙层 |

### 6.3 AI 按钮设计要求

- AI 按钮必须和普通主按钮区分：普通主按钮走 `p6/p5/p7`，AI 按钮走三态渐变。
- AI 按钮应说明执行后会产生什么结果。
- 涉及写入、发布、删除、变更配置的 AI 操作，不能直接自动执行，必须由用户确认。
- AI 生成中必须有 loading 状态。
- AI 结果必须支持查看、修改、应用和撤销。
- 关键 AI 操作应保留日志，便于审计。
- 不要把所有主要按钮都做成 AI 渐变，否则用户无法判断哪些操作真的调用 AI 能力。

## 7. 代码生成要求

- Vue 代码使用 `a-button`。
- 主按钮使用 `type="primary"`。
- 只有当前操作区域最重要的按钮使用主按钮。
- 危险操作必须有确认机制。
- HTML 预览文件必须体现默认、hover、disabled、loading、danger 和 AI 三态按钮样式。
