# 反馈组件规范
## Feedback Component Rules

Keywords: feedback, message, modal, drawer, loading, empty, error

本文定义后台页面中的反馈组件，包括全局提示、通知、警告、弹窗、抽屉、加载、空状态和异常页。

## 1. 基础规则

- 所有用户操作都应有可感知反馈。
- 异步操作必须展示 loading。
- 成功、失败、异常应有明确提示。
- 空状态不能只留白，应说明原因并提供下一步动作。
- 高风险操作必须使用确认弹窗或二次确认。

## 2. 弹窗与抽屉

弹窗用于阻断性确认、短表单和高风险操作。抽屉用于不离开当前页面查看详情、编辑辅助信息或配置筛选条件。

## 3. 空状态与异常

空状态应包含标题、说明和可选操作。异常页用于无权限、网络不可用、系统维护、加载失败、404、500 等场景，应包含标题、说明和建议操作。
