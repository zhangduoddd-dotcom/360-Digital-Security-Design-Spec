# 图标 Icon 规范
## Icon Rules

Keywords: icon, iconfont, glyph, semantic consistency, backend components

本文定义后台产品中的图标使用规则。AI 生成页面、HTML 可演示页面、Vue 代码或设计稿时，遇到 icon 应优先遵循本文。

## 1. 默认图标来源

设计和页面生成中遇到 icon 时，优先引用以下 iconfont 项目中的图标。

```css
/* 在线链接服务仅供平台体验和调试使用，平台不承诺服务的稳定性，企业客户需下载字体包自行发布使用并做好备份。 */
@font-face {
  font-family: 'font_family';  /* Project id 3024647 */
  src: url('//at.alicdn.com/t/c/font_3024647_emhbagh91hg.woff2?t=1743044666433') format('woff2'),
       url('//at.alicdn.com/t/c/font_3024647_emhbagh91hg.woff?t=1743044666433') format('woff'),
       url('//at.alicdn.com/t/c/font_3024647_emhbagh91hg.ttf?t=1743044666433') format('truetype');
}
```

## 2. 使用原则

- 相同语义、相同动作、相同状态必须使用同一个 icon。
- 不同页面中同一含义的 icon 不得随意更换。
- icon 仅作为辅助识别，不能替代文字说明。
- 关键操作按钮不建议只使用 icon，除非空间有限且语义非常明确。
- 图标语义不清时，必须配合 Tooltip 或文字说明。
- 右侧全局配置区、表格工具区等低频辅助操作可使用纯 icon 按钮，但 hover 时必须显示具体操作名称。

## 3. 语义一致性规则

| 含义类型 | 规则 |
|---|---|
| 新建 / 添加 | 全站统一使用同一个新增类 icon |
| 编辑 | 全站统一使用同一个编辑类 icon |
| 删除 | 全站统一使用同一个删除类 icon，且必须配合风险确认 |
| 导入 / 上传 | 区分导入数据与上传文件，但同类语义内部保持一致 |
| 导出 / 下载 | 区分导出数据与下载文件，但同类语义内部保持一致 |
| 刷新 | 全站统一使用刷新类 icon |
| 配置 | 全站统一使用设置 / 齿轮类 icon |
| 筛选 | 全站统一使用筛选类 icon |
| 搜索 | 全站统一使用搜索类 icon |
| 告警 / 风险 | 按语义色和等级规范配合使用，不只依赖图标表达 |
| AI 能力 | AI 生成、AI 分析、智能推荐等能力入口应使用统一 AI 类 icon 或 AI 渐变按钮风格 |

## 4. 样式规则

- 图标默认尺寸建议为 16px。
- 表格行操作、工具栏紧凑按钮可使用 14px 或 16px。
- 页面级入口、卡片入口可使用 18px 或 20px。
- 图标颜色默认使用 `#8A9099`。
- hover 状态可使用品牌主色 `p6 #00AB7A` 或正文主色，按组件语义决定。
- 禁用状态使用灰阶，不可点击。
- 风险操作图标可使用错误色，但必须同时保留文字或确认机制。

## 5. 代码生成要求

### 5.1 HTML 可演示页面

生成 HTML 可演示页面时，可以通过 `@font-face` 引入上述 iconfont 在线链接用于体验和调试。

要求：

- 保留 `font-family: 'font_family'`。
- icon 类名或字符映射应在页面中集中管理。
- 不要在页面中混用多套来源不明的 icon。
- 同一语义的 icon 在同一页面和跨页面中保持一致。

### 5.2 Vue / 工程代码

生成 Vue 工程代码时：

- 如果项目已接入该 iconfont，应优先复用项目内 icon 组件或字体文件。
- 不建议在企业生产环境直接依赖在线 iconfont 链接。
- 企业客户需下载字体包自行发布使用并做好备份。
- 如果使用 Ant Design Vue 自带 icon，必须保证与本规范的语义一致性，不得同义混用。

## 6. 禁止项

- 禁止同一个含义在不同页面使用不同 icon。
- 禁止只靠 icon 表达关键操作。
- 禁止删除、停用、覆盖等风险操作只显示 icon 而没有文字、Tooltip 或确认机制。
- 禁止在同一页面混用多套风格差异明显的 icon。
- 禁止把线上 iconfont 链接作为企业生产环境唯一依赖。
