Keywords: component size, component state, control height, radius, acceptance, backend

## 2. 尺寸使用原则

- 常规 B 端表单控件默认使用 32px 高度。
- 紧凑筛选区、表格行内编辑、工具栏轻量操作可使用 24px 高度。
- 低密度表单、重点输入和引导型页面可使用 40px 高度。
- 小 / 中 / 大控件圆角分别对应 4 / 6 / 8px，不随意新增圆角值。
- 常规表单控件使用 14px / 22px；紧凑控件使用 12px / 20px；大尺寸控件使用 16px / 28px。

## 3. 组件状态基线

所有交互组件至少包含：

```text
默认、hover、激活 / 按下、禁用
```

补充状态：

- 输入类组件必须包含输入完成和失败状态。
- 选择器类组件必须包含选中、禁用、加载、无数据状态。
- 多选类组件必须包含半选 / 部分选中状态。
- 上传类组件必须包含上传中、暂停、完成、失败、格式错误、文件大小错误状态。
- AI 按钮必须包含默认、悬停、按下和 loading 状态。

## 4. 组件使用验收清单

| 检查项 | 必须满足的标准 |
|---|---|
| 尺寸 | 输入、选择、按钮等基础控件是否优先使用 24 / 32 / 40px 三档高度 |
| 字体 | 常规表单控件是否使用 14px / 22px；紧凑控件是否使用 12px / 20px |
| 圆角 | 小 / 中 / 大控件是否对应 4 / 6 / 8px，不随意新增圆角值 |
| 状态 | 每个交互控件是否至少包含默认、hover、激活 / 按下、禁用；输入类是否适配失败和输入完成 |
| 错误提示 | 失败态是否有明确错误文案，而不仅仅是红色边框 |
| 选择器 | Select / Cascader / TreeSelect 是否包含面板、选项 hover、选中、禁用、加载等状态 |
| 日期时间 | DatePicker / TimePicker 是否包含区间、清空悬浮、禁用、聚焦、输入中等状态 |
| 上传 | 上传组件是否适配上传中、暂停、完成、失败、拖拽、格式错误和文件大小错误 |
| 多选半选 | Checkbox 和 TreeSelect 是否包含半选 / 部分选中状态 |
| 弹窗 | 上传 / 导入对话框是否使用 560px 作为默认宽度，并与全局弹窗规范一致 |
| 投影 | 卡片只用一级投影；抽屉、弹窗、遮罩浮层使用二级投影 |

## 5. Vue / HTML 生成要求

- Vue 代码生成时，组件尺寸、字号、圆角、状态必须与本文一致。
- HTML 预览文件需要模拟主要组件状态，不能只展示默认态。
- 生成高保真页面时，应优先从本文选择尺寸档位，不要随机设定控件高度。
- 前端验收时，应将本文作为组件尺寸和状态的第一检查入口。
