# 表单组件规范
## Form Component Rules

Keywords: form, input, validation, select, date picker, backend

本文定义后台页面中的表单、输入、选择、开关、日期、上传等数据录入组件规则。

## 1. 表单规则

- 表单字段应按业务含义分组。
- 必填项必须有统一标识。
- 错误提示必须说明错误原因和修正方式。
- 长表单应使用分组、步骤、锚点或折叠结构。
- 提交操作必须包含 loading 和结果反馈。

## 2. 输入框

默认 placeholder 使用“请输入”。有格式要求时写明示例。长文本框右下角可显示字数。错误状态必须显示错误文案。

## 3. 选择控件

Select 用于选项较多的场景。选项少于 5 个时，优先考虑 Radio 或 Checkbox。树选择适用于组织、分类、地区等树形结构，节点过多时必须支持搜索。

## 4. 开关与上传

Switch 表示开启 / 关闭，切换后通常立即生效。高风险开关切换前应二次确认。上传必须明确文件类型、大小限制、上传进度和失败原因。

## 5. 代码生成要求

Vue 代码使用 `a-form`、`a-form-item` 及对应控件。必须包含类型定义、表单校验、提交 loading、成功 / 失败反馈。HTML 预览文件应支持字段输入、校验失败、提交 loading 和成功提示。
