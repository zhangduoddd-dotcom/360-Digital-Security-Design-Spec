# 数据录入组件规范
## Data Entry Component Rules

Keywords: form, input, validation, select, date picker, upload, data entry, backend

本文定义后台页面中的表单、输入框、选择器、单选、多选、开关、日期时间、级联、树选择、穿梭框和上传组件规则。AI 生成页面、Vue 代码或 HTML 预览文件时，必须遵循本文。

## 1. 表单

### 1.1 使用场景

- 创建、编辑、配置、审批、提交数据。
- 由输入框、选择器、单选框、多选框等控件组成。
- 需要收集、校验、提交数据。

### 1.2 表单标签规则

| 项目 | 规范 |
|---|---|
| 标签长度 | 建议单行，不超过 10 个中文字符 |
| 标签表达 | 简洁、准确、业务可理解 |
| 必填项 | 使用统一必填标识 |
| 非必填项 | 不建议大量标注“选填”，避免视觉噪音 |
| 帮助说明 | 放在标签旁或输入框下方 |
| 错误说明 | 紧贴出错控件展示 |

### 1.3 表单布局

| 类型 | 使用场景 |
|---|---|
| 单列表单 | 简单创建、编辑 |
| 多列表单 | 字段较多但信息结构清晰 |
| 分组表单 | 字段多且有明显类别 |
| 分步表单 | 流程长、需要逐步确认 |
| 抽屉表单 | 在不离开当前页面的情况下完成附加编辑 |
| 弹窗表单 | 轻量创建或确认，不适合复杂录入 |

## 2. 基础输入框 `input-basic`

### 2.1 尺寸

| 尺寸 | 高度 | 常见宽度 | 字号 / 行高 | 圆角 | 使用场景 |
|---|---:|---:|---|---:|---|
| 小 | 24px | 200px | 12px / 20px | 4px | 表格筛选、紧凑工具栏、行内编辑 |
| 中 | 32px | 200px | 14px / 22px | 6px | 常规表单、搜索、筛选 |
| 大 | 40px | 200px | 16px / 28px | 8px | 重点输入、引导页、低密度表单 |

中号输入框是 B 端表单默认规格，高度为 32px，内边距常见为 5px 12px。

### 2.2 状态

输入框状态统一为：默认、悬停、激活、禁用、输入完成、失败。失败状态必须配合错误文案，不要只改变边框颜色。

### 2.3 占位文案

- 默认使用“请输入”。
- 需要具体说明时使用“请输入 XX”。
- 有格式要求时写明示例，例如“请输入邮箱地址”。
- 有字数限制时可提示“不超过 18 个字符”。

### 2.4 组合能力

输入框支持纯文字输入、前置标签、后置标签、前置图标、后置图标、字数统计，例如 `0/10`。

## 3. 文本域 `input-textarea`

文本域常见默认尺寸为 200 × 100px；启用字数控制时常见尺寸为 200 × 122px。

| 状态 | 规则 |
|---|---|
| 默认 | 显示占位文案“请输入...” |
| 悬停 | 边框或背景轻微反馈 |
| 激活 | 使用主色边框或 focus ring |
| 输入完成 | 显示输入内容，必要时保留字数统计 |
| 失败 | 显示错误边框和错误说明 |
| 禁用 | 文本与边框进入禁用灰阶 |

补充规则：

- 右下角显示字数限制与当前字数，例如 `0/100`。
- 超出字数限制时应阻止继续输入或明确提示。
- 内容超过默认高度时可出现滚动条。
- 可拖拽改变高度时需要限制最大高度。
- 文本域滚动条宽度示例为 4px，应使用弱视觉灰阶。

## 4. 数字输入框 `inputnumber`

数字输入框宽度常见为 200px，三档高度为 24 / 32 / 40px。

必须包含状态：默认、hover、键入、输入中、输入完成、报错、禁用、悬浮增减图标。

规则：

- 数字输入框不是普通输入框的简单替代。
- 必须包含数值范围、增减控制、错误提示和禁用态。
- 超出范围应提示或自动修正为边界值。

典型提示文案：

```text
0-100
请输入0-100之间的数值
```

## 5. IPv4 输入框 `input-ipv4`

IPv4 输入框是专用输入组件，默认尺寸为 188 × 32px。出现格式错误时，组件高度可扩展到约 52px，用于承载错误提示。

输入结构按四段 IP 地址组织：

```text
0 . 0 . 0 . 0
192 . 168 . 1 . 1
```

校验规则：每段只允许 0–255 的正整数。

错误提示：

```text
格式错误，请输入0-255的正整数
```

## 6. Select 选择器 `select`

### 6.1 使用场景

- 弹出下拉菜单供用户选择。
- 选项较多，不适合平铺展示。
- 支持单选、多选、搜索。

### 6.2 尺寸

| 尺寸 | 高度 | 常见宽度 | 使用场景 |
|---|---:|---:|---|
| 小 | 24px | 200px | 紧凑筛选、表格内筛选 |
| 中 | 32px | 200px | 常规表单选择器 |
| 大 | 40px | 200px | 低密度表单、引导式配置 |

### 6.3 状态

Select 必须支持：默认、hover、激活-未选下拉、激活-选中、选择完成、选择后 hover、鼠标再次悬浮、悬浮删除图标、选项加载中、禁用、多选-选择、多选-选择完成、多选-禁用、级联-选择完成。

下拉选项需要区分：默认、悬浮、选中、禁用、加载中。选项文字默认 14px / 22px。

### 6.4 规则

- 选项少于 5 个时，优先考虑 Radio 或 Checkbox。
- 单选可支持搜索。
- 多选应支持标签展示和清除。
- 无结果时展示“暂无数据”。
- 加载时展示“加载中”。

## 7. 单选与多选

### 7.1 胶囊单选 `radio-btn`

胶囊单选适合筛选条件、模式切换、周期切换、视图切换。单项标准尺寸为 74 × 32px，内边距为 5px 16px，文字为 14px / 22px。

| 方位 | 圆角规则 |
|---|---|
| 左 | 左上、左下圆角 6px；右侧为直角 |
| 中 | 左右均为直角 |
| 右 | 右上、右下圆角 6px；左侧为直角 |

状态必须包含：默认、hover、选中、未选禁用、已选禁用。

### 7.2 基础单选 `radio`

基础单选适合表单中二选一或少量互斥选项。常见选项高度为 22px，文字为 14px / 22px。

规则：

- 横向排列间距建议 24px。
- 纵向排列间距建议 12px。
- 如果选项超过 5 个，建议改用 Select。

### 7.3 多选框 `checkbox-basic`

基础多选框控件尺寸为 16 × 16px，控件圆角为 4px。

必须包含状态：默认、悬浮、选中、半选、未选失效、已选失效、半选失效。

多选项组文字高度为 22px，文字为 14px / 22px。在树选择、权限配置、批量选择场景中，半选状态不能省略。

### 7.4 Checkbox 与 Switch 区别

| 组件 | 区别 |
|---|---|
| Checkbox | 通常作为状态标记，需要配合提交按钮生效 |
| Switch | 切换后立即生效 |

## 8. 开关 Switch

Switch 用于表示开启 / 关闭，两种互斥状态之间切换，用户选择后系统立即执行。

规则：

- 适合简单、直观的状态切换。
- 对高风险开关，切换前应二次确认。
- 切换后必须反馈结果。
- 禁用态需要说明原因。

## 9. 级联选择与树选择

### 9.1 Cascader 级联选择器 `cascader`

适合选择具有父子层级的数据，例如地区、组织、权限分类、业务对象分类。

| 层级 | 面板尺寸 |
|---|---|
| 一级 | 120 × 160px |
| 二级 | 240 × 160px |
| 三级 | 360 × 160px |

规则：

- 支持单选与多选。
- 每一级选项文字为 14px / 22px。
- 面板圆角为 6px。
- 支持搜索时应提示匹配路径。
- 如果只选择最终节点，应避免误选中间层。
- 层级过深时建议改为树选择。

### 9.2 TreeSelect 树选择 `treeselect`

| 样式 | 面板尺寸 | 使用场景 |
|---|---|---|
| 基本样式 | 约 267 × 232px | 单选层级对象 |
| 多选框样式 | 约 239 × 232px | 权限、组织、分类多选 |

规则：

- 建议最多 4 级。
- 支持单选和多选。
- 多选时应明确父子节点联动关系。
- 节点过多时必须支持搜索。
- 节点状态至少包含：父级默认、父级禁用、子级默认、子级悬浮、子级选中、子级禁用、三级子级。
- 展开图标尺寸示例为 12 × 12px。

## 10. 日期与时间选择器

### 10.1 DatePicker 日期选择器 `datepicker-basic`

| 类型 | 常见尺寸 | 说明 |
|---|---|---|
| 单日期中号 | 240 × 32px | 默认表单日期选择 |
| 日期区间中号 | 400 × 32px | 开始日期 + 结束日期 |
| 大号日期输入 | 高度 40px | 低密度表单或重点输入 |
| 小号日期输入 | 高度 24px | 紧凑筛选区 |

状态分为：

1. 填写状态：未填写完成、已填写完成。
2. 交互状态：默认、悬停、聚焦、输入中、禁用、悬停清空图标。

日期格常见 24 × 24px，面板标题行常见 280 × 40px。日期下拉面板支持日、月、年、日+时、日-双月、双月+时间范围等结构；常见面板宽度为 280px、560px、657px。

设计原则：

- 标识当天日期。
- 明确选中日期或范围。
- 必要时标注周末、节假日或特殊日期。
- 支持键盘输入时必须容错。
- 日期范围应明确开始和结束。

### 10.2 TimePicker 时间选择器 `timepicker`

| 类型 | 常见尺寸 |
|---|---|
| 单时间中号 | 240 × 32px |
| 时间区间大号 | 320 × 40px |
| 小号时间输入 | 高度 24px |

时间下拉面板常见尺寸：

| 面板类型 | 尺寸 |
|---|---|
| 单列 | 112 × 248px |
| 双列 / 复合列 | 168 × 248px |
| 区间或多列 | 340 × 248px |

规则：

- 时间格式必须统一。
- 禁用不可选时间。
- 错误格式需要即时提示。
- 默认值应符合业务场景。
- 时间选项需要支持悬停、选中、禁用与滚动。

## 11. 穿梭框 Transfer

使用场景：在两栏之间移动元素，需要从候选集合中选择一个或多个对象。

规则：

- 左侧为来源 Source。
- 右侧为目标 Target。
- 支持搜索。
- 支持已选数量展示。
- 移动按钮必须有禁用态。

## 12. 上传组件

### 12.1 文件上传 `upload-basic`

支持点击上传、上传过程、上传中、暂停、上传完成、上传失败六类状态。

| 状态 | 尺寸 / 表现 |
|---|---|
| 点击上传 | 常见 306 × 40px，通常由按钮和说明组成 |
| 上传中 / 暂停 / 完成 | 保留文件名、进度、状态图标或操作按钮 |
| 上传失败 | 显示失败原因，例如“上传失败！失败原因xxx” |
| 上传过程 | 可扩展为更高容器，用于显示多个文件进度 |

说明文案示例：

```text
支持扩展名：.rar .zip .doc .docx .pdf .jpg...
```

### 12.2 图片上传 `upload-image`

图片上传基础格尺寸为 80 × 80px，圆角为 8px。适合头像、封面、素材图、证件图等上传场景。

必须包含状态：默认、hover、上传中、上传成功、上传失败、上传成功后鼠标悬浮、上传失败后鼠标悬浮。

说明文案示例：

```text
建议尺寸 900*400，最多 9 张，单个图片不超过 20M。
```

### 12.3 拖拽上传 `upload-drag`

拖拽上传默认尺寸为 384 × 194px，带上传文件列表时可扩展到 384 × 346px。圆角为 8px。

状态包含：默认、hover、禁用、上传文件。

主文案示例：

```text
点击或将文件拖拽到这里上传
```

### 12.4 上传 / 导入对话框 `upload-dialog-group`

上传对话框以 560px 宽为主要规格，与全局弹窗标准宽度一致。高度根据内容变化，常见为 346 / 372 / 384 / 399 / 400px。

必须包含状态：默认、拖拽、上传中、上传成功、上传成功 hover、导入失败、格式错误、文件大小不符合导入失败。

常见文案：

```text
单次仅支持上传 1 个文件，支持文件格式：Excel、CSV
下载模版
请下载模版完成填写后上传
上传文件格式错误！
上传失败！文件大小不超过x
导入中
已完成进度 4   65%
文件总数: 4   已上传: 1   上传中: 1   暂停: 1   上传失败: 1
```

## 13. Vue / HTML 生成要求

- Vue 代码使用 Ant Design Vue 表单与录入控件。
- 必须包含类型定义、表单校验、提交 loading、成功 / 失败反馈。
- HTML 预览文件应支持字段输入、校验失败、提交 loading 和成功提示。
- 涉及上传时必须模拟上传中、上传成功、上传失败。
- 涉及选择器时必须模拟下拉面板、选中、禁用、无数据、加载中。
